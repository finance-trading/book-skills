# 案例候选 (Cases)

- id: c01
  title: 约翰和马克的量化交易公司
  type: case
  source_chapter: 第1章
  source_quote: |
    "约翰是一个中等规模对冲基金的量化交易员。他的合伙人马克坂负责高频交易。约翰的策略在60%的交易日和85%的交易月里均获得收益。马克的高频交易策略已经在几乎95%的时间里获利。"
  summary: |
    约翰和马克代表了量化交易的两种典型模式：
    - 约翰：中等频率、相对稳定的策略
    - 马克：高频交易、更高胜率的策略
    两者结合展示了量化交易的多样性。
  bound_to:
    - "量化交易的多样性"
    - "高频交易 vs 中低频交易"
  outcome: |
    约翰的策略在60%交易日和85%交易月获利；马克的高频策略在95%的时间获利。
  tags: [case, quant-trading, HFT]

    - "量化策略的长期优势"
    - "危机中的表现"

- id: c03
  title: 长期资本管理公司（LTCM）的失败
  type: case
  source_chapter: 第1章、第10章
  source_quote: |
    "迄今为止最著名的案例当属长期资本管理公司(LTCM)。曾经在4年时间里，扣除各种费用之后，每年平均获得30%回报率的长期资本管理公司，于1998年8-10月，清算了自己几乎100%的资产。"
  summary: |

  bound_to:
    - "模型风险 + 极端事件"
    - "杠杆控制 + 风险管理"
    - "流动性风险"
    - "蔓延风险"
  outcome: |
    1998年8-10月清算几乎100%资产，需要美联储救助。
  tags: [case, failure, LTCM, leverage, model-risk]

- id: c04
  title: 2007年8月量化危机（Quant Quake）
  type: case
  source_chapter: 第10章
  source_quote: |
    "2007年8月，宽客面对的危机的4个主要驱动力是：①拥挤交易效应；②策略年初以来表现欠佳；③交叉所有权；④波动率下降导致杠杆增加。"
  summary: |
    2007年8月量化危机是量化历史上最严重的危机之一：
    - 高盛全球阿尔法基金估计损失40%
    - 许多量化基金在几天内损失10%-40%
    - 四个驱动力：拥挤交易、表现欠佳、交叉所有权、杠杆增加
    - 说明了系统性风险和蔓延风险
  bound_to:
    - "拥挤交易风险"
    - "流动性风险"
    - "杠杆风险"
    - "蔓延风险"
  outcome: |
    高盛全球阿尔法基金2007年估计损失40%，许多量化基金损失10%-40%。
  tags: [case, quant-quake, 2007-August, systemic-risk]

    - "统计套利风险"

    - "蔓延风险"
  outcome: |
