## R 原文

> "全景式量化交易策略可以分成五类：基本面量化交易策略、资产配置量化交易策略、阿尔法量化交易策略、贝塔量化交易策略和另类量化交易策略。它们之间既有相同点，也有不同之处，并都有各自的代表人物。"（第1.4节）

## I 方法论骨架

所有量化交易策略按"优势来源"可分为五类，而非简单的"数量多少"。

- **基本面量化**（代表：巴菲特）：在财务数据和业绩反转中寻找价值低估，深度但覆盖面窄，适合中等规模资金。
- **资产配置量化**（代表：达利欧）：不预测方向，通过风险平衡跨越牛熊周期，适合超大规模资金。
- **阿尔法量化**（代表：西蒙斯）：挖掘隐藏的统计因子获取超额收益，技术要求最高，因子会随竞争者增加而失效。
- **贝塔量化**（代表：斯坦利·克罗）：追踪价格趋势，方法古老但有效，可以被应用到股票和大宗商品。
- **另类量化**（代表：索罗斯）：利用人性弱点、事件驱动、卫星数据等非常规信号，难以复制，风险极高。

决策变量不是"哪类最好"，而是哪类与投资者的**资金规模、认知优势、人生观**最匹配。框架的底层提示是：广义量化包含一切可建模的理性方法；"所有的阿尔法都是贝塔"——优势终将被套利掉。

1. **基本面类**：A股行业基本面景气增强量化策略——2022年4月26日新入选大气治理、科技、建材行业，过去6个月累计跑赢沪深300超50%（图1.1）。

## A2 触发场景

1. 量化新手问"我该从哪种策略入手" — 先用此框架定位类型，再选具体工具
   触发词：`量化入门 / where to start in quant / 策略方向`
2. 资金规模从散户升级到机构级别 — 评估是否需要从阿尔法/贝塔切换到资产配置
   触发词：`规模化 / scale up / 大资金 / large capital`
3. 策略持续回撤，需要重新审视定位 — 检查策略类型与资金/风险偏好是否匹配
   触发词：`回撤太大 / drawdown / 策略失效`
4. 构建多策略组合时 — 跨类别选择以降低相关性
   触发词：`策略组合 / multi-strategy / 分散`
5. 评估研究报告或竞品策略 — 快速归类以理解其优势和局限
   触发词：`这个策略属于什么类型 / classify this strategy`

## E 可执行步骤

1. **判断资金规模**：< 百万 → 贝塔或另类；百万到千万 → 阿尔法或基本面；亿级以上 → 资产配置优先。
   完成标准：输出明确的规模档位判断。

2. **评估认知优势**：擅长财务分析 → 基本面量化；擅长数据挖掘/统计 → 阿尔法；擅长宏观判断 → 资产配置；擅长技术图表 → 贝塔；擅长事件解读 → 另类。
   完成标准：识别出1-2个最强的认知优势维度。

3. **确认风险承受力**：追求穿越牛熊的稳健 → 资产配置；接受中等波动追求超额 → 阿尔法/基本面；可接受高波动 → 贝塔/另类。
   完成标准：候选类型缩窄到1个。

4. **查找该类别的具体可量化方法**：基本面 → 巴菲特四指标/格雷厄姆因子；资产配置 → 全天候四象限/风险平价；阿尔法 → Alpha101因子体系；贝塔 → RSRS/PTSS择时；另类 → 事件驱动因子。
   完成标准：找到该类别对应的具体可回测框架。

5. **回测验证匹配性**：用历史数据验证所选策略类型在目标市场的表现。
   完成标准：夏普比率 > 0.5，最大回撤在预定容忍范围内，样本覆盖至少一个完整牛熊周期。

## B 边界

**不适用场景**：
- 已进入具体策略执行阶段（此时需要执行框架，不是分类框架）
- 需要快速交易决策（此框架是战略层，非战术层）
- 市场处于极端异常状态（五类策略均面临系统性风险）

**作者警示的失败模式**：
- 用阿尔法策略框架管理超大规模资金——因子因资金规模自身的市场冲击而失效
- 用贝塔/另类策略框架管理长期养老资金——趋势反转时回撤无法承受
- 把"量化"等同于"对冲/阿尔法"，忽略基本面量化和资产配置两大类——错失与自身能力最匹配的方向

**盲点**：
- 五类之间边界模糊（同一策略可能兼跨两类）
- 框架不提供何时从一类迁移到另一类的触发机制
- 另类策略的"另类"程度因人而异，可复制性和可量化性最弱
