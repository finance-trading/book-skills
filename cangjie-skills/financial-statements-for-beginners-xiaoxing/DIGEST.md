# 《一本书读懂财报》精华 — 可执行版

## 一、先把企业看成现金循环
企业的活动可以归为经营、投资、融资。读财报时先问现金从哪里来、经过哪些资源和交易、是否回到企业；再看三类活动是否互相匹配。融资现金流掩盖不了经营现金长期为负，投资扩张也必须有回款节奏。

## 二、三张报表要联读
资产负债表是时点快照，利润表是期间录像，现金流量表解释现金变化。收入不等于收款，费用不等于付款。净利润与经营现金流的差额，通常要从应收、存货、折旧、应付和预收等科目寻找原因。

## 三、利润质量取决于现金和库存
销售增长如果只变成应收账款，利润还没有变成钱；毛利上升如果伴随增产不增销，可能只是固定成本留在库存。把成本从投入、存货到营业成本的路径画出来，才能判断利润是否可持续。

## 四、比率只能成组、匹配时间使用
同型分析把绝对额转成结构比例；周转率要用平均资产匹配期间收入；短期偿债应剔除难以及时变现的存货；长期偿债不能假设靠变卖长期资产解决。单一阈值不能替代行业和趋势比较。

## 五、八类现金流组合不是简单的好坏排序
按经营、投资、融资现金流的正负，可得八类：`+++` 为融资准备投资的成熟企业，先查融资用途；`++-` 是经营造血、投资有收益、还债或分红的健康成熟状态；`+-+` 是扩张型企业，风险在投资规模、节奏与回收期；`+--` 依赖经营现金覆盖投资和还债，重点看净现金缓冲。

经营现金为负的四类更需穿透：`-++` 要区分可持续分红与卖资产/金融收益；`-+-` 是变卖资产同时还债，压力极高；`--+` 对初创公司可以正常，但对衰退公司可能是艰难转型；`---` 三路都流出，不能长期维持。现金流符号只给出排查起点，不能直接替代商业模式、订单质量和融资可得性判断。

## 六、从行业、战略、执行解释结果
同一行业的公司表现不同，先看竞争结构，再看成本领先或差异化战略，最后看执行是否把选择落地。不要把所有问题都归因于行业，也不要用一次成功掩盖战略与执行的错配。

## 七、增长必须覆盖资本成本
净利润为正不代表创造价值。比较 ROIC 与 WACC：只有回报持续超过资本成本，扩张才是在创造经济利润。借债可以放大回报，也会放大现金压力和违约风险；投资方向正确仍可能因规模过大、速度过快而断裂。

## 八、识别报表包装
异常资产增值、卖出再买回、关联方其他应收款、资产循环和不受交易成本支持的估值，都要回到经济实质和现金闭环核查。研发资本化也必须与成功概率和可验证未来收益相匹配。

## 九、使用本套 skills 的顺序
1. 用 `business-cash-cycle` 和 `three-statement-reconciliation` 建立现金与三表框架。
2. 用 `cash-conversion-working-capital`、`inventory-cost-flow`、`sustainable-profit-quality` 检查盈利质量。
3. 用 `ratio-time-group-diagnosis` 做可比分析，再用 `cashflow-lifecycle-quadrants` 判断阶段。
4. 用 `industry-strategy-execution`、`roic-wacc-economic-profit` 判断竞争力和价值创造。
5. 发现异常时切换到 `report-packaging-asset-authenticity`、`economic-substance-historical-cost` 或 `rd-capitalization-boundary`。
6. 在借贷和扩张决策中补充 `leverage-risk-return` 与 `investment-scale-pace`。

所有结论都应标注来源、期间和证据强度；缺少数据时写 `Unavailable`，不以猜测补齐。
