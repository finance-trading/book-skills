# 现金流八象限与企业生命周期

## R — 原文 (Reading)

> 现金流量表按经营、投资、融资三项活动，将企业分成8类；不同状态的企业处在不同发展阶段，具有不同风险特性。
>
> — 肖星，控制风险的要诀 · 表18（PDF第233页）

## I — 方法论骨架 (Interpretation)

按“经营、投资、融资”这一固定顺序记录三项现金流正负，得到八种状态；再用企业所处阶段、行业风险和资金来源解释组合，而不是把正数机械地视为好、负数机械地视为坏。

经营现金流是最稳定的造血来源，优先判断它能否覆盖采购、工资和税费。投资与融资现金流则要追问来源、用途与可持续性：处置资产、借入资金和一次性投资收益都可能改善当期符号，却不能自动降低风险。

### 原表指标与八类现金流组合

表18的三个判别指标按固定顺序为：**经营现金流、投资现金流、融资现金流**。`+` 表示该类现金流净流入，`-` 表示净流出；不是“利润、资产、负债”或其他财务比率。

### 八类现金流组合与首要判断

| 类别 | 经营 | 投资 | 融资 | 书中的典型含义 | 首要核查 |
|---|---:|---:|---:|---|---|
| 1 | + | + | + | 成熟企业正在为未来投资筹钱 | 是否有明确投资计划；否则可能囤积闲钱、稀释回报或关联方占用 |
| 2 | + | + | - | 健康成熟企业，经营造血、投资有收益、还债或分红 | 投资流入是否是真实可持续收益，而非偶发处置 |
| 3 | + | - | + | 经营造血且融资支持大额扩张 | 压力测试投资规模、节奏、回收期和资金链 |
| 4 | + | - | - | 只靠经营现金覆盖投资与还债的成熟/扩张企业 | 净现金流是否为负；经营一旦受冲击，是否有足够缓冲 |
| 5 | - | + | + | 初创期通常不应长期如此，更可能是衰退或资产处置 | 投资流入是卖资产、金融收益，还是子公司分红等可持续实业收益 |
| 6 | - | + | - | 一边变卖资产、一边还债 | 资产处置能持续多久；此类组合显示压力极高 |
| 7 | - | - | + | 初创企业常见：经营未造血、持续投入、依赖融资 | 是早期可融资的成长投资，还是衰退企业被迫转型；避免在衰退时盲目扩产 |
| 8 | - | - | - | 三个渠道都在流出现金，接近资金枯竭 | 必须尽快改善经营、出售投资或融资；任何一项都难且有代价，不能长期停留 |

组合只是起点，不是评级。相同的 `- + +` 可能是子公司稳定分红支撑下的暂时经营亏损，也可能是靠卖资产掩盖衰退；两者必须穿透现金来源后才可区分。

## A1 — 书中的应用 (Past Application)

### 案例 1: 非油炸方便面企业扩产过快
- **问题**: 主业销售和回款良好，却因扩大产能导致资金链断裂。
- **方法论的使用**: 对第三类 `+ - +` 企业，比较投资规模和回收期与经营、融资可提供的现金支撑。
- **结论**: 投资方向正确不足以保证安全；投资速度也必须受现金约束。
- **结果**: 企业账户仅余 3000 元并最终破产。

### 案例 2: 房地产企业由第四类滑向第八类
- **问题**: 市场转冷使原本为正的经营现金流变负。
- **方法论的使用**: 从 `+ - -` 变为 `- - -` 后，分别评估降价回款、变卖投资和高成本融资三条自救路径。
- **结论**: 经营现金流是第四类企业的关键脆弱点；资产出售和高息融资都有明显代价。
- **结果**: 市场回暖前，企业可能被迫出售资产或走向破产。

### 案例 3: 融资为正但没有投资计划的成熟企业
- **问题**: 企业经营和投资均有现金流入，却仍大量融资。
- **方法论的使用**: 对第一类 `+ + +` 企业追问融资目的与后续资本配置。
- **结论**: 若无投资计划，闲置融资可能稀释回报，甚至带来关联方资金占用风险。
- **结果**: 不能仅因三个现金流均为正就判定企业健康。

## A2 — 触发场景 (Future Trigger) ★

1. 用户要求解释财报中相互矛盾的指标。
2. 用户说“现金流/利润/库存/杠杆看起来不对”。
3. 用户需要在投资、借贷或扩张前做结构化判断。

语言信号：现金流八象限、初创、成长、成熟、衰退；“为什么净利润和现金流不一致”；“这家公司是在创造价值吗”。

与相邻 skill 的区分：本 skill 聚焦 **现金流八象限与企业生命周期**；若问题核心转为兄弟单元的专门主题，应切换到对应 skill。

## E — 可执行步骤 (Execution)

1. **标记组合**：列出同一期间经营、投资、融资现金流的金额和正负，按表格映射到第 1–8 类。完成标准：说明每个正负号来自何种现金来源/用途，而非只报净现金流。
2. **穿透来源与阶段**：核查经营现金是否可持续，投资流入是否来自处置资产，融资是否有明确用途；再判断初创、成长、成熟、衰退或转型。完成标准：为三类现金流各给出至少一个业务解释；缺证据写 `Unavailable`。
3. **压力测试与行动**：对第 3、4、7、8 类计算现金缓冲、投资回收期和融资可得性；对第 1、5、6 类核查闲置资金、资产出售或偿债压力。完成标准：明确最主要风险、触发条件和下一步核查，不把组合直接等同于买卖结论。

## B — 边界 (Boundary) ★

- 不要仅凭正负号判断企业好坏；必须区分一次性出售资产、金融投资收益、可持续分红与主营造血。
- 第 7 类既可能是正常初创融资，也可能是衰退企业被迫转型；不得忽略市场需求和融资可得性。
- 警惕对应反例：ce14-ce18。若经营转负、投资扩张过快或融资用途不明，应先做穿透核查和压力测试。
- 本方法不能替代审计、法律判断或实时经营数据；历史会计口径可能无法代表未来。
