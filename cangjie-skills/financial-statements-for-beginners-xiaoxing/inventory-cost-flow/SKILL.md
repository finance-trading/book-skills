# 成本流转与库存毛利幻觉

## R — 原文 (Reading)

> 毛利润的提升不一定由业绩提升引起，还有可能是产成品库存增加。如果库存积压的同时毛利润提升，这个毛利润其实不可信。
>
> — 肖星，财务报表的诞生和内在逻辑

## I — 方法论骨架 (Interpretation)

沿着生产成本进入存货、售出后进入营业成本的路径，识别增产不增销造成的利润幻觉。先把问题转换成可核验的报表关系，再用业务背景解释数字。输出应区分事实、推断和待核查证据，并避免把单一指标当作结论。

## A1 — 书中的应用 (Past Application)

- **案例**：c07,c08。作者把业务问题映射到本方法，比较报表项目与现金结果，得出风险或价值判断。

## A2 — 触发场景 (Future Trigger) ★

1. 用户要求解释财报中相互矛盾的指标。
2. 用户说“现金流/利润/库存/杠杆看起来不对”。
3. 用户需要在投资、借贷或扩张前做结构化判断。

语言信号：库存积压、毛利上升、固定成本、增产不增销；“为什么净利润和现金流不一致”；“这家公司是在创造价值吗”。

与相邻 skill 的区分：本 skill 聚焦 **成本流转与库存毛利幻觉**；若问题核心转为兄弟单元的专门主题，应切换到对应 skill。

## E — 可执行步骤 (Execution)

1. **界定对象与期间**：列出涉及的报表、科目、期间和业务动作。完成标准：所有数字都有来源和时间维度。
2. **建立关系并核验**：按本方法计算/勾稽关键关系，检查异常项与反例信号。完成标准：形成一张关系表；若证据不足，标记 `Unavailable`，不补猜。
3. **给出判断与动作**：区分基准、风险、待核查事项，提出可执行的下一步。完成标准：结论能回答用户问题，并说明适用边界。

## B — 边界 (Boundary) ★

- 不要在只有单一指标、没有期间或业务背景时下结论。
- 警惕对应反例：ce08。若出现这些信号，应先做穿透核查或压力测试。
- 本方法不能替代审计、法律判断或实时经营数据；历史会计口径可能无法代表未来。
