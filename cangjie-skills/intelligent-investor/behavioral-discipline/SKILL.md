# 行为纪律框架

## R — 原文 (Reading)

> "投资者最大的敌人就是自己——情绪纪律比分析能力更重要。"
>
> — 本杰明·格雷厄姆, 《聪明的投资者》第8章

> "投资成功并不需要顶级智商、超凡的商业头脑或秘密信息，而是需要一个稳妥的知识体系作为决策的基础，并且有能力控制自己的情绪，使其不会对这种体系造成侵蚀。"
>
> — 本杰明·格雷厄姆, 《聪明的投资者》第4版序言（巴菲特引用）

---

## I — 方法论骨架 (Interpretation)

格雷厄姆的核心洞察是：**投资的最大风险不是市场，而是你自己。**

情绪纪律的重要性超越了分析能力：
- 你可以在分析上犯错，但只要有纪律就能存活。
- 但如果你有完美的分析能力却没有纪律，市场会把你摧毁。

**两个最大的敌人**：
1. **贪婪**：在牛市中追涨，害怕错过机会，忽视安全边际。
2. **恐惧**：在熊市中恐慌卖出，害怕进一步亏损，在市场最低点离场。

**纪律的核心**：
- 有一套**固定的决策系统**（如安全边际框架、50/50资产配置）。
- 在情绪波动时**坚持执行**系统，不因市场先生的情绪而改变。
- 承认自己的局限性：你不是全知全能的，市场不可预测。

**格雷厄姆的解决方案**：
- 机械化的规则（如再平衡）减少情绪干扰。
- 安全边际提供心理缓冲：知道即使判断有误，仍有保护。
- 分散化提供组合保护：即使一只股票出问题，整体仍安全。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1948年公众对股票的态度
- **问题**: 1948年超过90%公众认为股票"像赌博一样不安全"，拒绝购买。
- **方法论的使用**: 格雷厄姆指出，当恐惧主导时，反而是买入的机会。纪律要求你克服恐惧，在市场恐慌时买入。
- **结论**: 市场情绪是反指，纪律要求你不被情绪左右。
- **结果**: 1948年之后股市迎来史上最大涨幅。

### 案例 2: 1962年卖空事件
- **问题**: 1962年市场大跌，投资者卖空，相信市场会继续下跌。
- **方法论的使用**: 格雷厄姆指出这些人在市场恐慌时跟风，是在最坏时做空——缺乏纪律的投机行为。
- **结论**: 缺乏纪律的投资者在市场情绪最低点时卖出（或做空），是最糟糕的决策。
- **结果**: 市场随后大幅反弹，卖空者亏损。

### 案例 3: 两个合伙人的故事
- **问题**: 两位合伙人面对市场恐慌和狂热。
- **方法论的使用**: 他们严格执行纪律——在恐慌时买入，在狂热时卖出。
- **结论**: 纪律让他们在市场情绪极端时做出正确决策。
- **结果**: 积累了巨额财富。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 市场大跌，用户感到恐慌，想卖出。
2. 市场大涨，用户感到兴奋，想追涨。
3. 用户持有一只股票下跌，感到焦虑，不知道该持有还是卖出。
4. 用户想建立投资纪律，但不知道怎么开始。
5. 用户发现自己总是追涨杀跌，想打破这个循环。

### 语言信号

- "我恐慌了，该不该卖出？"
- "市场大跌，怎么办？"
- "我控制不住追涨。" 
- "如何保持投资纪律？"
- "投资心态怎么调整？"
- "我总是在高点买入，低点卖出，怎么破？"
- "I'm panicking, should I sell?"（英文）

### 与相邻 skill 的区分

- 与 `mr-market` 的区别：市场先生是认知框架（理解市场的非理性），行为纪律是行动规则（控制自己的情绪）。
- 与 `investment-vs-speculation` 的区别：分类框架决定"做什么"，行为纪律决定"怎么做"。

## E — 可执行步骤 (Execution)

1. **识别情绪状态**
   - 帮助用户识别当前的情绪：恐慌、贪婪、焦虑、平静？
   - 问："你现在的感受是什么？是因为市场波动，还是因为具体事件？"
   - 完成标准：用户能清楚地描述自己的情绪状态。

2. **检查决策系统**
   - 用户是否有一套既定的决策系统（如估值公式、选股清单、资产配置规则）？
   - 如果没有 → 建议先建立系统（可使用其他 skill）。
   - 如果有 → 检查当前决策是否符合系统规则。
   - 完成标准：明确用户是否有系统，以及当前决策是否偏离系统。

3. **执行系统 vs 情绪**
   - 如果当前决策 **符合** 系统规则 → 执行系统，忽略情绪。
   - 如果当前决策 **偏离** 系统规则 → 暂停，重新评估。
   - 完成标准：给出明确的行动建议（执行或暂停）。

4. **情绪缓冲**
   - 建议用户：在极端情绪下，延迟决策24-48小时。
   - 写下来：你的决策理由、预期结果、最大亏损容忍度。
   - 完成标准：用户确认采取了情绪缓冲措施。

5. **回顾与学习**
   - 建议用户定期回顾（每季度）自己的情绪决策记录。
   - 找出哪些情绪导致了错误决策，并总结经验。
   - 完成标准：用户设定了回顾计划。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户面临紧急财务危机（如需要支付账单）——这是财务规划问题，不是情绪纪律问题。
- 用户已经建立了系统并严格执行——不需要额外的纪律提醒。
- 用户问的是纯粹的分析问题（如"怎么估值"）——应使用其他 skill。

### 作者在书中警告的失败模式

- **过度自信**: 在牛市连续盈利后，认为自己已经"看透"市场，从而放弃纪律。
- **恐惧驱动**: 在熊市中恐慌卖出，确认亏损，然后错过反弹。
- **贪婪驱动**: 在牛市中追涨，忽视安全边际，买入价格过高的股票。
- **锚定效应**: 固守买入价，拒绝在合理价位卖出（或拒绝止损）。

### 作者的盲点 / 时代局限

- **现代行为金融学**: 格雷厄姆没有现代的认知偏差框架，但他的直觉被后来的研究证实。
- **社交媒体**: 社交媒体放大了情绪传染，纪律更难执行。
- **高频交易**: 现代市场波动更大，纪律更需要机械执行。

### 容易混淆的邻近方法论

- 市场先生（理解市场情绪 vs 控制个人情绪）
- 安全边际（价格保护 vs 心理保护）
