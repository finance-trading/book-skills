# 防御型投资者的资产配置框架

## R — 原文 (Reading)

> "我们建议投资者将其资金分配于高等级债券和蓝筹股上；其中，债券所占的比例不低于25%，也不高过75%，而股票的比例则与之相适应。最简单的选择则是，两者各占一半，并根据市场情况的变化进行小幅（比如5%左右）的调整。"
>
> — 本杰明·格雷厄姆, 《聪明的投资者》第4章

---

## I — 方法论骨架 (Interpretation)

格雷厄姆为防御型投资者（不想花太多时间精力的人）提供了一个极简但有效的资产配置框架：

**核心规则**: 将资金平均分配（50/50）于高等级债券和优质股票。

**调整范围**: 当市场估值过高时，可将股票降至25%（债券75%）；当市场估值过低时，可将股票升至75%（债券25%）。

**再平衡机制**: 当股票比例因市场波动超出目标（如从50%涨到55%），卖出超出部分转投债券，恢复平衡。反之亦然。

这个框架的精髓在于它的**机械性**——它不依赖市场预测，不需要判断顶部和底部，只需要一个简单的规则来自动执行"低买高卖"。

格雷厄姆建议的调整信号是股息率 vs 债券利率的比较：当股票股息率达到债券利率的2/3时，可以考虑增持股票。

## A1 — 书中的应用 (Past Application)

### 案例 1: 耶鲁大学的公式投资法
- **问题**: 1937年之后，耶鲁大学一直遵循类似的对半开规则，但其"正常持仓"是35%股票。
- **方法论的使用**: 耶鲁的规则与格雷厄姆的50/50框架本质相同——基于预定规则而非市场预测进行调整。
- **结论**: 这种机械性规则曾经是标准方法，后来被放弃（1969年耶鲁股占比达61%）。
- **结果**: 格雷厄姆认为耶鲁放弃规则是市场情绪驱动的结果，而非证明规则无效。

### 案例 2: 1964-1971年债券利率变化
- **问题**: 1964年高等级债券利率4.5%，到1972年达7.5%。债券价格大跌。
- **方法论的使用**: 格雷厄姆指出，即使债券也会波动——但50/50框架通过分散化降低了整体风险。
- **结论**: 对半开规则不追求最优，但确保在牛市和熊市中都有合理的表现。
- **结果**: 持有50/50组合的投资者在1970年市场大跌中损失远小于全仓股票者。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户是投资新手，不知道如何建立自己的第一个投资组合。
2. 用户有一笔储蓄（如年终奖、积蓄）需要配置，但不想花时间研究个股。
3. 用户想知道自己目前的股债配比是否合理。
4. 用户看到市场大涨或大跌，想调整仓位但不知道怎么做。

### 语言信号

- "我是新手，应该怎么配置资产？"
- "股票和债券各买多少合适？"
- "我的投资组合应该怎么分配？"
- "现在市场很高，我该减仓吗？"
- "How should I allocate my portfolio?"（英文）

### 与相邻 skill 的区分

- 与 `investment-vs-speculation` 的区别：这个 skill 解决"怎么配"的问题，前面的 skill 解决"什么能买"的问题。先判断投资资格，再配置资产。
- 与 `diversification` 的区别：这个 skill 解决大类资产配置（股vs债），分散化解决个股/个券的数量和行业分布。

## E — 可执行步骤 (Execution)

1. **确定投资者类型**
   - 询问用户：你愿意花多少时间在投资上？你能承受多大的波动？
   - 完成标准：确认用户属于防御型投资者（不想花太多时间+重视安全）。

2. **确定初始配置比例**
   - 建议起始50%股票/50%债券。如用户年龄较大或风险承受能力低，可调整为40/60。
   - 完成标准：设定一个具体的股债比例目标。

3. **选择具体投资工具**
   - 股票端：推荐宽基指数基金（如标普500ETF、沪深300ETF）
   - 债券端：推荐高等级债券基金或国债
   - 完成标准：用户选定了具体的投资品种。

4. **设定再平衡规则**
   - 规则：每季度或每半年检查一次，当股票比例偏离目标5%以上时，卖出超出部分买入债券（或反之）。
   - 完成标准：用户确认了再平衡频率和阈值。

5. **执行并记录**
   - 按规则执行首次配置，记录目标比例和检查日期。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户是积极型投资者，愿意花大量时间做研究——应推荐积极型策略。
- 用户问的是具体个股选择——应用 defensive-stock-checklist。
- 用户有特殊财务需求（如即将退休、大额支出）——需要调整比例，但框架仍适用。

### 作者在书中警告的失败模式

- **过度自信**: 防御型投资者最容易犯的错误是在牛市中觉得自己"有经验"，放弃规则追涨。
- **择时倾向**: 规则本身是机械的，但执行时容易被情绪左右——在市场恐慌时不敢加仓。
- **忽视通胀**: 债券占比过高时，购买力可能被通胀侵蚀。

### 作者的盲点 / 时代局限

- **零利率时代**: 格雷厄姆时代的债券利率（4-7%）在今天可能不可及。零利率环境下，债券端需要调整策略。
- **指数基金**: 格雷厄姆没有指数基金，今天被动投资已证明优于大多数主动选股。
- **全球配置**: 格雷厄姆仅讨论美国市场，全球化配置可进一步分散风险。

### 容易混淆的邻近方法论

- 分散化（大类资产配置 vs 个股分散）
- 防御型选股（选什么股票 vs 怎么配）
