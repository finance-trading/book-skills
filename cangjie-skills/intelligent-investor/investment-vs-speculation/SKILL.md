# 投资与投机的分界框架

## R — 原文 (Reading)

> "投资操作是经过深入分析、能确保本金安全且获得适当回报的操作。不能满足这些要求的操作就是投机。"
>
> — 本杰明·格雷厄姆, 《聪明的投资者》第1章

> "如果你要投机，请使用独立的账户，资金不得超过总资产的10%，并且从心理上明确这是投机而非投资。"
>
> — 本杰明·格雷厄姆, 《聪明的投资者》第1章

---

## I — 方法论骨架 (Interpretation)

格雷厄姆为"投资"设定了三个严格的必要条件，三者缺一不可：

1. **经过深入分析** — 不是听消息、看K线、跟朋友买、追热点。你要能说清楚：公司的业务是什么、赚钱能力如何、资产负债表是否健康、未来现金流大概是什么水平。

2. **能确保本金安全** — 不是"可能会涨"。本金安全意味着你有充分的理由相信，在合理的时间范围内，你的本金不会遭受永久性损失。这通常来自安全边际（价格远低于价值）。

3. **获得适当回报** — 不是追求暴利。适当回报是合理的、与风险相匹配的收益预期，通常是跑赢通胀+略高于债券收益率的水平。

如果一个操作不满足其中任何一条，它就是投机——而不是投资。

格雷厄姆并不禁止投机，但他坚持：**投机必须是有意识的、受控的、物理隔离的**。用不超过总资产10%的资金、开立独立账户、明确标记为"投机账户"，且永远不要用投资账户的钱来弥补投机亏损。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1962年"小投资者卖空"事件
- **问题**: 1962年6月，一家主流财经报刊刊登头条："小投资者看空后市，他们正在进行小额股票的卖空交易"，并将这些人称为"投资者"。
- **方法论的使用**: 格雷厄姆指出这是滥用"投资者"一词。卖空是纯粹的投机行为——卖空者没有经过对公司的深入分析，本金安全无法保证（卖空亏损理论上无限），且目的不是适当回报而是赌下跌。
- **结论**: 将投机行为称为"投资者"是对公众的误导。那些在1962年卖空的人，实际上是在市场即将大幅上涨前做空——他们是在投机，而不是投资。
- **结果**: 市场随后大幅上涨，卖空者亏损。

### 案例 2: 1948年公众对股票的态度
- **问题**: 1948年，超过90%的被访公众不赞成购买普通股，理由包括"像赌博一样不安全"和"对此不熟悉"。
- **方法论的使用**: 格雷厄姆指出，当公众普遍认为所有股票都是投机时，市场价格反而处于有吸引力的低位——这恰恰是投资的机会。
- **结论**: 市场情绪与投资决策无关。真正的投资决策基于分析和安全边际，而非公众情绪。
- **结果**: 1948年之后股市迎来了史上最大涨幅之一。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户正在考虑购买一只股票或基金，犹豫不决，想知道这是不是"靠谱的投资"。
2. 用户跟风买入了一只热门股，现在想确认自己做的到底是投资还是赌博。
3. 用户想建立投资纪律，但分不清哪些行为是投资、哪些是投机。
4. 用户的朋友/家人/同事推荐了一只股票，用户想知道如何判断。

### 语言信号 (用户的话里出现这些就应激活)

- "我该买这只股票吗？"
- "这算投资还是投机？"
- "朋友推荐了一只股票，说是'内幕消息'。"
- "我追涨买了XX，现在有点慌。"
- "我想开始投资，但不知道怎么判断什么能买。"
- "Is this investing or speculating?"（英文）

### 与相邻 skill 的区分

- 与 `margin-of-safety` 的区别：这个 skill 回答"是什么"（投资还是投机），安全边际回答"买不买"（价格是否足够便宜）。先判断是投资还是投机，再评估安全边际。
- 与 `behavioral-discipline` 的区别：这个 skill 是分类框架，行为纪律是执行时的情绪管理。先分清楚类别，再管理执行中的情绪。

## E — 可执行步骤 (Execution)

当 skill 被激活后，按以下步骤执行：

1. **识别操作类型**
   - 询问用户：你打算买/卖的是什么？你了解它的业务吗？
   - 完成标准：用户能描述出该证券的基本面（公司做什么、赚多少、债务多少）或者承认"我不了解"。

2. **检查投资三条件**
   - 逐一检核：① 你做了哪些分析？信息来源是什么？② 你凭什么认为本金安全？③ 你期望的回报率是多少？这个回报率合理吗？
   - 完成标准：对三个条件都有明确的回答（即使答案是"不满足"）。
   - 判停条件：如果三个条件全部满足 → 进入步骤3；如果有一条或多条不满足 → 跳到步骤4。

3. **确认投资操作，给出纪律建议**
   - 告诉用户：这个操作符合格雷厄姆的投资定义。建议设置安全边际目标和持有期限。
   - 完成标准：输出"这是一笔投资"的结论，并列出下一步行动清单。

4. **确认投机操作，给出隔离建议**
   - 告诉用户：这个操作本质上是投机。不是说你不能做，但必须：
     - 使用独立账户，与投资账户物理隔离
     - 投入资金不超过总资产的10%
     - 清楚意识到这是投机，不是投资
     - 设好止损线
   - 完成标准：用户确认理解了投机隔离规则。

5. **存档决策**
   - 将判断结果（投资/投机）和理由简要记录，供后续回顾使用。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户已经明确说"我要投机"并有独立账户——不需要再判断。
- 用户问的是"哪个基金更好"——这是产品选择，不是分类问题。
- 用户问的是技术分析或短线交易策略——那是投机方法论，不是分类框架。

### 作者在书中警告的失败模式

- **无意识的投机**: 最危险的投机是自以为在投资，实际上在赌博。追涨、听消息、买热门股，却安慰自己说"我在长期投资"。
- **投资与投机账户混用**: 把投机资金放在投资账户里，心理上混淆两者。投机亏损后想通过"投资"补回来。
- **过度投机**: 投入超过10%的资金用于投机，一旦亏损影响整体财务安全。

### 作者的盲点 / 时代局限

- **指数基金时代**: 格雷厄姆写此书时指数基金尚未普及。今天对大多数防御型投资者来说，持有指数基金可能比选股更符合"投资"的定义。
- **科技股与无形资产**: 格雷厄姆的分析框架以有形资产和稳定盈利为核心，对高增长、高无形资产的科技公司适用性有限。
- **量化交易与ETF**: 现代市场中的量化策略和杠杆ETF带来了新的投机工具，格雷厄姆的定义框架仍适用，但具体案例需要更新。

### 容易混淆的邻近方法论

- 安全边际框架（先分类，后评估价格）
- 行为纪律（分类决定后，执行时需要纪律）
