# 分散化原则

## R — 原文 (Reading)

> "分散化是保护投资者免受单个证券错误判断影响的安全网。"
>
> — 本杰明·格雷厄姆, 《聪明的投资者》第20章

> "适当的分散化，你的持股数应限制在最少10只，最多30只不同行业的股票。"
>
> — 本杰明·格雷厄姆, 《聪明的投资者》第14章

---

## I — 方法论骨架 (Interpretation)

分散化是格雷厄姆投资体系中的**免费午餐**。它的逻辑是：

- **你不是神**：即使你做了深入分析，仍然可能犯错。分散化保护你免受单个判断错误的影响。
- **未知的未知**：有些风险你无法预见（如监管变化、技术颠覆、管理层丑闻）。分散化让这些风险对你的整体组合影响有限。
- **行业分散**：持有不同行业的股票，避免行业系统性风险。

**格雷厄姆的具体建议**：
- 防御型投资者：持有 **10-30只** 股票，分散在不同行业。
- 积极型投资者：可以更集中，但不要少于10只。
- 单只股票仓位：建议不超过总组合的 **5-10%**。

**分散化的双重作用**：
1. **降低风险**：单只股票出问题不影响整体组合。
2. **提高收益稳定性**：波动更小，回撤更浅。

## A1 — 书中的应用 (Past Application)

### 案例 1: 四家公司比较
- **问题**: 格雷厄姆比较了四家机械制造公司（ELTRA、Emerson、Emery、Emhart），发现即使基本面相似，市场给予的估值可能大相径庭。
- **方法论的使用**: 如果只持有其中一家，你可能遭遇"错误定价"的风险。分散化持有四家，降低了这种风险。
- **结论**: 分散化让投资者避免被单一市场错误定价所伤害。
- **结果**: 四家公司的长期表现验证了分散化降低风险的有效性。

### 案例 2: LTV 和 NVF 的警示
- **问题**: LTV和NVF都是高度集中的投机性操作——过度杠杆+单一标的，最终走向灾难。
- **方法论的使用**: 格雷厄姆用这些反例说明：即使标的本身有吸引力，缺乏分散化也会导致毁灭性风险。
- **结论**: 分散化不是可选项，是必选项。
- **结果**: 集中持仓的投资者在LTV和NVF中损失惨重。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户正在构建投资组合，不确定多少只股票才够分散。
2. 用户持有一只股票仓位很重，想评估风险。
3. 用户想理解"集中投资 vs 分散投资"的争论。
4. 用户看到某只股票大跌，担心组合风险。

### 语言信号

- "我应该买几只股票？"
- "如何分散风险？"
- "集中投资好还是分散好？"
- "单个股票仓位该多大？"
- "How many stocks should I hold?"（英文）
- "Is my portfolio diversified enough?"（英文）

### 与相邻 skill 的区分

- 与 `defensive-allocation` 的区别：资产配置解决股vs债的大类分配，分散化解决个股/行业层面的分散。
- 与 `margin-of-safety` 的区别：安全边际保护单个投资，分散化保护整个组合。两者互补。

## E — 可执行步骤 (Execution)

1. **评估当前持仓**
   - 列出所有持仓，计算每只股票的仓位百分比。
   - 按行业分类，看是否有行业集中。
   - 完成标准：有清晰的持仓分布表。

2. **检查分散化程度**
   - 总持股数是否在 10-30 只之间？
   - 最大单只持仓是否 ≤ 10%？
   - 前5大持仓是否 ≥ 50%？（如果是，集中度高）
   - 最大行业仓位是否 ≥ 30%？（如果是，行业集中）
   - 完成标准：每项都有明确结论。

3. **调整持仓**
   - 如果持股数 < 10 → 建议增持新标的（分散化不足）。
   - 如果单只持仓 > 10% → 建议减仓（过度集中）。
   - 如果行业集中度高 → 建议增持其他行业。
   - 完成标准：给出具体的调整建议。

4. **定期检查**
   - 每季度或每半年检查一次分散化程度，因市场波动而调整。
   - 完成标准：设定检查频率。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户是积极型投资者且精通个别公司分析——可以适当集中，但仍需遵循分散化原则。
- 用户只持有指数基金——指数基金本身已分散，不需要额外个股分散化。
- 用户资金量很小（如 < 10万美元）——10只股票可能已经足够分散。

### 作者在书中警告的失败模式

- **过度分散化**: 持有50只以上股票可能导致收益平庸——分散化应有限度。
- **伪分散化**: 买同一行业的5只股票不是分散化——需要跨行业。
- **情绪驱动**: 在牛市中看到某些股票大涨后，可能想集中追涨——违反分散化原则。
- **忽视安全边际**: 分散化不能替代安全边际——每只股票本身仍需有安全边际。

### 作者的盲点 / 时代局限

- **指数基金**: 格雷厄姆时代指数基金尚不存在。今天，持有指数基金天然实现了高度分散化。
- **全球市场**: 可进一步分散到全球市场，不仅限于美国。
- **成本**: 分散化需要交易成本——指数基金是最低成本的分散化工具。

### 容易混淆的邻近方法论

- 资产配置（大类资产分散 vs 个股分散）
- 安全边际（每只股票的保护 vs 组合保护）
