# AI 辅助量化因子挖掘工作流

## R — 原文 (Reading)

> 在大数据和 AI 的加持下，量化交易中的因子挖掘已从传统的线性回归、
> 主成分分析等方法，转向深度神经网络、图神经网络（GNN）、自监督学习
> 等前沿技术。AI 模型能够从海量结构化与非结构化数据中自动提取复杂的
> 非线性特征，发现隐藏的交易信号。
>
> — 罗勇 等, 第1章 1.4节

> 传统量化投资中，线性因子模型（如 Fama-French 三因子、Alpha 因子等）
> 长期主导着策略开发。然而，市场结构日益复杂，交易行为愈发多样，单纯
> 依靠线性因子模型已难以捕捉市场的隐性规律。机器学习，尤其是随机森林
>（Random Forest）、XGBoost 等非线性模型，凭借其强大的特征筛选与拟合
> 能力，为量价因子的深度挖掘和策略优化提供了全新思路。
>
> — 罗勇 等, 第3章 3.7节

## I — 方法论骨架 (Interpretation)

本书展示的 AI 辅助因子挖掘是一个完整闭环：

**1. 因子来源多元化**: 不再局限于传统量价数据，而是从研报（NLP 解析）、新闻（情感分析）、LV2 订单簿（微观结构）、社交媒体（舆情）等多维度提取信号。

**2. AI 驱动的因子生成**: 用大模型从非结构化文本中自动提取因子公式和参数（如从研报中提取"市盈率相对盈利增长比率"等因子），用机器学习（随机森林、XGBoost）从量价数据中筛选最具预测力的特征。

**3. 因子验证与迭代**: 每个因子必须经过回测验证，关注因子的 IC 值（信息系数）、单调性、稳定性。失效因子要及时淘汰，新因子要持续挖掘——因为 Alpha 因子具有时效性。

**4. 提示词模板加速**: 书中为每类因子挖掘任务都配备了专用的提示词模板（BROKE/CRISPE/ICIO 框架），让大模型快速生成因子公式和代码。

## A1 — 书中的应用 (Past Application)

### 案例 1: LV2 订单簿不平衡因子
- **问题**: 需要从 Level2 逐笔委托数据中挖掘买卖力量失衡的预测信号
- **方法论的使用**: 统计前5档盘口的买卖挂单量差异，结合撤单率构建不平衡指标；用 Python 实现因子计算，回测验证预测能力
- **结论**: 订单簿不平衡因子能有效捕捉主力资金动向，对短期价格有预测力
- **结果**: 形成了可复用的因子公式和代码模板

### 案例 2: ML 量价特征工程
- **问题**: 传统线性因子难以捕捉市场的非线性规律
- **方法论的使用**: 用随机森林/XGBoost 对换手率、振幅、量比等基础量价指标进行非线性组合，筛选出最具预测力的特征子集
- **结论**: ML 模型能自动发现量价指标间的复杂交互关系
- **结果**: 预测准确率优于传统线性因子模型

### 案例 3: 研报因子自动解析
- **问题**: 券商研报中蕴含大量量化因子，但人工提取效率极低
- **方法论的使用**: 用大模型（ICIO 框架）自动解析研报，提取因子名称、公式、参数，输出标准 JSON 格式
- **结论**: 大模型能结构化输出研报中的量化因子
- **结果**: 1 分钟内完成从研报到因子的转换（传统方式需要数小时）

### 与相邻 skill 的区分 (定稿)

- 与 `prompt-engineering` 的分工: 本 skill 是因子挖掘的**完整方法论**（数据源→特征工程→IC 验证→入库迭代），prompt-engineering 只是其中的**交互工具**之一。当你问"如何挖因子"→本 skill；问"如何写 prompt 让大模型帮我生成因子公式"→prompt-engineering
- 与 `data-pipeline` 的边界: 本 skill 是**因子层**（挖掘/验证/迭代），data-pipeline 是**数据工程层**（获取/清洗/存储）。因子挖掘以数据流水线为前置条件——没有干净的数据就没有有效因子
- 与 `sentiment-quant` 的对比: 本 skill 是**通用**因子挖掘框架（覆盖量价/基本面/高频/另类等所有类型），sentiment-quant 是**专门**做情绪/舆情类因子的方法论。当目标是情绪因子时，sentiment-quant 更专精；当目标是多类型因子组合或比较时，用本 skill

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确定因子类型与数据来源**
   - 基本面因子 → 财务数据、研报
   - 量价因子 → 日线/分钟线行情数据
   - 高频因子 → LV2 逐笔数据
   - 另类因子 → 新闻、舆情、事件数据
   - 完成标准: 已明确因子类型和对应数据源

2. **选择因子构建方法**
   - 规则型因子: 用提示词模板让大模型生成公式（BROKE/CRISPE 框架）
   - ML 型因子: 用随机森林/XGBoost 做特征筛选
   - NLP 型因子: 用大模型从文本中提取（ICIO 框架）
   - 完成标准: 已确定构建方法

3. **构建因子公式与代码**
   - 用大模型生成因子计算公式
   - 实现 Python 代码（pandas 计算）
   - 完成标准: 因子计算代码可运行

4. **因子有效性验证**
   - 计算 IC 值（信息系数）
   - 检验单调性（分组收益是否单调）
   - 检验稳定性（滚动窗口 IC 是否稳定）
   - 完成标准: 因子通过有效性检验
   - 判停条件: 若 IC < 0.03 或不单调 → 回到步骤 2 重新构建

5. **因子入库与持续迭代**
   - 将有效因子纳入因子库
   - 定期重新评估因子有效性
   - 淘汰衰减因子，挖掘新因子
   - 完成标准: 因子已入库并建立监控机制

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只需要简单的技术指标（MA、MACD、RSI）—— 这些是已有公式，不需要"挖掘"
- 用户的任务纯是数据获取或清洗 —— 用 `data-pipeline` skill
- 用户要做策略回测框架选择 —— 用 `strategy-decision` skill

### 作者在书中警告的失败模式

- **过拟合风险**: ML 模型在历史数据上表现好，但样本外失效
- **因子衰减**: Alpha 因子有时效性，市场参与者增多后因子会失效
- **数据挖掘偏误**: 在大量因子中"试"出来的因子可能只是统计噪声
- **线性模型局限**: 传统线性因子难以捕捉市场非线性规律

### 作者的盲点 / 时代局限

- 书中未充分讨论样本外测试和交叉验证的方法
- 展示的因子都是"成功案例"，缺少失败因子的教训
- 实盘中的滑点、手续费等交易成本对因子收益的侵蚀未讨论
- 监管变化（如高频交易限制）可能使某些因子策略不可行

### 容易混淆的邻近方法论

- 传统因子投资（Fama-French 等学术因子）—— 本 skill 侧重 AI 辅助的新型因子挖掘
- 因子中性化/正交化 —— 这是因子处理技术，不是因子挖掘方法
