# 《AI量化交易》技能库 - 使用指南

## 快速开始

### 场景 1：我是量化交易新手
**推荐路径**：`data-pipeline` → `factor-mining` → `strategy-decision`

1. 先用 `data-pipeline` 搭建数据基础设施
2. 学习用 `factor-mining` 挖掘第一个因子
3. 用 `strategy-decision` 构建完整策略

### 场景 2：我想用大模型辅助量化
**推荐路径**：`llm-capability` → `prompt-engineering` → 具体技能

1. 先用 `llm-capability` 选择合适的模型
2. 学习用 `prompt-engineering` 与模型高效交互
3. 根据需求选择具体技能（因子挖掘/策略决策等）

### 场景 3：我想做 A 股短线交易
**推荐路径**：`a-share-patterns` + `sentiment-quant`

1. 用 `a-share-patterns` 分析交易模式（涨停/连板/游资）
2. 用 `sentiment-quant` 评估市场情绪和舆情
3. 结合两者做出交易决策

### 场景 4：我想构建 AI Agent 自动化系统
**推荐路径**：`mcp-toolchain` + `prompt-engineering`

1. 用 `mcp-toolchain` 搭建 Agent 工具链
2. 用 `prompt-engineering` 设计高效的 Agent 提示词
3. 集成其他技能实现完整系统

## 技能详细使用

### strategy-decision（策略决策）

**何时使用**：
- 不确定该构建什么类型的量化策略
- 需要在多种策略间做选择
- 策略失效需要诊断问题

**使用示例**：
```
用户：我有 500 万资金，风险偏好中等，该做什么策略？

技能响应：
1. 评估资金规模和风险偏好
2. 推荐适合的策略类型（资产配置/阿尔法/贝塔）
3. 分析各策略的优劣势
4. 给出实施建议
```

**输出**：策略推荐报告，包含策略类型、实施步骤、风险提示

---

### prompt-engineering（提示词工程）

**何时使用**：
- 需要设计高效的量化交易提示词
- 大模型输出质量不稳定需要优化
- 想了解 CRISPE/BROKE/ICIO 框架

**使用示例**：
```
用户：怎么设计 prompt 让大模型帮我从研报提取量化因子？

技能响应：
1. 推荐使用 ICIO 框架（数据处理场景）
2. 构建完整的 prompt 结构：
   - Instruction: 提取研报中的量化因子
   - Input: 研报文本
   - Context: 量化因子专家角色
   - Output: 结构化 JSON 格式
3. 提供完整的 prompt 模板
```

**输出**：可复用的 prompt 模板和使用说明

---

### factor-mining（因子挖掘）

**何时使用**：
- 需要挖掘新的量化因子
- 验证因子有效性
- 从非结构化数据提取因子

**使用示例**：
```
用户：我想从 LV2 订单簿数据挖掘买卖力量失衡信号

技能响应：
1. 介绍 LV2 订单簿不平衡因子的原理
2. 提供因子构建方法：
   - 前 5 档买卖挂单量差异
   - 撤单率计算
   - 资金流向指标
3. 给出 Python 代码实现
4. 说明验证方法（IC 值、分组回测）
```

**输出**：因子定义、计算公式、代码实现、验证方法

---

### data-pipeline（数据管道）

**何时使用**：
- 需要搭建量化数据获取系统
- 处理数据质量问题（缺失值/异常值）
- 评估和选择数据源

**使用示例**：
```
用户：怎么从 Tushare 批量获取数据并处理 API 限流？

技能响应：
1. 介绍 Tushare API 调用方法
2. 提供批量下载策略：
   - 分批请求 + 延迟控制
   - 断点续传机制
   - 数据完整性校验
3. 给出数据清洗方案：
   - 缺失值处理（前向填充/插值）
   - 异常值检测（3σ 法则）
   - 复权处理
```

**输出**：数据获取代码、清洗方案、质量保障机制

---

### a-share-patterns（A 股模式）

**何时使用**：
- 量化 A 股特有交易模式
- 分析涨停板/竞价/游资行为
- 构建 A 股短线策略

**使用示例**：
```
用户：怎么判断涨停板的持续性？

技能响应：
1. 介绍涨停原因归类方法：
   - 题材驱动型
   - 业绩驱动型
   - 游资炒作型
2. 提供持续性评估指标：
   - 封单量/流通市值比
   - 题材热度指数
   - 板块联动效应
3. 给出连板概率预测模型
```

**输出**：涨停分类方法、持续性指标、交易策略

---

### mcp-toolchain（MCP 工具链）

**何时使用**：
- 构建 AI Agent 量化系统
- 让大模型调用外部工具
- 实现多 Agent 协作

**使用示例**：
```
用户：怎么搭建 MCP Server 让大模型调用量化数据工具？

技能响应：
1. 介绍 MCP 协议核心概念
2. 提供 MCP Server 搭建代码：
   - 定义工具接口（数据查询/因子计算/回测）
   - 实现工具逻辑
   - 注册到 MCP Server
3. 说明 Agent 连接方法
4. 给出安全配置建议
```

**输出**：MCP Server 代码、工具定义、Agent 集成方案

---

### sentiment-quant（情绪量化）

**何时使用**：
- 用 NLP 分析市场情绪
- 构建舆情监控系统
- 设计情绪驱动的交易策略

**使用示例**：
```
用户：怎么量化市场恐慌和贪婪情绪？

技能响应：
1. 介绍情绪指标构建方法：
   - 新闻情感分析（正面/负面比例）
   - 社交媒体情绪指数
   - 恐慌贪婪指数
2. 提供 NLP 分析流程：
   - 文本预处理
   - 情感分类模型
   - 情绪强度评分
3. 给出交易策略：
   - 极值反转策略
   - 情绪动量策略
```

**输出**：情绪指标定义、NLP 分析代码、交易策略

---

### llm-capability（大模型能力）

**何时使用**：
- 选择合适的大模型
- 评估任务与模型能力匹配度
- 了解推理模型 vs 非推理模型

**使用示例**：
```
用户：复杂量化推理任务该用推理模型还是非推理模型？

技能响应：
1. 解释两类模型的核心差异：
   - 推理模型：多步逻辑推理（DeepSeek-R1、o1）
   - 非推理模型：模式匹配和生成（GPT-4、Claude）
2. 评估任务复杂度（九大段位体系）
3. 推荐适合的模型类型
4. 说明成本和性能权衡
```

**输出**：模型对比表、能力评估、选型建议

## 常见问题

**Q: 我是纯新手，应该从哪个技能开始？**
A: 推荐从 `data-pipeline` 开始，先搭建数据基础，然后学习 `factor-mining` 和 `strategy-decision`。

**Q: 这些技能需要编程基础吗？**
A: 需要基础 Python 能力，但技能会提供完整的代码模板，可以逐步学习。

**Q: 可以只用其中一个技能吗？**
A: 可以，但技能之间是互补的。例如只用 `factor-mining` 而不用 `data-pipeline`，可能面临数据质量问题。

**Q: 这些技能适用于哪些市场？**
A: 大部分技能适用于全球市场，`a-share-patterns` 专门针对 A 股市场。

**Q: 如何更新技能？**
A: 技能会随《AI量化交易》书籍更新而更新，请关注项目仓库获取最新版本。
