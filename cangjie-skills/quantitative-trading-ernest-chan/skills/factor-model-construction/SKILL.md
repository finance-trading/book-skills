# Factor Model Construction — 因子模型构建与应用

## R — 原文 (Reading)

> "因子模型，或套利定价理论，常用于模拟基本面因素对股票收益率的线性影响。最著名的因子模型之一是Fama-French三因子模型，它假设股票收益率与贝塔值和账面市值比率正相关，与市值负相关。...因子收益率通常比个股收益率更稳定。换句话说，它们具有'惯性'。因此，可以假设它们的值从当期到下一期保持不变。"
>
> — Ernest Chan, 第7章

---

## I — 方法论骨架 (Interpretation)

这个框架解决的核心问题是：**如何将主观的基本面分析转化为可量化、可回测的因子模型？**

方法论骨架：

1. **因子模型的基本结构**：股票超额收益率 = 因子风险暴露 × 因子收益率 + 特有收益率。因子风险是可以被解释的系统性风险，特有收益率是无法被解释的随机噪声。

2. **两类因子构建方法**：
   - **基本面因子**：如Fama-French三因子（贝塔值、市值、账面市值比），需要历史基本面数据（昂贵且不切实际）
   - **数据驱动因子**：如主成分分析（PCA），仅依赖历史收益率数据，无需基本面数据

3. **因子模型的使用逻辑**：虽然因子模型看起来只能解释历史数据，但关键洞察是——因子收益率比个股收益率更稳定，具有"惯性"。因此可以假设当期因子收益率在下一期保持不变，从而预测超额收益率。

4. **模型质量判断**：好的因子模型应该能充分解释股票超额收益率。根据Grinold和Kahn的建议，1000只股票的月度收益率和50个因子之间，R²应当在30%-40%。如果R²过低，说明因子选择不当，模型无法充分解释收益率。

5. **因子模型可用于均值回归和惯性策略**：如果股票收益率是均值回归的，前期收益率为负，则相应的因子收益率就会是正值。因子模型不局限于惯性策略。

关键洞察：**因子收益率比个股收益率更稳定、更具惯性，因此更容易预测。因子模型将主观的基本面分析转化为客观的量化框架。**

## A1 — 书中的应用 (Past Application)

### 案例 1: Fama-French三因子模型
- **问题**: 如何量化基本面因素（市值、价值、风险）对股票收益率的影响？
- **方法论的使用**: 构建三因子模型，因子风险包括贝塔值（市场敏感度）、市值、账面市值比率。对每个时间段单独做多元线性回归，得到因子收益率的估计值。
- **结论**: 市值因子收益率通常是负的（小盘股收益率高于大盘股），账面市值比因子收益率通常是正的（价值股收益率高于成长股），贝塔因子收益率是正的（大部分股票与市场指数正相关）。
- **结果**: 成功解释了股票超额收益率的系统性部分，为量化基本面分析提供了框架。

### 案例 2: 主成分分析（PCA）构建因子
- **问题**: 独立交易员无法负担昂贵的历史基本面数据，如何构建因子模型？
- **方法论的使用**: 使用主成分分析，仅依赖历史收益率数据构建因子风险。假设因子风险在估计时间段内不变（时间独立）。
- **结论**: PCA可以从纯价格数据中提取出主导的因子结构，无需基本面数据。
- **结果**: 为独立交易员提供了一种低成本的因子模型构建方法。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **想要量化基本面分析**：用户说"我觉得小盘股表现更好"、"价值股应该跑赢成长股"，但无法量化验证。
2. **构建多因子策略**：用户想要"用多个因子预测股票收益"、"如何组合不同的基本面因素"。
3. **理解股票收益来源**：用户问"为什么某些股票表现更好"、"如何区分系统性风险和个股特异性"。
4. **缺乏基本面数据**：用户说"我没有昂贵的历史财务数据，能否用价格数据做因子分析"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **选择因子构建方法**
   - 完成标准: 用户能明确回答"我有基本面数据吗？"
   - 若有基本面数据 → 进入步骤2（基本面因子）
   - 若仅有价格数据 → 进入步骤2（PCA因子）

2. **构建因子风险矩阵**
   - 完成标准: 用户能计算每只股票在每个因子上的风险暴露
   - 基本面因子：对每个因子（贝塔值、市值、账面市值比），计算所有股票在该因子上的值，标准化为均值0、标准差1
   - PCA因子：对历史收益率矩阵进行主成分分析，提取前k个主成分作为因子风险
   - 判停条件: 因子风险矩阵构建完成，进入步骤3

3. **估计因子收益率**
   - 完成标准: 用户能通过多元线性回归得到因子收益率
   - 方法: 对每个时间段，将股票超额收益率对因子风险进行多元线性回归，回归系数即为因子收益率
   - 判停条件: 因子收益率估计完成，进入步骤4

4. **评估模型质量**
   - 完成标准: 用户能计算R²并判断模型是否充分解释收益率
   - 方法: 计算回归的R²统计量。若R²在30%-40%（1000只股票、50个因子），模型质量良好；若R²过低，需重新选择因子
   - 判停条件: R²达标 → 进入步骤5；R²过低 → 返回步骤1重新选择因子

5. **预测超额收益率并构建策略**
   - 完成标准: 用户能假设当期因子收益率在下一期保持不变，预测股票超额收益率
   - 方法: 预测超额收益率 = 因子风险 × 当期因子收益率。根据预测值构建多头（高预测收益）或空头（低预测收益）头寸
   - 判停条件: 策略构建完成，可回测验证

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯技术分析**: 如果用户只关心价格模式、图表形态，不涉及基本面因素，本skill不适用。
- **高频交易**: 因子模型通常用于中低频策略（日频、周频、月频），高频交易（秒级、毫秒级）不适用。
- **单一股票预测**: 因子模型用于横截面（多只股票）的相对强弱比较，不适合预测单一股票的绝对收益率。

### 作者在书中警告的失败模式

- **数据窥探偏差**: 如果尝试大量因子组合直到找到R²高的模型，会陷入数据窥探偏差。应基于经济理论选择因子，而非盲目搜索。
- **因子选择不当**: 如果因子风险（或整个模型）选择不恰当，线性回归将会产生显著的特有收益率，并且拟合方程的R²统计量将会很小。
- **假设因子收益率不变的局限**: 因子模型假设当期因子收益率在下一期保持不变，但市场状态转换时这个假设可能失效。

### 作者的盲点 / 时代局限

- **未讨论因子拥挤**: 书中未提及当大量交易员使用相同因子模型时，因子收益率会被竞争消除的问题。
- **未讨论非线性因子关系**: 书中假设因子与收益率是线性关系，但实际中可能存在非线性关系（如门槛效应、交互效应）。
- **PCA的时间独立性假设过强**: 书中承认PCA假设因子风险在估计时间段内不变，但实际中因子结构可能随时间变化。

### 容易混淆的邻近方法论

- **因子模型 vs 机器学习**: 因子模型是线性模型，强调经济解释；机器学习（如神经网络）可以捕捉非线性关系，但缺乏解释性。
- **因子收益率 vs 个股收益率**: 因子收益率更稳定、更具惯性，但个股收益率包含特有收益率（随机噪声），波动更大。
