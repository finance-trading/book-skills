# Mean Reversion vs Momentum — 均值回归vs动量策略选择框架

## R — 原文 (Reading)

> "只有当证券价格是均值回归的或趋势的，交易策略才能盈利。否则，价格是随机漫步的，交易将无利可图。...学术研究表明，股票价格'一般而言'非常接近随机漫步。但这并不意味着在特殊条件下价格不会表现出一定程度的均值回归或趋势行为。...因此，构建一个策略，实际上就是要判断，在特定条件和特定时间段，价格究竟是均值回归的还是趋势的。"
>
> — Ernest Chan, 第7章 7.1节 line 4263-4270

---

## I — 方法论骨架 (Interpretation)

这个框架的核心是：**所有盈利策略都只有两种底层逻辑——均值回归或趋势（动量）**。选择策略的第一步不是找"最好的策略"，而是判断市场处于哪种状态。

方法论骨架：
1. **根本性分类**：任何盈利策略必属于两类之一。均值回归策略假设价格偏离后会回归；动量策略假设价格变化会持续。如果你的策略既不是均值回归也不是趋势，那它依赖的就是随机漫步，不可能盈利。

2. **状态判断优先**：
   - **均值回归状态更常见**（第7章小结），适合短线、高频交易
   - **趋势状态较少但更危险**，由新信息缓慢扩散、机构大单、羊群效应引发
   - 同一时刻价格可以既是均值回归的（短期）也是趋势的（长期）——分形性质

3. **持有期差异**：
   - **均值回归**：持有期短（日内到数天），用Ornstein-Uhlenbeck公式估计半衰期确定最优持有期
   - **动量/惯性**：持有期长（数周到数月），但最优持有期容易因信号数量少而估计出错

4. **竞争影响不同**：
   - **均值回归**：竞争消除套利机会，收益率→0
   - **动量**：竞争缩短趋势持续时间，均衡价格更快实现

5. **数据陷阱差异**：
   - **均值回归**：特别容易受异常报价和存活偏差影响（买入虚假低价→按正常价格卖出=虚假利润）
   - **动量**：主要受前视偏差和过拟合影响

关键洞察：**不是"哪种策略更好"，而是"市场现在处于哪种状态"**。必须先判断状态，再选策略。

## A1 — 书中的应用 (Past Application)

### 案例 1: Khandani-Lo均值回归模型的教训 (ca013)
- **问题**: Khandani和Lo（2007）建立了一个非常简单的短期均值回归模型，不考虑交易成本时能持续盈利。
- **方法论的使用**: 作者应用简单至上原则，测试这个均值回归策略。但发现引入交易成本后，策略从盈利转为巨亏。
- **结论**: 均值回归策略必须足够强、足够长，才能在扣除交易成本后仍有利可图。找到这样的特殊情形才是交易员的任务。
- **结果**: 夏普比率从4.47降至-3.19，验证了均值回归策略对交易成本的极端敏感性。

### 案例 2: GLD-GDX配对交易的均值回归 (ca015)
- **问题**: 需要判断GLD（黄金ETF）和GDX（金矿股ETF）的差价是否均值回归，以及回归的速度。
- **方法论的使用**: 
  1. 用协整检验确认差价序列平稳（均值回归）
  2. 用Ornstein-Uhlenbeck公式估计半衰期（约10天）
  3. 根据半衰期确定最优持有期
- **结论**: 差价确实均值回归，半衰期约10天，适合作为均值回归策略。
- **结果**: 训练集夏普2.3，测试集1.5。验证了均值回归判断的正确性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **策略选择困惑**：用户在均值回归和动量策略之间犹豫，不知道该做哪种。
2. **市场状态判断**：用户问"现在市场是均值回归还是趋势？"、"我的策略为什么失效了？"
3. **持有期确定**：用户问"我应该持有头寸多久？"、"多久应该清仓？"
4. **策略失效诊断**：用户的均值回归或动量策略突然失效，需要诊断是市场状态转换还是竞争加剧。

### 与相邻 skill 的区分

- **与 `cointegration-pair-trading` 的区别**: 本skill回答"选哪种策略类型"（均值回归还是动量），cointegration回答"如何构建均值回归策略"（配对交易的具体方法）。本skill是战略层面，cointegration是战术层面。

- **与 `exit-strategy-framework` 的区别**: 本skill决定策略类型（均值回归vs动量），exit-strategy根据策略类型选择清仓方式（目标价格vs止损）。本skill在前，exit-strategy在后。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判断用户的目标市场状态**
   - 完成标准: 用户能明确回答"我交易的市场是均值回归还是趋势？"
   - 方法: 
     - 询问用户交易的资产类别（股票、期货、外汇）
     - 询问用户偏好的持有期（日内、数天、数周）
     - 如果用户不确定，建议使用ADF检验或Hurst指数测试价格序列
   - 判停条件: 若用户明确是均值回归状态，进入步骤2；若是趋势状态，跳到步骤3；若不确定，建议先做统计检验。

2. **为均值回归策略选择参数**
   - 完成标准: 用户能确定持有期、进出场阈值、对冲比率
   - 方法:
     - 用Ornstein-Uhlenbeck公式估计半衰期，半衰期即为最优持有天数
     - 用协整检验（ADF）确认价格序列平稳
     - 设定进出场阈值（通常为1倍或0.5倍标准差）
   - 判停条件: 若半衰期估计成功，进入步骤4；若序列不平稳，返回步骤1重新判断。

3. **为动量策略选择参数**
   - 完成标准: 用户能确定持有期、止损价格、信号阈值
   - 方法:
     - 根据信息扩散速度估计持有期（季报公布后数天到数周）
     - 设定止损价格（动量策略在趋势状态下止损有益）
     - 使用移动平均突破或动量指标作为信号
   - 判停条件: 若参数确定，进入步骤4。

4. **验证策略的稳健性**
   - 完成标准: 用户能回答"扣除交易成本后策略还盈利吗？"
   - 方法:
     - 在回测中加入现实的交易成本（佣金、滑点、市场冲击）
     - 对均值回归策略：彻底清除异常报价，使用无存活偏差数据
     - 进行样本外测试（将数据分为训练集和测试集）
   - 判停条件: 若扣除成本后夏普比率仍>1，策略可用；否则返回步骤1或步骤2重新优化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **高频交易算法设计**：高频交易（毫秒级）有特殊的微观结构考量，本skill的持有期框架（日内到数周）不适用。
- **基本面长期投资**：价值投资持有数年，不属于本skill的均值回归或动量框架（虽然本质上是长期均值回归）。
- **已经确定策略类型后需要具体实现**：如果用户已经确定做均值回归配对交易，应该用 `cointegration-pair-trading` 而不是本skill。

### 作者在书中警告的失败模式

- **ce04 - 存活偏差人为拔高均值回测**: 均值回归策略会买入极端低价股票（可能破产），但破产股票从数据库消失，导致回测业绩虚假抬高。
- **ce07 - 忽略交易成本**: 均值回归策略对交易成本极端敏感。Khandani-Lo策略夏普从4.47降至-3.19。
- **ce15 - 竞争导致利润消失**: 均值回归策略的套利机会被竞争消除，收益率降至零；动量策略的趋势持续时间缩短。
- **ce16 - 止损并不总是有效**: 止损只适用于动量策略（趋势状态），不适用于均值回归策略。在均值回归市场中止损会锁定损失。

### 作者的盲点 / 时代局限

1. **过度简化了策略分类**: 现实中许多策略是混合型的（如统计套利可能同时包含均值回归和动量成分），严格的二分法可能忽略复杂性。
2. **忽视了机器学习方法的进展**: 作者承认"还没发现隐马尔可夫模型特别有用"，但2010年代后深度学习在状态识别上取得突破，可能改变状态判断的方法。
3. **2009年的市场结构与2025年不同**: 高频交易、算法交易的普及改变了均值回归和动量的相对优势，书中结论可能需要更新。

### 容易混淆的邻近方法论

- **均值回归 ≠ 价值投资**: 均值回归是短期统计现象（数天到数周），价值投资是长期基本面判断（数年）。
- **动量 ≠ 追涨杀跌**: 动量策略基于信息缓慢扩散的统计规律，不是情绪化的追涨杀跌。
- **状态判断 ≠ 市场预测**: 本skill是判断"当前市场更适合哪种策略"，不是预测"市场明天会涨还是跌"。
