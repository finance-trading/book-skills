# Capital Scale Determines Strategy — 资本规模决定策略类型框架

## R — 原文 (Reading)

> "你是否有足够的资本可用于交易，以及支付设备和运营费用？我并不推荐资本规模少于5万美元的账户采用量化交易策略进行交易。我们以10万美元作为大资本账户和小资本账户的分界线。可用资本会影响许多选择……可用资本（或杠杆）决定了你应该进行单向交易（纯多头或纯空头）还是货币中性交易（对冲交易或配对交易）。"
>
> — Ernest Chan, 第2章 2.1.3节 line 796-808

---

## I — 方法论骨架 (Interpretation)

这个框架的核心是：**资本规模不是"能做多大"的问题，而是"能做什么类型"的问题**。

方法论骨架：
1. **资本作为硬约束**：
   - 资本规模决定了策略的**容量类型**（高频/低频、大容量/小容量）
   - 资本规模决定了策略的**杠杆空间**（配对交易需要高杠杆）
   - 资本规模决定了策略的**标的类型**（大盘股/小盘股、期货/股票）
2. **资本规模的阶梯效应**：
   - **<5万美元**：只能做小容量策略（交易频繁、持仓少、标的少），如日内均值回归、小盘股动量
   - **5-50万美元**：可以做中等容量策略，如日线配对交易、行业轮动
   - **>50万美元**：可以做大部分策略类型，但仍受容量上限约束
   - **>1000万美元**：需要考虑市场冲击成本，部分小容量策略反而不可行
3. **资本增加的调整路径**：
   - 从单向交易 → 配对交易（需要更多资本做对冲）
   - 从高频 → 低频（高频需要大容量才能覆盖固定成本）
   - 从小容量 → 大容量（随资本增长逐步扩展策略空间）
4. **资本的边际效用递减**：
   - 10万美元账户比1亿美元账户更容易获得高夏普比率
   - 超过一定规模后，策略选择空间反而缩小（大容量策略竞争激烈）

关键洞察：**资本不是越多越好，而是"合适"最好**。小资本有小资本的优势（可以交易机构忽略的小容量策略），大资本有大资本的劣势（被迫进入竞争激烈的红海市场）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 小账户的容量优势 (c19)
- **问题**: Ernest Chan 2006年独立交易，想知道在没有机构约束的环境下能否盈利。
- **方法论的使用**: 发现关键优势在于"容量"——10万美元账户能交易那些对大基金（管理数十亿）毫无价值的高夏普策略。
- **结论**: 小账户获得较高夏普比率要容易得多。独立交易者在小容量策略上有结构性优势。
- **结果**: 成功存活并持续盈利，验证了小容量策略的可行性。

### 案例 2: 自营交易公司vs零售账户的选择
- **问题**: 用户问"我应该加入自营交易公司还是自己做零售账户？"
- **方法论的使用**: 资本规模决定选择。如果需要高杠杆但资本不足，自营交易公司提供杠杆；如果资本充足且想保持独立性，零售账户更优。
- **结论**: 资本规模是选择交易环境的关键约束。
- **结果**: 避免了"资本不足但硬做零售账户"或"资本充足但被迫加入自营公司"的错误匹配。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **资本规模疑问**：用户在问"我只有X万，能做量化吗？"或"需要多少资本才能开始？"
2. **策略与资本不匹配**：用户想用5万美元做需要50万美元的策略（如大盘股配对交易）。
3. **资本增长规划**：用户在考虑如何从小资本逐步增长到大资本，策略如何调整。
4. **容量优势认知**：用户没有意识到小资本的结构性优势，盲目追求大资本。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **评估当前资本规模**
   - 完成标准: 用户能明确回答可用交易资本的具体金额（区分"交易资本"和"生活储备"）。
   - 判停条件: 若交易资本<5万美元，警告量化交易可能不适合，建议先积累资本。

2. **确定资本对应的策略类型**
   - 完成标准: 用户能列出当前资本规模下可行的策略类型（如<5万：日内均值回归、小盘股动量；5-50万：日线配对交易、行业轮动）。
   - 判停条件: 若无可行策略，返回步骤1考虑增加资本或调整目标。

3. **评估杠杆空间**
   - 完成标准: 用户能计算当前资本下的最大合理杠杆（参考凯利公式），并确定哪些策略需要高杠杆。
   - 判停条件: 若策略需要杠杆超过凯利公式建议值，调整策略或增加资本。

4. **规划资本增长路径**
   - 完成标准: 用户能列出未来1-3年的资本增长预期，以及对应的策略调整路径（如从单向→配对、从高频→低频）。
   - 判停条件: 完成。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **资本充足且策略已确定**：用户已经有足够资本且策略确定，只是想知道如何优化。本skill只用于策略选择阶段，不用于优化阶段。
- **纯理论讨论**：用户在问"资本与策略的关系是什么"，而不是"我的资本能做什么策略"。本skill是实操框架，不是理论框架。
- **不考虑资本约束的场景**：用户在自营交易公司工作，杠杆由公司提供商，个人资本约束不适用。

### 作者在书中警告的失败模式

- **ce02 - 机构交易员因过度杠杆和贪婪破产**: 作者因贪婪对仅运行6个月的策略追加1亿美元资本，造成灾难性损失。资本规模不仅是"能做多少"，还是"能承担多少风险"。
- **ce26 - 没有足够的存款撑过收入空窗期**: 资本不足会导致财务压力，进而导致情绪化决策。
- **ce12 - LTCM与Amaranth破产**: 过度杠杆化的致命后果。资本规模决定了杠杆空间，但杠杆过高会导致破产。

### 作者的盲点 / 时代局限

来自 BOOK_OVERVIEW.md 的批判：

1. **忽视了众筹和PAMM账户等现代资本解决方案**: 2009年书中未提及众筹基金、PAMM账户、复制交易等现代资本聚合方式。小资本交易者可以通过这些方式聚合资本，突破个人资本约束。
2. **过于强调个人资本**: 现实中很多成功的量化交易者使用外部资本（亲友、投资人），而非全部自有资金。框架假设资本来自个人储蓄，但实际可以多元化。
3. **未考虑加密货币市场的资本需求**: 加密货币市场降低了量化交易的资本门槛（可以交易小数位），但书中未涉及。

### 容易混淆的邻近方法论

- **资本规模 ≠ 账户规模**: 资本规模是可用资本，账户规模是经纪商账户余额。可以有多个账户，但资本总量不变。
- **资本约束 ≠ 资本限制**: 资本约束是筛选器（决定能做哪些策略），资本限制是障碍（让你放弃）。
