# Strategy Modification Methodology — 策略变形方法论

## R — 原文 (Reading)

> "不过，真正的窍门是：对基础策略进行变形，并用于赚钱。例如，有人曾向我推荐财富实验室论坛上的一项策略，据称具有高夏普比率。但当我对其进行回测后发现，它完全没有声称的那样出色。于是我开始对这项策略进行一些简单的调整，如缩短持有期、改变建仓和清仓的时点，最终这一策略成了我主要的盈利来源。"
>
> — Ernest Chan, 第2章 line 712-720

---

## I — 方法论骨架 (Interpretation)

这个方法论的核心是：**基础策略本身几乎没有价值，真正的alpha来自你自己的变形和窍门**。

方法论骨架：
1. **前提假设**：任何公开的基础策略——无论来自论坛、论文、书籍——在严格回测下都不会如声称的那样出色。这是常态，不是例外。
2. **核心操作——系统性变形**：
   - **持有期**：缩短或延长（如从5天改为3天）
   - **建仓/清仓时点**：从收盘改为开盘（或反向）
   - **参数调整**：移动平均天数、阈值倍数等
   - **股票池**：更换标的集合（如从全市场改为特定行业）
   - **交易频率**：日频改为周频，或反向
   - **进出场规则**：调整触发条件
3. **关键约束**：
   - 变形必须保持简单（参数不超过5个，参考simple-first-principle）
   - 每次只改一个维度，用样本外测试验证
   - 避免过度优化（252倍参数数量的数据点要求）
4. **价值定位**：
   - 基础策略：可以公开分享（因为本身无独有价值）
   - 变形窍门：这才是真正的"商业秘密"和核心竞争力

关键洞察：**策略变形不是一次性的，而是持续的过程**。竞争会让策略失效，状态转换会让策略失效，只有持续变形才能保持策略的生命力。

## A1 — 书中的应用 (Past Application)

### 案例 1: 财富实验室论坛策略的变形 (ca006)
- **问题**: 作者从博客读者处获得财富实验室论坛上的策略推荐，据称具有高夏普比率。
- **方法论的使用**: 初步回测发现"完全没有声称的那样出色"。于是进行简单调整：**缩短持有期、改变建仓和清仓的时点**。
- **结论**: 变形后的策略成为作者主要的盈利来源。
- **结果**: 验证了"变形比基础版本更有价值"。

### 案例 2: Khandani-Lo均值回归策略的改进 (ca014)
- **问题**: MIT Khandani-Lo均值回归策略考虑交易成本后夏普比率从+4.47降至-3.19（ca013）。
- **方法论的使用**: 仅做了一个微小调整：**将头寸更新时点从收盘改为开盘**。
- **结论**: 不考虑交易成本时夏普从0.25升至1.43；考虑交易成本后从-3.19升至+0.78。
- **结果**: 一个时点改变让策略从亏损变为盈利。验证了"微小调整的巨大威力"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **现成策略回测不理想**：用户从论坛、论文获得策略，回测效果远不如声称。
2. **策略开始衰退**：用户运行了一段时间的策略，夏普比率持续下降。
3. **参数调优困境**：用户不断调整参数但无法改善业绩，可能陷入了过度优化。
4. **想放弃某个策略**：用户准备放弃一个基础逻辑合理但回测不佳的策略。

### 语言信号 (用户的话里出现这些就应激活)

- "这个策略回测不好，怎么办？"
- "我的策略最近不灵了"
- "参数调来调去都不行"
- "Should I abandon this strategy?"
- "How to tweak/improve a trading strategy?"
- "Strategy modification" / "strategy doesn't work as advertised"

### 与相邻 skill 的区分

- **与 `simple-first-principle` 的区别**: 本skill关注"如何变形策略"（方法层面），simple-first关注"为什么简单更好"（原则层面）。变形应保持简单，但simple-first不涉及具体变形操作。
- **与 `sharing-over-secrecy` 的区别**: 本skill关注"变形的技术方法"，sharing-over-secrecy关注"变形后的分享策略"。本skill回答"怎么变形"，sharing回答"变形后该不该分享"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **评估基础策略的可行性**
   - 完成标准: 用户能确认基础策略有经济学逻辑支撑（不是纯数据挖掘），只是回测表现不佳。
   - 判停条件: 若策略逻辑本身不合理（如纯粹的数据挖掘模式），放弃该策略，回到策略选择阶段。

2. **系统性尝试变形维度**
   - 完成标准: 用户能按顺序逐一尝试以下变形：(a)持有期 (b)建仓/清仓时点 (c)参数微调 (d)股票池更换 (e)交易频率。每次只改一个维度。
   - 判停条件: 若某个变形使夏普比率从负变正或显著提升（>0.5），进入步骤3；若所有维度都试遍仍无改善，放弃该策略。

3. **样本外验证**
   - 完成标准: 用户能将数据分为训练集和测试集，确认变形后的策略在测试集上仍表现良好。
   - 判停条件: 若测试集业绩显著差于训练集（夏普比率降幅>50%），可能过拟合，返回步骤2进一步简化。

4. **记录变形窍门**
   - 完成标准: 用户能记录自己的变形操作（"将持有期从X改为Y"、"将建仓时点从收盘改为开盘"等），作为自己的独有价值。
   - 判停条件: 完成。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **基础策略逻辑不合理**：如果策略本身是纯数据挖掘（无经济学意义），变形无法挽救。
- **过度优化陷阱**：如果用户不断调整参数（10个、20个），这不是"变形"而是"数据窥探"。应回到simple-first-principle。
- **策略已完全崩溃**：如果策略在所有变形维度上都失败，且样本外测试全面崩溃，说明基础逻辑已失效，需替换策略。

### 作者在书中警告的失败模式

- **ce06 - 数据窥探偏差（过拟合）**: 参数越多（超过5个），越容易拟合噪声而非信号。"因迁就历史数据的噪声而过度优化模型参数，造成策略的回测业绩高于未来业绩。"变形不等于过度优化。
- **ce14 - 状态转换导致策略失效**: "状态转换是指金融市场结构或宏观经济环境发生了巨变，从而使得原本盈利的策略现在不盈利了。"变形可能无法解决结构性变化。
- **ce15 - 竞争导致策略利润消失**: 竞争会让策略失效。均值回归策略的套利机会逐步消失，惯性策略的趋势持续时间缩短。

### 作者的盲点 / 时代局限

来自 BOOK_OVERVIEW.md 的批判：

1. **策略变形成本被低估**: 作者说"对基础策略进行简单调整就能盈利"，但策略变形本身需要大量研究、回测、试错，成本不低。这不是"简单调整"那么容易。
2. **2009年竞争环境已剧变**: 量化交易的竞争在过去15年指数级增长。简单变形的alpha空间被机构榨干，独立交易者能找到的"低垂果实"比2009年少得多。
3. **幸存者偏差**: 作者分享了自己成功变形的案例（财富实验室策略），但无数交易员尝试变形后仍然失败的案例未被提及。

### 容易混淆的邻近方法论

- **变形 ≠ 优化**: 变形是调整策略逻辑（如改变持有期、建仓时点），优化是调整参数（如移动平均天数）。变形是质的改变，优化是量的调整。
- **变形 ≠ 过度拟合**: 变形基于经济学逻辑（如"开盘比收盘更稳定"），过度拟合基于数据挖掘的参数调优。
