# State Transition Prediction — 状态转换预测方法

## R — 原文 (Reading)

> "状态转换是指金融市场结构或宏观经济环境发生了巨变，从而使得原本盈利的策略现在不盈利了。...经验表明，随着越来越多的交易员发现这些策略并且加入竞争，这些策略就会失去盈利潜力。你必须不断研究新的策略。每十年都会有一些突然的、重大的状态转换发生，导致某些策略的突然死亡。"
>
> — Ernest Chan, 第5章/第7章 7.2节, 第8章

---

## I — 方法论骨架 (Interpretation)

这个框架回答一个核心问题：**如何预测策略从盈利转为亏损的"拐点"？**

方法论骨架：
1. **状态转换的定义**：金融市场结构或宏观经济环境发生巨变，原本盈利的策略不再盈利。典型来源包括：(1)监管变化（十进制报价、涨点规则废除）(2)市场结构变化（竞争加剧、效率提升）(3)宏观经济变化（通胀/衰退、高波动/低波动）。

2. **两种预测方法**：
   - **马尔可夫状态转换模型**：假设状态之间的转移概率固定。用经典计量经济学工具建模，如GARCH模型预测波动率状态转换。适用于波动率状态（对期权交易员有用），但对股票交易员帮助有限。
   - **数据挖掘方法（拐点模型）**：用机器学习（如感知器神经网络）在**后顾移动窗口**中训练，预测状态转换。关键优势：能捕捉非线性关系。关键约束：参数必须极少（避免过拟合），必须严格使用后顾窗口（避免数据迁就偏差）。

3. **有效AI的核心约束**：金融数据独立样本有限，因此有效AI必须概念简单、参数少、移动窗口优化。作者的成功案例：用Alphacet Discovery平台，仅输入日收益率和10日高低点（2个简单技术指标），50天移动窗口，感知器线性组合，获得37.93%累计收益（vs 买入持有15.77%）。

4. **策略生命周期**：没有任何策略可以永远盈利。竞争必然消灭超额收益——均值回归策略的套利机会被消除（收益率→0），惯性策略的趋势持续时间缩短（持有期→0）。每十年还有突然的重大状态转换导致策略突然死亡。

5. **实战应对**：当模型业绩不佳时，逐步降低杠杆直到零（按凯利公式），而非突然弃用。持续研发新策略是核心活动。

关键洞察：**状态转换难以准确预测，但可以检测**。用数据挖掘方法识别拐点，配合持续研发和动态杠杆调整，是对抗策略衰亡的唯一路径。

## A1 — 书中的应用 (Past Application)

### 案例 1: 用机器学习(Alphacet Discovery)预测高盛(GS)股票的状态转换 (c14)
- **问题**: 作者想预测金融行业代表GS股票的牛市/熊市拐点。
- **方法论的使用**: 
  1. 使用Alphacet Discovery平台的感知器神经网络
  2. 输入变量：GS股票日收益率 + 10日高低点（仅2个简单技术指标）
  3. 在不同持有期(1-60天)下训练
  4. 使用50天后顾移动窗口严格避免数据迁就偏差
  5. 感知器在不同持有期下对不同规则的线性权重做最优组合
- **结论**: 50天移动窗口模型最佳，6个月回测期内89次往返交易获得37.93%累计收益率，远超买入持有的15.77%（且后者挫跌4%）。
- **结果**: 回测表现优异。但作者诚实承认回测期较短，可能存在数据迁就偏差风险（虽然平台设计上避免了这一点）。

### 案例 2: 十进制报价导致统计套利策略失效 (ce14)
- **问题**: 2001年4月9日美国股票改为十进制报价，统计套利策略盈利能力大幅下降。
- **方法论的使用**: 作者识别这是一次"市场结构"类型的状态转换——十进制报价减少了价格发现过程中的摩擦，统计套利者正是从摩擦和低效中获利的。
- **结论**: 这种状态转换由政策变化导致，没有再转回之前的状态。
- **结果**: 许多依赖分数报价摩擦的统计套利策略永久失效。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **策略连续亏损**：用户的均值回归或动量策略突然出现连续亏损，怀疑市场状态已转换。
2. **预测拐点需求**：用户想判断当前策略是否即将失效，或市场即将从牛市转熊市。
3. **机器学习应用**：用户想用AI/ML预测市场状态，需要方法论指导。
4. **策略生命周期管理**：用户发现策略收益率逐年下降，想知道是竞争还是状态转换。

### 语言信号 (用户的话里出现这些就应激活)

- "我的策略突然不灵了"
- "市场状态变了吗？"
- "regime change" / "state transition"
- "怎么预测牛市熊市拐点？"
- "如何用机器学习做交易预测？"
- "策略收益率一直在下降"

### 与相邻 skill 的区分

- **与 `mean-reversion-vs-momentum` 的区别**: 本skill回答"如何预测市场从均值回归状态转为趋势状态（或反之）"，mean-reversion-vs-momentum回答"在已知状态下选哪种策略"。本skill是"何时切换策略"，后者是"选哪种策略"。
- **与 `strategy-modification-methodology` 的区别**: 本skill聚焦"市场状态变了怎么办"（宏观层面），strategy-modification聚焦"如何改进具体策略参数"（微观层面）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断策略失效的原因**
   - 完成标准: 用户能区分三种失效原因——(1)正常波动（统计噪声）(2)竞争导致利润消失（渐进性）(3)状态转换（突然性）。
   - 方法: 比较策略近期业绩与历史分布。若夏普比率在历史标准差范围内波动，为正常噪声；若逐年缓慢下降，为竞争；若突然跳变，为状态转换。
   - 判停条件: 若诊断为正常波动，返回交易并按凯利公式管理杠杆；若为竞争或状态转换，进入步骤2。

2. **选择预测方法**
   - 完成标准: 用户能回答"我用马尔可夫模型还是数据挖掘方法？"
   - 方法:
     - 若预测波动率状态转换 → 使用GARCH模型
     - 若预测均值回归/趋势状态转换 → 使用数据挖掘方法（感知器 + 后顾移动窗口）
     - 若预测监管/结构变化 → 无法用模型预测，只能持续监控新闻和政策
   - 判停条件: 若选择数据挖掘方法，进入步骤3；若选择GARCH，建议参考Klaassen(2002)；若为监管变化，进入步骤4。

3. **构建数据挖掘拐点模型**
   - 完成标准: 用户能用感知器+后顾移动窗口构建预测模型，参数数量≤5个。
   - 方法:
     1. 选择2-3个简单技术指标作为输入（如日收益率、N日高低点）
     2. 设定多个持有期（如1天、10天、60天）
     3. 使用后顾移动窗口（如50天）训练感知器
     4. 在移动窗口内严格优化，不使用任何未来数据
     5. 用样本外数据测试
   - 判停条件: 若样本外测试通过（夏普>1），可部署；否则调整参数或放弃。

4. **应对策略衰亡**
   - 完成标准: 用户能制定策略衰亡的应对计划。
   - 方法:
     - 按凯利公式逐步降低杠杆，而非突然弃用
     - 将研发新策略作为持续性核心活动
     - 在小容量策略领域寻找新的市场无效性
   - 判停条件: 计划制定完成。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯日内均值回归策略**：日内均值回归策略不依赖市场状态判断（每天都有短暂无效性可利用），不需要状态转换预测。
- **长期宏观经济预测**：本skill关注交易策略层面的状态转换，不是预测GDP、通胀等宏观指标。
- **不需要状态判断的策略**：如纯季节性策略（汽油夏季驾驶高峰）、纯高频策略（每天都有机会）。

### 作者在书中警告的失败模式

- **ce14 - 状态转换导致策略失效**: 十进制报价使统计套利策略永久失效。机制：市场效率提高，套利机会消失。
- **ce15 - 竞争导致利润消失**: 竞争使均值回归策略收益率→0，惯性策略持有期→0。
- **ce06 - 数据窥探偏差**: 用机器学习预测状态转换时，极易因参数过多或回测窗口选择产生过拟合。必须严格使用后顾移动窗口、限制参数数量。
- **pr-p2-027 - 策略终将因竞争失效**: 没有任何策略可以永远盈利。正确做法是持续研发，而非依赖单一策略。

### 作者的盲点 / 时代局限

1. **对AI方法过于悲观**: 作者承认"还没发现隐马尔可夫模型特别有用"，但2010年代后深度学习在状态识别上取得突破（如LSTM、Transformer用于时序预测）。2009年的局限性不代表2025年仍然成立。
2. **回测期过短的案例**: 作者用6个月回测期验证状态转换预测模型，统计上不足以得出稳健结论。作者自己也承认这一点。
3. **忽视了另类数据**: 书中的状态转换预测仅基于价格数据，未考虑新闻情绪、社交媒体、宏观经济指标等另类数据源的预测价值。

### 容易混淆的邻近方法论

- **状态转换预测 ≠ 市场方向预测**: 本skill预测"市场处于哪种状态"（均值回归还是趋势），不是预测"市场会涨还是会跌"。
- **状态转换 ≠ 正常波动**: 策略短期亏损可能是正常统计波动，不一定是状态转换。必须区分两者。
