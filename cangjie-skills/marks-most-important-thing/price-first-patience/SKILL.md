# 价格优先与耐心等待

## R — 原文 (Reading)

> 對市場時機沒有興趣意味著更重視價格是否便宜；希望能在低點買進是不切實際的作法。
>
> — 霍華·馬克斯，第12、13章

## I — 方法论骨架 (Interpretation)

不要先问市场何时见底，而要先问当前价格相对价值是否已经足够有利。
低价并不保证马上上涨，等待更低价格也不保证获得更好机会。
当价值判断、风险承受能力和价格关系成立时，可以用可承受规模开始行动。
用分批买入、保留现金和明确的论点失效条件，吸收价格继续下跌的可能。
持有期间定期复核价值、风险和原始论点，不把短期价格偏离自动当成失败。
耐心不是无限期死守，而是有筛选标准、有资金能力的等待。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2008 年低点前继续下跌
- **问题**: 市场已经极度便宜，但投资者仍不知道真正低点何时出现。
- **方法论的使用**: 不以准确抄底为入场前提，接受价格可能继续下跌，并把判断建立在价值和风险承受能力上。
- **结论**: 便宜不等于不会再跌，耐心和仓位容错比点位预测更重要。
- **结果**: 2009 年 3 月反转前，股价比 2008 年低点再跌约 20%，之后两年回报惊人。

### 案例 2: 2005 年提前离场
- **问题**: 作者无法确定市场何时真正结束风险积累。
- **方法论的使用**: 接受过早防守会错失部分上涨，但不把精确择时当作必要条件。
- **结论**: 在重大风险不可承受时，提前行动可能优于等待确认。
- **结果**: 2005 年退出虽非最佳时机，结果仍优于 2007 年 5 月继续留在市场。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户认为资产便宜，却因为无法确认底部而迟迟不行动。
2. 用户想把“等更低价”或“等宏观确认”作为唯一入场条件。
3. 用户已经买入便宜资产，因短期继续下跌而想立即改变长期判断。

### 语言信号 (用户的话里出现这些就应激活)

- “现在买还是等底部 / buy now or wait for the bottom?”
- “价格还会不会再跌？”
- “要不要分批买 / scale in?”
- “便宜了为什么还不上涨？”

### 与相邻 skill 的区分

- 与 `price-value-separation` 的区别: 本 skill 处理行动时点、等待和分批执行；后者先建立价值与价格的判断。
- 与 `margin-of-safety` 的区别: 本 skill 管理时间和入场节奏；后者设计更广义的价格、仓位、杠杆和组合缓冲。
- 与 `defensive-investing` 的区别: 本 skill 解决是否等待和如何逐步行动；后者管理长期组合的生存结构。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **确认价格关系**
   - 完成标准: 写出当前价格、价值范围、下行风险和买入理由；若没有可靠价值参照，停止择时讨论。

2. **制定容错式行动计划**
   - 完成标准: 明确一次投入还是分批投入、保留多少流动性、价格继续下跌时如何处理。
   - 判停条件: 若只能依靠准确底部或短期催化剂才能成立，降低仓位或等待更好的价格关系，不伪装成确定性判断。

3. **设定论点复核点**
   - 完成标准: 写出价值、基本面、流动性或风险发生何种变化时停止持有；仅因价格短期下跌不自动改判。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只要求预测具体顶部、底部或反转日期。
- 没有可估值对象、风险约束或资金期限，却要求制定买入节奏。

### 作者在书中警告的失败模式

- 把低价误认为不会再跌或即将上涨。
- 把买在最低点当成入场前提，因无法确认拐点而错过机会。
- 没有论点复核条件，却把“耐心”变成无限期持有。

### 作者的盲点 / 时代局限

- 书中强调等待和价格，但没有给出适用于所有资产的统一分批规则。
- “足够便宜”和“风险可控”仍依赖估值质量与投资者自身资金期限，不能机械迁移。

### 容易混淆的邻近方法论

- 耐心不是预测能力；本 skill 通过容错行动应对不可预测，而不是猜中拐点。
- 价格下跌不自动创造加仓理由，必须先复核价值和永久损失风险。
