# 概率分布与多情境

## R — 原文 (Reading)

> 我們一定不能只考慮未來的單一結果，而是要考量一系列的可能性，最好產生一個機率分布。
>
> — 霍華·馬克斯，第5、14、16、21章

## I — 方法论骨架 (Interpretation)

未来不是一个需要猜中的数字，而是一组可能结果。
先列出悲观、基准、乐观和尾部情境，再说明每个情境的触发条件。
概率只需达到决策所需的粗略程度，不应制造虚假的精确感。
同时看结果大小和发生概率，不能只追逐最可能的情境。
特别检查低概率但会造成永久损失或被迫卖出的结果。
若结论只有在单一故事成立时才成立，就降低仓位、增加缓冲或放弃。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2008 年危机中的极端情境
- **问题**: 市场原本把复杂信用产品和稳定融资视为可控，危机却迅速扩散。
- **方法论的使用**: 作者强调不能只看基准路径，要把违约、流动性断裂、机构倒闭和传染纳入可能分布。
- **结论**: 即使极端情境概率不高，只要损失足以摧毁资本，就必须影响仓位和结构。
- **结果**: 次级贷款冲击扩散至 CDO、退休基金、投行和汽车企业。

### 案例 2: 黑色星期一
- **问题**: 市场单日出现远超多数直觉预期的跌幅。
- **方法论的使用**: 把异常冲击作为风险分布的一部分，而不是只依据平静时期的历史样本。
- **结论**: 计划必须能承受未被精确预测的极端结果。
- **结果**: 道琼工业指数单日市值下跌 22.6%，说明尾部情境不能被模型遗漏。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户用一个宏观预测、盈利预测或增长故事直接决定买入和仓位。
2. 用户问“最可能发生什么”，却没有讨论如果预测错了会怎样。
3. 用户需要比较一个高上行、但尾部损失很大的方案。

### 语言信号 (用户的话里出现这些就应激活)

- “基准情境 / base case 是什么？”
- “如果这个预测错了 / what if I am wrong?”
- “最坏情况 / downside scenario 会怎样？”
- “概率分布 / probability distribution 怎么建？”

### 与相邻 skill 的区分

- 与 `permanent-loss-risk` 的区别: 本 skill 建立未来结果集合；后者追踪哪些路径会造成永久损失。
- 与 `margin-of-safety` 的区别: 本 skill 先描述不确定性；后者把不确定性转成折价、仓位和结构缓冲。
- 与 `cycle-positioning` 的区别: 本 skill 处理结果分布；后者判断当前处于周期的哪一段。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **定义决策变量与结果范围**
   - 完成标准: 写清要决定的是买入、持有、卖出、仓位还是资金配置，并列出至少四种合理情境。

2. **标注概率与影响**
   - 完成标准: 为每种情境给出粗略概率、触发条件和结果影响；单独标出低概率高损失情境。
   - 判停条件: 若只能写出一个情境，停止给出高确信结论，先补反方路径。

3. **把分布转成行动约束**
   - 完成标准: 说明哪些情境要求降低仓位、留现金、去杠杆、分散或放弃，并写出触发条件。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只要求报告已经发生的收益、价格或统计结果。
- 结果分布不会改变行动，且问题只是执行一条已确定的机械规则。

### 作者在书中警告的失败模式

- 用一个最喜欢的故事代替概率分布，集中押注单一路径。
- 把“最可能发生”当成“一定发生”，忽略尾部损失。
- 用一次预测成功证明长期预测能力。

### 作者的盲点 / 时代局限

- 书中没有给出统一的概率校准、基准率数据库或统计模型。
- 情境概率仍依赖判断者，主观分布可能继承原有偏见。

### 容易混淆的邻近方法论

- 多情境不是把所有可能性平均看待，而是识别会改变决策的关键分支。
- 高概率不等于低风险；尾部损失仍需交给 `permanent-loss-risk` 检查。
