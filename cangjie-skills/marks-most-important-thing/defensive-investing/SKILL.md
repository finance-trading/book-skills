# 防御优先

## R — 原文 (Reading)

> 防禦型投資人要強調的，不是把事情做對，而是不做錯的事情。
>
> — 霍華·馬克斯，第7、17、21章

## I — 方法论骨架 (Interpretation)

防御型投资把长期生存和避免永久损失放在追求最高单期收益之前。
先排除会让组合出局的结构，再在剩余范围内寻找合理回报。
低杠杆、足够流动性、分散、保守估值和安全边际共同构成防守。
防守不是拒绝风险，而是只承担不会摧毁资金目标的风险。
牛市中防守可能显得落后，这是保护成本的一部分，不应单独据此否定策略。
评价防守要跨越顺风和逆风环境，看是否保留资本与继续行动的能力。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1999 年拒绝科技泡沫
- **问题**: 巴菲特和朱利安·罗伯森因不参与科技泡沫而在当年相对落后。
- **方法论的使用**: 拒绝无法合理估值、风险补偿不足的热门资产，接受短期相对排名代价。
- **结论**: 短期落后不一定代表判断失败，可能是防守成功的成本。
- **结果**: 他们看起来表现不佳，但没有参与科技泡沫的风险暴露。

### 案例 2: 2000 至 2003 年谨慎的捐款基金
- **问题**: 一档基金五年没有投资成长股、科技股、企业收购和创业投资，繁荣期绩效落后。
- **方法论的使用**: 保持较高筛选标准，避免追逐拥挤资产，并接受相对回报不突出。
- **结论**: 防守的价值要在不同环境中评估，不能只看上涨市场。
- **结果**: 科技股崩盘期间，该基金取得约 3% 年报酬，而多数捐款基金亏损。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户为追求更高收益，准备增加杠杆、集中度或复杂结构。
2. 用户比较一个牛市收益更高但下行更脆弱的方案。
3. 用户需要设计能穿过危机、保留现金和后续选择权的长期组合。

### 语言信号 (用户的话里出现这些就应激活)

- “怎么避免一把亏光 / avoid ruin?”
- “防御型投资 / defensive investing 怎么做？”
- “为了多赚一点，值得加杠杆吗？”
- “为什么组合要留现金、分散和接受较低回报？”

### 与相邻 skill 的区分

- 与 `permanent-loss-risk` 的区别: 本 skill 将风险判断转化为组合结构和长期生存目标；后者先识别具体损失机制。
- 与 `margin-of-safety` 的区别: 本 skill 覆盖整个组合和投资生涯；后者聚焦单项决策中的错误缓冲。
- 与 `correlation-diversification` 的区别: 本 skill 是总的防守框架；后者专门检查持仓是否在压力期共同下跌。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **定义不可承受的结果**
   - 完成标准: 明确最大可承受回撤、资金期限、流动性需求和不能发生的永久损失。

2. **筛掉脆弱结构**
   - 完成标准: 检查杠杆、集中度、期限错配、共同风险来源和被迫卖出触发条件。
   - 判停条件: 若单一冲击即可导致出局，先去杠杆、降集中或增加流动性，不继续优化名义收益。

3. **在安全范围内设定合理目标**
   - 完成标准: 用低杠杆、有效分散、保守估值和合理回报目标重建组合，并说明防守成本与预期收益的取舍。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想最大化某一轮牛市收益，不关心长期资金目标或尾部损失。
- 用户把防守理解为零风险、永久持有现金或完全拒绝波动。

### 作者在书中警告的失败模式

- 用相对跑赢大盘掩盖绝对亏损。
- 只看顺风期收益，把风格暴露误认为技巧。
- 为高峰回报牺牲杠杆、流动性和错误空间。

### 作者的盲点 / 时代局限

- 防守优先可能使投资者低估低成本被动投资或长期增长暴露的价值。
- 书中没有为不同资金目标给出统一的防守比例，配置仍需结合期限和负债。

### 容易混淆的邻近方法论

- 防守不等于低波动表面；低波动资产仍可能有永久损失风险。
- 防守不等于不行动；在价格足够低且风险可承受时，防御型投资者也可以主动进攻。
