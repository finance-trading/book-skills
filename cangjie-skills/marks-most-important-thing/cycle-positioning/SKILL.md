# 周期定位

## R — 原文 (Reading)

> 我們也許從不知道要去哪裡，但最好清楚了解我們人在哪裡。
>
> — 霍華·馬克斯，第15、21章

## I — 方法论骨架 (Interpretation)

周期定位不要求知道下一次转折的日期和幅度。
它要求判断当前环境位于繁荣还是衰退、宽松还是紧缩、热还是冷。
观察资金供给、放贷标准、估值、风险容忍度和参与者行为。
当繁荣持续时，检查资本是否过剩、标准是否放松、风险补偿是否下降。
当恐慌扩散时，检查价格是否已反映过度悲观，以及是否有被迫卖出。
定位的用途是调整风险承受和行动强度，而不是替代价值分析。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2007 年信贷市场过热
- **问题**: 高收益债券和低评级贷款发行激增，CCC 债券比例异常上升。
- **方法论的使用**: 作者从融资条件和风险容忍度判断周期位置，而不是等待宏观数据确认衰退。
- **结论**: 资本过度追逐较差信用质量，说明市场已接近危险的繁荣末端。
- **结果**: 2007 年异常扩张之后，信贷市场遭遇严重打击。

### 案例 2: 2007 年私募股权收购价格
- **问题**: 收购者为公司支付的现金流倍数明显高于 2001 年。
- **方法论的使用**: 将估值、竞争程度和资金流向作为周期温度计。
- **结论**: 价格上涨不只反映基本面，也反映资金过多和风险偏好过强。
- **结果**: 2007 年支付倍数比 2001 年高 50%，随后市场严重下挫。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问“现在是牛市后段还是仍有空间”，但无法预测具体顶部。
2. 用户看到融资变容易、低质量资产大量发行或估值快速扩张。
3. 用户需要根据市场冷热调整仓位，而不是押注一个拐点日期。

### 语言信号 (用户的话里出现这些就应激活)

- “我们现在处于什么周期 / where are we in the cycle?”
- “信用周期 / credit cycle 到哪了？”
- “这次不一样 / this time is different？”
- “应该进攻还是防守？”

### 与相邻 skill 的区分

- 与 `pendulum-psychology` 的区别: 本 skill 看资金、信用、估值和供需结构；后者看群体情绪的摆动。
- 与 `contrarian-investing` 的区别: 本 skill 先定位环境；后者在极端错价和价值支持下决定是否逆向行动。
- 与 `probability-distribution` 的区别: 本 skill 判断当前状态；后者展开未来结果的多种路径。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **建立周期温度表**
   - 完成标准: 分别记录信用条件、估值、风险偏好、资金供需、资产质量和市场情绪。

2. **判定当前位置**
   - 完成标准: 将环境标为偏冷、正常、偏热或极端，并为每个判断写出证据。
   - 判停条件: 若证据互相矛盾，不预测拐点，改用中性仓位和多情境方案。

3. **调整风险承受**
   - 完成标准: 把定位转成仓位、杠杆、流动性和资产选择的变化；极热时减少脆弱暴露，极冷时研究被迫卖出的机会。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想得到一个精确顶部、底部或转折日期。
- 没有可观察的信用、估值、资金或行为信息，只凭个人感觉问市场冷热。

### 作者在书中警告的失败模式

- 把近期繁荣或衰退外推成永久趋势。
- 用“这次不一样”否认周期反转的约束。
- 发现市场很热就直接做空，忽略时点、价值和持仓承受力。

### 作者的盲点 / 时代局限

- 周期指标在不同资产类别、监管制度和市场结构中的领先性并不稳定。
- 定位只能改善风险暴露，不能保证预测方向或抓住转折。

### 容易混淆的邻近方法论

- 周期偏热不等于明天下跌；它首先是风险预算信号。
- 周期偏冷不等于任何低价资产都值得买，仍须调用 `contrarian-investing` 和价值、风险检查。
