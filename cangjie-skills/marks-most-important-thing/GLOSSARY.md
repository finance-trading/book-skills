# 《投資最重要的事》共享术语词典

> 由 Stage 1 glossary extractor 候选池整理。定义以霍华·马克斯在本书中的用法为准。

| 术语 | 本书中的含义 | 不要混淆为 |
|---|---|---|
| 第二层思考 | 同时检查结果、概率、共识、价格和预期差 | 多看几条资讯 |
| 第一层思考 | 只处理表层事实和直接结论 | 所有快速判断 |
| 市场共识 | 已经进入价格的集体预期 | 必然正确的答案 |
| 效率市场 | 资讯快速进入价格，但不保证价格永远正确 | 没有任何错误定价 |
| 实质价值 | 基于基本面和假设对资产价值的估计 | 当前市场价格 |
| 价值投资 | 先估计价值，再判断价格是否足够有利 | 只买好公司 |
| 价格与价值 | 决策核心是两者的关系，而非单看任一方 | 价格上涨趋势 |
| 风险 | 永久亏损、无法实现目标、被迫卖出或失去参与能力 | 单纯波动率 |
| 风险补偿 | 承担额外风险所要求的额外预期回报 | 高风险必然高回报 |
| 安全边际 | 价值和价格之间吸收判断错误的缓冲 | 盈利保证 |
| 景气循环 | 经济、信贷、获利和情绪的扩张收缩 | 永远延续的趋势 |
| 钟摆效应 | 群体心理在乐观和悲观极端之间摆动 | 可精确预测的周期 |
| 反向投资 | 在群体极端时寻找有价值支撑的不同动作 | 为反对多数而反对 |
| 便宜标的 | 价格相对价值足够低且风险可承受的资产 | 跌得多就一定便宜 |
| 防御型投资 | 优先避免致命错误和被迫退出 | 完全不承担风险 |
| 能力圈 | 能持续理解、验证并做出较好判断的范围 | 仅仅熟悉某个行业 |
| 概率分布 | 用多个可能结果和大致概率代替单一预测 | 精确预测未来 |
| 合理预期 | 足以满足资金用途、且不需承担不必要风险的回报 | 越高越好 |
| 跨环境能力 | 在顺风、逆风和过渡期都能控制损失并创造价值 | 单一牛市收益 |
| 结果主义 | 用结果倒推决策质量 | 正确流程的复盘 |

## 术语使用规则

1. 先区分“价值”和“价格”，再讨论是否便宜。
2. 先识别永久损失机制，再讨论波动或收益率。
3. 反向投资必须同时验证价值、价格和承受等待的能力。
4. 预测只能作为情景输入，不能成为单一方向下注的唯一理由。
