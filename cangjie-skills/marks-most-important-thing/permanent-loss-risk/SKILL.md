# 永久损失风险

## R — 原文 (Reading)

> 最重要的風險就是出現永久虧損的風險；波動性不等於大多數投資人真正關心的風險。
>
> — 霍華·馬克斯，第5章

## I — 方法论骨架 (Interpretation)

风险不是已经发生的价格变化，而是未来可能造成实质伤害的结果分布。
先问本金是否可能永久受损，再问是否会无法实现资金目标或被迫退出。
把资产风险拆成基本面恶化、杠杆、流动性、期限错配、相关性和融资条件。
低波动只说明过去价格较平稳，不能证明尾部损失小。
高波动也不自动等于永久损失；关键是下跌是否可等待、价值是否仍在、投资者是否有行动能力。
风险评估必须先于收益评估，并转化为仓位、融资和退出约束。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2007 年“风险已经消失”
- **问题**: 市场相信风险已经被分散、切割或消除，价格被推到泡沫水平。
- **方法论的使用**: 反问风险是否真的消失，检查价格、结构、尾部情境和资金链，而不是只看平静时期的表现。
- **结论**: 风险感知下降可能正是风险积累和价格过高的信号。
- **结果**: 当时被认为低风险的进入行为后来被证明是高风险行动。

### 案例 2: 次级贷款风险传染
- **问题**: 次级贷款违约先影响 CDO，再影响退休基金和贝尔斯登基金。
- **方法论的使用**: 沿着相关性、融资和流动性路径追踪局部损失如何扩散。
- **结论**: 不能只看单一资产的历史损失；系统连接可能把局部问题放大。
- **结果**: 损失从次级贷款扩散到结构化产品、退休基金和贝尔斯登基金。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户把低波动、历史不亏或高评级直接称为“安全”。
2. 用户准备使用杠杆、融资或短期限资金持有资产。
3. 用户需要评估极端情境下是否会被迫卖出或永久失去本金。

### 语言信号 (用户的话里出现这些就应激活)

- “波动率低是不是就没风险？”
- “这笔投资最坏会亏多少 / permanent loss?”
- “如果保证金上升会怎样？”
- “流动性 / liquidity 出问题时能撑多久？”

### 与相邻 skill 的区分

- 与 `second-level-thinking` 的区别: 本 skill 直接追踪损失机制；前者判断用户是否拥有超越共识的观点。
- 与 `price-value-separation` 的区别: 本 skill 识别永久损失、流动性和杠杆风险；后者判断价格是否低于价值。
- 与 `margin-of-safety` 的区别: 本 skill 先识别会造成伤害的路径；后者设计缓冲来降低这些路径的影响。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **定义损失对象**
   - 完成标准: 明确用户真正要保护的是本金、现金流、目标资金，还是继续持有的能力。

2. **画出损失路径**
   - 完成标准: 列出基本面、杠杆、流动性、期限、相关性和被迫卖出的触发条件，并覆盖至少一个压力情境。

3. **检查可承受性**
   - 完成标准: 估计最坏合理结果、持有者能否等待、是否会触发强平或资金断裂；若不可承受，降低仓位、去杠杆或放弃。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只要求计算历史标准差、贝塔或最大回撤，且没有投资行动问题。
- 讨论的是短期价格噪音，不涉及本金、流动性、杠杆或退出能力。

### 作者在书中警告的失败模式

- 把波动性等同于全部风险，忽略永久损失。
- 因为过去没有出事或模型给出低风险，就假设未来风险很小。
- 在高杠杆下把可等待的判断错误变成追加保证金和被迫卖出。

### 作者的盲点 / 时代局限

- 永久损失比波动率更贴近投资者关心的问题，但不提供统一、可重复的概率估计方法。
- 书中经验主要来自主动投资和信用周期，不能替代具体资产、账户和监管约束下的风险模型。

### 容易混淆的邻近方法论

- 风险高不等于价格一定会下跌；本 skill 识别损失机制，不负责预测方向。
- 资产低估不等于风险已消失；估值关系仍需与损失路径同时审查。
