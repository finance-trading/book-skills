# 钟摆与投资心理

## R — 原文 (Reading)

> 市場心理會在樂觀與悲觀、輕信與多疑、害怕錯失機會與害怕虧錢之間擺盪。
>
> — 霍華·馬克斯，第9章

## I — 方法论骨架 (Interpretation)

市场心理很少停在理性中点，而会在相反情绪之间过度摆动。
先识别主导情绪：贪婪、怕错过、轻信，还是恐惧、投降和怕亏损。
再判断情绪是否已经影响估值、融资条件、持仓拥挤度和卖方行为。
极端乐观通常压低风险感知并抬高价格，极端悲观则可能制造被迫卖出。
情绪本身不是买卖信号；它只告诉你要加强价格、价值和风险核查。
反应应与极端程度相匹配，而不是在情绪最强时跟随群体。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2000 年科技股泡沫
- **问题**: 技术改变世界的故事和追涨情绪推高价格。
- **方法论的使用**: 作者把“怕错过”和对高成长的轻信视为钟摆偏向乐观端的信号，并重新检查价格是否能被基本面支撑。
- **结论**: 好故事和好技术不等于任何价格都合理。
- **结果**: 科技股在没有单一触发事件时开始崩盘，许多代表性股票下跌 90% 以上。

### 案例 2: 2008 年金融危机
- **问题**: 市场从无忧无虑快速转向系统性恐惧和投降。
- **方法论的使用**: 观察情绪、流动性和机构行为共同摆向悲观端，寻找价格是否已被恐慌压低。
- **结论**: 情绪极端会同时暴露风险，也可能产生错价机会。
- **结果**: 金融机构接管或获援助，不良债券在随后成为反向投资机会。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户因 FOMO、社交媒体热度或“人人都赚钱”准备追价。
2. 用户因恐慌新闻、连续下跌或群体投降准备不加区分地卖出。
3. 用户需要判断市场情绪是在合理区间，还是已经摆向极端。

### 语言信号 (用户的话里出现这些就应激活)

- “大家都在买 / everyone is buying。”
- “我怕错过 / FOMO。”
- “是不是已经完了 / is everything collapsing?”
- “市场情绪 / market sentiment 到什么程度？”

### 与相邻 skill 的区分

- 与 `cycle-positioning` 的区别: 本 skill 诊断情绪极端；后者综合信用、估值和资金条件判断周期位置。
- 与 `contrarian-investing` 的区别: 本 skill 识别钟摆和心理压力；后者决定是否有足够价值与价格支持采取反向行动。
- 与 `second-level-thinking` 的区别: 本 skill 关注群体情绪；后者检查共识、预期差和自己是否更可能正确。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **命名主导情绪**
   - 完成标准: 明确市场主要由贪婪、怕错过、轻信、恐惧、怀疑或投降中的哪一种驱动。

2. **寻找极端证据**
   - 完成标准: 检查估值、追涨行为、融资条件、拥挤度、新闻叙事和被迫交易是否共同指向同一端。
   - 判停条件: 若只有一条情绪化新闻，没有跨来源证据，不判定钟摆已到极端。

3. **交给价值与风险核查**
   - 完成标准: 极端乐观时降低盲目追价，极端悲观时筛查有价值的错价；行动前调用 `contrarian-investing`、`price-value-separation` 或 `permanent-loss-risk`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只要求估值、财报或历史价格，不涉及群体行为和情绪驱动。
- 没有市场参与者行为证据，只把个人焦虑当成市场钟摆。

### 作者在书中警告的失败模式

- 在人气最高时买入，或在恐慌最低点卖出。
- 把“大家都错”当作自动交易信号。
- 把反向身份本身变成新的群体共识。

### 作者的盲点 / 时代局限

- 情绪极端的识别依赖叙事、行为和经验，缺少统一可复现的量表。
- 信息传播速度和社交媒体结构变化后，钟摆的持续时间可能不同于书中案例。

### 容易混淆的邻近方法论

- 情绪很强不等于价格一定错误；必须转交价值和风险分析。
- 恐慌不是永远的买入机会，若资产价值已永久受损，应使用 `permanent-loss-risk`。
