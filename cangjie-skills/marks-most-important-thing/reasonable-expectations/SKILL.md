# 合理预期与风险预算

## R — 原文 (Reading)

> 我需要八％的報酬，但我不會試著賺更多，因為這樣得承擔我不願承擔的風險。
>
> — 霍華·馬克斯，《投資最重要的事》第20章

## I — 方法论骨架 (Interpretation)

投资目标不是越高越好，而是要先判断什么结果已经足够满足资金用途。
超过“够用”之后，每增加一点预期回报，通常都要付出更多集中、杠杆、流动性或预测风险。
因此先设定最低可接受结果，再反推允许的风险预算。
如果方案必须依赖极端乐观假设才能达标，目标或方案就不稳健。
合理预期不是降低标准，而是避免为了不必要的收益把整个组合暴露给致命损失。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2007 年高收益资产发行激增
- **问题**: 市场在繁荣期不断追求更高收益，低评级贷款和高收益债券发行激增。
- **方法论的使用**: 作者把新增收益与新增杠杆、信用恶化和流动性风险一起看。
- **结论**: 仅因收益率更高就扩大风险预算，是把目标收益误当成免费午餐。
- **结果**: 随后的信用危机证明，额外收益并未补偿尾部损失。

### 案例 2: 个人只需要 8% 回报
- **问题**: 投资者为了超过实际资金需求而追求 20% 回报。
- **方法论的使用**: 先比较资金目标和实现更高回报所需承担的风险。
- **结论**: 目标已足够时，不应继续增加不愿承受的风险。
- **结果**: 该框架把“赚更多”改成“用可承受风险达到目标”。

## A2 — 触发场景 (Future Trigger) ★

1. 用户设定了很高的年化收益目标，但没有说明资金用途和可承受亏损。
2. 用户在比较两个方案，较高收益方案明显依赖杠杆或集中持仓。
3. 用户问“为了多赚几个百分点，是否值得承担这些风险”。

### 语言信号

- “年化 20% 合理吗？”
- “为了更高收益要不要加杠杆？”
- “回报够用就好是什么意思？”
- “reasonable return / risk budget”

### 与相邻 skill 的区分

- 与 `permanent-loss-risk` 的区别：本 skill 先校准目标和风险预算，后者识别损失机制。
- 与 `defensive-investing` 的区别：本 skill 判断目标是否过高，后者设计生存优先的组合结构。

## E — 可执行步骤 (Execution)

1. **定义资金用途和最低够用结果**
   - 完成标准：写出期限、目标金额和最低可接受年化回报。
2. **列出达成目标所需的风险**
   - 检查杠杆、集中度、流动性、估值和尾部假设。
   - 判停条件：若目标只靠不可验证的乐观情境成立，降低目标或放弃方案。
3. **比较新增收益与新增风险**
   - 完成标准：明确说明多出来的收益是否足以补偿可能的永久损失。
4. **设定风险上限并执行**
   - 完成标准：形成仓位、杠杆和最大可接受损失规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问某个资产的当前价格或估值，不涉及目标回报与风险交换。
- 用户进行明确的短线赌博，且没有长期资金目标。

### 作者警告的失败模式

- 为满足过高目标而不断加杠杆。
- 把稳定高收益当成没有风险。
- 用相对排名掩盖绝对亏损。

### 作者的盲点 / 时代局限

- “够用”取决于个人负债、税务、通胀和生命周期，不能直接套用作者示例。
- 低利率或高通胀环境可能改变合理回报区间。

### 容易混淆的邻近方法论

- 合理预期不是承诺收益率，也不是市场预测。
