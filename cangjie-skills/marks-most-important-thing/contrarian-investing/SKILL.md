# 反向投资

## R — 原文 (Reading)

> 只與群眾做出相反的事是不夠的……你必須根據理性和分析，確認是否有潛在獲利的可能。
>
> — 霍華·馬克斯，第11章

## I — 方法论骨架 (Interpretation)

反向投资的对象不是“多数人”，而是多数人造成的错误定价。
先识别群体为何卖出或买入，再判断这个理由是否夸大、已被价格过度反映。
确认资产仍有可分析的价值、风险可承受、价格提供足够补偿。
检查是否存在被迫卖出、融资限制、污名或机构规则造成的非基本面供需。
只有当自己能解释群众错在哪里，逆向行动才有逻辑。
执行时接受价格可能继续不利，使用分批、低杠杆和足够流动性等待验证。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2008 年第四季不良债券
- **问题**: 恐慌和流动性需求使不良债券成为多数投资人不愿碰的资产。
- **方法论的使用**: 作者先确认价格、违约风险和回收价值，再利用被迫卖出造成的错价，而不是把“不受欢迎”当作理由。
- **结论**: 群体的约束可能制造价格低于可支持价值的机会。
- **结果**: 这些债券十八个月后取得 50% 至 100% 甚至更高的回报。

### 案例 2: 巴菲特在 1973 至 1974 年熊市买入
- **问题**: 市场被空头和恐惧压低，普遍投资者不愿承担买入风险。
- **方法论的使用**: 在价值判断和安全边际仍成立时，逆着悲观情绪买入。
- **结论**: 恐惧可以制造机会，但必须由价值和价格关系支持。
- **结果**: 作者将巴菲特的熊市逢低买入作为防御转进攻的实例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户关注被污名化、冷门、遭遇赎回或机构被迫出售的资产。
2. 用户问“所有人都在卖，是不是反而应该买”。
3. 用户看到极端悲观，但仍能建立价值底线和持有期限。

### 语言信号 (用户的话里出现这些就应激活)

- “反向投资 / contrarian investing 值得吗？”
- “大家都在卖 / everyone is selling。”
- “这是被迫卖出 / forced selling 吗？”
- “我是在接住刀子 / catching a falling knife 吗？”

### 与相邻 skill 的区分

- 与 `pendulum-psychology` 的区别: 后者识别情绪摆向极端；本 skill 判断是否有价值支撑的反向交易。
- 与 `price-value-separation` 的区别: 本 skill 从群体错误和供需压力出发；后者系统估计价值与价格差。
- 与 `permanent-loss-risk` 的区别: 本 skill 寻找反向机会；后者先排除永久损失、杠杆和流动性陷阱。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **重建群体行动**
   - 完成标准: 写明多数人在买还是卖、驱动因素是什么、是否有被迫交易或制度约束。

2. **证明群众可能错在价格**
   - 完成标准: 给出保守价值、价格折价、价值底线和与共识不同的因果解释。
   - 判停条件: 若唯一理由是“大家都错”或“跌了很多”，停止逆向结论。

3. **设计能等待的仓位**
   - 完成标准: 检查永久损失、杠杆、流动性、继续下跌空间和持有期限；通过后才决定分批买入、观察或放弃。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户没有具体资产、价格或群体行为，只想讨论“逆向思维”概念。
- 资产价值已明显永久受损，或买入依据只有跌幅、冷门标签和媒体悲观。

### 作者在书中警告的失败模式

- 把反向投资机械化为“多数买就卖、多数卖就买”。
- 把价格过高等同于明天就会下跌，无法承受长期逆风。
- 因为“反向”很流行，就把反向标签当成独立优势。
- 为了等所有不确定性消失而错过最便宜的阶段。

### 作者的盲点 / 时代局限

- 反向投资高度依赖估值、信息质量和资本耐心，普通投资者未必具备同等研究与融资条件。
- 被迫卖出和价值回归的持续时间没有稳定时钟，历史案例不能保证重复。

### 容易混淆的邻近方法论

- 便宜不等于反向机会；先排除价值陷阱和永久损失。
- 情绪极端只启动研究，不自动产生买入信号。
