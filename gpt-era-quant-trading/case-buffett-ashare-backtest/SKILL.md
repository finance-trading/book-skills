## R 原文

> "①回测区间：从2010年6月到2022年12月，初始投入10万元，每次买入一手。
> ②选股标准：近5年净资产收益率大于20%；近5年公司毛利率大于40%；近5年公司净利率大于5%。
> ④止盈止损标准：市盈率低于20倍就买入，高于40倍就卖出，不符合选股标准的就卖出。
> 忽略市场波动，赚企业价值回报的钱，获得的年化收益十分接近巴菲特在美股的投资。"
> ——《GPT时代的量化交易》第2.1.3节（约120字）

## I 方法论骨架

巴菲特A股量化策略将巴菲特的价值投资理念转化为**四个可机械执行的量化指标**，实现系统化选股和自动化买卖。

方法论五层结构：

1. **质量筛选（三道门）**：用ROE>20%、毛利率>40%、净利率>5%三个指标过滤全市场股票。三个指标分别衡量资本回报效率（ROE）、核心竞争力和定价权（毛利率）、成本控制和盈利转化能力（净利率）。"近5年"的时间窗口避免短期利润虚高，确保持续性。

2. **估值买入信号（PE<20）**：市盈率低于20倍代表股价相对偏低，是买入时机。A股历史底部市盈率中位数约在16-28倍之间，20倍是一个相对保守的安全边际门槛。

3. **估值卖出信号（PE>40）**：市盈率超过40倍说明股价已被明显高估，此时获利了结。止盈范围（20倍→40倍）意味着允许股价翻倍后才卖出，体现"赚企业价值成长的钱"而非短期价差。

4. **基本面恶化强制卖出**：如果持仓股票不再满足ROE/毛利率/净利率标准，无论市盈率如何都必须卖出——这是价值投资纪律的关键，防止抱着"便宜"的烂股不放。

5. **低频操作（年度调仓）**：每年交易一次，交易成本极低，且避免了频繁操作带来的情绪干扰和过度交易。

## A1 书中应用

**案例：巴菲特量化策略A股回测（2010年6月-2022年12月）**

- 背景：书中以A股市场为标的，将巴菲特的四项核心指标转化为可编程的量化选股和买卖规则，进行长达12.5年的历史回测。初始资金10万元，覆盖了2015年股灾、2018年熊市、2020年新冠冲击等多个极端市场环境。
- 行动：每年扫描全A股，筛选出近5年ROE>20%、毛利率>40%、净利率>5%的股票；对入选股票，当PE<20倍时买入一手；当PE>40倍或股票不再达标时卖出；每年执行一次，不做其他主动操作。
- 结果：获得的年化收益"十分接近巴菲特在美股的投资表现"。书中将此作为基本面量化策略的核心实战案例，验证价值投资的量化可行性，以及巴菲特选股逻辑在中国市场的迁移有效性。

## A2 触发场景

**适合引用本案例的情形：**

1. **论证巴菲特价值投资在A股可以量化复制**：当对方认为"巴菲特方法只适合美股"或"价值投资在A股不管用"时，以12.5年回测数据反驳。
   触发词：巴菲特A股 / value investing China / 价值投资A股有效

2. **介绍具体的量化选股指标体系**：需要给非专业投资者解释"怎么量化选股"时，ROE/毛利率/净利率/PE四指标组合是最易理解的入门示范。
   触发词：选股指标 / stock screening / 量化选股入门

3. **说明基本面指标的时间窗口设计**：讨论回测中"用历史数据的哪段时间"时，用"近5年均值"而非单年数据作为选股条件的设计理由。
   触发词：指标时间窗口 / look-back period / 多年均值选股

4. **止盈止损规则设计**：PE20/40的买卖点是一个清晰的量化止盈止损规则，适合在策略设计讨论中作为基本面止盈止损的参考模板。
   触发词：止盈止损 / exit rules / PE买卖点

5. **价值投资量化化的入门教学**：本案例是书中基本面量化章节的压轴实战案例，适合在量化入门课程或价值投资量化化的教学场景中使用。
   触发词：基本面量化入门 / fundamental quant 101 / 价值投资量化

## E 可执行步骤

1. **确认场景匹配**：确认讨论涉及A股价值选股、巴菲特方法迁移、量化指标体系设计或基本面买卖规则。
2. **给出背景定位**（1-2句）：2010年6月至2022年12月，12.5年A股回测，初始10万元，年度调仓，覆盖多轮牛熊。
3. **描述三道选股门**（1-2句）：近5年ROE>20%（盈利持续性）、毛利率>40%（竞争护城河）、净利率>5%（成本管理），三指标同时满足才入选。
4. **描述PE买卖规则**（1句）：PE<20倍买入，PE>40倍卖出，不达标直接卖出；每年执行一次。
5. **引用结果**（1句）：年化收益十分接近巴菲特在美股的实际投资表现。
6. **说明设计逻辑**（1句）：五年窗口避免单年利润虚高，PE20/40区间"赚企业价值成长的钱"而非短期博弈。
7. **映射到当前讨论**（1句）：将案例与当前的选股策略设计、回测方法或指标选取挂钩。
8. **完成标准**：对方能复述三道选股门和PE买卖规则，并理解"年度调仓"对降低交易成本和情绪干扰的作用。

## B 边界

**不适合使用本案例的场景：**
- 追求20%以上年化收益——该策略目标是"接近巴菲特美股收益"（约20%/年），不是超额高收益策略。
- 高频或短线交易场景——年度调仓完全不适用于任何短期交易需求。
- 新兴行业/科技股选股——ROE>20%和毛利率>40%的门槛会自动过滤大多数处于投入期的科技公司，不适合成长股选股场景。
- 当前市盈率普遍偏高的市场环境——如果全市场PE普遍在40倍以上（如科创板），PE<20的买入条件可能长时间无法触发。

**作者警示的失败模式：**
- 书中明确警示"低市盈率并不总是意味着更高的投资收益率"——PE<20只是必要条件，不是充分条件，必须与三道质量门联合使用，单独用PE低买入会落入"价值陷阱"。
- 财务数据可能存在"猫腻"：高财务杠杆可以人为提高ROE，而不反映真实盈利能力。2018年前后A股大量爆雷公司与过高负债有关——使用ROE时需同时检查资产负债率，防止高杠杆虚增ROE。
- "基本面恶化不卖"是最常见的实操失误：当持仓股票ROE或毛利率开始下滑时，很多投资者会以"暂时性"为由拖延卖出，导致拿着恶化的标的等待反转。

**盲点：**
- 书中未披露回测的具体年化收益数字，只说"十分接近巴菲特在美股的投资表现"——这是一个相对描述，不是绝对数字，引用时需注意。
- 12.5年回测以2010年为起点，A股在2010年整体估值处于相对合理区间，不同起点（如2007年高估时入场）的回测结果可能差异显著，存在起点选择偏差。
- 10万元初始资金、每次买入一手的设定意味着资金分散有限，在持仓集中时面临个股黑天鹅风险；大资金复制时需要调整持仓分散策略。
- 回测假设了完美的历史数据可用性，但实际操作中，A股2010年前5年的可靠财务数据（2005年以前）质量存疑，近5年ROE的可靠性有历史数据局限。
