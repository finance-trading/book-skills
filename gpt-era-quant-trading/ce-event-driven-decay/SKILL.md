## R — 原文

> "随着事件驱动量化交易策略的使用者越来越多，这类策略的可使用时间也变得更加短暂，以前可以维持几天的上涨，而现在则普遍出现了资金'一日游'的现象，这就需要使用这一策略的量化交易者具备更高维度的逻辑与判断力。"
>
> — §2.5（事件驱动量化交易策略边界条件）

## I — 方法论骨架

事件驱动策略的alpha来源是信息优势：在市场尚未充分反映某个事件（如业绩公告、并购消息、
政策出台）时，率先建仓，等待市场追随定价，从中获利。
这个alpha来源有内在的自我消除机制：
策略越有效 → 使用者越多 → 所有人同时追进 → 拥挤效应出现 →
事件发生时大量资金同时入场 → 价格在事件当天就完全反应 → 次日无法持续。

这就是"策略拥挤导致alpha衰减"（strategy crowding decay）的完整机制。
结果是：原本可以持仓3-5天的事件驱动行情，被压缩到1天甚至当天，
策略需要用更精准的时机判断（在哪个小时入场、哪个时点出场）来维持盈利。
这提升了策略的技术门槛，同时增加了执行失误的风险。

与ce12（动量策略在无序市场失效）的区别：
ce12是市场状态变化导致的外生失效；ce14是策略参与者增多导致的内生衰减。
前者随市场状态改善可能恢复；后者在策略广泛普及后通常不可逆。

## A1 — 书中应用

书中§2.5在介绍事件驱动策略时，直接指出了其内生的衰减机制：
早期事件驱动策略因使用者少，可以在事件发生后持续受益数天，获得稳定的超额收益。
随着量化交易的普及，越来越多的资金开始使用相同的事件驱动逻辑。
结果是：市场对事件的反应时间从数天压缩至1天，甚至出现"当天涨停、次日开盘即跌"的模式。
这意味着持仓超过1天的事件驱动策略已经无法产生稳定收益，
策略窗口期的压缩要求使用者在判断时机上具备更高维度的能力——
不只是"什么事件值得交易"，还要精确判断"在事件反应的哪个时间节点入场和出场"。

## A2 — 触发场景

1. 事件驱动策略的持仓平均获利时间从历史的3天以上缩短至1天以内时触发。
   信号词：window compression / 窗口期压缩、event alpha shrinking / 事件alpha缩减。

2. 策略回测中，近1年的表现明显差于3年前的同类事件样本时触发。
   信号词：out-of-sample degradation / 样本外表现恶化、recent underperformance / 近期表现差。

3. 同类事件的市场反应速度（从事件公告到价格调整完成的时间）持续缩短时触发。
   信号词：faster market reaction / 市场反应加速、efficient market improving / 市场效率提升。

4. 策略的同类竞争者数量显著增加（通过拥挤度指标或市场观察评估）时触发。
   信号词：crowded trade / 拥挤交易、too many players / 参与者过多。

5. 策略依赖"公开已知事件"（如财报日期、已公告政策）而非独家分析优势时触发。
   信号词：public event calendar / 公开事件日历、no proprietary edge / 无专有优势。

## E — 可执行步骤

1. 测量策略窗口期的历史变化：将同类事件按年份分组，计算每年平均持仓获利天数，
   绘制时间趋势图。完成标准：趋势图完成，窗口期变化趋势清晰量化。

2. 评估当前策略的有效窗口期：基于最近12个月数据，估计当前事件类型的有效持仓时间。
   若有效窗口期 < 2天，标记为"高拥挤风险"。
   完成标准：有效窗口期估计值记录，有分类标签（低/中/高拥挤）。

3. 调整策略为短窗口操作：若窗口期已压缩至1天，重新设计进出场时机规则，
   从"事件当天收盘买入、持有3天"调整为"事件前预判建仓、事件当天高开出场"。
   完成标准：新规则有回测验证，与旧规则的收益对比完成。

4. 寻找"更高维度"的事件判断维度：按书中建议，分析哪些维度可以在拥挤的事件中
   区分出真正有持续性的行情（如事件配合量能、行业资金流、主力资金动向）。
   完成标准：至少提出2个额外维度，并有数据验证。

5. 定期监控策略拥挤度：使用因子IC衰减速度、换手率异常、同类策略表现对比等
   作为拥挤度代理指标，每月评估一次。
   完成标准：拥挤度监控指标已建立，有月度报告格式。

6. 建立策略退出或迁移计划：预先定义"策略衰减到何种程度时停止使用"的标准，
   以及退出后的资金迁移方向（新事件类型或其他策略）。
   完成标准：退出标准有文字定义，迁移方向已初步规划。

## B — 边界

**不适用场景：**
- 依赖独家信息优势或专有数据的事件驱动策略，拥挤效应较弱，
  本反例适用于依赖公开事件信息的通用型事件驱动策略。
- 新兴市场或细分市场中，参与者仍然较少，窗口期尚未被大幅压缩，
  本反例的紧迫性较低，但仍是未来需要关注的趋势。

**作者警告的失败模式：**
- 以历史回测的长窗口期参数运营已进入拥挤状态的事件驱动策略，高估实际盈利空间。
- 在策略表现下降时，以"市场短期异常"解释，而非检查是否已进入结构性衰减。
- 在"一日游"市场中仍按"持仓3天"的旧规则操作，次日面临反转时才意识到规则需要更新。

**盲点：**
- 策略衰减的速度难以预测，有时衰减是渐进的（每年性能小幅下降），
  有时是跳跃式的（监管或市场结构变化触发）；本反例提供监控框架，但不能预测衰减时点。
- 某些事件类型（如超预期的突发事件）天然不会被策略拥挤，
  因为无法预判，不适用本反例的拥挤机制分析。
