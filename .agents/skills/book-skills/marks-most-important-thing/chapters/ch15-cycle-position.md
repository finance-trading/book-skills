# Chapter 15: 察觉所在的景气位置

## Core Idea
你也许不知道要去哪，但得知道你在哪。判断自己在周期的哪一段，比精确预测拐点更现实。

## Frameworks Introduced
- **周期定位**: 找位置，不抓时点
  - When to use: 决定要进攻还是防守时
  - How: 观察人群态度、资金供需、风险容忍、估值温度

## Key Concepts
- **热度**: 市场偏乐观还是偏恐惧
- **反转前的极端**: 越极端越危险
- **检查清单**: 用固定问题判断市场热不热

## Mental Models
You cannot know the turn, but you can know whether the room is overheated.

## Anti-patterns
- **把今天的趋势当成明天的常态**
- **在高点继续加速冒进**

## Worked Example
当大家只担心错过机会、而不担心亏损时，市场通常已经很热；反过来，当大家只担心亏损时，机会更可能出现。

## Key Takeaways
1. 位置判断比点位预测更可行。
2. 热的时候小心，冷的时候积极。
3. 周期极端常常先于心理极端。
