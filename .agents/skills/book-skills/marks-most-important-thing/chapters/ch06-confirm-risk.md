# Chapter 6: 确认风险

## Core Idea
了解“风险是什么”还不够，你还要看清风险会如何出现在现实中。很多危险不是来自均值，而是来自尾部和极端情况。

## Frameworks Introduced
- **风险确认**: 识别最坏会怎样，以及它是否可承受
  - When to use: 结构复杂、杠杆存在、或者历史很平静时
  - How: 追问极端情境、压力情境和连锁反应

## Key Concepts
- **尾部风险**: 少见但破坏力大的结果
- **想像力不足**: 想不到结果分布的全范围
- **过度自信**: 让风险看起来比实际小

## Mental Models
Do not ask only “what is likely?” Ask “what if the unlikely happens and then cascades?”

## Anti-patterns
- **只按常态分布想问题**
- **把过去没有出事当成未来也不会出事**

## Worked Example
房价长期平稳时，大家以为全国性下跌不会发生，于是把原本保守的放贷规则放松，结果尾部风险一次兑现。

## Key Takeaways
1. 风险常在平静期积累。
2. 最坏情况常来自你没想过的连锁反应。
3. 历史没发生过，不等于不会发生。
