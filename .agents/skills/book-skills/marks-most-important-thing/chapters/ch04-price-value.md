# Chapter 4: 找出价格与价值的关系

## Core Idea
真正决定成败的，不是你买了什么，而是你付了多少。好东西买贵了，也会变成坏投资。

## Frameworks Introduced
- **价格/价值关系**: 价格必须显著低于价值才有吸引力
  - When to use: 每一次买卖决策
  - How: 先估值，再看折价，再决定是否值得出手

## Key Concepts
- **公平价值**: 没有偏差的合理价格
- **低价买进**: 最可靠的获利方式
- **心理面**: 会短期压过基本面
- **技术面**: 供需、资金流、被迫卖出

## Mental Models
Think of price as the vote and value as the count. Votes swing faster than counts change.

## Anti-patterns
- **不看价格就买**
- **因为资产“好”就默认值得拥有**

## Worked Example
漂亮五十股票看起来都是好公司，但在高倍数时买入后，估值回落比公司本身好坏更致命。

## Key Takeaways
1. 买得好比买得对更重要。
2. 价格偏离价值时，机会和风险都会放大。
3. 价格高不等于下一秒就跌，但风险已经更大。
