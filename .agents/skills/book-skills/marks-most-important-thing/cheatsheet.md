# quick reference

## 决策规则

| 情况 | 行动 |
|---|---|
| 市场已经把好消息全买进 | 不追价，等更好价格 |
| 资产无人喜欢但价值没坏 | 重点看，必要时逆向买入 |
| 估值看起来“好到不像真的” | 先怀疑，再验证 |
| 需要靠预测才能成立 | 降低仓位或放弃 |
| 需要加杠杆才能勉强达标 | 重新设目标 |
| 没有安全边际 | 不买 |
| 没有时间研究 | 选择更防守的结构 |
| 组合在下跌时会被迫卖出 | 先修结构，不先求收益 |

## 记住这几条

- 价格低于价值才是买点。
- 风险里最重要的是永久亏损和被迫卖出。
- 预测可以参考，不能依赖。
- 周期和钟摆不会直线走完。
- 便宜往往来自厌恶、恐慌、错配和被迫卖出。
- 真正的技巧是少亏、活久、等机会。

## 常见误判

| 误判 | 更好的问法 |
|---|---|
| “这家公司不错” | “我是不是买贵了？” |
| “这次不一样” | “历史和激励为什么会失效？” |
| “大家都在买” | “价格里还剩多少上行？” |
| “模型说没问题” | “极端情境下会怎样？” |
| “我能预测” | “我能承受预测错多少？” |
| “高回报很合理” | “为什么这笔机会轮到我？” |

## 组合原则

1. 先定义不能承受的损失。
2. 再定义可接受的报酬。
3. 用价格、分散、流动性和杠杆去约束结果。
4. 多头时别把防守扔掉。
5. 空头时别把勇气扔掉。
