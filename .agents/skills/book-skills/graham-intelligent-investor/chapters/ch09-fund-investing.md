# 第9章：基金投资

## Core Idea
投资基金是防御型投资者替代自行构建股票组合的合理选择，但投资者必须了解基金的业绩局限性——大多数基金不能持续击败市场。

## 投资基金的优点
- 专业管理：由经验丰富的专家管理，适合没有时间或能力自行选股的投资者
- 分散化：自动实现广泛的分散投资
- 便利性：买卖方便，管理成本相对较低
- 适合防御型投资者：作为替代自行构建股票组合的做法

## 投资基金的局限
- 大多数投资基金不能击败市场，尽管拥有经验丰富的专家
- 基金追逐"业绩"导致的一些令人担心的后果
- 1969-1970年市场下跌中，基金大量介入高度投机且价值明显高估的股票

## 投资建议
- 防御型投资者可以选择一只地位稳固的投资基金
- 也可以利用信托公司或银行经营的"共同信托基金"或"混合基金"
- 如果资金规模较大，可以聘请知名的投资咨询公司
- **关键**：不要期望基金能获得超越市场的优异表现，合理预期是获得市场平均回报
