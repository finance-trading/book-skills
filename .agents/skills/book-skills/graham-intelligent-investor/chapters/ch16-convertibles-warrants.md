# 第16章：可转换证券及认股权证

## Core Idea
可转换证券和认股权证是包含投机成分的混合证券，普通投资者应谨慎对待，除非充分理解其条款和风险。

## 可转换证券
- **定义**：可以在特定条件下转换为普通股的公司债券或优先股
- **优点**：提供固定收益的同时保留了参与股票上涨的机会
- **风险**：转换条款可能不利，强制转换可能导致损失
- **适用场景**：当投资者看好公司但希望获得下行保护时

## 认股权证
- **定义**：赋予持有人在特定时间内以特定价格购买公司股票的权利
- **投机特征**：高杠杆、高风险，本质上是一种投机工具
- **风险**：如果股价未达到行权价，权证可能变得一文不值
- 格雷厄姆认为，普通投资者应避免投资认股权证

## 核心建议
- 普通投资者应优先选择简单的投资工具——普通股和债券
- 只有在充分理解复杂证券的条款和风险后才考虑投资
- 可转换证券可以作为一种折中方案，但需要仔细评估转换条款
- 认股权证本质上具有投机性，不适合保守投资者
