# 第6章：积极型投资者的证券组合策略：被动的方法

## Core Idea
积极型投资者若采用"被动"方法，核心是寻找被市场忽视的低估证券。格雷厄姆对大多数流行的积极投资策略持怀疑态度，但承认某些特定方法在过去有效。

## 被动的积极策略
- **低价股/低市盈率选股**：寻找那些因无人关注或毫无根据的普遍偏见而受到低估的股票
- **廉价证券（bargain issues）**：售价低于净流动资产（营运资本）本身的价值的股票
- 1957年市场上约有200只这样的股票，平均年收益率远高于其他方式

## 成长股投资的陷阱
- 事先发现成长行业和公司并不像事后看到的那么简单
- 即使专家，也没有可靠的方法挑出前景光明的行业中最佳的公司
- 航空业案例：业务收入不断增长，但利润十分不稳定，1970年亏损2亿美元
- 基金对IBM的投资不到3%，即使IBM表现优异，也不能使整体业绩增加多少

## 两条教训
1. 一个行业显而易见的业务增长前景，并不一定会为投资者带来显而易见的利润
2. 即使是专家，也没有什么可靠的方法挑出前景光明的行业中最有前途的公司
