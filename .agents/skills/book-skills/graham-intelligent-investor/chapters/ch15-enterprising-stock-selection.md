# 第15章：积极型投资者的股票选择

## Core Idea
积极型投资者应寻找被市场忽视或低估的廉价证券，其中最极端的形式是净流动资产价值（NCAV）策略——购买股价低于净流动资产价值的股票。

## 净流动资产价值（NCAV）策略
- **定义**：流动资产 - 总负债，不包括固定资产的价值
- **买入条件**：股价低于NCAV（即低于净流动资产价值）
- **极端保守**：相当于免费获得固定资产
- **历史表现**：1957年市场上有近200只这样的股票，平均年收益率远高于其他方式
- 1970年股市低点，这类股票再次大批涌现

## 积极型投资者的选股策略
1. **低市盈率股票**：寻找市盈率显著低于市场平均水平的股票
2. **低于营运资本的股票**：寻找股价低于净流动资产价值的极端低估股票
3. **特殊情形**：并购套利、资产清算、保护性对冲
4. **被忽视的股票**：因无人关注或毫无根据的偏见而受到低估的股票

## 关键原则
- 除非投资者能从中获得比平均水平高出5%以上的税前收益，否则不值得费心费力
- 要想通过买入一只受忽视因而被低估的股票赚钱，通常需要长期的等待和忍耐
- 分散化投资于一组被低估的股票，而非押注于少数几只
