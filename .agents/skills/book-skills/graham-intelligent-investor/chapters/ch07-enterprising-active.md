# 第7章：积极型投资者的证券组合策略：主动的方法

## Core Idea
积极型投资者要想持续获得优于平均业绩的机会，必须遵循两种策略：①具有内在稳健性和成功希望的策略；②在华尔街并不流行的策略。

## 主动的积极策略

### 1. 特殊情形（Special Situations）
- 包括不同证券的交叉套利、资产清算、某些种类的保护性对冲
- 最典型的是即将发生的并购，并购方往往提出比公告日股价高出相当幅度的报价
- 驾轻就熟的老手只需承担最低风险，即可在多年内获得20%以上的年收益率
- **风险**：随着并购交易成倍增加，面临障碍也成倍增长，导致许多交易流产

### 2. 廉价证券（Bargain Issues）
- 特征：售价低于净流动资产（营运资本）本身的价值（不包括厂房等资产，扣除优先债务）
- 任何私人业主或大股东，都不会在如此荒谬的低价出售其拥有的股份
- 1970年股市低点，这类股票再次大批涌现
- 构成一个完整的投资组合的足够数量

### 3. 被低估的证券
- 大量上市交易的证券中一定包含相当多被低估的证券
- 除非投资者能从中获得比平均水平高出5%以上的税前收益，否则不值得费心费力

## 核心原则
- 要想通过买入一只受忽视因而被低估的股票赚钱，通常需要长期的等待和忍耐
- 卖空一只过去热门因而被高估的股票，不仅是对卖出者胆略和毅力的考验，也是对其财力的考验
- 这种投资原则是稳健的，其成功的运用也并非不可能，但它绝不是一种可以轻易掌握的技术
