# 第18章：对八组公司的比较

## Core Idea
通过对八组公司的对比分析，展示行业分析和对公司比较的方法论，帮助投资者识别哪些公司值得投资。

## 比较分析方法
1. **盈利能力比较**：比较各公司的利润率、资本回报率、利润增长率
2. **财务稳健性比较**：比较负债率、流动比率、利息覆盖倍数
3. **估值水平比较**：比较市盈率、市净率、股息率
4. **市场表现比较**：比较股价的历史波动和相对表现

## 关键发现
- 同行业公司之间的差异可能大于不同行业之间的差异
- 财务稳健的公司通常在市场下跌时表现更好
- 低市盈率股票在长期中系统性地跑赢高市盈率股票
- 持续支付股息是公司财务健康的重要标志

## 实践意义
- 投资者应进行系统性的公司比较，而非随机选择
- 选择一组具有相似特征的股票进行比较更有意义
- 比较分析应同时关注定量因素和定性因素
- 历史表现不能预测未来，但可以提供有价值的参考
