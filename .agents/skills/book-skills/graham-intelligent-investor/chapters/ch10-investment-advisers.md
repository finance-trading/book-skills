# 第10章：投资者与投资顾问

## Core Idea
投资者需要明智地选择和管理投资顾问，了解何时需要专业帮助，何时不需要。

## 投资顾问的角色
- 投资顾问可以提供专业分析和建议，帮助投资者避免常见错误
- 并非所有顾问都值得信赖，投资者需要保持批判态度
- 最终决策权应始终在投资者自己手中

## 选择顾问的原则
- 选择有良好声誉和长期业绩记录的顾问
- 了解顾问的收费结构和利益冲突
- 不要完全依赖顾问的建议——保持独立思考
- 对华尔街的所谓"事实"持批判态度

## 投资者与顾问的关系
- 防御型投资者更需要专业顾问的帮助
- 积极型投资者应自行研究，将顾问作为信息来源而非决策者
- 即使是最优秀的顾问，也不能保证超越市场的表现
- 投资者应了解基本的投资原则，以便评估顾问的建议
