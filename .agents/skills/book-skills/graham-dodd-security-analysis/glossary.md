# 证券分析 — 术语表（Glossary）

按字母排序；中文术语按拼音首字母归入对应英文字母。格式：**术语** — 定义 (Ch N)

## A

- **安全边际 (Margin of Safety)** — 投资价值与市场价格之间由充分保障倍数和客观标准支撑的缓冲空间；证券分析与市场分析的根本分水岭 (Ch 1, 7, 21, 28, 52)
- **安全性让步补偿** — 低价+高回报必须足以补偿安全性不足，否则不构成购买理由 (Ch 26)
- **Acceleration Clause / 提前支付条款** — 使债券持有人获得与其他债权人同等地位的要求权，目的是保障本息全额收回 (Ch 18)
- **Amortization / 摊销** — 将无形资产或资本性投资（专利、租赁物改良）在有效寿命期内系统分摊至费用 (Ch 35, 36)
- **Arbitrage / 套利·置换** — 相关证券间确定性价格背离的利用，基于契约关系而非方向预测；分析师第四类有效活动 (Ch 51, 52)

## B

- **Blanket Mortgage / 总括式抵押** — 覆盖公司全部或大部分资产的抵押安排，铁路部门常用 (Ch 19)
- **Book Value / 帐面价值** — 资产负债表所载属于股东的有形资产净值，排除商誉等无形资产；对盈利能力相关性弱，但极端偏离时有诊断功能 (Ch 42, 43)
- **Blue-Sky Promotion / 蓝天促销术** — 对真实企业多次高估出售的融资诈骗进化形态 (Ch 47)
- **Businessmen's Investments / 商人投资** — 品质略低于严格投资标准、售价略低于平价的夹生类别；已被否定 (Ch 7, 26)

## C

- **Chart Analysis / 图表分析** — 从市场历史表现挖掘预测材料的技术分析；格雷厄姆断言其不可能成为科学 (Ch 52)
- **Cheap Call / 廉价求权** — 投机性融资结构中普通股以极少自有资金使用债券资金，获得不对称索取权 (Ch 40)
- **Chain Inflation of Earnings / 连环虚胀** — 控股公司按市价入账子公司股票股息→虚构利润被乘数放大 (Ch 33)
- **Clean Balance Sheet / 清洁资产负债表** — 无应付票据、无需深度审计即可信任的报表 (Ch 45)
- **Conflict of Interest / 利益冲突** — 董事主要代表普通股股东利益，可能牺牲优先股股东收入 (Ch 14)
- **Contractual Weaknesses / 合同弱点** — 优先股缺乏法定强制力保证，股息支付可被董事自主停止 (Ch 14)
- **Corrective Forces / 修正力量** — 极端有利和极端不利都不会持久的市场自我调节机制 (Ch 2)
- **Cumulative Preferred Stock / 累积性优先股** — 未支付股息可累积到未来支付；总是优于非累积性 (Ch 14, 15)
- **Current Asset Value / 流动资产价值 (NCAV)** — 速动资产减去全部优先级要求权；清算价值的粗略指标 (Ch 43)

## D

- **Double Leverage / 双重杠杆** — 控股公司层面债务+运营公司层面债务叠加，放大收益与亏损 (Ch 48)
- **Double Taxation / 双征收效应** — 优先股股息来自税后利润而债券利息税前支付，税收地位劣势 (Ch 14)
- **Depletion / 耗损** — 自然资源经开采逐步消耗资产价值；投资者须按自己支付的价格独立计算 (Ch 36)
- **Depreciation / 折旧** — 固定资产价值减损的估计量；营业费用而非纯账面项目 (Ch 34, 35)
- **Dilution Effect / 稀释效应** — 认股权证行权或新发股份导致原股东每股收益与权益比例下降 (Ch 46)
- **Divergence / 背离** — 市场价格偏离内在价值；根源是群体心理的夸大、过度简化与忽略 (Ch 50, 51)
- **Dual Holding Perspective / 双重持有观** — 普通股作为可转让证券 vs 企业合伙人利益的两种出发点冲突 (Ch 29)

## E

- **Earnings Power / 预示的盈利能力 (Indicated Earning Power)** — 商业条件不变前提下公司年复一年的预期收益 (Ch 31)
- **Event of Default / 违约事件** — 触发本金提前到期的契约条款 (Ch 18)
- **Expended Depreciation / 已花费折旧** — 实际花费在财产上的平均现金支出；折旧计提底线 (Ch 35)
- **Extraordinary Items / 偶生项目** — 偶发非经常损益（固定资产出售、诉讼、退税等）；必须从报告收益中剔除 (Ch 31, 32)

## F

- **Fiduciary Duty / 受托责任** — 董事会仅以所有者利益行事的法律责任 (Ch 44)
- **Fully-Diluted EPS / 完全稀释每股收益** — 假设全部权证可转债实施后的每股收益 (Ch 39)
- **Fixed Charges Coverage / 固定费用保障倍数** — 收益对固定费用的倍数；铁路/公用事业 2×、工业 3× 为投资级门槛 (Ch 7, 8, 11)

## G

- **Going-Concern Basis / 继续经营假设** — 以持续经营实体为前提估值，区别于清算价值 (Ch 36)
- **Group Operation / 组合性操作** — 成组、分散、以有吸引力价格购买普通股的投资方案 (Ch 28)

## H

- **Homogeneous Group / 同质群体** — 未来变化对全组影响类似的公司集合；统计比较可靠的前提 (Ch 49)

## I

- **Income Bonds / 收入债券** — 利息支付取决于收益的工具；法律地位类似优先股，本质缺陷明显 (Ch 16)
- **Indicated Earning Power / 预示的盈利能力** — 见 Earnings Power (Ch 31)
- **Intrinsic Value / 内在价值** — 由事实（资产、收益、股息、明确前景）支撑的价值；是"近似值范围"而非精确点 (Ch 1)
- **Intrinsic Stability / 内在稳定性** — 抗变动性，根源在业务性质而非统计数据；质的因素中最重要项 (Ch 2)
- **Investment Operation / 投资操作** — 根据详尽分析，本金安全和满意回报有保证的操作；不符即投机 (Ch 4)

## L

- **Liquidation Value / 清算价值** — 业主放弃经营时能从资产变现中获得的资金；折扣规律见表 (Ch 43, 44)
- **Listing the Earnings Record / 收益记录** — 估值起点而非终点；须配合定性调查 (Ch 37, 38)

## M

- **Margin of Safety** — 见安全边际 (A)
- **Market Analysis / 市场分析** — 预测证券价格变化的全部活动；与证券分析分属两界 (Ch 52)

## O

- **Obsolescence Hazard / 废弃风险** — 与物理损耗无关的商业风险；属于投资判断而非会计问题 (Ch 35)
- **Overcapitalization / 过度资本化** — 初始资本化超出有形资产价值的差额 (Ch 29)

## P

- **Payout Ratio / 派息率** — 收益中以现金股息形式发放的比例 (Ch 29)
- **Preferred Stock / 优先股** — 优先于普通股但次于债券；合同弱点使其非理想投资工具 (Ch 14)
- **Price Inertia / 价格惯性** — 市场价格对基本面变化的滞后反应；现代市场逐渐消失 (Ch 21, 51)
- **Pyramiding / 金字塔结构** — 层层控股以少量资本控制大量资产的杠杆结构；系统性剥削少数股东 (Ch 48)
- **P/E Ceiling / 市盈率上限** — 16× 平均收益为投资级硬上限；10× 为合理基准 (Ch 37, 39)

## R

- **Range of Approximation / 近似值范围** — 内在价值是一个区间；价格超出区间即可得出明确结论 (Ch 1)
- **Retroactive Restatement / 回溯重述** — 资本结构变化后对历史 EPS 的等比调整 (Ch 39)

## S

- **Seasoned / Unseasoned Issues / 成熟·不成熟证券** — 历史悠久的知名证券 vs 新上市工业证券；后者对不利发展极敏感 (Ch 50, 51)
- **Securities Analysis 三功能** — 描述功能、选择功能、评判功能 (Ch 1)
- **Sinking Fund / 偿债基金** — 定期清偿高级证券的机制；缩小流通规模+市场支持双重好处 (Ch 19)
- **Speculative Component / 投机成分** — 价格中超出分析家估值的部分，对应期望而非已显示结果 (Ch 37)
- **Subjective Variations Zone / 主观离差区** — 70–100 价格区间，证券地位由投资者个人标准决定 (Ch 26, 51)
- **Sinking Fund** — 见偿债基金 (S)

## T

- **Total-Deductions Basis / 完全扣除计算法** — 保障比率须将债券利息+优先股股息加总 (Ch 14, 15)
- **Trustee / 受托人** — 债券持有人代表；传统被动准则（"不做任何可能受指责的事"）是无效保护根源 (Ch 18)

## W

- **Working Capital Covenant / 营运资金条款** — 要求营运资金对债券保持比率的保护条款；违反时惩罚应分级而非直接违约 (Ch 19)
- **Working Capital Standard / 营运资金标准** — 工业公司 $2 速动资产 : $1 流动负债的最低比率 (Ch 45)
