# 第23章 附权高级证券的技术特征
# Ch23: Technical Features of Privileged Senior Securities

## Core Idea

附权证券的三种特权形式——可转换权、参与权、认购权——在技术特征上存在重要差异。**核心结论**：从长线投资持有角度看，优质的参与证券是利润分享特权的最优形式；而从有利的市场条件下最大化价格增益的角度看，附有可分离认股权证的高级证券很可能能够带来最佳效果。

**Key Insight**: Participation privileges are best for long-term investment; separable stock-purchase warrants offer the best price appreciation in favorable markets.

## Frameworks Introduced

### 1. 三种特权的共同之处 (Common Features)

**价值决定因素**：
利润分享特征的价值大小取决于两个主要的、完全互不相关的因素：
1. 这种安排的条款
2. 可分享的利润的前景

**示例对比**：
```
A公司：6%债券，售价$100，可以$50转换价格转换成2股股票
B公司：6%债券，售价$100，可以$33转换价格转换成3股股票
股票市价：$30

A公司债券：股价只需再上涨略多于3个点，转换利润就会出现
B公司债券：股价必须上涨20个点以上，才会出现转换利润
```

**关键洞察**：
- A公司债券转换权条款更吸引人
- 但购买A公司债券却很有可能被证明是更划算的
- 因为当A公司股票价格翻一倍的同时，B公司股票可能只是原地踏步

### 2. 无限参与特权的优越性

**西屋电气和制造公司优先股案例**：
- 每年$3.50优先股息（平价时股息率7%），具有累积性
- 在普通股年股息超过$3.50的情况下，有权平等地参与超额股息分配
- 1917年市场价：$52.5

**15年表现（1917-1932）**：
- 基本股息：7%
- 额外股息：每股约$7
- 1929年最高价：$284
- 1932年市场低迷时：仍按时获得7%股息，每股股价$32.5
- 同时普通股：股息停止，价格跌至$15.625

**优势分析**：
1. **好年景**：参与普通股盈余利润的分配
2. **差年景**：保持优先地位，失去的仅仅是暂时的利润
3. **对比可转换证券**：如果实施转换权，随后将发现所持普通股的股息没能得到支付，股票价值也贬损至初始投资价值以下

**参与证券的缺点**：
- 在强劲的小市背景下，表现不如可转换证券或附认股权证证券
- 原因：普通股价格从很大程度上是那些对短线利润感兴趣的投机者的操作形成的
- 投机者愿意多支付几个点购买品质较低但交易更活跃的普通股

### 3. 可转换证券和附认股权证证券的价格变化规律

**1929年4月4种附权证券价格对比**：

| 证券类型 | 公司 | 普通股价格 | 附权证券价格 | 相对溢价 |
|---------|------|-----------|-------------|---------|
| 附认股权证优先股 | 费城-瑞金-能源 | $60 | $105 | 75% |
| 附认股权证债券 | 怀特缝纫机 | $45 | $103 | 129% |
| 可转换优先股 | 中州电气 | $55 | $98 | 78% |
| 可转换债券 | 独立石油天然气 | $40 | $95 | 138% |

**关键发现**：
- 在投机市场上，附认股权证证券价格中往往存在大幅溢价
- 这种溢价比条件相似的可转换证券价格中的溢价高得多

### 4. 投机部分与投资部分相分离的优势

**核心机制**：
认股权证的投机部分（权证本身）与投资部分（剔除权证的债券或优先股）可以完全分离。

**运作方式**：
1. 投机者总是寻找以小博大的机会
2. 认股权证恰恰具有这种特点
3. 在上升市场上，投机者争先恐后购买附权证券附带的认股权证
4. 即使权证还不具备即刻实施价值，售价也相当可观
5. 结果：债券单独的市场价格加上认股权证的价格明显高于条件非常相近的可转换债券

**商业投资信托公司6.5%优先股案例**：
- 1925年发行，附有认股权证，允许以每股$80购买普通股
- 1929年，每股优先股所附认股权证售价高达$69.50
- 持有人可以高价出售证券的投机部分，同时保留优先股契约
- 该优先股历经大萧条考验始终保持投资性证券地位
- 1933年4月1日以$110提前赎回

**对比可转换证券**：
如果该优先股是可转换型的，很多持有人势必选择实施转换，将普通股留在手上。这样，他们不仅无法赚取大量利润，相反还将面对沉重的损失。

## Key Concepts

### 提前赎回条款的影响 (Impact of Call Provisions)

**对参与证券的不利影响**：
- 公司保留在到期日之前提前赎回证券的权力
- 只有在对证券发行人有利的情况下才会使用
- 一旦公司兴旺到快要开始对参与证券支付额外利益的临界点时，提前赎回的危险就出现了
- 可能彻底侵蚀参与特权的价值

**对认股权证证券的优势**：
- 即使证券本身可能在到期日之前被提前赎回
- 认购特权几乎无一例外地在规定存续期内有效，直到寿终正寝
- 如果权证是可分离的，将继续独立其身直到有效期满
- 即便权证不可分离，公司一般会为持有人另外提供独立的认股权证

**示例：联合飞行器与运输公司6%累积优先股**：
- 1934年1月1日之前，尚有150,000股未清偿
- 附有不可分离的认股权证，每两股优先股有权以每股$30购买1股普通股
- 认购特权截止日期：1938年1月1日
- 保护性条款：如果优先股在1938年11月1日之前被赎回，公司将发行保证与原权证同权的新权证
- 1933年1月1日优先股被通知赎回，分离式权证随即向持有人发行

### 附认股权证证券的第三个优点

**四种选择对比**：

**1. 参与证券持有人**：
a. 可以以有利可图的价格出售证券
b. 可以持有证券，获得来自参与利润分配的收入

**2. 可转换证券持有人**：
a. 可以以有利可图的价格出售证券
b. 可以继续持有证券，但不能分享普通股高额股息的利益
c. 可以实施转换以获得大量的股息收入，但牺牲了优先要求权的地位

**3. 附认股权证证券持有人**：
a. 可以以有利可图的价格出售证券
b. 可以继续持有证券，但不能分享普通股高额股息的利益
c. 可以认购普通股以获得高额股息收入
   - 追加资金或来源于出售剔除权证的证券所得
   - 承担普通股股东所需承担的风险
d. **独有优势**：可以将认股权证处理掉，兑现一定利润，同时继续持有原有剔除认股权证的证券

**第四种选择的战略价值**：
- 从证券的投机部分中兑现利润
- 同时保持原有的投资地位
- 没有必要出售整个契约
- 典型投资者的主要兴趣在于进行成功的投资，其次才是从特权中赚取利润

## Mental Models

### 1. 参与证券的"长期最优"模型

**适用场景**：长线投资持有

**优势机制**：
- 好年景：参与利润分配，获得额外收入
- 差年景：保持优先地位，失去的只是暂时利润
- 不改变高级证券持有人地位

**劣势场景**：强劲的小市背景
- 投机者偏好交易活跃的普通股
- 参与证券交易相对不活跃
- 价格常常低于正常水平

**典型案例**：西屋电气优先股
- 1929年价格常常比普通股低5-10个点
- 尽管每股内在价值并不比普通股低
- 原因：普通股价格由短线投机者操作形成

### 2. 可转换证券的"有限获利"模型

**获利区间**：
- 在投资性价格区域内，获利幅度通常限于25-35%
- 一旦进入投机性区域，行为与普通股无异

**关键限制**：
- 持有人必须在获利区域果断出货
- 否则面临与股东完全一样的风险
- 持有时间较短

### 3. 认股权证的"投机-投资分离"模型

**核心优势**：
- 投机部分（权证）与投资部分（剔除权证的证券）完全分离
- 可以分别管理，分别变现

**市场表现**：
- 在上升市场上，权证价格中包含大幅溢价
- 溢价高于条件相似的可转换证券
- 原因：投机者愿意为"以小博大"的机会支付溢价

**战略灵活性**：
- 可以出售权证兑现投机利润，同时保持投资地位
- 可以认购普通股获得股息，但承担股东风险
- 可以选择不出售整个契约

## Anti-patterns

### ❌ 忽视提前赎回条款的威胁

**错误做法**：
- 购买参与证券时不关注提前赎回条款
- 忽视提前赎回对特权价值的侵蚀

**后果**：
- 一旦公司兴旺到临界点，提前赎回危险出现
- 特权价值被彻底侵蚀

**正确做法**：
- 选择设有保护性条款的证券
- 如：赎回价格直接与参与特权价值挂钩
- 或：提前赎回时发行独立的新权证

**示例**：
- 西门子-哈尔斯克参与信用债券：赎回价格取决于赎回通知发出以前6个月的平均市场价格，但不低于原始发行价格（平价的230%）
- 克罗伊格和托尔公司参与信用债券：类似条款

### ❌ 参与证券在强劲小市中的错误定价

**错误认知**：
- 认为参与证券内在价值高于普通股，价格应该更高
- 忽视了市场流动性和投机偏好的影响

**正确认知**：
- 在强劲小市中，参与证券价格常常低于普通股
- 原因：投机者偏好交易活跃的普通股
- 这是市场普遍规律：在缺少特殊需求的情况下，相对稀少很可能导致较低的价格

**典型案例**：
- 美国烟草公司B类股票（无投票权）多年来售价一直高于原始（有投票权）股票
- 类似情形在伯利恒钢铁、泛美石油、利格特和迈尔斯等公司存在

### ❌ 可转换证券持有人的角色混乱

**错误做法**：
- 既想保持债券投资者的安全性
- 又想获得股票投机者的获利机会
- 在转换与不转换之间犹豫不决

**后果**：
- 兴趣分散到企业本身和特权条款两个方面
- 最后可能说不清自己是股票持有者还是债券持有者
- 对不可避免的亏损没有资金上或精神上的准备

**正确做法**：
- 明确立场：要么是投资者，要么是投机者
- 投资者：果断在投机性区域出货
- 投机者：接受高风险，追求高收益

## Worked Example

### 案例：西屋电气和制造公司优先股

**基本情况**：
- 优先股股息：每年$3.50（平价时股息率7%），累积性
- 参与条件：普通股年股息超过$3.50时，优先股有权平等参与超额股息分配
- 1917年市场价：$52.5

**15年表现（1917-1932）**：

**基本收入**：
- 7%基本股息 × 15年 = 105%

**额外收入**：
- 参与超额股息：每股约$7

**总股息收入**：
- $7（基本）+ $7（额外）= $14/股
- 按$52.5购买价计算，年化收益率约18%

**资本利得**：
- 1929年最高价：$284
- 获利：($284 - $52.5) / $52.5 = 440%

**大萧条考验（1932年）**：
- 优先股：按时获得7%股息，股价$32.5
- 普通股：股息停止，股价$15.625

**关键洞察**：
1. **好年景**：参与利润分配，获得额外收入
2. **差年景**：保持优先地位，失去的只是暂时利润
3. **对比可转换证券**：如果实施转换，1932年将面临普通股股息停止和股价暴跌的双重打击

**投资决策分析**：

**如果购买参与优先股**：
- 15年总回报：($14 + $32.5 - $52.5) / $52.5 = -11.4%（仅考虑资本损失）
- 但获得了14/52.5 = 26.7%的股息回报
- 总回报：26.7% - 11.4% = 15.3%（15年）
- 年化收益率约1%

**如果购买可转换证券并实施转换**：
- 假设1929年以$284转换，获得普通股
- 1932年股价跌至$15.625
- 损失：($284 - $15.625) / $284 = 94.5%
- 3年股息：$0（普通股停止支付）
- 总损失：94.5%

**结论**：
- 参与优先股在大萧条中保持了投资价值
- 可转换证券在转换后面临巨大损失
- 证明了参与特权在长期投资中的优越性

### 与全书核心思想的关系

**投资与投机的明确区分**：
- 三种特权形式适合不同的投资策略
- 参与证券适合长线投资
- 可转换证券和认股权证适合短期投机

**安全边际原则**：
- 提前赎回条款对特权价值的侵蚀
- 需要保护性条款来维持安全边际

**价格与价值的背离**：
- 参与证券在强劲小市中价格低于内在价值
- 这是市场流动性和投机偏好的结果

**风险管理**：
- 认股权证的可分离性提供了投机-投资分离的机会
- 可以在保持投资地位的同时获取投机利润
