# 第35章 从投资者角度考虑的摊销费用
# Chapter 35: Amortization Charges Considered from the Investor's Standpoint

## Core Idea
合法的会计方法未必反映投资者面对的真实情况。当公司固定资产的账面成本与实际市场价值严重背离时（无论是因低价购入还是大幅减值），标准折旧计提将导致报告收益严重失真。投资者必须放弃公司自行选择的折旧基数，以资产的"继续经营价值"（going-value）或正常工商业折旧为基础，建立独立于公司报表的折旧评估体系。关键原则：只要事实上的折旧必须计提，就不能因账面操作而省略。

## Frameworks Introduced
1. **投资者视角折旧三原则**：
   - **原则1**：仅当同时满足 (a) 折旧按固定资产公允估价的常规会计原则计提，且 (b) 工厂设备净额在一段时期中有所增加或保持稳定，公司折旧数字才可作为分析依据。
   - **原则2**：若折旧费用始终超过财产现金支出，分析家可降低费用——以平均现金支出额作为"已花费折旧"从收益中扣除，其余视为废弃风险（通过支付价格反映，而非通过折旧扣除反映）。
   - **原则3**：若折旧费用既低于财产平均现金支出，又低于公认会计原则规定的储备额，分析家必须提高费用。
2. **"已花费折旧"（Expended Depreciation）概念**：用于财产项目的平均现金花费 = 维持企业继续经营的最低折旧底线。当财产账户增加额超过当年折旧时，全部折旧均被视为"已花费"。
3. **废弃风险 vs 折旧费用的区分**：长期折旧因素不如废弃风险重要；废弃风险是投资问题而非会计问题，应通过购买价格而非收益扣除来反映。

## Key Concepts
- **已花费折旧（Expended depreciation）**：实际花费在财产项目上的现金支出，代表企业继续经营所必需的最低折旧计提额。
- **废弃风险（Obsolescence/abandonment risk）**：与资产物理损耗无关的商业风险——工厂不会真正报废，十有八九是行业环境变化导致被迫放弃；属于投资判断问题，不属于会计折旧范畴。
- **股票掺水逆转（Reversal of stock-watering）**：一代人前通过高估资产价值人为抬高净值（"掺水"）；当前则通过低估资产价值（减值至$1）消除折旧、虚增收益——异曲同工的欺骗。
- **继续经营假设（Going-concern basis）**：以企业作为持续经营实体为前提进行估值，区别于清算价值。
- **摊销的强制性（Mandatory nature of amortization）**：不论公司是否通过账面操作"取消"折旧，事实上的资本消耗客观存在，投资者在分析时必须自行计提。

## Mental Models
- **"三个运货车公司"思想实验**：A、B、C 三家公司经营相同业务、折旧前收益相同，唯一区别是运货车的购买价格不同（$10K、$5K、$10K被减记至$0）。会计处理导致A亏损、C盈利暴增——但企业家视角下三者价值等同。市场的荒谬：给A估值$500、给C估值$20,000——恰恰因为A资产价值高反而被惩罚。
- **"尤里卡管道"现实版**：公司账面显示零盈利能力（因高额折旧），但平均每年仅花$90K于财产维护，企业实为"摇钱树"——仅"已花费折旧"应从收益扣除，剩余折旧因素实为废弃风险。
- **"你不能假装资产不存在"模型**：安全汽车供热照明公司将固定资产减记至$1以消除折旧——但股东不会因账面操作而少付购买价格，设备维护支出也不会因此消失。

## Anti-patterns
- **将固定资产减记至$1消除折旧**：美国工业酒精公司和安伟汽车供热照明公司的做法——用"魔法"消灭折旧费用，虚增报告收益，本质与股票掺水无异。
- **用"更新储备"取代法定折旧**：以董事会任意决定的"更换储备"替代标准化折旧计提，使得费用金额完全脱离合理基础。
- **忽视减记后折旧不足**：美国工业酒精公司1933年将折旧储备从~$740K降至$300K——若公司恢复往日盈利能力，急剧减少的折旧计提将导致真实盈利能力的误导性高估。
- **混淆"合法"与"真实"**：会计上的合法操作（如将资产减记后不再计提折旧）不反映投资者面对的经济实质。

## Worked Example
**尤里卡管道公司（Eureka Pipe Line）1924-1926年**

公司报告（按高额折旧计提）：
- 折旧前收益年均：$442,000（每股$8.84）
- 折旧计提年均：$442,000+ → 净收益 ≈ $0（每股≈$0.10）
- 结论：按继续经营假设，股票无价值

**投资者视角重新分析**：
- 财产账户平均年支出仅 $90,000 → "已花费折旧"≈$100,000
- 无迹象表明企业会在可预见日期更换所有工厂设备
- 企业具有无限寿命（持续维护、修理、改造）
- 调整后真实盈利能力：$442,000 - $100,000 = $342,000（每股≈$6.84）
- 若以20%收益率补偿废弃等商业风险 → 估计股票价值 ≈ $35/股

→ 报告说"零盈利"、分析说"每股$35"——差距源于折旧基数的错误选择。

## Key Takeaways
1. **投资者必须建立独立于公司的折旧基数**——公司账面折旧未必反映投资者实际面对的经济现实。
2. **"已花费折旧"是盈利能力分析的底线**——维持继续经营的实际现金支出 = 不可省略的最低折旧。
3. **废弃风险不是会计问题而是投资问题**——应通过购买价格而非收益扣除来反映。
4. **将资产减记至$1是股票掺水的逆转**——通过低估资产价值虚增收益，与通过高估资产虚增资产如出一辙。
5. **法定折旧费用是反映企业真实状况的最基本要求**——公司通过任意减计处理来减少这种费用毫无道理，分析家自己也不应这样做。
6. **典型公司的工厂不会真正报废**——它们只是在不断老化；长期折旧因素远不如废弃风险重要。
