# 第12章 铁路和公用事业类债券分析中的特殊问题

## Core Idea

铁路和公用事业债券分析需要处理独特的会计结构和固定费用构成。铁路债券分析应将定量分析限制在**固定费用保障比率**和**股东权益规模**两项核心检验上，无需复杂技术追踪。公用事业债券须警惕三大误导手法：冒用"公用事业"标签、预先扣除法（prior-deductions method）计算保障比率、忽略折旧费用。

## Frameworks Introduced

### 1. 铁路固定费用保障比率：双公式检验法
**何时使用**：分析铁路债券安全性时，从两个公式中选较严格者。

**如何操作**：
- **方法A**：固定费用保障倍数 = 总收益 ÷ 固定费用
  - 总收益 = "偿付公积金后净收益" + "其他收入"
  - 固定费用 = 可用于派发股息的收益余额之前的所有固定扣减
- **方法B**：净扣减项目总数保障倍数 = 铁路经营收益 ÷ 净扣减项目总数
  - 铁路经营收益 = 营业总收入 - 营业费用 - 税收
  - 净扣减项目 = 可用于发放股息之前的所有扣减
- **选取规则**：若总收益>税后净收益，选方法A；反之选方法B

### 2. 公用事业折旧费用检验
**何时使用**：审核公用事业债券募集公告时。

**如何操作**：
- 控股公司：折旧储备应≥营业总收入的6%
- 经营型公司：折旧至少占营业总收入的8%
- 低于此标准需高度警惕——折旧低估可能导致实际利息保障从正变负

### 3. 假冒公用事业识别框架
**何时使用**：识别债券发行人是否为真正的公用事业。

**如何操作**：
- 真正公用事业：拥有政府特许权、受法规管制、提供必需性垄断服务
- 可疑信号：电力/电话业务与工业业务混合（如制冰+电话）
- 天然气 ≠ 公用事业：产出大部分被制造业使用，处于燃料工业经营风险中
- 核心检验：融资结构是否超过纯粹公用事业可安全承受的限度

## Key Concepts

- **固定费用（fixed charges）**：综合代表债券利息、租金义务、保息股票、经营中子公司非付息的优先股等所有类债务支出。铁路分析中比单纯"债券利息"更全面。
- **净扣减项目（net deductions）**：铁路经营收益中可用于发放股息之前扣除的所有项目，包括设备租金、杂项扣减等介于固定费用和营业费用之间的项目。
- **维护保证金（maintenance reserve）**：铁路两大人为操纵项目之一（另一为股息收入）。维保费用过低=利润虚增+财产受损；过高=利润低估。正常维保费用应占营业总收入的32%-34.5%。
- **预先扣除法（prior-deductions method）**：扣除优先费用后计算利息保障比率，使发行在后的债券看起来比实际情况更安全——格雷厄姆斥之为"严重的职业道德危机"。
- **双重杠杆（double leverage）**：公用事业控股公司结构中，子公司优先股股息在级别上高于母公司债券（因后者收入来源是子公司普通股股息），须计入固定费用。

## Mental Models

1. **"奥卡姆剃刀"用于铁路分析**：数据充裕≠分析必要。复杂技术追踪（列车载重、燃料消耗、每英里成本）与固定收益证券"回报有限"的本质不匹配。
2. **"标签≠实质"**：公用事业的标签常被盗用。制冰+电话的混合公司不是公用事业——杂交目的全是盗名欺世。
3. **"折旧是真实的现金需求"**：不是纯账面概念。典型经营良好公司每年大部分折旧资金用于更新毁损设备。

## Anti-patterns

- ❌ **过度复杂化铁路分析**：金融机构的专业分析适合投机性证券，但固定价值投资者只需两项核心检验
- ❌ **接受募集公告的表面数字**：投行常用三种误导手法——冒用公用事业标签、预先扣除法、忽略折旧
- ❌ **用"其他收入"粉饰保障比率**：如宾夕法尼亚铁路的"其他收入"中包含大量应互相抵消的利息和租金，未剔除将压低保障倍数
- ❌ **因维护费用过高或子公司未分配利润而提升债券评级**：只能让已合格的债券更有吸引力，不能使不合格变合格

## Worked Example

**公共事业服务公司可转换信用债券（1928年发行，$99.5，票面6.5%）**

募集公告声称：利息保障比率2.71×，$1000债券对应$1650资产。

格雷厄姆的拆解：
1. 该公司是电话（公用事业）+制冰（工业）混合体，总债务占资产估值84%——超出纯粹公用事业安全限度
2. 折旧费用被完全省略！电话公司正常折旧应≥营业总收入15%，若按$300,000计，则利息保障从2.71×骤降至1.05×——收益几乎不够付息
3. 预先扣除法使信用债券看起来比优先债务更安全——逻辑荒谬
4. 实际$1000总债券债务仅对应$1190固定资产，非公告所称$1650

**结论**：募集公告存在欺诈性误导。真实保障比率接近1×，完全不符合投资标准。

## Key Takeaways

1. 铁路分析应简化：固定费用保障比率+股东权益规模两项检验即可，复杂性不产生价值
2. 公用事业三大陷阱：假冒标签、预先扣除法、折旧省略——投资者须独立核实
3. 折旧是真实的现金需求，不是可选的账面处理；低于营业总收入6-8%即应警惕
4. 维护保证金比率（32%-34.5%）是检测铁路利润操纵的关键指标
5. 固定费用资本化方法（铁路×20，公用事业×18）可将所有类债务项目折算为等效债务本金
6. 子公司优先股股息在控股公司结构中属于固定费用——因其级别高于母公司债券
