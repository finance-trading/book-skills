# 第34章 折旧和类似费用与盈利能力的关系
# Chapter 34: Depreciation and Similar Charges in Relation to Earning Power

## Core Idea
折旧与摊销费用（depreciation and amortization）不是纯粹的账面数字游戏——它代表资本价值的真实损耗。会计处理与经济实质之间的系统性差异，使得报告收益严重偏离真实盈利能力。公共事业公司普遍采用双重折旧政策（对税务报高、对股东报低），管理层可通过随意设定折旧率操纵利润；投资者必须独立验证折旧费用的充足性，否则无法判断证券的真实安全边际。

## Frameworks Introduced
1. **折旧三问检验框架**：分析家对折旧帐户必须依次追问——(a) 收益是否已扣除摊销费用？(b) 所采用的摊销比率是否合理（符合公认会计原则）？(c) 摊销所依据的成本基数是否合理反映了投资者所面对的资产公允价值？
2. **折旧充足度双向验证法**：
   - 纵向：审视公司上市申请/募集公告中披露的折旧政策表述，与同行标准做法比对。
   - 横向：同行业多家企业折旧率比较 → 确定"众数区间"（modal range）→ 偏离过远即值得怀疑。
3. **隐藏折旧的四种手法谱系**：(a) 完全省略（城市服务公司）；(b) 部分冲减收益、部分冲减盈余（底特律爱迪生公司）；(c) 冲减法定资本补口（美国电力能源公司）；(d) 双重折旧率制度（美国供水电公司）。

## Key Concepts
- **折旧费用是营业费用（operating expense）**：虽不表现为当期现金支出，但记录资本价值的真实减损；忽略折旧等于自欺。
- **双重折旧政策（Dual depreciation policy）**：同一资产按不同费率分别用于报税与报股东——报税者依标准寿命表、费率较高；报股东者通过"更新/报废储备"科目任意压低。
- **已花费折旧（Expended depreciation）**：实际用于财产项目的现金支出 = 维持企业继续经营的最低折旧底线。
- **众数区间（Modal range）**：同行业多数企业遵循的折旧率集中带，偏离过远即为异常信号。
- **耗损费用（Depletion）**：将资本性资产通过转化为可售产品而逐步消耗的过程，适用于金属、石油、天然气、硫磺、木材等行业。

## Mental Models
- **"不花钱≠无成本"模型**：折旧虽非现金流出，但对应着资产寿命的真实消耗；忽视折旧如同忽视汽车油耗——车还在跑，但价值正在蒸发。
- **管理层"随心所欲闸门"模型**：公共事业公司折旧率完全由管理层主观决定，使得不同公司利润差异可能纯粹是会计选择的结果，而非经营效率差异。
- **"两副面孔"的税单模型**：税务报表折旧额是"真话"（因为税务局要收钱），股东报表折旧额是"表演"——两者的差距就是利润虚增的空间。

## Anti-patterns
- **省略折旧费用的报告**：城市服务公司模式——在招股书和年报中公布未扣除折旧的数字，导致每股收益完全失真。
- **部分折旧冲减盈余而非收益**：底特律爱迪生模式——声称"已计提折旧"，实际将部分折旧偷偷转移到盈余账户，掩盖真实收益水平。
- **"财产增值无需折旧"谬论**：城市服务公司辩解——即便资产增值，增值已反映在利润增加中，再省略折旧等于"同一张牌算两遍"。
- **以"更新储备"替代标准折旧**：美国供水电公司模式——不叫折旧而叫"更新储备"，费率远低于标准，审计师也拒绝公证该科目。
- **资本投资冲销利润（国民饼干模式）**：新建工厂成本被隐含计入利润，真实收益被大幅低估，直到会计政策变更时盈利能力才"突然"暴增。

→ 设"更新/报废储备"的公司折旧政策比设"折旧储备"的公司更不谨慎。

### 美国供水电公司双重折旧政策对比（1930-1933）
| 年份 | 对政府报税折旧额 | 对公众报告折旧额 | 差额 |
|---|---|---|---|
| 1930 | $4,205,000 | $6,781,000 | $2,576,000 |
| 1931 | $3,095,000 | $7,089,000 | $3,994,000 |
| 1932 | $2,747,000 | $7,023,000 | $4,276,000 |
| 1933(10月) | $2,654,000 | $6,384,000 | $3,730,000 |

→ 对公众报告的折旧额（低）远低于报税折旧额（高），差额即利润虚增空间。

## Worked Example
**美国供水电公司（American Water Works & Electric）1930-1933年**

募集公告暴露了公司双重折旧政策：
- 对报税：依标准寿命表计提，年均 ~$3.2M
- 对股东：通过"更新储备"科目，年均 ~$2.5M（仅为报税额的 ~78%）
- 审计师特别声明：不对"更新等储备"进行核查公证

加上：(1) 放弃电气铁路财产的 ~$9M 冲销从不在报表中体现；(2) 所得税数字与报告收益完全不匹配。

**调整过程**：
- 报告净收益 1930年 = $1,501,000
- 假设报告收益为真则应付所得税远超实付 → 调整后 1930年收益 ≤ $3.02/股
- 若按报税折旧额调整则进一步大幅下调

→ 谨慎的分析家或投资者几乎不会将报告数字视作企业真实或可比的盈利能力指标。

## Key Takeaways
1. **折旧是真实成本，不是会计虚构**——忽略折旧的报告"不可原谅"。
2. **公共事业公司折旧率高度随意**——不同公司利润差异可能只是会计选择差异。
3. **双重折旧政策是系统性红旗**——报税折旧与报股东折旧的巨大差距 = 利润虚增空间。
4. **同行业比较是验证折旧充足度的实用方法**——偏离众数区间过远即需深入调查。
5. **不报告折旧数额的公司不值得信任**——没有令人信服的理由可以为此开脱。
6. **并购分析中折旧差异是关键变量**——切萨皮克-俄亥俄铁路合并案即因折旧差异引发股东诉讼。
