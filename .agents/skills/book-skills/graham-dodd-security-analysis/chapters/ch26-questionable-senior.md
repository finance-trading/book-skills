# 第26章 安全性存在问题的高级证券

## Core Idea
投机性高级证券（低价债券与优先股）应从普通股的视角而非投资品的标准来分析——低价提供的"诱人回报"必须经过与普通股同等深入的损益与资产负债检验，而 70–100 的价格区间只是"主观离差区"，不存在客观的投资/投机分界线。

## Frameworks Introduced
- **投机性高级证券双视角检验**
  - When to use: 安全性存疑、价格处于投机水平的高级证券
  - How: 两种分析角度——(1) 投资品标准角度：低价格+高回报是否足以补偿安全性让步；(2) 普通股契约角度：本金损失风险较小能否补偿资本利得局限。格雷厄姆结论：**普通股分析法更可取**——风险估值更彻底，迫使购买者更深入考察公司状况
- **主观离差区间（Subjective Variations Zone）**
  - When to use: 证券价格落在约 70–100 区间（息票率 5% 以上的债券）
  - How: 该区间内安全性判断依赖各投资者个人标准（定量客观标准 + 定性主观标准并存）；投机价值开始出现的临界价格约为 70，此后资本增值最大可能至少达本金 50%
- **低价债券利润局限性论证**
  - When to use: 评估"低价债券是否有吸引力"时
  - How: 利息率 5%、售价 $35 的债券最大价格浮动约 70 点（+200%）；而以 $35 买入的普通股在牛市心理下的平均期利润通常不超过此数——利润有限性并非真正缺点，投资者不会因此吃亏

## Key Concepts
- **投机性高级证券（Speculative Senior Issues）**: 安全性不足的债券与优先股；1932 年市场谷底时至少 80% 的公司债与优先股属此类
- **主观离差区（Subjective Variations）**: 约 70–100 的价格带，其中证券地位由投资者个人评判标准决定
- **商人投资（Businessmen's Investments）**: 第7章已否定的类别——品质略低于严格投资标准、售价略低于平价的债券
- **资本利得天花板**: 债券价格回归平价即到顶，契约形式天然限制上行空间
- **纯粹投机工具偏好**: 若决定投机，选普通股以免受"半投机半投资"夹板之累
- **供给过剩折价**: 此类证券供给巨大而自发需求少，导致价格常低于内在价值——这是机会来源

## Mental Models
1. **"要投机就投纯粹的工具"**: 首鼠两端于投资与投机之间的证券最危险——上限封死、下限开放
2. **"把低价债券当普通股研究"**: 用同等精力分析损益帐户、资产负债表与未来吉凶，而非只看票息
3. **"70 是分水岭"**: 息票率 5%+ 的债券跌破 70，投机价值才开始出现；70–100 只是评判标尺因人而异的灰色带
4. **"品质滑一档，价格跳一截"**: 符合严格标准的债券守在平价上方；品质稍降即跌至 $70 左右——价格连续性背后是评判标准的离散性

## Anti-patterns
- **❌ 按证券名称与法律形式判断安全性**: "债券"二字不提供任何安全——劣质债券与一文无几的优先股比比皆是
- **❌ 把"商人投资"当投资**: 品质略逊、价格略低的债券恰是第7章否定的夹生品种——要么全标准通过，要么按投机处理
- **❌ 幻想低价债券的巨额利润**: 契约形式封顶（回归平价），实际可实现的利润通常低于同等价位普通股
- **❌ 对 70–100 区间证券含糊定性**: 不明确自己的检验标准就买入，等于把安全性判断外包给市场情绪

## Worked Example
作者的算术演示：一种利息率 5%、售价 $35 的债券，其可能的最大价格浮动是 70 个点（涨回平价 = +200%）。而在"牛市心理"最危险的情形下，以 $35 买入的普通股持有期平均利润不会超过这个数。由此推出两个结论：(1) 低价债券"利润有限"并非真实缺点；(2) 从普通股视角分析投机性高级证券不会低估其机会——反而促使购买者对损益帐户与资产负债表做出同样深入的评估，对未来的吉凶付出同样的精力。

## Key Takeaways
1. 1932 年谷底时至少 80% 的公司债与优先股安全性存疑——"不合适的类别"是美国证券市场的常态而非例外
2. 投机性高级证券用**普通股分析法**检验，不用投资品标准硬套
3. 临界价格 ≈ 70（息票率 5%+ 债券）；70–100 是主观离差区，先明确自己的标尺再出手
4. 低价债券的利润天花板是契约形式决定的，低价本身就是吸引力的来源（供给过剩 → 定价偏低）
5. 分散化是这类操作的必备安全边际（与第50章呼应）
