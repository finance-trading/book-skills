# 第10章 债券投资的具体标准（续）——资产与债务关系

## Core Idea
**债券安全性取决于公司偿债能力，而非抵押资产价值**——这是 Graham 对传统"资产担保"思维的根本颠覆。例外仅限于：设备信托凭证、抵押信托债券、投资公司信用债等具有独立变现价值的特殊品种。

## Frameworks Introduced
- **资产价值与偿债能力的关系分类**
  - 一般公司债券（铁路/公用事业/工业）：抵押资产账面价值**毫无意义**，安全性=企业经营能力
  - 设备信托凭证（Equipment Trust Certificates）：抵押品（机车/货车/客车）具有独立转让价值和运营必要性，债权人拥有双重保护
  - 抵押信托债券（Collateral Trust Bonds）：以股票/债券为抵押，投资公司的品种因保护性条款而接近设备信托
  - 房地产抵押债券：资产价值=继续经营价值（租金能力），与整体企业经营息息相关
  - When to use: 评估任何有抵押的债券发行
- **房地产债券的量化标准**
  - 贷款额 ≤ 资产价值的 2/3（以实际成本或经验丰富开发商愿付价格计）
  - 该成本/价格不得反映当前投机性膨胀，不得明显高于历史长期水平
  - 扣除折旧后的预期收入 ≥ 利息费用的 2×（即 100% 超额）
  - 折旧提留用于偿债基金，逐步赎回债券
- **设备信托凭证的结构特征**
  - 发债公司至少承担 20% 设备成本，债券 ≤ 设备成本 80%
  - 15 年等额分期付款，从举债后第 1 年开始
  - 债务递减速率 > 设备折旧速率
- **NY 州法对公用事业抵押债的要求**
  - 抵押资产价值 ≥ 债券数量的 1.5×（账面价值，可人为调整）
  - Graham 反对：账面价值无意义，应看偿债能力

## Key Concepts
- **留置权无关性（Lien Irrelevance）**：优质公司无担保信用债 > 劣质公司第一抵押债（例：1942 年通用电气 3.5% 无抵押债）
- **设备信托凭证的双重保护**：① 发债公司资信+成功运营；② 抵押设备的独立变现价值
- **主观离差区（Subjective Variations）**：价格 70–100 反映不同投资者对安全性的宽容度差异
- **继续经营价值（Going-Concern Value）**：房地产资产的变现价值=租金收益能力，与整体企业经营不可分
- **期初租金陷阱**：新建筑期初租金远高于债券存续期平均租金，用期初租金资本化会高估资产价值
- **超额建筑成本陷阱**：繁荣期建筑成本虚高，即使债券≤实际成本 2/3 仍无保护

## Mental Models
1. **"偿债能力>资产价值"思维**：抵押品的意义在于其独立变现能力（设备信托），而非账面数字（一般公司）
2. **"双重保护"思维**：设备信托债权人=公司运营成功+设备可转让；一般债券债权人=仅公司运营成功
3. **"长周期平均租金"思维**：用债券存续期（10-20 年）的预期平均租金，而非新楼期初租金
4. **"成本 vs 评估价"思维**：忽视"评估价值"，要求实际成本至少比债券发行额高 50%

## Anti-patterns
- 用"账面价值"或"评估价值"判断抵押债券安全性——数字可人为操纵
- 用期初租金资本化估算房地产债券的资产价值——新楼租金会随老化下跌
- 把旅馆/车库/教堂/工厂等特种建筑的抵押债券当作"常规房地产债券"——缺乏易变卖价值
- 因债券有"第一抵押"头衔就放松对发债公司整体偿债能力的考察
- 忽视建筑成本周期性——繁荣期成本虚高，债券发行额/成本比即使"保守"仍不安全

## Reference Tables

### 特殊债券类型的安全性基础
| 类型 | 安全性来源 | 抵押品特征 |
|------|------------|------------|
| 设备信托凭证 | 公司资信+设备独立变现价值 | 机车/货车/客车，可转让给其他运营商 |
| 抵押信托债券 | 抵押证券市值+保护性条款 | 子公司股票/债券，投资公司品种有市值保障 |
| 房地产抵押债券 | 租金收益能力（继续经营价值） | 住房/公寓/商铺，有广泛潜在买家/租户 |
| 一般公司债券 | 公司整体偿债能力 | 厂房/设备，无独立变现价值 |

| 指标 | 要求 |

| 特征 | 典型条款 |
|------|----------|

| 债务递减速率 | 快于设备折旧 |

## Worked Example
**设备信托凭证 vs 一般铁路债券**
铁路公司 A 发行两类债券：① 第一抵押债券（以全线铁路为抵押）；② 设备信托凭证（以 50 台机车为抵押）。萧条中公司违约：
- 第一抵押债券持有人：除允许新运营商接手整条线路外别无选择（几乎不可能）
- 设备信托凭证持有人：可威胁将 50 台机车转移给其他运营商，或实际执行
- 结果：设备信托凭证几乎从未延迟付息/还本，即使公司整体破产

**房地产债券的评估陷阱**
开发商建公寓楼，实际成本 $100 万，但"评估报告"写 $150 万（用期望租金资本化）。发行 $100 万债券（"仅占评估价 2/3"）。Graham 指出：
- 评估价是伪造的——用投机性高租金资本化
- 实际成本 $100 万 vs 债券 $100 万 = 100%，远超 2/3 安全线
- 投资者应要求：实际成本至少比债券高 50%，即债券≤$67 万

## Key Takeaways
1. 一般公司债券的安全性=公司偿债能力，与抵押资产账面价值无关
2. 例外：设备信托凭证（设备可独立变现）、投资公司抵押信托债券（保护性条款+市值保障）
3. 房地产债券的安全性=租金收益能力（继续经营价值），而非评估价值
4. 房地产债券量化标准：贷款≤成本 2/3；（收入-折旧）≥利息 2×
5. 忽视"评估价值"和期初租金——用实际成本和长周期平均租金
6. 特种建筑（旅馆/车库/教堂）的抵押债券=工业债券，需用更严格标准
