# 第33章 损益帐户中的误导性伎俩·子公司收益 / Chapter 33: Misleading Devices in the Income Account · Subsidiary Earnings

## Core Idea
损益帐户中最恶劣的操纵伎俩包括：(1)直接虚增不存在的项目（如联合雪茄商店公司虚计租赁物增值、帕克和蒂尔福德虚计商誉）；(2)通过控股公司机制使股票股息以3倍价值入账形成连环虚胀；(3)利用未合并的子公司隐瞒利润或亏损以操纵各年报告收益。格雷厄姆的铁律：一旦发现帐目篡改的迹象，就可以发现股票操纵——应远离这种公司的一切证券。

## Frameworks Introduced
- **联邦所得税交叉检验法 (Federal Income Tax Cross-Check)**:
  - 步骤：已知某一年的应缴联邦税额 → 根据当年税率计算应税利润 → 将该应税所得与向股东报告的净收益比较 → 若已知必要调整（免税债券利息/国内公司股息等）后仍存在巨大差异，则怀疑报告收益可信度。
  - When to use: 任何公司报表可信度的初步筛查。
  - How: 对比应税所得与报告收益；差异大时要求公司解释。

- **操纵伎俩识别四步 (Four-Step Manipulation Detection)**:
  1. 检查资产负债表变化（流动资产、商誉、商标项目的异常变动）
  2. 核对联邦所得税与报告收益的对应关系
  3. 检验子公司是否完全合并、是否用特别股息操纵各年数字
  4. 分析股票股息入账价值——入账价是否超过子公司设定的价值

- **子公司三类操纵 (Three Subsidiary Manipulations)**:
  1. **未合并利润 (Non-consolidated profits)**: 子公司利润未计入母公司报表——低估真实盈利能力。典型：1923年前丁丁公司未合并煤矿子公司利润、纽约统一煤气公司未合并附属电气子公司收益。
  2. **未合并亏损 (Non-consolidated losses)**: 子公司亏损未从母公司收益中扣除——高估真实盈利能力。典型：沃伦兄弟公司1923年报告收益$724,000，未计入两家子公司$623,000亏损，合并后亏损$101,000，税前赤字$50,000，无一分钱联邦税。
  3. **特别股息操纵 (Special Dividend Manipulation)**: 好年景隐瞒子公司利润累积于子公司盈余→坏年景通过特别股息回流→拾高母公司当年收益。典型：伊利铁路公司1922年从宾夕法尼亚煤炭/山腰煤炭公司获得$11M特别股息、北大平洋铁路从芝加哥-伯灵顿-昆西/北部快运/西北改建公司获特别股息、纽约-芝加哥-圣路易斯铁路1931年从惠灵和伊利诺伊铁路获$1.6M返还股息。

## Key Concepts
- **虚增商誉和商标 (Goodwill/Trademark Inflation)**: 将当期费用（如广告）计入商誉账户而不向股东披露——直接虚增当期报告收益。
- **连环虚胀 (Multiplier Inflation)**: 控股公司将收到的子公司股票股息按市价（而非票面）入账，当子公司按票面值冲减盈余时，母公司入账价值为其3倍——"神不知鬼不觉地被乘了个3"。
- **善意欺骗 (Good-Faith Deception)**: 管理者即使出于保持收益稳定性的善意而窜改报告收益，也应受到批评——"这种做法很容易导致居心不良的篡改"。
- **租赁物估价入账 (Leasehold Valuation Capitalization)**: 将已存在的租赁物评估为资本，并将增值计入以后几年的收益——将过去期间的资产"创造"为未来收益。
- **股票股息收入的虚假价值 (Fictitious Value of Stock Dividend Income)**: 控股公司按子公司股票的市价而非票面值将收到的股票股息计入收益——从1929年起纽约股票交易所严格禁止这种做法。

## Mental Models
- 当看到某公司利润上升但流动资产反而缩水时 → 检查商誉/商标项目是否虚增——流动资产减少额如果超过股息支付额还多，多出的部分很可能被虚增商誉掩盖。帕克和蒂尔福德案例：15个月内流动资产减少了$1.6M（比现金股息支付还多$1M），被商誉从$1M增计至$2M掩盖。
- 当公司收益与联邦税严重背离时 → 应税所得与报告收益存在巨大差异 = 报告收益可信度可疑。帕克和蒂尔福德1927-1929年间：应税所得$380K-$742K，而报告收益$792K-$1.076M——正是这一时期"在帐上作了很多手脚"。
- 当发现公司使用问题会计政策时 → 格雷厄姆的经验：应该对所有证券退避三舍，无论其中一些看起来多么安全和有吸引力。联合雪茄商店公司优先股尽管在修正后仍显示充足的安全边际——但"你无法量化应从收益中扣除的管理不善这个因素，对付这种问题的唯一办法就是躲开它们"。
- 当看到子公司隐瞒/回流利润时 → 回忆纽约股票交易所的合理规定：报告每一时期真实的经营业绩和全部真相是管理者的责任；通过平衡繁荣期和萧条期的收益来推测公司"正常盈利能力"是股东的工作。

## Anti-patterns
- **将当期广告费计入商誉虚增收益**：帕克和蒂尔福德公司1929年9月30日至12月31日的短短3个月内商誉和商标从$1M→$1.6M→$2M，$1M的增计来自"广告和其他促销活动费用"。失败原因：(a)会计准则下不允许；(b)不向股东通报；(c)1929年第四季度收益极度失真；(d)年度报表未附会计师验证报告。
- **租赁物估价入账虚增收益**：联合雪茄商店公司1924-1927年——将1924年5月之前已存在的、价值$20M+的租赁物估价，分3个月入账，并以$25平价的9%普通股股息形式每年发放。失败原因：(1)租赁物本质上是负债；(2)无形资产按高于真实成本标示违反会计原则；(3)资本增值应计入资本盈余而非收益；(4)过去期间的资产不能变成未来收益；(5)若真增值了应体现在来自升值建筑物的收益增加——但该公司EPS并未上升。
- **控股公司将股票股息按3倍市价入账**：烟草制品公司从联合雪茄商店公司收到的股票股息（票面$840,000）按市价$5,136,000入账——3倍的乘数虚胀。失败原因：(1)子公司按票面冲减盈余；(2)母公司按3倍市价入账收益；(3)合并基础上真实EPS约$7.27而非报告的$11——高估约50%。
- **"善意"的子公司利润隐瞒**：好年景累积利润到子公司盈余→坏年景提取特别股息贴补母公司微薄收益。表面看是"稳定报告盈利能力"的善意措施，实际为居心不良的篡改留下后门。

## Worked Example
**烟草制品公司——连环虚胀的完整解剖**

背景：从1922年起，联合雪茄商店公司的大部分普通股被烟草制品公司持有（后者又由一家控股公司控制着同样比例的股权）。烟草制品公司市值在1926-1927年平均超过$100M。

操纵手法：
1. 联合雪茄商店公司按票面值$840,000冲减盈余，发放股票股息；
2. 烟草制品公司按市价入账——入账价值为票面值的3倍（$5,136,000）；
3. 股票股息发行本身就是为了在收益中加入虚假因素——即租赁物价值的增值。
4. 通过控股公司机制，虚构的利润被"神不知鬼不觉地乘了个3"。

合并基础上的1926年真实收益：
- 来自美国烟草公司的租金，凑所得税等：+$2,100,000
- 其他来源：+$5,828,000
- 合计：$7,928,000
- 减：股票股息（按票面值计）：-$3,136,000
- 给普通股留下的余额：$4,792,000
- 每股真实收益：$7.27（而非报告的$11）

报告收益高估约50%——完全来自虚构的股票股息入账。

格雷厄姆的格言："只要发现了帐目篡改的迹象，就可以发现这种或那种形式的股票杂耍(stock juggling)。熟悉各种可疑的财务方法有助于分析家，甚至包括公众，在这些伎俩出现的时候及时地识破它们。"

## Key Takeaways
1. **一旦发现帐目篡改迹象，就应退避三舍**——无论其他证券看起来多么安全和有吸引力。联合雪茄商店公司优先股"修正后"安全边际仍充足，但"你无法量化应从收益中扣除的管理不善这个因素，对付这种问题的唯一办法就是躲开它们"。
2. **联邦所得税交叉检验是发现虚假收益的最锐利工具**——帕克和蒂尔福德案例中，应税所得与报告收益的巨大差异无可辩驳地证实了1927-1929年报告收益的虚假。
3. **资产负债表和损益帐户的联合分析是发现操纵的关键**——克罗伊格、帕克和蒂尔福德、联合雪茄商店公司、烟草制品公司，都是损益帐户分析+资产负债表的核查结合发现欺骗。
4. **年度报告应包含将向股东报告的净收益与联邦税应税所得进行比较的对照表**——这是格雷厄姆的监管建议，以消除虚假收益的可乘之机。
5. **子公司必须完全合并报告**——未合并利润会低估真实盈利能力，未合并亏损会高估真实盈利能力，特别股息操纵会扭曲各年报告。纽约股票交易所的新规定：要求对子公司的收益如实报告。
6. **管理者即使出于善意也不应窜改报告收益**——通过平衡繁荣期和萧条期的收益来推测公司"正常盈利能力"是股东的工作，不是管理者的责任；"善意的欺骗"很容易被居心不良的篡改利用。
