# 第28章 普通股投资的推荐原则 / Chapter 28: Recommendation Principles for Common-Stock Investment

## Core Idea
在旧三重标准失效而新时代教条灾难性破产之后，普通股投资仍可建立于两条推荐原则之上：(1)投资应视为组合性操作，通过分散化中和个别风险；(2)购买必须基于定性+定量检验，且支付价格须有据可查地低于内在价值——同时应比债券选择更重视前景分析。

## Frameworks Introduced
- **两条推荐原则 (Two Recommendation Principles)**:
  1. 投资应视为一种组合性操作(group operation)——分散措施是获得满意平均结果的保证。
  2. 具体证券的选择应采用与固定价值投资选择相对应的定量和定性检验措施，同时更重视对所考察证券前景的分析。
  - When to use: 构建任何普通股投资方案时的顶层框架。
  - How: 先分散化再精选；每一笔购买必须有价格合理性依据。

- **保险类比模型 (Insurance Analogy)**: 普通股投资≈保险商承保。保险商根据实际经验衡量每宗风险、收取保费，通过分散化中和不可预见的损失。投资者类似地从财务报表出发分析每宗"风险性投资"的完全价值，形成对前景的准确判断，最后通过分散化中和变化。
  - When to use: 理解为何单笔普通股购买不能称为"投资"，而一组成组购买可以。
  - How: 类比人寿保险——出售一份保单≠一项保险业务；购买一支股票≠一项投资操作。

- **基本面假设三命题 (Three Fundamental Assumptions)**: 普通股长期投资可行的前提：(1)国家福利和盈利能力将继续增进；(2)重要企业在资源和利润上会增长；(3)增长主要来自追加资本投资和未分配收益再投资的正常过程。
  - When to use: 检验长期投资论据是否成立。
  - How: 若这三条不成立，则普通股整体策略失去逻辑基础。

## Key Concepts
- **组合性操作 (Group Operation)**: 通过成组、分散、仔细筛选的购买，使得平均结果可靠——是普通股投资区别于普通股投机的核心机制。
- **价格合理性检验 (Price Reasonableness Test)**: 购买价格的合理性必须根据过去和现期记录所进行的慎重估价结果的验证——这是新时代教条的致命漏洞所在。
- **历史记录的重要性 (Importance of Historical Record)**: 良好历史记录虽非未来的确定性指标，但在组合层面提供了比不良记录更充分的保证——资本、经验、声誉、贸易合同构成过去盈利能力的因素必然影响未来。
- **投资vs投机的分界模糊 (Blurred Investment-Speculation Boundary)**: 当投资者和投机者操作同样的媒介（普通股）时，分界线只存在于脑子里——普通股投资者必须时刻关注价格及价格变化，不可避免成为股市参与者。
- **内在价值与价格的背离 (Intrinsic Value vs. Price Divergence)**: 投资者关心内在价值不意味着价格毫无意义；只有当表现出的内在价值与支付价格相称时，证券才具吸引力。

## Mental Models
- 当被建议"买入好股票即可，不必管价格"时 → 回忆：这是新时代教条的致命漏洞；如果没有以过去记录为根据的检验，就无从确定股票价值的上界，投资必然演变为投机。
- 当单笔购买看起来像"投资"时 → 类比保险：出售一份保单≠一项保险业务；购买一支股票≠一项投资操作。投资性购买只能在成组、分散、以有吸引力价格执行时才成立。
- 当市场波动幅度极大时 → 投资者的注意力注定从"相对价值而言价格是否有吸引力"转向"市场运行是处于低点还是高点"——1927-1933的狂乱模式足以灭绝普通股理性投资的全部意义。
- 当管理层随意留存收益时 → 回忆：股东获得对股息问题的清醒认识的障碍之一，是股息政策被普遍视为纯粹管理职能。

## Anti-patterns
- **忽视价格因素 (Neglect of Price Factor)**: 新时代教条的核心漏洞——无论证券品质多好，支付价格必须根据过去和现期记录验证。失败原因：没有数量限制的价值度量不如有数量限制的，投资必然退化为投机。
- **以单笔购买冒充投资 (Single-Stock Purchase as Investment)**: 仅仅购买一支普通股不再成其为投资——如同出售一份保单不构成一项保险业务。失败原因：缺乏分散化中和不可预见的未来变化。
- **将投资与投机的界限视为天然清晰 (Assuming Clear Investment-Speculation Boundary)**: 当投资与投机操作同一媒介时，分界线只存在于脑子里。失败原因：投资者无法免受投机气氛感染，尤其当其持有的"投资性"股票正被大肆炒作。
- **盲目外推增长 (Blind Growth Extrapolation)**: 将过去5年甚至3年的收益上升视为未来无限增长的保证。失败原因：收益递减和竞争加剧法则终将压平任何陡峭增长曲线；商业周期带来特殊危险——收益曲线最令人心动之时，也许经济正临顶点。

## Worked Example
**艾奇逊公司1916-1925年的价格稳定性——投资vs投机分界的实证**：
艾奇逊-托皮卡-圣菲铁路公司普通股在1916-1925年间，价格波动范围远小于投机性股票：1916年109-100，1917年108-75……1925年141-116。同期每股收益在$10.59-$17.19之间波动，股息稳定在$6-7。

格雷厄姆的论点是：1926年以前，投资性普通股与投机性普通股之间还存在比较明确的分界线——前者波幅百分比小得多，因为价格主要由既定的股息率决定。投资者所投资的证券起到了"他和投机公众隔离开来"的作用。新时代的一个特点是，投机的兴趣集中于那些过去达到投资等级的证券——这给所有金融界人士的思维带来了极大混乱。

**旁荷特和贺德公司（续第27章）的反面验证**：
1925-1928年收益直线上升→1929年IPO→1930年即亏损→1931-1933年清算。优先股1925-1928累积EPS达$46.79，1929-1932累积亏损-$3.50，最终清算时每股仅收回$17。证明：仅凭3-4年上升趋势即断定"好股票"是致命谬误。

## Key Takeaways
1. **普通股投资必须满足两个条件**：(1)组合性操作+分散化；(2)每笔购买以分析为基础，支付价格有据可查地低于内在价值。
2. **价格是每项投资决策中必不可少的考察因素**——不仅在购买时，在整个持有期中都是如此。当证券不再具有吸引力（品质退化或价格上升到与价值严重脱节）时，适时出手是明智的。
3. **历史记录虽非未来的确定性指标，但在组合层面提供了比不良记录更充分的保证**——"总的说来，实力雄厚的公司要比效益差和资产负债结构不良的企业更有前途"。
4. **投资信托公司的合理转变可以解决散户的困境**——它们在统计分析、分散化、资金管理技能上具有优势；法定义务可以充当"尤利西斯斯的保护神"，抵御投机的海妖诱惑。
5. **投资者必须关注价格及价格变化，不可避免成为股市参与者**——"高"和"低"永远是相对概念，在华尔街往往只有在反思过去时才会出现。
6. **分析技巧对于机智的普通股投资非常重要**——广大公众对普通股的兴趣不会满足于"初步和有限"的结论，必须用足够的实务知识和分析工具武装自己。
