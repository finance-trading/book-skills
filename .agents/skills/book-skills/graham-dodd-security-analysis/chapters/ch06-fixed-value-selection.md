# 第6章：固定价值类投资的选择 / Selection of Fixed-Value Investments

## Core Idea
固定价值类证券的筛选是一个**排除过程**（negative process），而非寻找过程。投资者的首要目标不是获利，而是避免损失。安全性不来自抵押品的账面价值或合同形式，而来自**发行企业履行所有义务的财务能力**。买债券是为收益，价格只是附加考虑——绝不能倒置这一逻辑。

## Frameworks Introduced

### 四项原则（The Four Principles）
| # | 原则 | 含义 |
|---|------|------|
| 1 | 安全性以支付能力衡量，非以留置权衡量 | 看企业整体偿债能力，不看特定抵押品 |
| 2 | 以萧条期而非繁荣期作为考察基础 | 压力测试应使用低谷数据 |
| 3 | 非常高的利率不能弥补安全性的不足 | 高收益≠值得承担的风险 |
| 4 | 挑选任何债券作为投资都应遵循排除性原则，并以量化指标检验 | 有疑问就否定 |

### 三条引理（Corollaries from Principle 1）
1. **有无留置权无关紧要**：优质信用债券优于劣质抵押债券（通用电气3.5%无抵押债券优于任何低资质抵押债券）
2. **最强企业的最高收益债务原理**：若一家企业的任一债券算投资级，则其全部证券都算；若高级债券不安全，则第一抵押债券也不安全。应选择强公司的最高收益率品种
3. **低级证券须有显著收益率优势才值得考虑**：若价差过小（如<5个百分点），宁取高级证券

### "买债券就为收益"的观念批判
- 错误逻辑："因为收益固定，所以价格无所谓"→ 实际上价格反映安全边际
- 错误逻辑："债券名称=安全性"→ 形式本身不代表安全，企业实力才是保障
- 债券的内在劣势：收益有限，故必须依靠优先求偿权+明确的偿还承诺；但这两者的有效性仍取决于企业的实际财务能力

## Key Concepts
1. **固定价值类证券（Fixed-Value Securities）**：包括优质普通债券与优先股、权利价值可忽略的优质权证、通过担保获得优质高级证券地位的普通股
2. **排除过程（Negative Process）**：选债如筛沙——排除与拒绝，而非寻找与接受
3. **留置权（Lien）**：对特定资产的法定要求权。实际价值只在破产时体现，且清算拖延成本高昂
4. **信用债券（Debenture）**：无抵押担保的债券。强企业的信用债券比弱企业的抵押债券更安全
5. **优先债券（Underlying Bonds）**：规模较小、以系统核心路段为留置权的铁路债券。几乎在所有重组中安然无恙，是"无优良公司就不存在优良债券"的例外
6. **分部留置权（Divisional Lien）**：以非干线/非赢利路段为抵押的第一抵押债券——不等于真正的优先债券
7. **最高收益率债务原理**：选定企业后，购买其收益率最高的证券品种

## Mental Models
- **"回避麻烦"模型**：首要目标是避免麻烦发生，而非在麻烦中寻求保护。投资者须求助于契约本身即说明投资不明智
- **抵押品三缺陷**：①经营失败时资产价值随之萎缩；②法定权利行使困难（法庭倾向保护股东/低级债权人）；③清算拖延导致市场价格持续下跌+心理压力
- **强公司-高收益优先模型**：先选企业，再选品种。宁要强公司的信用债，不要弱公司的第一抵押

## Anti-patterns
- ❌ 只看抵押品的原始成本或清算价值就买债券（账面价值在破产时不可靠——Seaboard-All Florida Railway 6%第一抵押债券，1931年铁路完工后价格仅1美分）
- ❌ 为抵押品的"保险费"牺牲收益率（如买古达西包装5%第一抵押债券而放弃5.5%信用债券，代价约1.5%收益率）
- ❌ 认为"只要收益好，风险不值得考虑"
- ❌ 因低级债券价格低就购买，忽视公司整体实力不足

### 跨公司选择原则（当考虑舍乙公司第一抵押而取甲公司低级证券时）
| 条件 | 说明 |
|------|------|
| 条件1 | 甲公司全部债务的收益保障倍数显著高于乙公司 |
| 条件2 | 若收益率无显著差异，则甲公司全部债务的安全性必须大大优于乙公司 |

## Worked Example
**古达西包装公司（Armour and Company）两债比较**
- 1946年到期的5%第一抵押债券：1931年12月价格$95，收益率约5.5%
- 1937年到期的5.5%信用债券：1931年12月价格$53，到期收益率高达20%

**决策逻辑**：
- 若以近面值购买5%抵押债券，唯一理由必须是相信公司能持续发展
- 既然对古达西有信心，为什么不买5.5%信用债获得更高收益？
- 买抵押债券的真实动机：预期公司可能出错，希望第一抵押权保护
- 但1932年实际检验：费斯克轮胎橡胶公司（Fisk Tire）8%第一抵押债券跌至17美元，8.5%信用债券仅12美元——价差几乎消失
- **结论**：要么拒绝古达西的任何债券，要么购买收益率高得多的低级债券。为"部分保险"付出1.5%收益率代价得不偿失

## Key Takeaways
1. 债券投资的核心是排除而非接受——有疑问就否定（沃特·巴吉特："如果发现难以决定或存有疑虑，那么就否定这张证券"）
2. 安全性来自企业实力，不是抵押品——"无优良公司就不存在优良债券"（优先债券是例外）
3. 应购买最强企业的最高收益率债务，而非为虚假安全感牺牲收益
4. 低级证券须有显著收益率优势（价差≥5个百分点）才值得放弃高级地位
