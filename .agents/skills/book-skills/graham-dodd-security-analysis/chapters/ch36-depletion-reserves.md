# 第36章 耗损、其他摊销费用及意外支出的储备
# Chapter 36: Depletion, Other Amortization Charges and Reserves for Contingencies

## Core Idea
耗损（depletion）是折旧在自然资源行业的特殊形态——矿山、油田、森林等可耗竭资源的价值随开采而逐步消耗。投资者必须根据自己为矿藏股份实际支付的价格（而非公司账面成本）计算耗损储备，从报告收益中扣除资本回收额，才能得到真实的盈利能力。专利、租赁物改良等无形资产同样需要摊销处理。此外，意外支出储备（contingency reserves）在1929年后被滥用——通过冲减盈余而非收益来掩盖真实亏损、平滑利润，严重扭曲了财务报告的真实性和透明度。

## Frameworks Introduced
1. **耗损计算的投资者视角**：
   - 公司计提的耗损费用基于技术性标准（如1913年估值）或公司账面成本，与投资者实际支付价格无关。
   - 投资者必须：以自己购买矿藏股份的价格为基础，按预计可开采年限计算年耗损额，从报告收益中扣除资本回收部分。
   - 公式：年耗损额 = (投资者购买价格 - 流动资产份额) ÷ 预计可开采年限。
2. **专利摊销的"商业风险"处理法**：
   - 理论上应与矿业财产相同——在剩余寿命期内摊销。
   - 实践中过于复杂（无法确定专利在总资产中的具体占比、无法准确判断专利到期后公司前景）。
   - 更合理的方法：将专利视作商业风险而非会计事项——通过支付价格而非收益扣除来反映。
3. **意外支出储备的滥用机制**：
   - 合法目的：在好年景下计提储备以平衡繁荣与萧条期的收益波动。
   - 滥用手法：(a) 使亏损冲减盈余而非收益，掩盖真实亏损；(b) 隐藏实际发生的亏损，虚增资产；(c) 为未来年份储备虚假利润。

## Key Concepts
- **耗损（Depletion）**：通过开采将资本性自然资源（矿藏、油田、森林）转化为可售产品而逐步消耗资产价值的过程。
- **投资者耗损额 vs 公司耗损额**：公司按历史成本或1913年估值计提；投资者必须按实际购买价格计提——两者差距可能巨大。
- **专利摊销的商业风险法**：由于无法准确计算专利在总资产中的占比及到期后影响，将其视作投资判断问题而非会计摊销问题。
- **租赁物改良摊销（Amortization of leasehold improvements）**：在租赁物上建造或改造的成本，必须在租赁期内摊销至零——租约到期后归土地所有者所有。
- **意外支出储备（Contingency reserves）**：好年景下计提以应对未来亏损——但必须通过收益扣除而非盈余冲减，否则丧失透明度。
- **"平衡收益"的谬误**：通过储备平滑收益看似善意，实则掩盖真相——管理者应如实披露每年经营结果，平衡工作留给股东完成。

## Mental Models
- **"霍姆斯特克采矿"投资者视角**：1926年矿藏市价$12.5M，其中流动资产$2.5M，矿场与厂房实际投资$10M——投资者必须按$10M而非公司账面成本计算耗损，从收益中回收资本。
- **"尤里卡管道"现实版的矿业版**：公司按历史成本计提耗损可能严重不足或过度——投资者必须根据自己支付的价格重新计算。
- **"美国商业酒精"的三步骤操纵术**：(1) 将大量资金从资本转移到资本盈余；(2) 从资本盈余向各储备转移不同金额；(3) 将各种亏损冲减储备而非收益——1931-1932年报告亏损仅$11K，实际流动资产减少$1.6M。
- **"股票掺水逆转"的储备版**：通过冲减盈余而非收益来掩盖亏损，与通过高估资产虚增利润如出一辙——都是会计魔术而非经济现实。

## Anti-patterns
- **按公司账面成本而非投资者购买价格计算耗损**：霍姆斯特克采矿公司1926年市价$12.5M，但公司按1913年估值计提耗损——投资者必须独立计算。
- **省略耗损费用的报告**：多家采矿公司（如肯尼科特铜业、维兰德采矿）在报告收益中不扣除耗损——投资者必须自行计提。
- **用冲减盈余替代冲减收益来处理亏损**：美国商业酒精公司1931-1932年通过冲减盈余掩盖$1.6M流动资产损失，报告仅亏损$11K——严重误导。
- **建立"意外支出储备"以备未来利润操纵**：将好年景利润转入储备，坏年景释放以平滑收益——丧失透明度，为操纵打开方便之门。
- **专利摊销的过度复杂化**：试图精确计算专利在总资产中的占比及到期影响——实践中不可行，不如视作商业风险。

## Worked Example
**霍姆斯特克采矿公司（Homestake Mining）1926年投资者视角耗损计算**

**公司报告数据**：
- 1926年净收益：$1,330,000（每股$5.32）
- 年初市价：$12,500,000（每股$24.32）
- 公司按1913年估值计提耗损

**投资者视角重新计算**：
- 投资者购买价格：$12,500,000
- 减：流动资产份额（现金等）：$2,500,000
- 矿场与厂房实际投资：$10,000,000
- 预计可开采年限：按当时产量最少17年，合理估计不超过20年
- 年耗损额：$10,000,000 ÷ 20年 = $500,000
- 调整后真实盈利能力：$1,330,000 - $500,000 = $830,000

→ 公司报告每股$5.32，调整后每股约$3.32——投资者实际回收的盈利能力比报告低37%。

## Key Takeaways
1. **耗损是资本回收，不是利润**——投资者必须按自己支付的价格计算，从收益中扣除。
2. **公司耗损额与投资者耗损额可能天差地别**——历史成本、1913年估值、投资者购买价格三者完全不同。
3. **专利摊销应视作商业风险**——通过支付价格而非收益扣除来反映，避免过度复杂化。
4. **租赁物改良必须在租赁期内摊销**——租约到期后归土地所有者，成本必须系统分摊。
5. **意外支出储备必须冲减收益而非盈余**——否则丧失透明度，为操纵打开方便之门。
6. **"平衡收益"是管理者的越权**——管理者应如实披露每年结果，平衡工作留给股东判断。
7. **采矿企业的投资者必须独立计算耗损**——不论公司是否报告，这是分析的基本功。
