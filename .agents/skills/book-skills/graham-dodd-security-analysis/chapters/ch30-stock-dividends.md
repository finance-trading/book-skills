# 第30章 股票股息 / Chapter 30: Stock Dividends

## Core Idea
以股票代替现金的股息分配分为特别的和定期的两类；特别股票股息（资本化累积盈余）合法合理但影响令人遗憾，定期股票股息（资本化当年收益的一部分）则在保留利润时构成公平安排——但其核心准则必须是：所发放股票股息的市场价值不得超过留存收益额。

## Frameworks Introduced
- **股票股息二分法 (Stock Dividend Dichotomy)**:
  1. **特别股票股息 (Special Stock Dividends)**: 将以往的累积盈余部分资本化的过程中发放的股票股息——将累积盈余帐户中的大量资金转移到法定资本帐户。
  2. **定期股票股息 (Regular Stock Dividends)**: 仅将当年收益部分资本化过程中发放的股票股息，数额相对较小，根据既定政策连续若干年发放。
  - When to use: 分析任何公司发放股票股息的性质与合理性。
  - How: 判断属于哪一类；考察其对股东的真实利益。

- **留存收益的三步原则 (Three-Step Retention Principle)**（本章总结）:
  1. 收益中的相当大一部分提留再投资的做法必须在确实对股东有利的前提下方可实行——判断依据是：股东从这种做法中获得的利益超过了如果将这些收益向股东分配，股东将获得的现金的价值。提留政策必须明确地得到股东的批准。
  2. 如果留存利润从任何意义上说都是一种必需而非一种选择，则必须得到明确的通报解释；被留存的资金应设置为"储备"而非"盈余利润"。
  3. 出于自愿而保留在企业中的收益应该通过定期配送新股票的方式将其大部分资本化——但它们的现期市场价值不得超过用于再投资的资金额。如果随后发现新增资本已不再需要保留在资本中，必须通过赎回相应发行的证券的方式将它们分配给股东。

- **现金股息不足之辩 (The Inadequacy-of-Cash-Dividend Argument)**: 定期股票股息的三项辩护理由：
  1. (心理/账务便利)公司可以"既留又付"，市场更易接受；
  2. 可能给股东带来较多的现金股息——既定现金股息率通常适用于新增发行的股票；
  3. 通过将再投资利润转入法定资本（而不是盈余），企业管理者负有直接的义务运用好这批新增资源并向它们支付股息——这是对经营效率的挑战和对投资资金运用得当与否的检验。

## Key Concepts
- **拆股 (Stock Split)**: 通过降低平价价值取得与大比例股票股息完全相同的效果；最近一次牛市中降平价的方法比发大比例股票股息常见得多，因为股价涨幅已超出未分配盈余所能覆盖的程度。
- **无平价股票的拆股与股票股息**: 对无平价普通股而言两者导致完全相同的结果，从实际效果上根本无法区别；会计处理上的无限灵活性可以使这种转移成为一种形式化程序（中州电气1926年900%股票股息，冲减盈余仅每股$1）。
- **市场价格的降位功能 (Price-Level Adjustment)**: 特别股票股息唯一表面合理之处在于可将市场价格调整到便于充分交易的水平——伯利恒钢铁1917年200%股票股息将$300降至$150。
- **提前增加现金股息的先兆效应 (Pre-Announcement Effect)**: 特别股票股息往往是固定现金股息率提高的先兆——这赋予其投机的、操纵性的魅力。
- **恶性循环危险 (Vicious Cycle)**: 市场价格越高→股票股息的表面价值越大→反过来给更高的市场价格提供看似合理的存在根据。10%股票股息下无论市价多高，股息回报率"显然都是10%"——这个结果具有欺骗性。

## Mental Models
- 当看到大比例股票股息消息时 → 问：(1)是不是为了把高价位降到可交易水平？(2)有没有即将提高现金股息的先兆？若是后者，警惕内部人借机炒作。
- 当公司长期支付固定比例的定期股票股息时 → 以北美公司检验：10%股票股息在帐面上仅代表每股$1，但因市价远高于设定价值$10，投资者实际收到的股票市值可能达每股$5-$13；若超过当期EPS，即为虚构收益。
- 当控股公司将收到的股票股息按市价入账时 → 警惕"连环虚胀"：子公司按票面价值冲减盈余，母公司却按3倍市价入账收益——联合雪茄商店公司/烟草制品公司的3倍乘数骗术。
- 当讨论是否应该发放股票股息时 → 参照S.H.克雷斯公司模式：景气年份留存收益+定期配送优先股代表这部分收益；萧条年份赎回优先股还给股东现金。

## Anti-patterns
- **恶性循环式股票股息 (Vicious-Cycle Stock Dividends)**: 固定比例（如10%）股票股息配合不断上涨的市价，创造出自我强化的虚假收益率信号。失败原因：无论市价多高，10%的股息回报率看起来不变——狂乱投机及下游投资的掩饰性激励。典型：北美公司1923-1931年持续季度2.5%股票股息。
- **股票股息收入的虚假入账 (Fictitious Valuation of Stock Dividends Received)**: 控股公司将收到的子公司股票股息按远高于子公司设定的市价入账收益。典型：烟草制品公司将从联合雪茄商店公司收到的股票股息按其市价的3倍入账（票面$840,000→入账$5M），虚构利润被连环乘以3倍。
- **以递延费用形式掩盖当期费用（第32章相关）**：把当年本该冲抵收益的费用作为递延资产冲抵盈余。

## Worked Example
**S.H.克雷斯公司：处理未分配收益的理想安排**

S.H.克雷斯公司从1922至1925年，除了每年固定的$8现金股息之外，还发放5%的额外股息——这些额外股息以6%平价$10的特别股票（实际上是优先股）的形式发放。

萧条来临后的运作：
- 1931-1933年的萧条减少了对营运资金的需求（销售量缩减）
- 公司认为用盈余中的现金清偿部分优先股是明智之举

两个步骤体现的原理：
1. 在景气的年份里，收益由公司留存用以支持公司的扩张和增加营运资金，股东则定期获得代表这些收益中一部分的优先股票；
2. 如果随后的商业衰退使得企业不再需要多余的资本，公司可以通过赎回优先股的办法将它们还付给股东。

遗憾之处：克雷斯公司的案例在美国金融史上显得形单影孤；且由于该公司以优先股形式支付的股息仅占这一时期盈余收益的20%，使得该案例的杰出性有所降低。不过它确实揭示了股东应该向管理者要求的股息政策的形式。

对比通用电气1922-1925年类似做法：每年固定$8现金股息外加5%额外股息，以6%平价$100的特别股票形式发放。

## Key Takeaways
1. **特别股票股息的唯一合理用途是价格位的调整**——使高额单价降至便于交易的水平；除此之外的视觉效果都属投机范畴，且易为内部人滥用。
2. **定期股票股息的核心准则是"市值不得超过留存额"**——简单规定即可防止滥用："发放股票股息的市场价值不得超过可用于发放股息的收益额"。拉斯基公司1926-1927年即采用此法：董事会宣布按其设定的$100/股价格发放每股$2的额外股息，同时申明这只是把市场价格当作客观事实。
3. **恶性循环是定期股票股息最危险的副作用**——固定比例股票股息使收益率看似恒定为10%，无论市价多高；这种欺骗性结果为狂乱投机提供了有害激励。
4. **以优先股代普通股发放股票股息有理论优点**——股息支付额明确固定于有效平价，避免帐面价值和市场价值的差别带来的复杂问题；且在不恶化资本结构的前提下代表再投资收益。
5. **以赎回优先股的方式返还多余资本是理想的萧条期应对**——景气的留存通过新股交付给股东，衰退时通过赎回还给股东现金。
6. **纽约股票交易所的上市新规**：要求对应股票股息发放所进行的冲减额度必须同时反映出新股在资本盈余以及法定资本中的权益——以及后续更严格的规定，禁止控股公司将以子公司的股票股息高于子公司设定价值入账收益。
