# 第39章 普通股的市盈率·针对资本结构变化的调整
# Chapter 39: Common-Stock P/E Ratios — Adjustments for Capital-Structure Changes

## Core Idea
市盈率（P/E ratio）是普通股投资中最核心的定量筛选工具：在正常市场条件下，10 倍平均收益是合理基准，16 倍是投资级上限；超过 16 倍的购买本质上是投机。当考察期内发生送股、拆股、配股或可转债/权证行权等资本结构变化时，历史每股数据必须**回溯重述**（retroactive restatement），否则市盈率比较将产生系统性误导。

## Frameworks Introduced
1. **10/16 倍警戒框架**：10× average earnings = 投资合理基准；16× = 投资级硬上限；>16× → 投机（依赖未来增长证明合理性的赌注）。
2. **资本结构回溯调整三层法**：
   - 第一层（简单）：股票股息/拆股 → 以当前股数重新计算整个考察期股数。
   - 第二层（复杂）：低价增发新股（认股权/认股证行权）或高级证券转换为普通股 → 将新增募集资金计入此前各期的可得收益，并加回已节省的利息/股息费用；新股销售收入的收益率按 6%–10% 的假定计入。
   - 第三层（前瞻性）：未行权但可能稀释未来 EPS 的权证/选择权，必须假设其已实施并重新计算"完全稀释"后的 EPS。
3. **投资/投机分界三组分类**：
   - A 组（高价投机）：盈利稳定、财务雄厚，但市价远超平均收益 16 倍。
   - B 组（不稳定投机）：收益波动剧烈，记录不符合投资检验。
   - C 组（通过投资定量检验）：10 年收益具有一定稳定性；平均收益与市价比率恰当；财务结构稳健、营运资金充足。

## Key Concepts
- **市盈率上限（P/E ceiling）**：16×，超过此点购买者长期大概率亏损。
- **回溯重述（Retroactive restatement）**：因资本结构变化而对历史 EPS 进行的等比调整。
- **完全稀释 EPS（Fully-diluted EPS）**：假设所有流通在外的选择权、权证、可转债均已实施时的每股收益。
- **参与权益调整（Participating-rights adjustment）**：管理合同中的利润分成、限制性股票的股息分级等，须按"真实可得"口径计算普通股可分配收益。
- **优质普通股投资 = 诱人投机**：若满足保守投资者的保值与盈利前景要求，该股票市价很可能在未来升值——投资与投机由此统一。

## Mental Models
- **"债券成分"心理模型**：纯股票公司（A 公司）的股票，理论上一部分相当于债券，应按债券标准估价；但市场几乎从不会正确识别这种"内含债券成分"，导致 A 公司整体估值往往低于结构合理的 B 公司。
- **16 倍天花板的心智锁**：牛市中最危险的叙事是"这次不一样"——为高价寻找特殊理由。历史上，习惯于 >16× 买入的人长期必亏。
- **回溯调整的"时间一致性"原则**：比较过去与现在的每股数据，必须保证股数口径一致——否则相当于用两种不同的尺子测量。

## Anti-patterns
- **不对比的错误**：直接用报告 EPS 计算多年平均市盈率，忽略期间拆股/送股/配股，导致系统性低估历史收益能力。
- **忽视稀释选择权**：当权证/可转债持有者拥有任何行权选择权时，分析者若不调整 EPS，等于假设稀释不存在。
- **"最优秀普通股"溢价陷阱**：将品质最优秀的企业等同于可以不受任何价格约束——高价使任何购买都变成投机。
- **混淆投资与投机边界**：忽视 C 组定量检验要求，仅凭"公司好"就无视市盈率已远超 16 倍的事实。

## Reference Tables

### 投资级普通股定量检验清单（C 组标准）
| 检验项 | 要求 |
|---|---|
| 10 年收益稳定性 | 在商业周期大幅波动下表现出一定稳定性 |
| 平均收益/市价比率 | 恰当（一般 ≤10×，上限 ≤16×） |
| 财务结构 | 稳健 |
| 营运资金 | 充足 |
| 资产溢价 | 不以远高于真实资源的溢价出售 |
| 前景 | 至少不差（购买者须主观判断） |

### 资本结构变化调整类型速查
| 变化类型 | 调整方法 |
|---|---|
| 股票股息/拆股 | 以当前股数重算整个考察期 |
| 低价增发（认股权行权） | 新增募集资金计入历史收益；假定收益率 6%–10% |
| 高级证券转普通股 | 回加历史利息/股息费用；增加对应股数 |
| 流通权证/选择权 | 假设已行权，计算完全稀释 EPS |
| 限制性股票 | 按股息分配规则分档计算各档真实 EPS |

## Worked Example
**巴斯克斯戴尔公司（Bathesda-style）1926 年权证稀释调整**

- 报告收益：$860,770；流通普通股 160,000 股 → 报告 EPS = $5.34
- 同时流通：100,000 股认股权证，可以 $25/股 认购新股
- 新募集资金将用于赎回 6% 利率、面值 $2,500,000 的债券

**假设行权后**：
- 新增收入 = $2,500,000 × $25 = $2,500,000（假定按 6% 产生收益 ≈ $150,000）
- 节省利息 = $2,500,000 × 6% = $150,000
- 调整后总收益 ≈ $7,577,000（原文口径）
- 调整后股数 = 160,000 + 100,000 = 260,000 股（原文为 214,000 股）
- 调整后 EPS = $7,577,000 ÷ 214,000 ≈ $3.55

→ 报告 EPS $5.34 与真实 EPS $3.55 差距巨大；未作调整的分析家将严重高估该公司的盈利能力。

## Key Takeaways
1. **10× 合理、16× 警戒**——这是投资与投机的分界线，不是经验法则而是安全边际的量化表达。
2. **任何资本结构变化都必须回溯重述**——不调整的历史 EPS 比较毫无意义。
3. **完全稀释视角是强制性要求**——只要存在任何选择权，就必须假设其已实施。
4. **C 组定量检验是投资的最低门槛**——稳定性、恰当估值、稳健财务缺一不可。
5. **"优质股"不是免死金牌**——高价使最优秀的公司同样沦为投机标的。
