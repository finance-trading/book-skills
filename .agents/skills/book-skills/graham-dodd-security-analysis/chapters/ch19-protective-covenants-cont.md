# 第19章 保护性条款（续）Protective Covenants (Continued)

## Core Idea

保护性条款的实际效果取决于执行力度与合理性平衡。**条款不能确保债券安全**——投资成功主要取决于企业经营成败，契约条款的作用相比之下微不足道。但争取这些条款仍然值得，因为它们"无疑增加了债券安全性"。关键在于：条款设计必须合理可执行，惩罚措施不能反而损害债券持有人利益。

## Frameworks Introduced

### 增发证券的限制框架

#### 一、收益覆盖率标准

| 公司类型 | 条款要求 | 具体比率 |
|---------|---------|---------|
| 纽约爱迪生公司 | 近12个月合并净收益/所有未清偿债券利息费用 | ≥2倍（发行第一留置权续黄金债券） |
| 奥的斯钢铁公司 | 收益/利息费用（发行6% 1941年第一抵押债券） | ≥2.5倍 |

#### 二、铁路部门特殊规则

**总括式抵押（blanket mortgage）债券的限制方式**：
- 长期债务总额 ≤ 已发行股本总额的一定比例
- 新发行债券额 ≤ 新购置财产成本或公平价值的一定比例

**典型案例**：
- 巴尔的摩和俄亥俄铁路公司
- 纽约-纽黑文-哈特福德铁路公司

**"以新抵旧"融资限制**：
- 扬斯薄板和钻管公司5%第一抵押债券：保留$50,000,000未了发行，为今后购置新抵押财产提供75%融资
- 太平洋电话和电报公司：继续发行1952年到期5.5%续债券，为新增和优化资产提供≤75%真实购置成本资金
- 厄尔马怀特铁路公司：发行第一抵押债券额度≤新建工程项目或新购置财产成本或公平价值（取较低者）的80%

### 营运资金要求的分层设计

| 惩罚级别 | 惩罚措施 | 适用场景 |
|---------|---------|---------|
| 轻度 | 停止股息发放，直至比率恢复到规定标准 | 较温和的营运资金不足 |
| 重度 | 宣布债券本金提前到期 | 严重财务恶化 |

**关键洞察**：将营运资金不足等同于"违约事件"实施严厉处罚，对债券持有人不是有效或有利的选择——财务清算有害而非有利于债权人。

### 投资信托债券的特殊保护

**核心原则**：投资信托债券本质上是"以可转让证券为抵押的贷款"，需要类似银行贷款的保护措施。

**有效条款组合**：
1. 抵押品市场价值必须始终高出债券金额足够幅度（如25%）
2. 抵押品价值下降时，投资信托公司必须：
   - 增加资本金（向股东募集更多资本），或
   - 出售证券并以出售收入清偿债务
3. 无条件永久性最低限（不仅作为增发前提）

## Key Concepts

- **Blanket Mortgage（总括式抵押）**：覆盖公司全部或大部分资产的抵押安排
- **After-Acquired Property Clause（后续取得财产条款）**：要求被抵押财产控制在相对较低的固定额度内，迫使新融资以发售低级证券形式取得
- **Working Capital Requirement（营运资金要求）**：规定营运资金相对债券类债务保持一定比率
- **Serial Maturities（分次到期）**：每年清偿部分证券，实现与偿债基金相同的目的
- **Sinking Fund（偿债基金）**：通过公司拨款定期清偿一定比例高级证券

## Mental Models

### 偿债基金的双重好处

1. **安全性提升**：不断缩小流通在外证券规模
2. **市场支持**：连续而充分的购买力量形成证券市场价格支撑

**分布特征**：
- 工业类债券：几乎全部设置
- 公共事业类债券：约一半
- 铁路类债券：很少

### 偿债基金的不可或缺场景

**当抵押品主要是消耗性资本（wasting assets）时**：
- 采掘设备抵押债券：无一例外设置偿债基金，年偿值比例较大
- 不动产抵押债券：偿债基金规模较小

**典型案例**：
- 城际高速运输公司5%第一抵押续债券（1966年到期）：租金收入为保证，必须在1967年租约到期前清偿所有债券
- 烟草制品公司6.5%债券（2022年到期）：价值完全决定于美国烟草公司$2,500,000年积金

### 投票控制权作为补偿机制

**创新思路**：当营运资金充足度未达标时，将股东的投票控制权部分让渡给债券持有人。

**理论基础**：
- 比指定清算人权利更有利（避免律师主导的信托契约）
- 美国实践中罕见但非没有（如第三街铁路公司5% 1960年到期调整债券）

## Anti-patterns

1. **条款万能论**：认为保护性条款可以确保债券安全——实际上投资成功主要取决于企业经营
2. **惩罚过度**：将营运资金不足等同于违约事件——财务清算对债券持有人有害
3. **忽视执行**：条款存在但不执行（如偿债基金支付拖欠时，受托人和持有人通常不采取补救行动）
4. **以偏概全**：大萧条中本息支付状况最好的高级证券，契约条款往往疏漏百出（因为是老牌证券）

## Reference Tables

### 偿债基金与分次到期对比

| 机制 | 运作方式 | 优点 | 缺点 |
|-----|---------|------|------|
| 偿债基金 | 公司定期拨款清偿债券（通知赎回/密封投标/公开市场购回） | 缩小流通规模+市场支持 | 执行问题（利息正常支付时拖欠偿债基金，通常不采取行动） |
| 分次到期 | 每年清偿部分证券 | 实现相同目的 | 导致同种债券市场价格多重性 |

### 偿债基金提留方式

- **最常见**：未清偿优先股总额的一定比例（也许3%最常见）
- **替代方式**：以利润额的一定百分比确定提留额
- **强制性条件**：(1)优先股股息已经或"准备"全额支付；且(2)剩余盈余利润能够满足偿债基金要求

## Worked Example

### 美国钢铁公司偿债基金案例

**背景**：
- 两种利息率5%债券，发行总额$504,000,000
- 优先级别较低的债券在纽约股票交易所上市
- 债券利息不计入基金（"存活着"的债券仍计提利息用于购买，加速基金壮大）

**运作效果**：
- 第一年：购买支付额$3,040,000
- 1928年：增加到$11,616,000
- 最终：所有债券都被清偿或购回

**启示**：偿债基金在企业经营良好时有效运作，但执行问题普遍存在。

### 联邦采捷和熔炼公司案例（缺乏偿债基金）

**背景**：
- 通过发行大规模优先股（约$12,000,000）为一家规模庞大的铁矿企业提供资金
- 优先股没有设置相应的偿债基金

**问题暴露**：
1. 1926年：公司公布10%普通股股息发放决议
2. 矿藏逐渐耗尽 + 向低级权益股东进行收益分配
3. 优先股地位岌岌可危

**法院行动**：
- 公司停止发放普通股股息
- 将这部分剩余利润用于赎购优先股

**教训**：以消耗性资产为抵押的证券，缺少偿债基金将后患无穷。

## Key Takeaways

1. **收益覆盖率条款的实际意义有限**：通常情况下，有保证的收益表现对于吸引投资者购买新发行债券是必不可少的
2. **营运资金条款需要合理设计**：禁止股息分配合理可行，但将营运资金不足等同于违约事件有害
3. **投资信托债券需要严格条款和充分补救措施**：保持抵押证券组合市场价值高于债券债务总额的契约条款非常有效
4. **偿债基金不总是必需**：如果企业被认为是永久性的（如优质铁路/公共事业债券），缺少偿债基金不一定威胁安全性
5. **执行问题普遍存在**：偿债基金条款实施中的问题与保持营运资金条款执行中的问题一样——利息正常支付时拖欠偿债基金，通常不采取行动
6. **条款 ≠ 安全**：大萧条中表现最好的证券往往契约条款最疏漏（因为是老牌证券）
