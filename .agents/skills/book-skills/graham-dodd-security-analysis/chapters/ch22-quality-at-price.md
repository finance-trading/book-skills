# 第22章 质优价廉的高级证券·附权证券
# Ch22: High-Quality, Low-Priced Senior Securities; Privileged Issues

## Core Idea

附权证券（Privileged Issues）——包括可转换证券、参与证券和附认股权证证券——形式上结合了"最大安全性"和"无限资本利得机会"，但实际投资效果往往差强人意。**核心原则**：售价接近或高于面值的附权证券，必须要么满足纯粹固定价值投资标准，要么满足纯粹普通股投机标准，绝不能以双重目的购买。

**The Core Principle**: A privileged senior security selling near or above par must either meet the strict standards of a pure fixed-value investment OR qualify as a pure common-stock speculation. Never buy for dual purposes.

## Frameworks Introduced

### 1. 附权证券的三种形式 (Three Forms of Privileges)

**可转换权 (Conversion Privilege)**
- 持有人有权按规定条件将高级证券转换成普通股
- 最为人们熟知，常用来泛指所有附权证券
- 限制：在投资性价格区间内，获利幅度通常限于面值的25-35%

**参与权 (Participation Privilege)**
- 持有人可获得额外收益，通常取决于普通股股息发放数额
- 优势：长年累月获得，不改变高级证券持有人地位
- 真正价值：在合适时机出售证券的权利提供的获利机会

**认购权 (Subscription/Stock-Purchase Warrants)**
- 持有人有权按规定价格、在规定期间内购买规定数量的普通股
- 利益实现方式：出售认股权证或通过认购股票随即卖出
- 关键风险：认购并持有普通股将带来追加投资风险

### 2. 附权证券选择的两条路径

**路径A：作为高品质投资购买**
- 必须满足纯粹固定价值投资的所有标准
- 安全性不因转换特权而降低要求
- 获利区域限制在25-35%溢价之内
- 持有时间较短，果断在投机性区域出货

**路径B：作为普通股投机购买**
- 对公司未来股价走势充满信心
- 主要兴趣在于转换特权带来的资本利得
- 不能因债券形式提供的表面安全性而倾心于差强人意的特权

### 3. 转换的时机决策框架

**反对投资者实施转换权的理由：**

1. **角色转换风险**：从债券投资者变成股票投机者
   - 放弃了本金和利息的无条件优先要求权
   - 即使品质优良的可转换债券也存在危险性

2. **获利上限**：投资性价格区域内的获利幅度有限（25-35%）
   - 溢价出售可转换证券绝不保险
   - 一旦进入投机性区域，证券行为与普通股无异

3. **时机判断**：当债券价格超出投资性价格区域时，应果断出货
   - 不要对先前判断自怨自艾
   - 价格进入投机区域后，规律与任何投机性股票相同

## Key Concepts

### 转换平价 (Conversion Parity)
当可转换证券的市场价值正好相当于转换可得普通股在现行价格下的市场价值时，称该证券正在以"转换平价"出售。

**公式**：
```
转换价值 = (债券面值 / 转换价格) × 普通股市场价格
```

### 溢价与折价 (Premium and Discount)
- **溢价出售 (Selling at Premium)**：高级证券价格高于转换平价
- **折价出售 (Selling at Discount)**：高级证券价格低于转换平价
- 溢价额 = 实际价格 - 转换平价

### 直接转换价值 (Direct Conversion Value)
不考虑市场溢价，纯粹基于转换比率计算的价值。
```
直接转换价值 = (债券面值 / 转换价格) × 当前股价
```

## Mental Models

### 1. "低价质优"逻辑 (Low-Price, High-Quality Logic)

在某些市场极度混乱时期（如1931-1933年），会出现大量"质优价廉"的证券：
- 财务指标完全达到所有安全性数量检验标准
- 市场价格却异常低廉
- 这是"价格与价值相背离"的典型表现

**识别方法**：
- 深入分析成百上千的证券
- 挑出屈指可数的几种符合要求的候选者
- 接受吹毛求疵式的核查，发现深藏不露的弱点

### 2. 附权证券的"形式与表现之差"

**形式上的吸引力**：
- 结合了最大安全性和无限资本利得机会
- 从形式上讲是所有证券中最具吸引力的

**实际表现的落差**：
- 只有小部分附权证券真正符合高品质投资标准
- 转换特征往往是对安全性不足的一种补偿（1926-1929年间尤为明显）
- 实力雄厚企业往往通过发行普通股融资，实力较弱企业倾向发行附权证券

### 3. 获利的不对称性

**投资者困境**：
- 以平价购买可转换债券，转换价格$50，购买时股价$45
- 股价涨到$55时，债券涨到$115（获利15%）
- 股价涨到$65时，债券涨到$130（获利30%）
- 股价涨到$90时，债券涨到$180（获利80%）
- 但此时持有人的地位和风险与股东完全一样

**关键洞察**：
- 持续持有附权证券成为投机性操作
- 一般购买者在持有期中的获利只是最成功持有人从市场交易中获得的最大斩获的一小部分
- 获利未必能够抵消由于买入劣质货所造成的损失

## Anti-patterns

### ❌ 中庸态度的陷阱 (The Trap of Middle Ground)

**错误做法**：
- 为了获得利润分享特权而放松安全性要求
- 希望通过操作可转换证券来降低风险的投机者
- 立场暧昧，结果必然是混乱、糊涂和自我欺骗

**后果**：
- 对由于时运不济造成的不可避免的亏损，常常没有作好资金上或精神上的准备
- 兴趣分散到企业本身和特权条款两个方面
- 到最后可能自己也说不清他们到底是股票持有者还是债券持有者

### ❌ 过早实施转换权

**错误时机**：
- 债券价格刚超过转换平价就急于转换
- 忽视了优先要求权的保护价值
- 没有考虑到角色转换带来的风险

**正确做法**：
- 一般情况下，投资者不应该实施可转换债券的转换权
- 只有在决意要通过这种特殊途径来获得股票进行投机时，才行使转换权

### ❌ 以溢价出售可转换证券

**错误认知**：
- 认为溢价出售可以保险获利
- 忽视了进入投机性区域后的风险

**正确认知**：
- 一旦进入投机性区域，证券的市场行为和其他任何投机性股票的价格变化遵循同样的规律
- 投资者对这些规律一无所知，因而也和他们不相干了

### 成功案例对比

**成功案例：美国电话电报公司6%可转换债券（1918年发行）**
- 发行价格：$94.875，到期收益率7.10%
- 转换条件：1920年8月-1925年8月，1兑1，另付$6
- 1918年8月31日：债券$94.875，股票$98.5
- 1925年：债券涨至$136.5
- **关键**：即使没有转换特权，作为投资性证券购买也是值得的

**失败案例：国民贸易杂志公司6%可转换债券（1928年发行）**
- 发行价格：$97.50，1938年到期
- 转换条件：1928年11月-1930年11月，$37.03/股；之后$40/股
- 1928年11月30日：债券$97.50，股票$34.125
- 1931年6月：清算人被指定
- 1931年8月：债券持有人每$1面值只得到8.5美分
- **教训**：估算收益中近一半来自预期收益，不应过分信赖

## Worked Example

### 案例：兰德·卡戴克斯衣柜公司5.5%债券（1925年发行）

**基本情况**：
- 发行价格：$99.50（原始发行价）
- 到期时间：1931年
- 附带认股权证（1927年7月1日后成为可分离的）
- 认股条件：1926年有权以$40价格购买22.5股A类股票
- A类股票实际上是参与优先股

**安全性检验**：
```
发行前几年收益对新发行债券利息的覆盖率：
1921年：1.7x
1922年：2.3x
1923年：6.7x
1924年：7.2x
1925年（9个月）：12.2x

速动资产净额比债券票面总额高两倍
```

**市场表现**：
- 发行时A类股票市场报价：$42左右（认股权证具有立即实现价值）
- 1926年：股价$53，债券价格$130.5
- 1927年（与雷明顿打字机公司合并）：股价$76，债券价格$190

**投资决策分析**：

**路径A投资者（高品质投资）**：
- 以$99.50购买，满足纯粹投资标准
- 1926年债券涨到$130.5时，获利30%，果断出货
- 将资金更换成另一种可以以接近该价格的附权证券
- 实现"不断地收获利润"的策略

**路径B投机者（普通股投机）**：
- 对公司的A类股票升值充满信心
- 1927年债券涨到$190时，获利90%
- 但此时已经从债券投资者变成了股票投机者
- 如果继续持有，面临与股东完全一样的风险

**关键洞察**：
- 该债券不仅是发行之初就有价值的纯粹投资
- 也是A类股票合适的调换品
- 提供了有利可图的对冲机会

- 第5章建立的证券分类法：固定价值证券 vs 变动价值证券
- 本章的应用：附权证券必须明确归类为投资或投机
- 中庸态度的危害：立场暧昧导致混乱和自我欺骗

- 投资性购买必须满足纯粹投资标准

- 投机性购买必须接受高风险换取高收益

- 市场极度混乱时期会出现"质优价廉"的证券
- 需要深入分析才能发现真正的价值
- 这是"吹毛求疵式核查"的典型应用场景
