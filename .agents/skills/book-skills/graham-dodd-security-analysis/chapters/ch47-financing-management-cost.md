# 第47章 融资和管理成本（Financing and Management Cost）

## Core Idea

公众为新企业融资和管理技能支付的真实代价远超表面数字。以认股权证（warrants）作为对承销商-促销商的部分报酬，是现代融资方法中最具欺骗性的伎俩——它使25-30%的真实融资成本隐匿于无形。Graham & Dodd 对比了旧时代投资银行"三条神圣准则"与1929年后投资信托/新企业融资标准的崩溃，揭示了"蓝天促销术"（blue-sky promotion）如何从明目张胆的诈骗进化为合法但同样欺骗公众的新形式。

## Frameworks Introduced

1. **管理成本三项目拆解**：
   - 融资成本（发行价差）：每股发行价与实际收到金额之差
   - 认股权证价值：从普通股初始价值中剔除的部分
   - 高级职员工资 + 额外税收：投资信托形式带来的附加成本
   - **合计占公众实际支付金额的25-30%**——且是对投入资金的扣除，而非对利润的扣除
2. **旧时代投资银行三准则** vs 新时代背离：
   - 准则①：企业经营记录良好，能以发行价证明合理性 → 投资信托无历史记录
   - 准则②：银行家须先作为股票购买者代表，与管理者保持距离 → 银行家同时是促销商和业主
   - 准则③：报酬必须合理，仅代表融资服务费用 → 认股权证使报酬完全由接受者自定
3. **"蓝天促销术"进化论**：
   - 旧版：销售"地上一个坑"的矿井——赤裸裸诈骗
   - 新版：挑选货真价实企业，对合理价值进行多次出售——合法但同样欺骗
4. **公众双重不利因素**：
   - 使用计谋隐匿交易真实条件
   - 发行公司与管理者之间不存在保持距离的批评关系

## Key Concepts

- **投资信托融资（Investment Trust Financing）**：新兴企业，管理者与投行身份重叠
- **蓝天促销商（Blue-Sky Promoters）**：销售毫无价值之物的投机推销
- **新企业融资陷阱**：无历史记录、无议价能力、投行身兼二职
- **完全公开（Full Disclosure）的局限**：典型投资者既不读招股说明书，也不理解其全部含义
- **"现代融资方法如魔术师的袋子"**：在众目睽睽下变出戏法
- **促销商双重身份**：代表自己与公司创办人做交易，又与公众做另一笔交易

## Mental Models

- **"为管理技能支付的价格"**：新投资信托公司最初资产只有"现金和管理"——投资者用三重代价购买管理
- **合法外衣下的多次出售**：挑选真企业→高估其价值→公开出售→多次获利
- **1933年证券法的保护局限**：强制公开对精明投资者有用，对普通购买者可能毫无实际用途
- **投资银行角色的根本转变**：从"购买者代表"到"促销商-业主-管理者"

## Anti-patterns

- ❌ 接受认股权证作为"不减少普通股价格"的融资工具——这是最隐蔽的稀释
- ❌ 将承销价差视为唯一融资成本——忽略认股权证价值和隐性管理费用
- ❌ 信任投行对无记录新企业的推荐——投行已不再是购买者代表
- ❌ 认为"完全公开"足以保护公众——魔术师的袋子在光天化日下也有效
- ❌ 将短期高收益（如石油/矿产产量）资本化为永久性收入——最典型的高估手法

**旧准则 vs 新现实**

| 旧准则 | 新时代背离 |
|--------|-----------|
| 企业记录良好 | 投资信托无历史记录 |
| 银行家=购买者代表 | 银行家=促销商+业主 |
| 报酬合理、代表服务费用 | 认股权证使报酬自定、无公认标准 |
| 保持距离、相互批评 | 无距离、无独立判断 |

## Worked Example

**毛奎恩股份公司——双重不利的完整展现**

1933年7月组建，目的是重振禁酒令前的家族酒类进口业务：
- 公众支付$6.75/股
- 承销商获：①$1.75/股差价（表面26%）；②$1价购14,000股选择权；③$7价购30,000股权利
- 真实佣金：$1选择权相当于$4.20/股 → 实际佣金率38%
- 原所有者：以$108K有形资产获得176,000股 → 每股仅62美分
- **最终结论**：公众$6.75/股 = 对$424K有形资产、无盈利记录企业做$1.67M估值
- **75%的售价被消耗**——作为销售佣金或组织者奖赏
- 双重不利：①使用计谋隐匿真实条件 ②不存在发行公司与管理者之间的独立批评关系

## Key Takeaways

1. 公众为新企业融资支付的真实代价（25-30%）远高于表面数字
2. 认股权证是隐匿融资成本的最佳工具——"现代融资方法如同魔术师的袋子"
3. 1933年证券法的完全公开对普通投资者保护有限
4. 投资银行角色已从"购买者代表"变为"促销商-业主-管理者"
5. 合法的高估与赤裸裸的欺诈同样有害——"多次出售真实企业"并不比"销售矿井坑洞"更道德
