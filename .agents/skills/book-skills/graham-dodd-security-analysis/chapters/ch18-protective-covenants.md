# 第18章 保护性条款与高级证券持有者的补救方法
## Protective Covenants and Remedies for Senior Security Holders

## Core Idea

保护性条款（indenture covenants）是债券契约中防止公司行为损害高级证券持有人利益的防御机制。但**条款的存在不等于执行**——受托人（trustee）的被动传统、债券持有人的分散性、以及法律程序的冗长昂贵，使得纸面保护常常落空。投资者需要同时理解条款设计、执行程序与现实困境。

## Frameworks Introduced

### 保护性条款分类框架

#### 一、债券持有人的保护条款

**1. 财务违约类（触发"提前支付条款"）**
- (a) 利息、本金或偿债基金支付违约
- (b) 增加新的担保债务或清算债务
- (c) 发行新的担保债务

**2. 股权稀释类**
- 可转换（或认购）权利导致的稀释（dilution）

#### 二、优先股持有人的保护条款

**1. 累积性保护**
- (a) 长期中支付（累积）优先股股息
- (b) 引入长期债务或优先级更高的债权
- (c) 可转换（或认购）权利的稀释

**2. 营运资金要求**
- 规定营运资金相对债券类债务保持一定比率
- 投资信托公司：要求所有资产市值相对债券类债务保持比率

### 受托人角色的三重矛盾

| 理想角色 | 现实表现 | 根源 |
|---------|---------|------|
| 主动保护受益人利益 | 被动等待持有人指令 | 行业准则："不做任何可能受指责的事" |
| 根据判断主动行事 | 唯命是从的代理人 | 担心"见机行事"招致未来指责 |
| 信托责任（fiduciary duty） | 债券持有人的代理人 | 标准报酬过低，不愿承担风险 |

## Key Concepts

- **Event of Default（违约事件）**：触发债券本金提前到期的契约条款
- **Acceleration Clause（提前支付条款）**：使债券持有人获得与其他债权人同等地位的要求权
- **Indenture or Deed of Trust（信托契约）**：记载保护条款的法律文件
- **Receiver（清算人）**：法院指定的财产管理者，24小时内可指定但收回财产需5年
- **Protective Committee（保护委员会）**：独立于受托人，代表债券持有人利益
- **Voluntary Readjustment Plan（自愿再调整计划）**：替代破产清算的协商方案

## Mental Models

### 清算程序的内在矛盾

债券持有人面临悖论：**他们拥有的法定权利（强制清算）恰恰会损害自身利益**。

- 清算导致所有证券价格下跌（包括债券）
- 仓促出售财产不能获得好价格
- 法律程序旷日持久（常达5年以上）
- 股东权益保护考量进一步延长过程

**结论**：更弱或更有限的法定权利反而使债券持有人处于更有利地位。

### 价格扭曲现象

处于清算过程的公司证券普遍低于公平价值：
- 违约债券价格与低级股票价格存在不合理关系
- 典型案例：菲斯克橡胶公司8%面值债券售40美分，而股票市值高于优先债券

## Anti-patterns

1. **迷信受托人保护**：认为受托人会主动出击维护债券持有人利益
2. **依赖清算权利**：强制清算对债券持有人和股东都没有好处
3. **忽视程序效率**：现行补救程序代价昂贵且拖延不决
4. **被动等待指令**：30%债券持有人提出要求时受托人才行动

## Worked Example

### 纽约金融投资公司案例（投资信托债券）

**背景**：
- 发行两种5%抵押信托债券（1932年和1940年到期）
- 契约要求：抵押证券市值 ≥ 未偿付债券价值的120%
- 受托人职责：(1)通报安全边际下降；(2)30日内未恢复则宣布提前到期；(3)出售抵押证券

**事件序列**：
1. 1931年10月：保障比率下降到不足20%（应为120%，实际跌至远低于标准）
2. 受托人向公司通报"违约事件"
3. 30天内抵押证券未被出售（受托人犹豫）
4. 1932年8月：债券买价跌至$20
5. 1932年10月：一种债券本金到期未偿付，触发行动
6. 1933年1月（15个月后）：抵押证券全部售出，持有人收到65美分/每$1本金

**失败原因分析**：
1. 契约条款缺乏明确程序规则配合
2. 债券持有人缺乏金融智慧和主动性
3. 托管业务准则要求受托人按被动和非理性的持有人指令行事

## Key Takeaways

1. **条款 ≠ 保护**：双联合同中的保护条款与实际结局之间存在明显反差
2. **程序效率是关键**：需要引入更有效的补救方法替代现行拖延且昂贵的清算
3. **两条改进路线**：
   - (a) 使债券持有人合同权利更具强制性，类似商业清算（快速让债权人选择清算或重组）
   - (b) 用自愿再调整计划替代破产法庭机制
4. **受托人改革势在必行**：从"唯命是从的代理人"转变为"根据判断主动行事"的真正受托人
5. **保护委员会定位模糊**：1929年后越来越不满意，承销商因利益关联难以公正代表持有人
