# 第27章 普通股投资理论 / Chapter 27: The Theory of Common-Stock Investment

## Core Idea
普通股投资理论经历了从"战前三重标准"到"新时代谬误"的演变；正确的投资理论必须融合旧理论的审慎与新理论对增长因素的合理关注，同时坚守"价格不得脱离价值"的底线。

## Frameworks Introduced
- **战前三重标准 (Pre-war Triple Standard)**: 投资性普通股必须满足：(1) 适量且准时的股息回报；(2) 稳定而充足的收益记录；(3) 足量有形资产保障。缺一则属投机。
  - When to use: 作为历史基准理解普通股分析演变；在"新时代"叙事再起时回归常识检验。
  - How: 将股息、收益、净资产三个维度同时纳入筛选。

- **新时代理论三命题 (New-Era Triad)**: (1)"普通股价值完全取决于未来收益"；(2)"好的普通股=高利润投资"；(3)"好的普通股=收益呈上升趋势的普通股"。
  - When to use: 识别任何将"收益趋势"作为唯一选股依据的投资叙事。
  - How: 检验叙事是否忽视了价格与价值的背离、是否抹煞了投资与投机的区别。

- **投资与投机的谱系学 (Genealogy of Investment vs. Speculation)**: 投资=面向过去既成事实(vested interest)；投机=面向未来预期(looking forward)。新时代将两者等同，是概念偷换。
  - When to use: 判断一种投资操作是否仅以"价格会继续上涨"为逻辑基础。
  - How: 若该操作的收益论证依赖于"未来收益趋势外推"而无价值锚，即为投机。

## Key Concepts
- **盈利能力 (Earnings Power)**: 企业基于历史记录和资本结构所展现的持续获利能力，区别于"收益趋势"。
- **收益趋势 (Earnings Trend)**: 过去若干年利润变动的方向；新时代将其抬升为唯一估值标准，格雷厄姆指出其与价格之间不存在逻辑联系。
- **账面价值 (Book Value) / 净资产 (Net Worth)**: 面值+累积盈余；战前估值起点，新时代被弃之如敝屣。
- **"蓝筹股"(Blue Chips)**: 新时代教条下最受追捧的高价高趋势股票；投资信托公司"买入之所买"的策略实质是价格动量追逐。
- **内在价值 (Intrinsic Value)**: 由分析支撑的价值判断，必须由既定标准衡量而非由市场价格反向定义。
- **投资信托公司的异化 (Perversion of Investment Trusts)**: 本应执行分散化+专业分析+谨慎购买，却沦为"买入高价蓝筹"的通道。

## Mental Models
- 当市场宣称"这次不一样"时 → 问：该叙事是否抹煞了投资与投机的界限？是否用未来外推取代了价值锚？
- 当"收益趋势"成为唯一选股依据时 → 回忆收益递减与竞争加剧的法则最终将压平任何陡峭的增长曲线。
- 当投资者被劝告"只管买入好股票，不必管价格"时 → 以200或1000的价格购买EPS仅$2.50的股票，其盈利能力并不高于债券，且无优先请求权保护。
- 当"长期持有分散组合必然盈利"的教条被无条件使用时 → 记住：该结论的前提是买入价格相对于收益合理；价格一旦脱离这一比例，整个理论基础随之湮灭。

## Anti-patterns
- **"新时代"教条 (New-Era Dogma)**: 将"收益趋势=价值"作为唯一判据，摒弃股息与资产标准。失败原因：趋势与价格之间无逻辑联系，估值沦为任意判断，等同于投机。典型：1927-1929年A公司（电力，趋势上升但平均收益低）获得比C公司（收益高两倍但趋势平稳）更高的估值。
- **"投资信托公司"的堕落 (Degradation of Investment Trusts)**: 放弃研究/分析/分散化三原则，改为"买入之所买"的高价蓝筹策略。失败原因：将受托人本应执行的审慎策略替换为投机者的动量策略。
- **"普通股作为长期投资"的错误推论 (Fallacious Inference from Long-Term Holding)**: 以埃德加·劳伦斯·史密斯的研究为前提，得出"任何价格购买普通股都合理"的结论。失败原因：史密斯的正确前提（收益>股息→资产价值增长）被错误外推到高价位；投资者争相利用优势的过程本身消灭了优势存在的基础。
- **以趋势外推取代分析 (Trend Extrapolation as Analysis)**: 仅凭3-5年收益上升即断定未来无限增长。失败原因：忽略了商业周期的周期性、竞争法则、收益递减规律。典型：旁荷特和贺德公司（丝袜），1925-1928年收益直线上升，1929年IPO，1930年亏损，1931-1933年清算。

## Worked Example
**新时代理论的两个致命缺陷——以1929年估值为例**：
格雷厄姆列举A、B、C三家公司（1925-1929），A公司5年平均收益仅$1.98/股，C公司平均收益$4.54/股（高130%）。但市场给A的1929最高价对应44倍平均收益，而C仅12倍。新时代逻辑：A"趋势向上"故值钱，C"趋势平稳"故被抛弃。

格雷厄姆的反驳：(1)趋势与价格之间无逻辑联系——良好趋势的"价值"判断是任意的，等于投机；(2)收益递减和竞争加剧将压平任何增长曲线；(3)将"投资"定义为"成功的投机"，抹煞了投资的本质——以分析确保本金安全和满意回报。

更致命的谬误：以每股$200购买收益$10的股票，所获盈利能力仅5%（不高于债券），且无优先请求权保护。"正确的前提（普通股长期收益优于债券）被用来支持错误的结论（任何价位购买都合理）"。

## Key Takeaways
1. **战前三重标准并非错误，而是不足**——它忽略了工业不稳定性的加剧，但其对股息/收益/资产的综合考察仍是安全边际的根基。
2. **新时代理论=旧式投机披投资外衣**——"投资即是成功的投机"这句话暴露了其本质：将对象限定于具有良好收益趋势的普通股。
3. **价格永远是投资决策不可或缺的考察因素**——无论证券品质多好，支付价格必须与内在价值相称。
4. **收益趋势不是比平均收益更可靠的指标**——它同样是一种外推，且与价格之间不存在逻辑联系。
5. **投资信托公司的堕落是新时代谬误的缩影**——放弃分析/分散化/谨慎原则，沦为"买入之所买"的高价蓝筹策略。
6. **普通股长期持有的优势依赖于合理的买入价格**——当价格相对于收益上涨到过高水平，相对于成本的收益率不再高于债券，整个理论的基础湮灭。
