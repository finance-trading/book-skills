# 第3章：信息来源

## Core Idea
证券分析所依赖的信息来源分为三个层次：（1）公司向股东提供的报告；（2）向公共机构提交的定期报告；（3）非定期信息源（上市申请、注册文件、官方报告）。分析家必须认识到——完整损益账户至少应包含八项内容（销售额、净收入、折旧耗损、利息支出、非营业收入明细、所得税、股息分配、盈余调整），而实际中只有不到半数重要企业能够提供如此完整的信息。隐瞒关键信息往往损害证券分析家和公众投资者的利益。

## Frameworks Introduced
- **信息层次金字塔 (Information Hierarchy)**:
  - **第一层：公司向股东的报告**（包括中期报告）——最直接但完备程度参差不齐
  - **第二层：向公共机构的报告**——通常比股东报告更详尽，是重要的补充资源
  - **第三层：非定期信息源**——上市申请、注册文件、官方报告等，价值高但获取不定期
  - **第四层：统计与金融出版物**——标准统计、穆迪、费奇等机构的数据汇总，方便但不可盲信

- **完整损益账户八要素清单 (Complete Income Statement Requirements)**:
  1. 销售收入 (Sales Revenue)
  2. 净收入 (Net Income)
  3. 折旧和耗损 (Depreciation and Depletion)
  4. 利息支出 (Interest Charges)
  5. 非营业收入明细 (Non-operating Income Details)
  6. 所得税 (Federal Income Taxes)
  7. 股息分配 (Dividend Distribution)
  8. 盈余调整明细 (Surplus Adjustments Details)

- **完整资产负债表补充要素**:
  - 存货明细、资产明细、股东人数
  - 财务费用明细、工资与薪金、国家与地方税收
  - 销售费用和一般费用、维修费与折旧
  - 产量与销售量、生产能力利用率
  - 国内与国外销售量、公司内部与对外销售量

## Key Concepts
- **季度报告 (Quarterly Reports)**: 以季度为周期公布统计数据，被认为是几乎适用于各行各业的标准程序。纽约证券交易所越来越积极地推行这种做法。
- **年度报告 (Annual Reports)**: 每一家上市公司都要发布，通常比中期报告更详尽，附有董事长附言总结年度业务并展望未来，最重要的是公布资产负债表。
- **上市申请 (Listing Applications)**: 最重要的非定期信息来源。企业为获得在纽约股票交易所上市的资格，必须提供非常详尽的资料（销售额、产量、联邦税、下属企业业务情况、折旧耗损费用的基准和数额等），这些资料股东们通常是无从得到的。
- **注册上市申请书与招股说明书 (Registration Statements and Prospectuses)**: 1933年《证券法案》规定欲发行新股的企业必须向联邦贸易委员会提交一系列注册申请，其中重要内容必须包含在招股说明书中。
- **股东信息获取权 (Shareholder Information Rights)**: 法律规定上市公司股东在获取信息方面应享有与私营公司合伙人同样的权利，前提是公司利益不应因此受到损害。使公司披露信息可能牵扯司法程序，但实践表明即使是最有抵触情绪的管理层也会在强有力的要求下屈服。

## Mental Models
- 当分析一家公司时 → 先检查其信息披露的完备程度：是否公布了销售收入？折旧政策？分部数据？信息缺失本身就是一个重要的质的因素。
- 当公司隐瞒信息时 → 记住"谁受益"：隐瞒销售收入或折旧费用使得根本无法有效分析财务报表，往往只有公司高层管理者了解这些数据——这给了他们巨大私利而损害广大公众。
- 当依赖统计摘要时 → 永远参考原始资料：标准统计、穆迪等机构的服务在过去20年发展迅速，但仍可能忽视收集某些重要信息，不可盲信二手资料。
- 当评估行业信息时 → 利用多种公开数据源：《当前商业观察》每月公布各行业产量、消费量、库存和未完成订单；贸易期刊定期刊登汇总数字和行业前景分析。

## Anti-patterns
- **隐瞒关键财务数据**: 公司不提供销售收入、折旧费用或分部数据。失败原因：这使得根本无法有效分析财务报表，严重损害证券分析家和股东利益，同时给管理层带来信息优势和不公平私利。
- **盲信统计摘要**: 完全依赖标准统计、穆迪等机构的二手数据而不查阅原始资料。失败原因：这些服务机构可能忽视收集某些重要信息，或存在数据更新延迟。
- **忽视公共机构报告**: 只关注公司公开的股东报告而忽视向监管机构提交的数据。失败案例：纽约联合煤气公司长期向股东提供的信息寥寥无几，但从纽约公共服务委员会可随时获得其详尽年度报告；标准石油集团输油管道企业向股东惜墨如金，但向州际商业委员会提交的报告揭示了大量事实。
- **将信息缺失视为无关紧要**: 认为"公司不公布这些数据说明不重要"。失败原因：信息缺失本身就是危险信号——可能是管理层试图掩盖不利事实。

## Reference Tables

**公司报告周期类型**:

| 报告类型 | 频率 | 适用行业/公司 | 典型内容 |
|----------|------|---------------|----------|
| 月报 | 每月 | 铁路、公用事业、连锁店、通用汽车 | 净收入、销售额、载货量 |
| 季报 | 每季 | 越来越成为各行业的标准程序 | 净收入，有时附损益账户和资产负债表 |
| 年中报告 | 半年 | 橡胶企业例外、美国机车公司 | 不成为任何行业惯例 |
| 年报 | 每年 | 所有上市公司 | 最详尽，附董事长附言，最重要的是资产负债表 |

**完整损益账户应包含的八项内容**:

| 序号 | 项目 | 常见缺失情况 |
|------|------|--------------|
| 1 | 销售收入 | 常被保留，理由是竞争对手或消费者得知会对公司不利 |
| 2 | 净收入 | 相对完整，但有时不扣除累积折旧或联邦税 |
| 3 | 折旧和耗损 | 常被省略，使得无法有效分析 |
| 4 | 利息支出 | 基本完整 |
| 5 | 非营业收入明细 | 常被合并或省略 |
| 6 | 所得税 | 基本完整 |
| 7 | 股息分配 | 基本完整 |
| 8 | 盈余调整明细 | 常被省略 |

## Worked Example
**纽约联合煤气公司 (Consolidated Gas Company of New York) 信息不对称案例**:
在1927年前的很长一段时间里，该公司在华尔街是一支"神秘"的股票，因为它向股东们提供的信息寥寥无几。投机者通常强调它在众多下属企业中未公布权益的价值。但事实上，从纽约公共服务委员会那里可以随时获得它的年度报告，所有与这家公司及其下属企业有关的业务情况和财务数据都可以从中找到。这个案例说明：（1）公司向股东公开的信息可能远少于向监管机构提交的数据；（2）分析家应主动寻找公共机构的报告，而非仅依赖公司主动披露；（3）信息不对称本身可能被投机者利用制造"神秘"溢价。

另一案例：**标准石油集团输油管道企业**向股东信息方面十分吝啬，但由于州际商业委员会的管辖，必须向华盛顿提交年度报告。如果提前几年审查这些年报告并比较价格，就可以发现这些股票被严重低估的事实。

## Key Takeaways
1. **完整损益账户至少需要八项内容**——缺少任何一项（尤其是销售收入、折旧费用）都会严重影响分析有效性。
2. **公共机构报告往往比股东报告更详尽**——铁路和公用事业公司被要求向联邦和州属机构提供数据，这些信息是宝贵的补充资源。
3. **上市申请是最重要的非定期信息源**——包含销售额、产量、联邦税、下属企业详情、折旧基准等股东通常无从得到的资料。
4. **股东有权获取信息**——法律保障上市公司股东在获取信息方面应享有与私营公司合伙人同样的权利，股东应积极行使这一权利。
5. **不可盲信二手统计摘要**——标准统计等机构的服务虽然便利，但仍需参考原始资料和其他可能得到的任何文件。
