# 第46章 认股权证（Stock Option Warrants）

## Core Idea

认股权证（stock option warrants）本质上是"企业前景的具体化身"——它代表了从普通股中取走的某种东西。Graham & Dodd 的根本等式：**普通股价值 + 认股权证价值 = 不含认股权证的普通股自身价值**。由于公众对稀释效应缺乏认识，认股权证成为向承销商、促销商和管理者支付不合理报酬的危险工具，在表面不减少普通股价的情况下实现了权益的隐性转移。

## Frameworks Introduced

1. **认股权证估值三步法**：
   - 确定认股权证的执行条件（比例、行权价、有效期）
   - 计算"执行价值"（exercise value）：一例为「1个认股权证 + 1/4股第二优先股 = 1股普通股」→ 权证价值 = 10 − 1/4(12) = $7。即使市价跌至行权价下方15个点，权证仍具有执行价值
   - 评估稀释影响：新股份发行后EPS下降幅度与增值分享比例的转移
2. **投机吸引力两因素模型**：
   - 质因素（quality factor）：企业获得巨大发展的机会——看好变化前景胜过稳定性，故公共事业类认股权证在特定时期更有吸引力
   - 量因素（quantity factor）：认股权证提供的条件数量（比例/期限/行权价）
   - 杠杆示例：普通股涨175%时某权证可涨2680%（因比例条款放大）；而权证=$70时以$12投资对应一股普通股权益的权利，普通股下跌损失更小
3. **稀释定量分析框架**（A公司假设例）：
   - 情景A：100,000股无权证，资本$2M、收益$200K（$2/股），企业翻倍后价值$4M → $40/股
   - 情景B：另有按$20购100,000股的权证。发行时无执行价值却有真实价值（设每证$5）→ 普通股应减$5。价值翻倍并执行后：新增现金$2M按10%收益率贡献$200K，企业价值$6M、200K股 → $30/股而非$36+
   - 结论：当企业收益和价值增加时，认股权证使普通股所得利益减少——即使行权价高于现价，行使也会摊薄
4. **认股权证定价的"归谬法"**：
   - 经营良好的企业只在需要新资本时增发新股，此时股东有权按比例购买
   - 在不需要资金时分给股东购买权 = "临时凭证"式多余的单独表示形式
   - 基本等式：普通股的价值 + 认股权证的价值 = 普通股自身的价值（不含认股权证）

## Key Concepts

- **执行价值（Exercise Value）**：立即行权的套算价值；无执行价值 ≠ 无真实价值
- **稀释效应（Dilution Effect）**：即使以后情况改观，原股东也只拥有50%股份（以前是100%）
- **信用债券权利（Debenture Rights）**：附属信用债券的认股权证的别称
- **股票购买权证（Stock Purchase Warrants）**：第三名称；独立发行的证券形式
- **认购权（Subscription Rights）的区别**：认股权证可在很长时期内交易，认购权期限短
- **交易基础（Trading Basis）**："旧"/"冷"系列与"新"系列权证的比例折算（如三个旧权证换一个新权证）
- **低价投机品**：给定权证价格与正股持平（平价关系）时便丧失投机优势，双双陷入"盲目"低价投机品之列
- **发行动机演变**：依附高级证券的参与权 → 对承销商推销商和管理者的补偿 → 独立证券公开发行

## Mental Models

- **"从普通股中取走的东西"**：认股权证的全部价值都以普通股价值的减少为代价
- **循环膨胀逻辑（Circular Reasoning）**：
  A公司股票实际值$25，投机至$75 → 发认股权（$25行权）→ 权利价值$10 → 被视为特别股息 → 证明$75合理 → 推动更高价格。对分析家这是骗局和陷阱；权利价值完全由投机者盲目的热情创造
- **稀释的隐蔽性**：股东对权证发行漠不关心，浑然不知未来部分权益已被带走；市场凭粗心在发行前后给出"模样一样的"估值——因此权证成了给推销商和其他内部人员不合理报酬而不引起怀疑的工具
- **认股权证 = 企业前景的具体化身**：提供资金承担"第一风险"的正是为了得到这种回报
- **认股权证的双面性**：经济萧条中许多权证可以很便宜地买到，但其相应投机优势亦告消失

## Anti-patterns

- ❌ 忽视认股权证对普通股权益的稀释——市场常对发行前后股价评定"一模一样"
- ❌ 将认股权证价值等同于普通股收入回报或特别股息——其价值完全由投机热情创造
- ❌ 向管理者发行低价认股权证作为报酬——不透明补偿方式
- ❌ 发行附带认股权证的原始普通股——除欺骗公众相信自己得了实惠外没有任何好处，破坏了财务健康的明显法则
- ❌ 仅因"执行价值"为正就购买认股权证——若价格已反映平价关系则并无投机优势可言
- ❌ 萧条中贪便宜买入认股权证以为捡漏——与其相关的行业前景可能已经改变

**认股权证稀释计算示例（假设A公司）**

| 情景 | 股数 | 企业价值 | 每股价值 | 每股收益 |
|------|------|----------|----------|----------|
| A：无认股权证 | 100K | $4M | $40 | $4 |

## Worked Example

**美国与外国电气公司（American & Foreign Power）——认股权证循环膨胀**

1926-1929年收益增长（主要用于普通股分配）：
| 年份 | 收益 | 可用分配 | 每股 |
|------|------|----------|------|
| 1926 | $216K | $1,244K | $0.17 |
| 1927 | $856K | $1,244K | $0.69 |
| 1928 | $1,528K | $1,249K | $1.22 |
| 1929 | $6,510K | $1,624K | $4.01 |

- 发行1.6M普通股 + 7.1M份认股权证（$25行权价）
- "好的公用事业股票可达50倍市盈率" → 股价$199.25，认股权证$174
- **$6.3M收入 → $320M普通股市值 + $1,240M认股权证市值**
- 电气债券与股票公司持有其80%+股份 → "财产清算价值"人为膨胀
- 1929年9月：电气债券股价$184.50，"财产清算价值"~$150
- 1932-33年：公司濒临清算，5%债券仅$15.25，但认股权证总市值仍近$50M
- **荒谬程度**：高级证券极低价值 vs 认股权证仍维持数十亿市值

## Key Takeaways

1. 认股权证代表从普通股中取走的东西——简单等式：普通股价值 + 认股权证价值 = 不含认股权证的普通股自身价值
2. 认股权证使普通股在未来增长中的所得减少——即使行权价高于市价
3. 稀释效应是隐性的，市场通常对发行前后普通股价"一视同仁"
4. 附带于原始普通股的认股权证是多余表示形式——股东本已拥有购买新股的内在权利
