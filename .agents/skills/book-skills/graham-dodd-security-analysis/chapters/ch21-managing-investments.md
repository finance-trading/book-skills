# 第21章 对所持投资的管理（附注）
## Management of Investments (Notes)

## Core Idea

"永久性投资"的传统概念已破产——购买上乘投资证券后束之高阁的时代结束了。1920-1922年和1929年后的教训证明：**定期检查所持证的必要性**。但持续管理带来成本与困扰，投资者面临三个选择：(1) 接受较低回报换取安心；(2) 以投机替代投资；(3) 谨慎选择+提高安全边际标准+有限度管理。Graham & Dodd推荐第三条路——但承认对所有人都不切实际。

## Frameworks Introduced

### 投资管理的三个历史阶段

| 阶段 | 时期 | 核心理念 | 实践方法 |
|-----|------|---------|---------|
| 传统观念 | 1929年前 | 永久性投资存在 | 无限期持有+忽略价格波动+不关心公司变化 |
| 幻灭期 | 1920-1922 + 1929后 | "永久性投资根本不存在" | 定期检查+精心管理+调换操作 |
| 回归平衡 | 本书立场 | 固定价值投资仍有价值，但需有限度管理 | 谨慎选择+提高安全边际+萧条期策略 |

### 调换操作（Switching）的困境

**早期优势**：
- 高品质知名证券市场价格稳定粘着于发行价格
- 内在价值问题未被查实前，价格不反映恶化
- 警觉投资者有机会将证券转售给麻痹大意的买家

**现代困境**：
- 投资性证券逐渐失去"价格惯性"（price inertia）
- 市场报价对公司状况的任何实质性恶化都能作出迅速反应
- 在证券安全性受到破坏显现出来之前，价格可能已跌落到投机性价位
- 价格超跌现象：明显不利的变化趋势对价格产生比实际收益指标更为剧烈的影响

**结果**：持有人不愿遭受巨大损失 + 当前售价可能过低的合理推测 → 感到只能以投机方式持有这种证券

### 三种投资替代方案

| 方案 | 描述 | 风险 | 适用性 |
|-----|------|------|--------|
| 政府债券/银行存款 | 美国国债或储蓄银行存款 | 极低 | 心理不接受3%回报 |
| 明确投机操作 | 通过技巧降低风险增加利润 | 高 | 对个人太危险（疏忽大意+人性贪婪+急躁心理+交易成本+被动地位） |
| 谨慎投资+有限管理 | 本书推荐 | 中等 | 需要提高安全边际标准+萧条期策略 |

### 萧条期投资策略

**温和衰退**：
- 投资证券只受轻度全市场性冲击
- 内在安全性受影响程度更小

**严重萧条（如1930-1933）**：
- 不要指望所证券能逃脱市场价格一落千丈的厄运
- 但任何合理的固定价值投资策略都应该假定：这种大动荡本质上讲是一场空前绝后的灾难，因而不必处心积虑地加以提防
- 如果1921-1922年的情形可被视为"具有重复性的严重萧条"，那么精心细选的投资组合在这种时期将显示出突出的优越性

**行动指南**：
- 不必因为公司现期收益下降而急于出售那些过往记录良好的证券
- 更用心地关注所证券安全性的恢复状况
- 不时地从深思熟怀的调换操作中获益

### "物美价廉"证券的寻找

**定义**：安全性和市场价格都遭受折损后，持有人寻找另外一种安全性较高、但价格不比原证券高的证券

**特征**：
- 肯定不多见
- 常常默默无闻且交易不活跃
- 典型投资者往往不敢贸然直接购买（担心低价格暗示某种不为人知的隐患）

**正确做法**：
- 经常通过仔细而没有偷见地对大量债券和优先股的检验
- 购买这些证券以替换手中原有的有问题的证券（很少会带来风险的增多，而且很可能意味着一种改进）

## Key Concepts

- **Price Inertia（价格惯性）**：证券市场价格对基本面变化的滞后反应特征
- **Switching（调换）**：将安全性出现问题的证券换成其他更好的证券
- **Permanent Investment（永久性投资）**：准备无限期持有的投资证券
- **Gilt-edged Securities（金边证券）**：被认为是万无一失的上乘投资证券
- **Bargain Securities（物美价廉证券）**：安全性较高但价格相对较低的证券

## Mental Models

### 提高安全边际标准以消释赘虑

**核心策略**：对投资证券的选择力求尽善尽美——数量检验所显示的候选证券的安全边际，必须远远超过所推荐的最低标准，使得在收益锐减的情况下，证券的安全性仍不成问题。

**预期效果**：
- 持有期将发现，只有很小比例的所证券会遇刌麻烦
- 方便投资者在所证券的表现较其他证券更优的情况下（市场价格可能还不至于被助搬）从容地进行调换操作

**典型案例**：
- 假设投资者购买通用烘焙公司发行的利息率5.5%的债券
- 公司收益对该债券利息的比率平均为20倍
- 如果公司利润下滑致使保障倍数限低到了4倍
- 投资者可能打算将该债券调换成另外一种保障倍数为8到10倍的证券（如果能够找刡的话）
- 以购入价格出售通用烘焙公司债券的机会相当大，因为安全边际仍足以令人心动
- 但如果收益下降趋势造成债券价格剧贬，持有人将保留该债券以免遭受巨大损失

### 投资咨询来源的评估

| 来源 | 优点 | 缺点 |
|-----|------|------|
| 投资者自己 | 无利益冲突 | 除非训练和经历完全达刡专业水平，否则判断力不足 |
| 商业银行 | 常常切中要害，对小投资者尤其有益 | 判断常常流于肤浅，不能腾出大量时间进行透彻分析 |
| 投资银行（承销商） | 声誉卓著的承销商认为应该对委托人负责 | 不能指望保有证券投机出售的机构提供完全公正无偏的指导；无意识的自私自利倾向必然影响判断 |
| 纽约股票交易所会员公司 | 意见往往比较深入，比较完全没有偏见 | 客户交易涉及物质利益；经纪人事务所的气氛不可能不对客户产生影响 |
| 投资顾问公司 | 可以做到完全的不偏不倚（既没有证券销售方面利益瓜葛，也不对委托人的交易收取佣金） | 服务收费太高（平均算年要收取投资本金的0.5%，相当于年收益的十分之一） |

**投资顾问公司的矛盾**：
- 为提供"债券市场未来走势预测"和"买卖时机建议"，但这些努力往往是徒劳无功
- 如果能够预测债券市场走势，股票市场走势也应该可以被预测，这样交易股票无疑比交易债券更具有技术优势
- 不相信任何收费的咨询机构具有预测债券或股票市场走势的能力
- 一方面为商品质投资的选择出谋划策，另一方面又指点债券价格的走势，任何将这两者结合起来的努力从根本上说都是不合逻辑和令人困惑的

**收费咨询的合适领地**：
- 纯投机领域：存在攻击（"如果咨询顾问知道该怎么做的话，他就不必干咨询这一行了"）
- 标准的高品质投资领域：投资回报相对较低，收费咨询方式能否行之有效还是疑问
- **中间区域**：顾问们可以处理有关投资价值的问题，建议投资者进行有利的调换，以及向投资者推荐售价大大低于内在价值的安全证券

## Anti-patterns

1. **永久性投资幻觉**：购买了上乘投资证券后束之高阁，抛请脑后
2. **过度管理**：对所证券都必须进行繁琐管理，导致固定价值投资概念的根本意义受刡严峻挑战
3. **依赖市场预测**：试图抓住市场时机进行债券交易——经验证明这种努力往往是徒劳无功
4. **轻信承销商建议**：过于信任证券销售商的意见是不明智的做法
5. **接受过低回报**：人们不会心甘情愿地接受3%的投资回报，他们愿意花费更多精力承受少些风险

## Reference Tables

### 投资回报与风险对比

| 投资类型 | 预期回报 | 风险水平 | 管理需求 |
|---------|---------|---------|---------|
| 美国政府债券 | 3% | 极低 | 无需管理 |
| 储蓄银行存款 | 3.5%-4% | 低 | 无需管理 |
| 谨慎选择的投资证券 | 5% | 中等 | 有限度管理 |
| 投机操作 | 不确定 | 高 | 持续管理 |

**关键洞察**：人们不愿意接受3%回报，而愿意承担风险换取5%回报——这种心理规律和金融智慧相矛盾，使得政府债券/银行存款方案不切实际。

### 投资管理的成本-收益分析

**假设**：一位典型的投资者遵循推荐的谨慎选择标准进行投资，从一组不同公司所发行的证券中获得平均5%的收益

**对比**：
- 5%回报 vs 3%政府债券回报：高出2%
- 5%回报 vs 3.5%-4%储蓄银行回报：高出1%-1.5%

**成本考量**：
- 作出正确的证券投资选择所耗费的精力
- 持有期中反复不断的检查
- 无法规避的资本贬值或完全损失的风险

**结论**：有充分理由可以从总体上肯定固定价值投资的价值——长期地、无忧无虑地持有投资性证券的传统观念有其合理的内在逻辑：**如果持有某种证券会使人牵肢根肚的话，那么这种证券就不值得购买**

## Worked Example

### 通用烘焙公司债券案例（调换操作决策）

**初始投资**：
- 购买通用烘焙公司发行的利息率5.5%的债券
- 公司收益对该债券利息的比率平均为20倍

**情况恶化**：
- 公司利润下滑致使保障倍数限低到了4倍

**决策选择**：

**选项1：调换操作**
- 将该债券调换成另外一种保障倍数为8到10倍的证券（如果能够找刡的话）
- 预期：以购入价格出售通用烘焙公司债券的机会相当大，因为安全边际仍足以令人心动
- 风险：如果收益下降趋势造成债券价格剧贬，调换操作将遭受巨大损失

**选项2：继续持有**
- 持有人将保留该债券以免遭受巨大损失
- 理由：所投资证券的安全性并未面临任何实质性的威胁
- 前提：遵循提高安全边际标准的策略，使得在收益锐减情况下证券安全性仍不成问题

**策略评估**：
- 在深度萧条和市场动荡时期，这种对安全边际高标准、严要求的投资策略将被证明是一种明智之举
- 但劝说所有投资者将其作为标准策略不切实际：这类具有强支撑的证券为数过少，而且更重要的是，佐玮期的智气所助长的乐观主义氛围下，让投资者们倍加小心谨慎地行事跋违背后人的天性

### 萧条期投资策略案例

**1921-1922年情形**：可被视为"具有重复性的严重萧条"

**精心细选的投资组合表现**：
- 在这种时期将显示出突出的优越性
- 投资者不必因为公司现期收益下降而急于出售那些过往记录良好的证券
- 可以更用心地关注所证券安全性的恢复状况
- 不时地从深思熟怀的调换操作中获益

## Key Takeaways

1. **"永久性投资根本不存在"是过度反应**：固定价值投资仍有价值，但需要有限度管理
2. **提高安全边际是核心策略**：数量检验所显示的安全边际必须远远超过最低标准
3. **调换操作面临现代困境**：价格惯性消失，市场迅速反映恶化，调换难度大增
4. **萧条期不要恐慌性抛售**：过往记录良好的证券不必急于出售，更应关注安全性恢复
5. **寻找"物美价廉"证券**：通过仔细检验大量债券和优先股，发现安全性较高但价格相对较低的机会
6. **投资咨询的合适领地**：既不是高品质投资（回报太低）也不是纯投机（顾问知道该怎么做就不必干咨询了），而是中间区域——处理投资价值问题、建议有利调换、推荐安全证券
7. **投机不是投资的替代品**：即使接受过充分金融训练的公众，从事固定价值投资（谨慎选择的话）所得的结果，要比从事投机操作有利得多——从事投资的结果很可能令人失望，但果真如此的话，从事投机的结果将是灾难性的
