# 第11章 债券投资的具体标准（完）

## Core Idea

仅靠收益记录（利息保障比率）不足以完成债券安全性评估。必须用**股票市值对债务比率（stock-value ratio）** 作为第二道数量检验，衡量企业继续经营价值（going-concern value）超过借入债务的幅度。两项检验互为补充：收益指标衡量付息能力，股价指标衡量资本缓冲。

## Frameworks Introduced

### 1. 双重数量检验框架（Dual Quantitative Test）
**何时使用**：工业类债券选择的标准程序；铁路与公用事业可选择性使用。

**如何操作**：
- 第一步：计算7年平均利息保障比率（已在ch8-10建立）
- 第二步：计算普通股总市值 ÷ 债券类负债总额
- 两者需同时达标，任一项不通过即应引起警觉

### 2. 股票价值比率最低标准表

| 企业类型 | 利息保障比率最低值 | 股票价值比率最低值 |
|----------|-------------------|-------------------|
| 公用事业 | 2× | $2股票 : $1债券 |
| 铁路   | 2× | $1.5股票 : $1债券 |
| 工业   | 3× | $1股票 : $1债券 |

### 3. 异常比率的诊断逻辑
- **利息保障勉强达标，股票价值比率远高于标准** → 强化信心，安全性得到额外保证
- **利息保障尚可，股票价值比率远低于标准** → 危险信号。若判断股价被低估就去买该股而非债券——"heads you lose, tails you don't win"

## Key Concepts

- **继续经营价值（going-concern value）**：企业作为整体的价值，完全取决于盈利能力，而非单项资产账面价值。账面固定资产对债券安全性几乎无意义。
- **权益检验（equity test）**：债务与股本+盈余比率上限60%:40%，比收益下限1.75×更严格。适用于对收益记录存疑时的辅助检查。
- **消极艺术（negative art）**：债券投资的核心原则——排除不合格者，而非选择最优者。数据不支持购买理由 ≠ 该证券必然失败。
- **投资信托（investment trust）发债问题**：需以资产市场价值为基础进行财产价值检验。

## Mental Models

1. **"借贷买房"类比**：买债券如同借钱给别人买房——须确信企业整体价值远超债务，如同银行审查房产价值。
2. **"一头输、另一头也不赢"**：如果你判断股价被低估，应该去买股票获利更丰；如果判断错误，你实际上投了一只质量不高的债券。
3. **价格作为补充而非替代**：股价是现有价值的粗略指标，是对收益数据的"详细和周密测评的补充"，不反映准确内在价值。

## Anti-patterns

- ❌ **仅凭收益记录做决策**：属暂时的有利/不利条件或损益表失真，可能使单一年份收益不具代表性
- ❌ **根据市场周期调整标准**：牛市上调、熊市下调股票价值比率标准——需要准确判断股价高低，这对普通人要求过高
- ❌ **依赖账面资产价值**：资产负债表上的财产价值在代表实际现金投资或重置价值方面缺乏可靠性
- ❌ **用"股价过低所以债券也不差"的推理**：如果你确信股价过低，应买股票；如果判断错误，说明你投资了质量不高的债券

## Worked Example

**内陆钢铁公司 vs 克鲁斯博钢铁 vs 通用烤制公司（1932年9月）**

内陆钢铁4.5%债券：利息保障比率6.5×（7年平均），但股票价值比率仅$0.67股票比$1债券——远低于工业$1:1标准。尽管收益尚可，股东权益的市场价值远低于债务。

对比克鲁斯博钢铁：收益表现至少同样出色，股票价值比率更佳，且到期收益率是内陆的两倍多。通用烤制5.5%债券则在两项检验上均表现优异。

**结论**：分析未提供购买内陆钢铁债券的确切理由。即使该公司声誉卓著，统计比较结果明确指向更优选择。这体现了"债券投资是消极艺术"——不是判定它必然失败，而是数据不支持购买。

## Key Takeaways

1. 收益记录是首要但非唯一的定量标准；股票市值对债务比率是不可缺少的重要补充
2. 工业债券必须做双重检验；铁路和公用事业因计算复杂性（租金、子公司优先股等），股票价值比率检验非不可或缺但推荐使用
3. 不能因市场条件变化而调整标准——这要求投资者精确判断市场高低，不切实际
4. 即使最严格检验下仍能找到合格投资（通用烤制公司之例），说明标准虽高但可行
5. 价格检验是补充而非替代，用于鉴别是否有充足所有者权益支持
