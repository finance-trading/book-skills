# 第43章 流动资产价值的重要性
# Chapter 43: The Importance of Current Asset Value (Net Current Asset Value)

## Core Idea
普通股的分析价值排序为：**流动资产价值 > 帐面价值 > 市场价格**。流动资产价值（current asset value）大体上是清算价值（liquidation value）的粗略指标。1932 年纽约证交所超过 40% 的上市公司报价低于其流动资产净值——这意味着大量美国公司"死了比活着更值钱"。这一现象在逻辑上只有两种解释：**要么价格太低（购买机会），要么公司该清算了**。

## Frameworks Introduced
1. **三命题框架**：
   - **命题一**：流动资产价值大体上是清算价值的粗略指标
   - **命题二**：大量普通股售价低于其流动资产价值（因此也低于清算中的可变现值）
   - **命题三**：这种现象本质上不合逻辑——表明在市场走向判断、公司管理策略或股东对资产态度三方面出现了严重错误

2. **低于清算价值交易的基本原理**：
   > 如果一支普通股售价长期低于其清算价值，则表明要么价格太低（购买机会），要么公司该进行清算了。

   **推论 1**：面对如此低的价格，股东不由会怀疑——公司继续经营是否符合股东利益？
   **推论 2**：面对如此低的价格，管理者将被迫采取恰当措施，纠正市价与内在价值之间的差距。

3. **清算折扣率框架（Liquidation Discount Schedule）**：

   | 资产类型 | 清算价值/账面价值范围 | 大数平均值 |
   |---|---|---|
   | 现金资产（含流通证券） | 100% | **100%** |
   | 应收账款（减去普通储备） | 75–90% | **80%** |
   | 存货（取成本价与市价较低者） | 50–75% | **66⅔%** |
   | 固定资产和杂项资产（不动产、房屋、机器、设备、不可转让投资、无形资产等） | 10–50% | **15%**（估计值） |

   **附注**：零售商品分期付款账户在清算中必须低价——范围约 30–60%，平均值为 **30%**。

4. **低于清算价值股票的获利路径（三路径模型）**：
   - **路径 A — 盈利能力恢复**：行业整体改善 或 公司经营策略改进（换管理层/新产品/直销/放弃亏损生产线）
   - **路径 B — 出售或合并**：别的企業能更有效地利用資源，出價至少等於清算價值
   - **路径 C — 全部或部分清算**：完全清算或部分清算派发特别股息

5. **"新时代理论"批判**：新时代理论将所有价值测试转化为对损益表的考察而完全忽略了资产负债表——正是这种理论直接导致了 1932 年大量股票低于清算价值交易的荒谬现象。

## Key Concepts
- **流动资产价值 / 净流动资产价值（Current Asset Value / Net Current Asset Value, NCAV）**：速动资产（现金+应收+存货等）减去全部优先级高于该股票的负债和要求权。不仅排除无形资产，还排除固定资产和杂项资产。
- **清算价值（Liquidation Value）**：当业主放弃经营时能够从中获得的资金——可能整体出售给他人，也可能将各类资产分批售出。
- **现金资产价值（Cash Asset Value）**：现金及准现金（现金、流通证券、存款证明、通知放款、可转让证券按市价计、保险单退保价值）减去全部优先请求权。
- **"死了比活着值钱"悖论（Dead-alive paradox）**：1932 年美国典型公司按清算价值计算的资源远超其市值——业主能够从破产中得到比继续经营更多的利益。
- **资产流失速率（Rate of asset dissipation）**：挑选低于清算价值股票时的关键鉴别指标——偏好流动资产稳定或增加的公司，规避流动资产正在快速流失且无停止之意的公司。

## Mental Models
- **"流动资产 = 粗略清算价值"模型**：在典型例子中（如怀特汽车公司），估算的清算价值与流动资产价值相差无几——非流动资产的变现值可能足以弥补流动资产清算中遭受的损失。
- **"价格太低 or 该清算"二分法模型**：低于清算价值交易只有两种合理解释——这构成了一个无懈可击的逻辑闭合：如果继续经营更有利，股价应高于清算价值；如果继续经营不利，就该清算。
- **"资产流失速率"筛选模型**：低于清算价值的股票中，优选流动资产稳定或增加的公司（如曼哈顿衬衫公司：流动资产总额仅减少 10%，现金资产余额反而大增）；规避资产快速流失的公司（如薛普轿车公司：大萧条时期失去一半多现金资产和超过 60% 净流动资产额）。
- **"华尔街从不问出售价格"模型**：华尔街从不问"出售这家企业时能得多少钱"——而这正是购买股票前应该问的第一个问题。

## Anti-patterns
- **完全忽略资产负债表**："新时代理论"将价值测试完全转化为损益表考察——这正是 1932 年荒谬定价的直接原因。
- **"不清算就没有意义"谬误**：即使公司无意清算，清算价值仍然有意义——它代表了资产的底线价值，也是管理层改善经营的压力来源。
- **不加鉴别地购买所有低于清算价值的股票**：必须规避流动资产正在快速流失且无停止之意的公司；应偏好有改善迹象（行业好转、管理层更换、新产品线）的公司。
- **忽视资产流失的时间维度**：1932 年低于清算价值的股票可能三年后依然低于——但如果公司资产在持续流失，"内在价值"本身也在下降。
- **将"低于清算价值"等同于"立即买入"**：必须结合即期收入和股息、过去获利能力、行业趋势等多维因素综合判断。

## Worked Example
**怀特汽车公司（White Motor Co.）1931.12 清算价值估算**

**基本面**：
- 资本结构：650,000 股普通股
- 市价（1931.12）：$8/股
- 总市值：$5,200,000

**资产负债表（1931.12，单位 $1,000）**：

| 资产项目 | 账面值 | 清算折扣率 | 清算估值 |
|---|---|---|---|
| 现金及流通证券 | $4,057 | 100% | $4,057 |
| 联邦及州政府债券 | 4,573 | 100% | 4,573 |
| 应收账款（减储备） | 56 | 80% | ~45 |
| 存货 | 929 | 66⅔% | ~620 |
| **流动资产清算合计** | | | **~$9,295** |
| 固定资产（减折旧） | 4,996 | 15% | ~750 |
| 杂项资产 | 388 | — | ~— |
| **总资产清算估算** | | | **~$10,045** |

| 负债项目 | 金额 |
|---|---|
| 全部负债（按面值扣除） | ~$4,143 |
| **普通股对应的清算净资产** | **~$5,900–$20,300**（原文口径：$20,300） |
| **每股清算价值** | **~$31** |

→ **市价 $8 vs 估算清算价值 $31** — 市价仅为清算价值的约 1/4。
→ **每股流动资产价值 $34** — 与清算价值 $31 相差不远（印证命题一：流动资产价值 ≈ 清算价值的粗略指标）。
→ **单是扣除所有负债之后的现金资产一项，就大大超过 $8 的市价** — 这确凿地证实了论点。

**后续验证**：
- 1932 年 9 月，斯塔贝克集团以流动资产价值为基础出价收购：现金 $5 + 票据 $25 + 1 股斯塔贝克股票
- 股价上升到 $27，后来达到 $31.50

## Key Takeaways
1. **流动资产价值是清算价值的粗略但有效的指标**——在典型例子中，两者相差无几。
2. **1932 年 40%+ 的纽交所上市公司低于流动资产净值交易** — "死了比活着值钱"。
3. **基本原理闭合**：低于清算价值 → 要么价格太低（机会），要么公司该清算（治理问题）。
4. **清算折扣率表是实用工具**：现金 100%、应收 80%、存货 66⅔%、固定资产 ≈15%、分期付款 30%。
5. **资产流失速率是关键鉴别指标**：优选流动资产稳定的公司，规避资产快速流失的陷阱。
6. **"新时代理论"是罪魁祸首**——完全忽略资产负债表导致系统性低估。
7. **获利的三条路径**：盈利恢复（行业好转/管理改进）、出售合并、全部或部分清算——分析家应偏好即将采取改善措施的公司。
