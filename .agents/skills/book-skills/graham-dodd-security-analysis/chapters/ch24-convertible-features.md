# 第24章 可转换证券的技术特点

## Core Idea
可转换证券的核心技术特征是**转换条件的动态变化**——既包括保护持有人的反稀释条款（降低转换价格），也包括公司为促进转换而设的滑动转换比率（逐步提高转换价格）。前者保护特权价值，后者削弱特权价值。投资者必须理解这两股力量的对抗，以及由此产生的"囚徒困境"式的转换博弈。

## Frameworks Introduced
- **反稀释公式（Anti-dilution Formula）**
  - C' = C × (CO + NP) / (CO + N)
  - C = 原转换价格；CO = 原流通股数；N = 新发行股数；P = 新发行价格
  - 作用：当新股发行导致每股价值稀释时，同比例降低转换价格，保护持有人本金/平价价值
  - 局限：仅保护平价部分；若证券以远高于平价交易，溢价部分仍受稀释损害
  - When to use: 评估任何可转换证券的条款质量
- **滑动转换比率（Sliding Conversion Ratio）**
  - 按时间递减型：如 AT&T 4.5% 债券，1930 年转换价 $180，1931-32 年 $190，1933-37 年 $200
  - 按转换比例递减型：如 Anaconda 7% 债券，前 $10M 按 $53，第二批 $10M 按 $56，逐步升至 $65
  - 效果：制造"抢先转换"的竞争激励，迫使持有人在条件恶化前行动，缩短特权有效期
  - Graham 立场：应完全禁止此类安排；投资者应小心回避
- **AT&T 4.5% 可转换债券案例（1929 年发行）**
  - 转换价格 $180；持有人可用 $100 债券 + $80 现金兑换 1 股
  - 当股价 > $180 时，债券价值 = (股价 - $80)
  - 例：股价 $360 → 债券价值 = $360 - $80 = $280
  - 本质：转换特权 + 认购权（认购价 $100）的组合

## Key Concepts
- **反稀释条款（Anti-dilution Provision）**：当普通股股数增加而资产/盈利未相应增加时，同比例降低转换价格
- **稀释防御的局限**：仅保护平价价值；若债券以 $200 交易（平价 $100），以平价发行等量新股后，除权股价从 $200 跌至 $150，未转换债券价值同步缩水 25%
- **滑动转换比率**：逐步提高转换价格，人为制造转换紧迫感
- **可转换为优先股的债券**：优先股股息通常略高于债券利息（如 5% 债→7% 优先股），但利润上限有限
- **可转换为其他债券的债券**：短期债→长期债，通常息票利率降低，但在利率下降或公司兴旺时获利
- **初始市价高于平价的可转换债券**：如 AT&T 4.5% 债券初始交易价 $142——本质是伪装的普通股购买
- **延期生效的可转换特权**：转换权在发行后数年方生效，引入新的不确定性，损害特权价值

## Mental Models
1. **"囚徒困境"思维**：滑动转换比率制造持有人之间的竞争——谁先转换谁获益，谁等待谁受损
2. **"平价保护 vs 溢价暴露"思维**：反稀释条款只保护面值；若债券溢价交易，溢价部分仍受稀释
3. **"转换特权 + 认购权"思维**：AT&T 案例揭示，允许现金+债券组合转换本质上是嵌入的认购权
4. **"初始溢价=伪装股票"思维**：以 $142 购买"债券"本质是购买普通股，且收益太低达不到投资标准

## Anti-patterns
- 忽视反稀释条款的存在与否——潜在购买者应将其作为选择可转换证券的前提条件
- 被"滑动转换比率"的复杂条款迷惑——其用意在于误导持有人，使其对特权真正性质和价值不明就里
- 以远高于平价的价格购买可转换债券——一旦股价下跌，将面临本金大幅贬值且收入太低
- 在转换条件即将恶化时犹豫不决——滑动比率迫使持有人在仓促与损失之间选择
- 混淆"可转换为优先股"与"可转换为普通股"——前者的利润上限由优先股市场价格决定

## Worked Example
**AT&T 4.5% 可转换债券（1929 年发行，1939 年到期）**
- 1929 年 5 月初始交易价 $142（远高于平价）
- 转换价格 $180；可用 $100 债券 + $80 现金兑换 1 股
- 当股价 $360 时：
  - 全额债券转换：$180 债券 → 1 股 = $360，债券价值 $360
  - 现金+债券转换：$100 债券 + $80 现金 → 1 股，债券价值 = $360 - $80 = $280
- 分析：以 $142 购买本质是购买普通股，且 4.5% 收益太低达不到投资标准；一旦股价下跌，将面临本金大幅贬值
- Graham 评价：这种"模棱两可的'债券'融资形式"极不恰当，增发普通股更直接了当

**Anaconda 7% 债券的滑动转换博弈**
- 总发行 $50M，分 5 批，转换价格从 $53 逐步升至 $65
- 当股价上涨，前几批持有人抢先转换以锁定优惠条件
- 一旦大部分转换完毕，最后一批债券的地位与普通可转换证券无异
- 但 1928 年债券市价存在 30% 溢价——这是投机氛围下的反常事件
- Graham 结论：在转换特权提高到最后一个阶段前，资本利得机会非常有限

## Key Takeaways
1. 反稀释条款保护平价价值，但不保护溢价部分——投资者必须意识到这一局限
2. 滑动转换比率意在削弱特权价值、促进转换——应完全回避
3. 按转换比例递减的滑动比率制造"囚徒困境"——持有人被迫仓促行动
4. 可转换为优先股的债券利润上限有限——优先股市场价格存在天花板
5. 以远高于平价发行的可转换债券本质是伪装的普通股——收益太低，风险太高
6. 延期生效的可转换特权引入新不确定性，损害特权价值
7. AT&T 4.5% 案例揭示：现金+债券转换选项本质是嵌入的认购权
