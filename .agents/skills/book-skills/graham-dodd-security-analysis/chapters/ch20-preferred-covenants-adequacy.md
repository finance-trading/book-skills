# 第20章 优先股保护条款·低级资本的充足度
## Preferred Stock Protective Covenants · Adequacy of Junior Capital

## Core Idea

优先股持有人面临**双重保护需求**：(1) 防止发行优先级更高的证券稀释其地位；(2) 保证低级资本（junior capital）的充足度。优先股在契约中处于不利地位——既无债券持有人的法定权利，又受公司法允许的资本削减操作威胁。**投票控制权**是优先股保护自身利益的关键武器，但实际效果令人怀疑。

## Frameworks Introduced

### 优先股保护条款体系

#### 一、防御更高级证券发行

**标准条款**：
- 除非得到2/3或3/4优先股股东同意，公司不得发行优先级更高的股票或抵押债券

**例外情况**：
- 经深思熟虑后认为批准发行优先证券对优先股股东有利（如新债券融资对于规避财务清算有必要）

**典型案例**：
- 1932年艾廷根-希尔德公司：股息率6.5%第一优先股保护条款规定不得将公司任何财产作为抵押/留置，但1932年财务状况危急时，优先股股东通过财务重整方案，批准发行$5,500,000、利息率5%的借用债券

#### 二、限制无担保债券发行

**现行规定的不合理性**：
- 优先股股东通常无权限制无担保债务发行
- 无担保债务和抵押债务一样，都会对优先股安全构成威胁

**典型案例**：
- 美国金属公司1930年：未经优先股股东投票程序，发行总额$20,000,000短期信用债券
- 1933年公司被迫应优先股股东申请，以抵押担保方式发行续债券

**改进方向**：优先股股东应该有权阻止无担保债券发行（或至少要求征得同意）

#### 三、资本重组中的投票表决

**常见操作**：
- 发行优先级更高或相同的优先股替换原有优先股（常为丢弃累积股息负担）
- 通过给予新优先股相同或更高优先级，迫使原倾向于反对的优先股股东接受妥协

**典型案例**：
1. **奥斯汀-尼科尔斯公司（1930年）**：
   - 原优先股：股息率7%，累积股息已达每股$21
   - 方案：每股换成1股股息率6%累积性优先A股 + 1.2股普通股
   - 结果：约99%老优先股实施转换

2. **风神公司**：
   - 原优先股：股息率7%累积性，由母公司担保
   - 方案：每$100优先股换成1张面值$50利息率6%短期担保债券 + 1张面值$50股息率6%无担保新优先股
   - 新债券和新优先股优先级都高于老优先股
   - 结果：老优先股股东全都接受转换

### 优先股偿债基金

**分布特征**：
- 公共事业和铁路优先股：很少规定
- 工业类优先股：已成为惯例

**关键悖论**：1922-1933年保持投资性证券地位的21支优先股中，只有1支存在偿债基金条款（因为几乎所有高品质优先股都是成熟股票，偿债基金相对而言是新生事物）

**提留方式**：
- 最常见：未清偿优先股总额的3%
- 替代：以利润额的一定百分比确定
- 强制性条件：(1)优先股股息已经或"准备"全额支付；且(2)剩余盈余利润能够满足要求

### 股息支付违约后的投票权

**时间范围**：从立即转移（一旦股息被滞付）到滞后8个季度生效

**权利类型**：
1. 投票选举全部董事
2. 单独推选大部分董事
3. 单独推选少数董事
4. 获得与普通股同等的选举权

**典型案例**：
- 1932年12月麦克渊和罗宾斯公司：优先股股息被滞付，4个季度后获得独占性董事选举权
- 1933年西斯百货公司：之前4个季度股息被滞付，获得推举多数董事权利
- 环球电影公司：6个月股息被滞付情况下，优先股股东有权推举两名董事

### 低级资本充足度保证

**核心问题**：
- 低级资本充足度对任何理性的固定价值投资必不可少
- 公司法允许股东在贷款发生后，撤回几乎所有的股本和盈余
- 债权人在限制这种作法方面无能为力，除非在贷款合同中订立了限制条款

**危险操作**：
1. 通过合法程序将资本数额削减到极低水平，再将剩余分配给股东
2. 大量营业亏损之后，通过削减股本的方式一笔勾销资产负债表赤字
3. 与有名无实的公司进行"合并"以达到削减股本目的

**典型案例**：
- 城际-大都市公司（第38章详细讨论）：为掩盖盈亏项目赤字，股东提议削减法定资本，将带有明显一次性色彩的收入以股息形式派发给股东，而不是保留在公司中保护债券持有人利益
- 国民顶炭公司：两度降低股票平价（1924年从$50降到$10，1933年从$10降到$1），法定股本从$25,000,000减少到$500,000

**有效保护条款（三重保护）**：
以明普顿-兰德股份有限公司发行的利息率6%信用债券为例：
1. 现金股息只能从收益盈余中支付
2. 只有当扣除了拉浪发放股息后的有形资产净额达到长期债务的175%
3. 不得注销总额超过$3,500,000的资本——除非是用新增实收资本或盈余

## Key Concepts

- **Junior Capital（低级资本）**：优先股和普通股构成的资本层级
- **Stated Capital / Legal Capital（法定资本）**：公司章程规定的资本数额
- **Capital Impairment（资本减损）**：通过削减股本消除资产负债表赤字
- **Voting Control Transfer（投票控制权转移）**：股息滞付时优先股获得公司控制权
- **Recapitalization Plan（资本重组计划）**：通过发行新证券替换旧证券

## Mental Models

### 优先股的尴尬立场

优先股股东在资本削减事件中面临两难：
- **利益所在**：与债券持有人相同——保持充足的低级资本
- **短期诱惑**：希望削减普通股设定价值，消除盈亏项目赤字，使得优先股可以继续获得股息
- **长期代价**：被迫放弃累积股息要求权、取消未来股息的累积性特征

**典型案例**：蒙哥马利-沃德公司（1921年底）
- 盈亏项目末字达$7,700,000，致使优先股股息被滞付
- 优先股持有人支持将优先股设定价值从$28,300,000降低$11,400,000
- 目的：消除资产负债表赤字，继续对优先股发放股息并偿还累积股息

### 投票控制权的实际价值

**梅奈格公司案例（1928-1933）**：

**资本结构**：
- 100,000股股息率6%累积性第一优先股
- 320,000股股息率8%累积性优先股（第二优先股）
- 1,600,000股普通股

**初始状态**：梅奈格家族掌握约80%股票，通过投资银行将优先股转售给公众，家族通过掌握普通股继续拥有控制权，个人获利$20,000,000

**章程规定**：两种优先股都没有投票权，除非某一种优先股股息连续4个月未能按期支付。如果发生这种情况，两种优先股的投票权合并，有权推选多数董事

**危机爆发**：1932年两种优先股股息被滞付，1933年两种股票持有人获得公司投票控制权

**实际结果**：
- 董事会人事变动仅一名董事主动辞职（被认为是优先股股东利益代表）
- 剩余5名董事全部是执行经理，倾向于普通股股东
- 两种优先股价格分别跌至$15和$3.125（发行价分别为$101和$50）

**教训**：投票控制权并未得到有效行使，普通股股东仍然在董事会中占据主导地位，且主导的优势更为彻底。

### 非累积性优先股需要更多保护

**反直觉原则**：特殊投票权条款应该只适用于累积性优先股的观点不合理——非累积性优先股在股息滞付时更有理由要求在董事会中安排利益代表，因为他们现期损失的股息无法在将来得到补偿。

## Anti-patterns

1. **迷信投票权保护**：赋予优先股股东投票控制权并不一定对他们有好处——可能得不到有效行使
2. **被动接受资本削减**：优先股股东为获得股息分配而支持削减低级资本，长期利益受损
3. **忽视无担保债券威胁**：优先股股东可以阻止更高级优先股和担保债务发行，但对无担保债务没有任何发言权
4. **依赖形式保护**：投票权条款存在但不执行（如梅奈格公司）

## Worked Example

### 假想案例：分期贷款公司的资本削减

**初始状态**：
- 一家主营分期贷款业务的公司
- 拥有股本和盈余$2,100,000
- 发行20年期利息率5%信用债券，向公众借入$2,000,000

**表面安全性**：公司收益和股权权益都可以保障债券的安全性

**业务萎缩**：公司业务开始萎缩，出现大量闲置现金

**资本削减操作**：
1. 通过股东投票表决，决定将股本数额减少到$100,000（理论上可以削减到$1）
2. 股东以资本返还的形式收回了$2,000,000现金

**最终状态**：
- 股东通过债券持有人提供的资金恢复了原有资本规模
- 股东继续拥有对企业的控制权
- 超过5%债券利息以上的利润完全归股东所有
- **债券持有人处境**：提供了几乎所有的资本，承担了所有风险，但无法染指正常利息以上的利润

**法律保护**：除非债券的双联合同禁止任何将导致股本和盈余降低到一定限额以下的对股东的利益分配，否则这种做法是合法的。

## Key Takeaways

1. **优先股需要双重保护**：防御更高级证券发行 + 限制无担保债券发行
2. **投票控制权是关键但不可靠**：实际效果令人怀疑（梅奈格公司案例），需要证券发行所承担提名和选举责任
3. **非累积性优先股更需要保护**：股息滞付时更有理由要求董事会代表
4. **低级资本充足度至关重要**：公司法允许股东撤回几乎所有股本和盈余，债权人需要契约条款保护
5. **优先股的尴尬立场**：短期利益（获得股息）与长期利益（保持资本充足）冲突，常被普通股股东利用
6. **标准安排应该是**：每种优先股和普通股在任何情况下都拥有分别选举一些董事的权利；只有优先股股息得到定期支付，让普通股股东推选大部分董事才合理
