# 第25章 附认股权证的高级证券·参与证券·三者比较（含调换与对冲）

## Core Idea
三种利润分享特权——**转换（Conversion）**、**参与（Participation）**、**认购（Subscription/认股权证）**——理论上参与特权最优，但牛市中附认股权证证券表现最佳。附权证券的科学用法有二：普通股→高级证券的**调换（Exchange）**，以及买进高级证券+卖空对应普通股的**对冲（Hedging）**。

## Frameworks Introduced
- **三种特权的相对优点比较**
  - 参与特权：保持高级地位的同时分享超额股息；理论最优，但牛市中相对价格常被低估
  - 转换特权：只在实施转换、放弃优先地位时才带来高收入；其真正价值是"在合适时机出售可转换证券的权利"
  - 认购特权：利益只能通过出售认股权证或认购即卖实现；长期认购并持有则给追加资金引入风险
- **调换原则（Exchange Principle）**
  - 愿意保留公司权益份额的普通股持有人，只要同一公司的可转换高级证券以投资性价格出售且接近转换平价，就应将股票调换成该证券
  - 补充：即使调换成本略高于转换平价（5 个点内），若债券收益率高于股票股息率，仍值得
- **对冲操作（Hedging）**
  - 买入可转换高级证券 + 卖空对应数量普通股
  - 市场上行：实施转换，损失限于初始价差+置存费用（carrying expenses）
  - 市场下行：轧平头寸，"undo" 原操作大赚
  - 中间形式：卖出相当于转换所得普通股的**一半**——无论涨跌都可获利，最科学的形式
- **转换平价（Conversion Parity）**
  - 公式：普通股转换平价 = 可转换证券价格 × (转换价格 / $100)
  - 例：优先股可转换为市价 $60 的普通股，证券售价 $90 → 平价 = 90 × (60/100) = $54

## Key Concepts
- **参与证券（Participating Security）**：享有固定股息+超额利润分配权
- **认股权证（Warrants）**：以既定价格购买普通股的权利凭证，可与主证券分离交易
- **调换（Exchange/Swap）**：把普通股换成同一公司的可转换高级证券
- **对冲（Hedging）**：多头高级证券+空头普通股的组合套利
- **置存费用（Carrying Expenses）**：维持对冲头寸的成本（借券费、印花税等）
- **持有期偏误（Holding-Period Bias）**：投机者愿为短线活跃品种多付几个点，导致低流动性优先股价格被低估
- **半额对冲（Half-Hedge）**：卖出相当于一半转换所得的普通股，是 Graham 认为最科学的形式

## Mental Models
1. **"特权独立性"思维**：认股权证的独特优势在于特权与主证券可以分离出售——既能兑现投机利润又保留原投资
2. **"流动性溢价扭曲"思维**：市场赋予高流动性资产不公平溢价，导致同一家公司的优先股比普通股便宜但价值更高
3. **"下行情景非对称性"思维**：对冲的盈利条件是市场下行——恰好与其他持仓形成天然保险
4. **"转换平价锚定"思维**：可转换证券的正确评估基准是它相对于普通股的平价关系，而非绝对价格

## Anti-patterns
- 为了获得较多数息而实施转换特权——结果是失去优先地位和股息保障
- 在强劲牛市中过度配置参与型证券——其相对价格常被低估
- 以远超投资性价格区间的价格（如 >$147）持有可转换证券——本质变成另一种普通股契约
- 忽视借入股票进行卖空的能力限制——对冲的前置条件不满足则整个策略失效
- 用绝对价格而非转换平价判断可转换证券的价值——后者才是可比基准
- 把无投票权的 B 类股票比有投票权的 A 类定价偏低视为反常——这是常态而非例外

## Reference Tables

### 三种特权的理论比较（Graham 排序）
| 特权形式 | 利益实现方式 | 保持高级地位？ | 长线投资评价 |
|----------|--------------|----------------|---------------|
| 参与 | 直接分享超额股息 | 是 | 理论最优 |
| 转换 | 实施转换（放弃优先地位）或择机出售 | 否（实施后） | 提供获利机会 |
| 认购（认股权证） | 出售权证或认购即卖 | 是（权证分离） | 牛市最佳 |

### 附认股权证证券的两大优势
| 优势 | 说明 |
|------|------|
| 特权不被提前赎回剥夺 | 认股权证通常独立存续 |
| 投机与投资地位分离 | 出售权证兑现利润，继续持有原始契约 |

### 对冲头寸的技术要素清单
| 序号 | 要素 |
|------|------|
| 1 | 借入用于卖空的股票的能力 + 无限期保持空头的能力 |
| 2 | 建立头寸的初始成本（价差+佣金） |
| 3 | 维持头寸成本（多头资金利息、空头应付股息、再借入费用、置存费用） |
| 4 | 机会出现时可获最大利润，及其与可能的最大损失的关系 |

## Worked Example
**西屋电气制造公司优先股——15 年参与的实证**
- 每年 $3.50 优先股息（平价 $50，股息率 7%），累积性
- 当普通股年股息超过 $3.50 时，优先股有权平等参与超额部分分配
- 1917 年可以 $52.5 买到
- 此后至 1932 年的 15 年中：
  - 除 7% 基本股息外，额外获得每股约 $7 的参与股息
  - 1929 年最高价 $284（反映参与特征带来的资本增值可能性）
  - 1932 年市场低谷时依然按时获得 7% 股息，每股报价仍达 $32.5
  - 同期普通股股息停止，价格跌至 $15.625
- 结论：参与者萧条中失去的仅仅是暂时利润；高级地位未被动摇

**统一纺织品公司 7% 可转换债券的对冲机会（1919–1921）**
- 公司组建于 1919 年 9 月，合并 6 家成熟纺织企业
- 1919 年 11 月股价 $31.75 → 1920 年 4 月最高 $46.25
- 1920 年 5 月发行 $3M, 7% 短期可转换债券，售价 $98.5，2023 年到期
- 转换比率：每张债券换 22 股普通股（自 1920.5.1 起）
- 保护性条款：当新股发行稀释时，转换价格同比例降低
- 1920.4.23：股价 $44，债券 $98.5，平价 $44.75 —— 债券以接近平价交易
- 22 股股票的年股息 $66 vs 债券年收入 $70
- 1920~1921 萧条：股价跌 60%+ 至 $12.75，股息停止
- 反稀释触发：1920.11 股东可以 $21 认购新股，转换价格从 $45.45 降至 $21
- 结果：债券价格始终保持在 $95 以上，最终 1922 年 10 月以 $102.5 提前赎回

**基思—阿尔比—奥菲厄姆公司优先股对冲（1929）**
- 多头 10 股 @120 = $12,000（含佣金 $55）
- 空头 300 股瑞—基—奥 A 类股票 @39.875 = $11,962.50
- 26 天后轧平：优先股 @$98 卖出（净得 $9,951），空头回购 @$29（成本 $8,745）
- 卖空获利 $3,160.50，多头损失 $2,074.00，净利 **$1,086.50**
- 总投入资金收益率 ~9%（历时 26 天），折年化超 100%
- 关键：交易不存在亏损的可能性，因此可用借款放大自有资金回报

## Key Takeaways
1. 三种特权理论排序：参与>转换>认购；牛市实际表现反转：认股权证>转换>参与
2. 附认股权证证券两大优势：特权不会被提前赎回剥夺；投机利润可单独兑现而保留投资地位
3. 普通股持有人应将股票调换为按投资性价格交易的可转换高级证券——即使付出略高于平价的代价
4. 半额对冲是最科学的形式——无需预测未来方向即可获利
5. 对冲的盈利条件是市场下行——这使其成为其他持仓的天然保险工具
6. 流动性溢价导致优质优先股系统性低估——这是结构性机会而非异常
7. 西屋电气 15 年案例证明：参与特权让投资者在繁荣中获益、在萧条中保住本金
