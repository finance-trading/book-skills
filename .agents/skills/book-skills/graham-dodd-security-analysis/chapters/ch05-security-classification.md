# 第5章：证券的分类

## Core Idea
传统上按法律名称（债券/优先股/普通股）分类证券是**错误且危险的**——"债券"名称不意味着安全，"优先股"名称不意味着优先。证券分析应采用以**购买后的一般表现**（风险-利润特征）为标准的分类法：固定价值类、变动价值类高级证券、普通股类型。

## Frameworks Introduced
- **三类证券新分类法 (Three-Class Classification by Risk-Return Profile)**:
  1. **固定价值类证券 (Fixed-Value Securities)**: 以优质债券或优先股为代表。价值变化是次要考虑因素，购买者的初衷是本金安全和稳定收益。
  2. **变动价值类高级证券 (Variable-Value Senior Securities)**，包含两组：
     - **安全性较高且有获利可能的证券**: 以优质可转换债券为代表——投资者既想获得普通投资的安全性，又想通过转换权获得额外利润。
     - **安全性不够高的证券**: 以劣质债券或优先股为代表——可以明显感觉到亏损风险的存在，但有相应的更多获利可能。
  3. **普通股类型证券 (Common-Stock-Type Securities)**: 以普通股为代表——从理论上或乐观地讲具有无限获利可能。

- **新旧分类对应关系**:
  - 新分类"固定价值类" ≈ 旧分类"投资型债券和优先股"
  - 新分类"变动价值类高级证券"（两组） ≈ 旧分类"投机型债券和优先股"（高质量投机级/低质高级证券）
  - 新分类"普通股类型" ≈ 旧分类"普通股"

- **证券安全性的来源定理**: 债券的安全不是由"债券"这个名称或持有人的法律地位确立的，而是建立在举债公司履行金融义务的能力之上，并且完全由这种能力的大小来衡量。一家一无资产、二无盈利能力的公司的债券和这家公司的股票毫无区别，都一文不值。

## Key Concepts
- **标准的三种证券形式及权利义务 (Standard Forms and Their Rights)**:
  - **债券**: (1) 无条件收取固定利息的权利；(2) 无条件收回固定本金的权利；(3) 无进一步权利，无管理发言权。
  - **优先股**: (1) 在普通股分红前按固定股息率分红；(2) 解散时在普通股获得支付前收回规定投资额；(3) 无表决权。
  - **普通股**: (1) 按比例享有资产所有权；(2) 按比例享有各项优先扣除后的利润；(3) 按比例享有选举董事会等事项的表决权。
- **非标准形式的证券变体 (Variants of Standard Forms)**: 收入债券、可转换债券、可转换优先股、附认股权证的债券或优先股、参与优先股、享有优先权的普通股、不带表决权的普通股等。
- **认股权证 (Warrants)**: 1929年前成为重要金融工具并带来不少灾祸——美国海外能源公司一家发行的认股权证市值达10亿美元，超过美国1914年的国债总额。
- **以名称分类的三大弊端**:
  1. 将优先股与普通股归于一类（优先股更应属于债券的范畴——购买者为固定收入和本金安全而买，而非为合伙权益）。
  2. 认为债券是安全的（名称不带来安全，只有履约能力才带来安全）。
  3. 名称未能对证券加以准确描述（越来越多的证券以非标准形式出现，名不副实）。

## Mental Models
- 当看到"债券"名称时 → 不要默认它安全；检查公司履行义务的能力——没有资产、没有盈利能力的公司的债券与股票一样一文不值。
- 当看到10美分价格的优先股时 → 它实际上就是普通股——不具备高级证券的基本要求（大量低级资本作保障），又有普通股的利润特点（获利可能几乎无限）。
- 当在200美元价位看到可转换债券时 → 购买者/持有者实际上与投资普通股没有区别——因为债券价格随普通股大幅波动。
- 当判断证券类别归属时 → 决定分类的基础不是名称本身，而是其条件和持有人的具体情况；重点不是法律地位可以要求的回报，而是实际可能获得（或购买时合理预期）的回报。

## Reference Tables

**标准证券形式的权利义务矩阵**:

| 证券 | 利息/股息 | 本金/清算 | 表决权 | 进一步权利 |
|------|-----------|-----------|--------|------------|
| 债券 | 固定日期无条件收取固定利息 | 固定日期无条件收回固定本金 | 无 | 无 |
| 优先股 | 普通股分红前按固定股息率分红 | 解散时在普通股之前收回规定投资额 | 无 | 无 |
| 普通股 | 按比例享有各项优先扣除后的利润 | 按比例享有超过债务和优先股之上的资产 | 按比例选举董事会 | 理论上有无限获利可能 |

**三类分类法的特征对比**:

| 类别 | 价值变化的重要性 | 购买者初衷 | 获利可能 |
|------|------------------|------------|----------|
| 固定价值类 | 次要 | 本金安全、稳定收益 | 有限 |
| 变动价值类（组1） | 重要 | 安全性+转换权额外利润 | 有限但明确 |
| 变动价值类（组2） | 重要 | 接受明显亏损风险换更高获利 | 较多但有限 |
| 普通股类型 | 核心 | 承担主要风险 | 理论上无限 |

**跨类归属的判定示例**:
- 售价60美元的3%长期债券 → 通常属于固定价值类
- 一年内到期的80美元债券（无论利率多少） → 不属于固定价值类（短期要么以高于价格20%的数额还本，要么宣告无力偿还使市值大幅下降）
- 200美元价位的AT&T 4.5%可转换债券 → 普通股类型（价格随普通股大幅波动）
- 10美分的优先股 → 普通股类型（无高级证券保障，有普通股利润特征）

## Worked Example
**克罗伊格和托尔公司参与性信用债券 (Kreuger & Toll Participation Certificates)**:
格雷厄姆用它作为"名称误导"的经典案例。该公司公开发售的"参与性信用债券"（名称含"债券"字样，暗示其高级证券地位），开盘价之高与其履行金融义务的能力相差悬殊。它的名称除了产生误导作用以外已经毫无实际意义——这些"债券"都确凿无疑地应该属于普通股类。该案例与随后的连锁反应（该公司最终因欺诈性财务操作崩溃）共同说明：证券名称是分析最不可靠的线索之一，必须穿透名称看证券的实际风险-利润特征。

**大北方铁路公司优先股**的另一例证：在相当一段时期，这支名为"优先股"的证券无论从哪个方面看都是一只普通的普通股——名称与实质完全脱节。

## Key Takeaways
1. **不要按名称分类证券**——决定分类的基础不是名称本身，而是其条件和持有人的具体情况；关键是"实际可能获得的回报"而非"法律地位要求的回报"。
2. **债券名称不等于安全**——安全性完全取决于公司的履约能力；一无资产、二无盈利能力的公司的债券与股票一样一文不值。
3. **优先股应与债券归为同类**——典型优先股因固定收入和本金安全性被购买，投资目标更象债券持有人而非公司合伙人。
4. **采用三类分类法**: 固定价值类 / 变动价值类高级证券（安全且可转换/安全性不足）/ 普通股类型。
5. **价格的极端值会改变证券实质**——10美分的优先股就是普通股；200美元的可转换债券也就是普通股。
