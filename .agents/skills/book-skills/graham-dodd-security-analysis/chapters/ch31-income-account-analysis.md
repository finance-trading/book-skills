# 第31章 损益帐户分析 / Chapter 31: Analysis of the Income Account

## Core Idea
损益帐户（收益报表）是普通股价值评估的核心依据，但其报告数字需要三类关键调整——偶生项目、子公司经营、储备——才能真正反映"预示的盈利能力"(indicated earnings power)；同时，完全专注于收益因素而忽视资产负债表是危险的。

## Frameworks Introduced
- **华尔街简化公式及其批判 (Wall Street Simplified Formula)**:
  - 标准流程：(1)确定每股收益（最新报告数据）→ (2)乘以"质量系数"(coefficient of quality)，反映股息率/记录、公司地位/规模/声誉/财务状况/前景、企业性质、市场整体趋势。
  - 公式：价格 = 每股收益 × 质量系数
  - 批判："质量系数"本身主要决定于"收益趋势"，后者又取决于一段时期内的报告收益——于是"每股收益"在判定价值方面获得了与其他所有因素加总相等的权重。
  - When to use: 识别估值权重失衡的分析框架。
  - How: 若估值几乎完全由单一报告收益决定，则任意性极强。

- **三大调整类别 (Three Adjustment Categories)**: 经审计的报表仍需关键解释和调整：
  1. **偶生利润和亏损 (Non-recurring items)** ——过去交易不应计入当期收益
  2. **子公司或附属公司的经营 (Subsidiary operations)** ——报告可能不完整或误导
  3. **储备 (Reserves)** ——折旧摊销、未来亏损和意外支出的储备易被高估或低估
  - When to use: 分析任何公司的收益质量时的检验清单。
  - How: 逐项检查上述三类的会计处理是否符合"预示的盈利能力"原则。

- **偶生项目的清单 (Inventory of Non-Recurring Items)**: 技术上可被视为当年经营结果一部分、却明显具有意外或非经常性质的科目：
  - 出售固定资产的利润或亏损
  - 出售可转让证券的利润或亏损
  - 清偿资本债务的折价或溢价
  - 人寿保险的保单收入
  - 退税及其利息
  - 来自诉讼的权益
  - 存货的非常减计
  - 应收帐款的非常减计
  - 保有非营业性财产的成本

- **片面对比收益表现的四大弊端 (Four Drawbacks of Income-Only Focus)**:
  1. 耳闻目睹的是与日常经营毫无联系的新概念；
  2. 放弃了收益+资产的双重价值检验，评判标准不够可靠；
  3. 收益报表变化的速度和剧烈程度超过资产负债表，引入夸大了的不稳定性；
  4. 收益报表采用误导性报告形式或从中得出错误结论的可能性远大于资产负债表。

## Key Concepts
- **预示的盈利能力 (Indicated Earnings Power)**: 如果在考察期占主导地位的商业条件继续保持不变，该公司年复一年的预期收益多大——这是分析家从年度报告中真正想了解的指标；一切偶生项目应与之分离。
- **银行和保险公司股票的特殊危险 (Special Hazard of Financial Institutions)**: 其经营状况必然受证券价值变化影响，证券增值部分以当年利润的面目出现——好年景获得的利得被误视为"盈利能力"的一部分，结果必然是荒唐的价值高估以及随之而来的崩溃。投资建议：劝说普通小投资者避免购买银行和保险公司的股票。
- **投资信托公司的矛盾 (Investment Trust Paradox)**: 作为受托机构可靠，作为可交易证券却是危险的工具——其股票本身对投资者不易驾驭。
- **折价购回高级证券所获利润 (Profit from Repurchasing Senior Securities below Par)**: 有时被计入当期收益——应当视为偶生项目剔除：(1)显然是非经常性利润；(2)至多是可疑利润，因为其获得以本公司证券持有人的利益为代价。

## Mental Models
- 当评价任何一家公司的年度业绩时 → 先做三项分离：(1)剥离非经常项目；(2)调整子公司未合并损益；(3)复核折旧/摊销/意外支出储备的合理性——剩下的才是真实经营结果。
- 当看到金融机构的丰厚收益时 → 检验其中有多少来自其所持证券的市场增值——这不是盈利能力，是牛市寄生效应。
- 当公司在萧条期报告出奇好的收益时 → 检查是否来自以低于平价的价格购回本公司债券的操作——这是以债券持有人利益为代价的。
- 当市场将银行的股价推得极高时 → 回忆20年代的教训：这些企业在好年景下的账面收益往往只是证券市值上涨的镜像，一旦行情逆转即现原形。

## Anti-patterns
- **金融机构的证券增值入账 (Securities Appreciation as Earnings for Financial Firms)**: 银行/保险公司将证券组合增值计入当期利润并据此派息。失败原因：好年景的利得不是盈利能力，随后必有等量或更大的缩水；导致股价剧烈波动，进而使新企业仓促草率开张、旧企业盲目扩张、既定标准纷纷背弃。
- **将"折价购回自己证券"计入当期收益 (Repurchase Profit as Earnings)**: 典型：犹他证券公司1915年——会计年度总收益$771,299 + 以折价清偿6%短期债券所获利润$1,309,657 = $2,050,668。若无该非常项目，收益不足以偿付利息。美国国际证券公司1932年购回$12,684,000的5%本公司债券（约半数），平均价55美元，获利约$6M用于抵消投资组合贬值。
- **反向不对称处理 (Asymmetric Treatment)**: 当高级证券被高于票面价格偿还时，溢价损失冲减盈余而非当期收益。典型：美国钢铁1929年将$40.6M注入盈余对应以110清偿$307M本息及子公司债券；固特异轮胎1927年$9.6M注资溢价清偿——分析家应将这些与自己证券相关的特别交易的利得或费用都从经常结果中剔除。

## Worked Example
**犹他证券公司1915年——回购利润撑起的"盈利能力"**

截止到1915年3月31日的会计年度：
- 收益，包括应计入的子公司数余：$771,299
- 减：费用和税额：-$30,288
- 净收益：$741,011
- 加：清偿利率6%短期债券所获利润：$1,309,657
- 合计：$2,050,668
- 减：利率6%短期债券的利息：$1,063,009
- 最终净值：$987,659

表面上看这家控股公司获得了近百万美元的"收益"；实际上它的主要"收益"来源于以折价购回本公司债务的操作。如果没有这个非常项目，公司的收益还不足以偿付利息。这个例子成为1931-1933年萧条期普遍现象的先声——由于充足的现金头寸和微薄的收益之间存在极不相称的反差，许多企业得以大量购回自己的低价证券；该现象在投资信托业最为明显。

分析家的应对：将这些与自己证券的交易视为偶生项目，无论是利得还是损失都应从经常结果中剔除。

## Key Takeaways
1. **经审计的收益报表不等于可靠的估值基础**——直接谎报数据的情况不多见（克罗伊格欺诈属例外），但经过审计的报表仍然需要对偶生项目、子公司、储备进行关键性调整才能使用。
2. **"预示的盈利能力"是唯一合法的分析目标**——即在给定的一组条件下的预期年复一年收入；所有偏离这一目标的临时事项均须分离。
3. **收益+资产双重检验不可或缺**——除非借助考察期初和期末的资产负债表数据，难以准确理解任何收益报表的含义；资源因素不容忽略。
4. **完全依赖收益表现的评价框架有四大结构性缺陷**——概念陌生化、单一标准不可靠、夸大不稳定性、更容易被操纵误导。
5. **对小型投资者：避免银行和保险公司的股票**——其收益严重依赖证券市值的顺周期波动，且容易催生行业性的投机狂热。
6. **折价回购自己证券的利润必须剔除**——它们既非经常，也涉及用债券持有人的利益补贴股东，性质可疑。
