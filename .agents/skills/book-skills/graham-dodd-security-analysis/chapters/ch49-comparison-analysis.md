# 第49章 相同领域公司的比较分析（Comparable Analysis）

## Core Idea

对既定行业的一组股份公司进行统计比较，是分析家的例行工作。它能在整个行业的显景下研究每个公司的业绩，经常能发现价值低估或高估，或得出"某企业证券应被同领域其他公司证券替代"的结论。Graham & Dodd 提出三张标准表格（铁路/公用事业/工业公司），其精髓在于：**横向对照不是简单找"最好看的数据"，而是通过多维度的同时检查——资本结构、收益质量、资产负债表、趋势与平均值——识别统计优势是否被质的因素所抵消**。

## Frameworks Introduced

1. **表格1：铁路公司标准比较表**（约33项指标）
   - A. 资本结构：有效债务（净扣除×20）、优先股市值、普通股市值、总资本及各项比率
   - B. 收益账户：总收益、维修费比率、铁路营业收入比率、净扣除比率
   - C. 计算：净扣除保障倍数、普通股每股收益与市价比率、总收益/普通股市值
   - D. 年均值：7年保障倍数、平均EPS
   - E. 趋势值：过去7年逐年EPS、股息率与报酬率
2. **表格2：公用事业公司**（差异项）：
   - "净扣除"→"固定支出"；有效债务 = 固定支出×18
   - 第10条变为"折旧/总收益"；可加维修费比率
   - 折旧率差异与铁路维修费率差异同等重要
3. **表格3：工业公司**（同领域企业）：
   - 加入销售额维度：销售利润率(10:8)、总资本收益率(10:4)、总销售/普通股市值
   - 补充数据：实物产出（单位收益、单位成本、单位资本）、商店数量/销量/利润
4. **投资性优先股 vs 投机性优先股的处理**：
   - 标"I.P."项目用于投资性优先股；标"S.P."用于投机性优先股
   - 低级收入债券按优先股处理（脚注注明实际名称）

## Key Concepts

- **同质群体（Homogeneous Group）**：未来变化对全组影响类似 → 统计比较可靠（糖、煤、金属、水泥、大型石油、连锁店）
- **异质群体（Heterogeneous Group）**：各公司对新条件反应可能大相径庭（汽车、机器设备、专利药、广告商标产品）
- **投机性 vs 保守性资本结构对比的局限**：面对好坏变化反应迥异，当前优势可能轻易丧失
- **低红利 ≠ 反消因素**：红利通常可在合理时间内调整到与其盈利能力相适应的水平
- **相对受欢迎程度和市场活力**：与内在价值无关，但强烈影响市场价格
- **掉换建议的个人责任**：分析家建议掉换时承担更大个人责任——投机者以立竿见影的市场结果检验建议

## Mental Models

- **工作底稿式多维度对照法**：
  单一指标的优势（如EPS/价格比率高）不能下结论，必须同时确认：
  - 总资本收益率也高？（第15条）
  - 销售额/普通股市值比率？（第19条）
  - 折旧充分性、营运资金状况？
- **行业同质性分级**：
  高度同质：铁路 / 大型电力 / 原材料标准化产品
  相当同质：石油巨头 / 烘烤奶制品包装 / 连锁零售
  中间群体：轮胎、香烟、鞋
  异质：汽车 / 机械设备 / 专利药 / 广告商标制成品
- **优先股逻辑劣势**：同样表现的优先股不如普通股有吸引力——后者享有现在和未来的全部所有权

## Anti-patterns

- ❌ 只看每股收益/市价比率而不验证总资本收益率
- ❌ 对折旧数据进行确切比较——折旧率仅在揭示显著不同时有价值
- ❌ 将维修费不足或子公司未实现红利造成的收益高估当作真实业绩（第10、19条）
- ❌ 在异质行业中依据统计数据得出排他结论
- ❌ 向投机者提出掉换普通股的建议（除非声明对市场结果不承担责任）
- ❌ 忽视质的因素直接行动——统计结果揭示相对吸引力后，必须调查原因

## Worked Example

**扬斯敦薄板和钢管公司 vs 科罗拉多燃料和炼铁公司（1929年7月）**

分析家进行主要钢铁生产企业的调查发现：
- 扬斯敦薄板和钢管表现较好
- 科罗拉多燃料和炼铁低于平均水平

运用标准表格（省去无关紧要项）：

**关键发现**：科罗拉多唯一优势是"最近六个时期收益较高"，但其它数据有力地支持扬斯敦在各自价格水平下的相对优势。以下项目扬斯敦均占优：
- 普通股每股收益
- 总资本收益率
- 利息保障比率
- 总销售额/普通股市值比率
- 销售利润率
- 折旧费用的充分性
- 营运资金状况
- 股息报酬率

**关键判断**："即使从投机角度而言，扬斯敦也更有吸引力。毕竟对其普通股支付每一美元对应着比别的公司多得多的销售额。"

**注意事项**：
- 只有在认真考虑质的因素之后才能接受统计结论
- 科罗拉多低价可能有统计无法揭示的原因（前景不乐观、管理漏洞）
- 一般不应把普通股较低的红利看作反消因素——市场价格迟早反映盈利能力

## Key Takeaways

1. 标准表格的价值在于系统化，而非完美——读者可自行调整以适应特定目的
2. EPS/市价比率是所有比较的主要数据，但必须结合总资本收益率（第15条）
3. 资产负债表不具主要意义，除非揭示明确财务缺陷或流动资产价值大大超过市场价值
4. 行业同质性越高，比较分析的可靠性越强
5. 分析家在建议证券掉换时应格外谨慎——投资者不愿变动，一旦出错会特别愤怒
6. 即使在同一行业内，投机性与保守性资本结构的公司之间也不宜直接推断优劣
