# 证券分析 — 决策速查表（Cheatsheet）

一书一页：格雷厄姆-多德的判断规则与数字阈值。

## 核心决策规则

| 当… | 则… | 因为… |
|------|-----|-------|
| 安全性只靠条款/担保/名称支撑 | 拒绝 | 安全性来自企业履行义务的能力，不是法律形式 |
| 收益率特别高 | 先问安全性 | 风险与回报本质不可抵消；高息是对风险的标价 |
| 证券品质略低于严格标准、价格略低 | 按投机品处理或拒绝 | "商人投资"是被否定的夹生类别 |
| 报告收益含偶生项目 | 剔除后再估值 | 估值基础是"预示的盈利能力"，非当年报告值 |
| 趋势亮眼 | 用 7–10 年均值估值，趋势只调乘数 | 趋势外推无数学约束，均值回归是常态 |
| 价格落在 70–100（债券） | 先明确自己的检验标尺 | 主观离差区——地位因人而异 |
| 股价长期低于清算价值 | 要么买入机会，要么该清算 | 二者必居其一（第43章基本原理） |
| 会计政策有问题 | 对该公司全部证券退避三舍 | 无法量化"管理不善"该扣多少 |
| 建议掉换 | 新标的自身有吸引力 或 存在契约关系，否则沉默 | 专业责任边界 |

## 数字阈值表

### 固定费用保障倍数（投资级门槛）

| 企业类型 | 债券 | 优先股（完全扣除法） |
|---------|------|---------------------|
| 铁路 | 2× 固定费用 | 2.5×（利息+股息） |
| 公用事业 | 2× | 2.5× |
| 工业 | 3× | 4× |

### 记录年限与其他标准

| 标准 | 要求 |
|------|------|
| 盈利记录考察期 | 7 年（最低 5 年） |
| 股息记录 | 连续支付（工业类要求更长） |
| 工业企业规模 | ≥ 500 万美元（1940年语境） |
| 投资信托：抵押品市值/债券 | ≥ 125%（无条件永久下限） |
| 营运资金条款示例 | 流动资产净额/债券 ≥ 125–150% |
| 低级资本充足度（示例） | 有形资产净额/长期债务 ≥ 175% |
| 优先股发行否决权 | 需 2/3 或 3/4 优先股同意 |
| 市盈率 | 10× 均值=合理基准；16×=硬上限 |
| 投机性债券临界价 | 息票 5%+ 者跌破 70 才按投机品分析 |
| 速动资产/流动负债 | ≥ 2:1（工业公司健康线） |
| 融资真实成本 | 公众实付 ≈ 投入资金的 25–30% |

### 清算折扣率

| 资产 | 清算价值/账面 |
|------|--------------|
| 现金资产 | 100% |
| 应收账款 | 75–90%（均 80%） |
| 存货 | 50–75%（均 66⅔%） |
| 分期付款账户 | ~30% |
| 固定资产及杂项 | 10–50%（均 ≈15%） |

## 判断捷径（Tells & Smells）

- **债券名称 ≠ 安全**；"可转换"≠ 优惠；"担保"≠ 履行能力
- 优先股条款弱点 = 债券的局限 + 股票的风险——需双倍安全边际
- 大额应付票据 + 即将到期长期债务 = 财务困难将至的红旗
- 流动资产减少额 > 股息支付额 → 差额藏进了虚增资产
- 应缴税额与报告收益矛盾 → 报告可信度存疑
- 市价 16× 帐面 或 仅 1/10 帐面 → 市场在某方向犯错（警示，非择时信号）
- 控股链 + 两层债务 + 权证循环 → 少数股东被系统性剥削
- 认股权证的价值 = 普通股价值的等额减少

## 分析师四类有效活动（全书收官）

1. 选择满足苛刻安全检验标准的高级证券
2. 发现达到投资等级且有可观增值可能的高级证券
3. 发现远低于内在价值出售的普通股/授权性高级证券
4. 利用相关证券间确定的价格偏离 → 置换·套期·套利

超出这四类 = 市场分析（预测价格方向），无安全边际可言。

## 投资的定义（Ch 4，全书基石）

> 投资操作 = 详尽分析 + 本金安全 + 满意回报，三者缺一即投机。

三功能：**描述**（呈现事实）→ **选择**（应用标准决定买卖）→ **评判**（对条款、管理层、会计的批判性审查）。
