# Chapter 7: 股利杂音

## Core Idea
股利是资本配置结果，不是自动的股东回报。关键问题是公司保留一美元能赚多少，以及政策是否稳定、诚实、适合企业阶段。

## Frameworks Introduced
- **Retained-dollar test**：若公司能以高回报再投资，低派息可能更有利；若没有高回报机会，现金应回馈股东。
- **Policy consistency**：稳定的股利政策让股东规划现金流，也显示管理层是否有纪律。

## Mental Models
把股利看作“取出一部分未来增长”而非免费收益。比较原始成本股利率与当前市价收益率，避免被表面数字误导。

## Worked Example
高成长公司保留盈余建设工厂、产品线和销售组织，几年后每股盈余与股利基数都更高。低当前收益率可能对应更高的长期现金回报。

## Anti-patterns
- **只按股利率排名**：会错过高回报再投资者。
- **把不派息等同不负责任**：要看保留资金用途和回报。
- **频繁改变政策**：增加不确定性，可能反映资本配置混乱。

## Key Takeaways
1. 股利问题要回到机会成本。
2. 先看企业回报率，再看派息率。
3. 需要现金流的投资者应把个人约束纳入选择。
