# Chapter 14: 哲学成熟

## Core Idea
成熟的投资哲学表现为稳定的判断顺序：企业质量、未来增长、价格、持有纪律。它减少情绪和市场噪音对决策的影响。

## Mental Models
耐心不是被动等待，而是持续验证后拒绝无理由行动。集中不是勇敢，而是对理解程度和风险边界负责。

## Key Takeaways
1. 形成少数真正有效的原则。
2. 原则必须能在压力情境下执行。
3. 为不确定性留出仓位和心理空间。

## Anti-patterns
- **风格漂移**：牛市追热门、熊市改做现金，失去一致性。
- **把自信当证据**：强烈观点仍需外部验证。
