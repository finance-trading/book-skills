# Chapter 4: 成长、利润率与竞争优势

## Core Idea
销售增长只有转化为可持续的利润增长，才具有投资价值。优秀公司通过研发、销售、规模、成本和组织能力不断扩大优势。

## Frameworks Introduced
- **Margin bridge**：拆解价格、产品组合、规模、成本、研发和销售投入对利润率的影响。
- **能力而非幸运**：区分“因为行业幸运而成长”和“因为管理能干而利用机会”。
- **相邻扩张**：优先把既有技术、客户和销售能力延伸到相近市场。

## Key Concepts
- **R&D productivity**：研究成果对收入和利润的贡献，不是研发人数或支出的绝对值。
- **销售组织**：招募、训练、服务和分销的系统能力。
- **专利局限**：专利可能短暂保护，持续工程改进和客户关系通常更耐久。

## Worked Example
新工厂试产期可能压低利润，但若技术已验证、后续工厂可复制，暂时压力可能创造买点。要验证产能爬坡、订单质量和单位经济，而非只听“即将改善”。

## Anti-patterns
- **只看收入增长**：忽略利润率下降。
- **只看研发金额**：忽略成果转化。
- **把专利等同护城河**：忽略替代技术和执行。

## Key Takeaways
1. 研究多年利润率及其相对同业位置。
2. 问管理层如何维持或改善利润率。
3. 关注可复制的能力，而非单一明星产品。
