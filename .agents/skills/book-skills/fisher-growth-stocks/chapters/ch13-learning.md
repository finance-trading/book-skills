# Chapter 13: 从经验中学习

## Core Idea
经验只有经过结构化复盘才会转化为优势。重点不是记住某只股票，而是找出判断链中哪一环失真。

## Frameworks Introduced
- **Investment postmortem**：分别复核事实、推理、执行、持有和退出。
- **Error taxonomy**：信息不足、错误权重、过度自信、时间错配、纪律失守。

## Worked Example
若卖出后股价继续涨，不要自动认为卖出错误；先检查当时的 15 点、替代机会和税费，再判断是判断错还是概率结果。

## Key Takeaways
1. 复盘要保留当时的信息集。
2. 把可控错误与不可控结果分开。
3. 修改流程，而非只修改结论。
