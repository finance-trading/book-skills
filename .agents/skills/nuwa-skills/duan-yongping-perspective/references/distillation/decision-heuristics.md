# 段永平决策启发式提炼

**提炼方法**：从调研中提取高频使用的"if-then"规则和快速判断准则
**调研时间**：2026-08-26
**来源**：research/01-06.md 六维度调研结果

---

## 核心决策启发式（12条）

### H1: 诚信门槛（Integrity Threshold）

**规则**：如果发现一家公司不诚信 → 立即排除，不再研究

**触发条件**：
- 财务造假
- 管理层公开撒谎
- 承诺不兑现且不解释

**执行逻辑**：
```
IF 发现不诚信迹象
THEN 立即终止研究
ELSE IF 无法判断是否诚信
THEN 继续观察但不买入
```

**真实案例**：
- 特斯拉："我如果认为一家公司不诚信的话，我就不碰了，比如特斯拉，我就完全没兴趣去了解"（S36）
- 标准严格到：即使生意模式再好，不诚信就不碰

**来源**：S04, S36
**类别**：一票否决型
**优先级**：最高（第一道过滤器）

---

### H2: 5分钟法则（5-Minute Rule）

**规则**：如果5分钟算不明白一家公司是否便宜 → 说明不够便宜或不够懂

**触发条件**：
- 需要复杂的DCF模型
- 需要多轮敏感性测试
- 需要请教专家才能判断

**执行逻辑**：
```
IF 5分钟内无法毛估估出便宜程度
THEN 要么不够便宜，要么不够懂
THEN 不买入
```

**真实案例**：
- 网易2001年股价<$1："业务基本面健康"→ 根本不需要计算器
- 反例：如果需要Excel建模，说明机会不够明显

**来源**：S04
**类别**：估值判断型
**优先级**：高（过滤"看似便宜"的陷阱）

---

### H3: 10年持有测试（10-Year Hold Test）

**规则**：如果不打算拿10年 → 那为什么要拿10天？

**触发条件**：
- 考虑买入任何股票时

**执行逻辑**：
```
IF 无法回答"10年后这家公司还会更好吗？"
THEN 说明不够理解
THEN 不买入
```

**真实案例**：
- Apple持有14年（S48）
- 网易持有8-9年后卖出，事后承认"证明没完全理解"（S10）

**来源**：S04, S10
**类别**：持有决策型
**优先级**：高（区分投资vs投机）

---

### H4: 三不原则（Three No's）

**规则**：
1. 不做空
2. 不借钱
3. 不做不懂的

**触发条件**：任何投资决策前检查

**执行逻辑**：
```
IF 需要做空或借钱或涉及不懂的领域
THEN 无论机会多诱人
THEN 不做
```

**真实案例**：
- 做空百度亏1.5-2亿美元后反思："这个错误是发生在巴菲特叫我不要做空之后"（S12）
- 即使"明知故犯"也要付出代价

**来源**：S04, S12
**类别**：风险控制型
**优先级**：最高（底线原则）

---

### H5: 立即止损法则（Immediate Stop Rule）

**规则**：如果发现错了 → 立即停止，因为此时机会成本最低

**触发条件**：
- 买入后发现理解有误
- 发现公司基本面恶化
- 发现违反自己的原则

**执行逻辑**：
```
IF 发现错误
THEN 立即卖出，不拖延
REASON: "两年后可能还在那个不好的地方"
```

**真实案例**：
- 油指数基金："发现错了立即卖出，损失>$10M"（S10）
- 不等反弹，不心存侥幸

**来源**：S04, S10
**类别**：止损决策型
**优先级**：高（避免小错变大错）

---

### H6: 卖出=不懂检验（Sell = Not Understanding）

**规则**：如果卖出了 → 事后反思是否真正理解

**触发条件**：
- 任何卖出行为（除非公司基本面恶化）

**执行逻辑**：
```
IF 卖出
THEN 事后问："如果真懂，为什么会卖？"
THEN 归因于"理解不够"而非"执行问题"
```

**真实案例**：
- 网易："I did sell—proving I didn't fully understand"（S10）
- 不为卖出决策辩护，直接承认没理解

**来源**：S10, S04
**类别**：自我验证型
**优先级**：中（事后复盘工具）

---

### H7: 企业文化一票否决（Culture Veto）

**规则**：如果企业文化不好 → 即使生意模式再好也不投

**触发条件**：
- 管理层经常说瞎话
- 短期主义盛行
- 内部勾心斗角

**执行逻辑**：
```
IF 企业文化有问题
THEN 长期必出问题
THEN 不投资
```

**判断标准**：
"企业文化不好最典型的特征就是经常说瞎话"（S04）

**真实案例**：
- 茅台："如果茅台的企业文化不够好的话，茅台走不到今天的"（S05）
- 特斯拉：不投资的核心原因之一

**来源**：S04, S05, S36
**类别**：质量过滤型
**优先级**：高（长期视角必检项）

---

### H8: 市场恐慌买入法则（Panic Buying Rule）

**规则**：如果我早就懂这家公司 + 市场极度恐慌 → 重仓买入

**前置条件**：
- 必须是我之前就研究过的公司
- 不能临时抱佛脚

**触发条件**：
- 市场一致看空
- 股价被非理性压低
- 基本面健康但遭遇暂时问题

**执行逻辑**：
```
IF 我早就理解这家公司
AND 市场极度悲观
AND 问题是暂时的（非根本性）
THEN 重仓买入
ELSE IF 不确定问题是否暂时
THEN 不买（可能是价值陷阱）
```

**真实案例**：
- 网易2001年：会计丑闻、股价<$1、面临退市 → 重仓买入 → 100倍回报（S42）
- 拼多多：被市场质疑"消费降级" → 重仓 → 300倍回报（S47）
- 泡泡玛特：被批"智商税" → Sell Put建仓（S33）

**来源**：S42, S47, S33
**类别**：时机把握型
**优先级**：高（但需要与H2、H3配合使用）

---

### H9: 不与成本挂钩（No Cost Anchoring）

**规则**：卖出决策与买入成本无关，只看当前价值

**触发条件**：
- 考虑卖出时

**执行逻辑**：
```
IF 考虑卖出
THEN 忘记买入成本
THEN 只问："现在这个价格，如果我没有持仓，会买入吗？"
IF 答案是"不会"
THEN 卖出
```

**理论依据**：
"无论什么时候卖都不要和买的成本联系起来"（S04）

**来源**：S04
**类别**：心理纪律型
**优先级**：中（避免沉没成本谬误）

---

### H10: 集中持仓法则（Concentration Rule）

**规则**：如果真正理解 → 重仓持有（Top 3占70%+）

**触发条件**：
- 通过H2、H3、H7所有测试的公司

**执行逻辑**：
```
IF 真正理解一家公司
THEN 重仓持有（不分散）
ELSE IF 不够理解
THEN 不买（而非小仓位试错）
```

**真实案例**：
- Apple占比41%、伯克希尔24%、拼多多（S31, S48）
- Top 3持仓占比超70%

**理论依据**：
- 引用巴菲特/芒格的"20-hole punch card"（S11）
- 一生只有20次投资机会

**来源**：S11, S31, S48
**类别**：仓位管理型
**优先级**：高（与H3配套使用）

---

### H11: 需要问就不该买（If You Ask, Don't Buy）

**规则**：如果需要问别人"这个股票能买吗" → 说明你不懂 → 不买

**触发条件**：
- 对某个投资标的不确定

**执行逻辑**：
```
IF 需要问别人意见才敢买
THEN 说明不在能力圈内
THEN 不买
```

**理论依据**：
段永平拒绝给具体股票建议，因为"需要问的时候就不该买"

**来源**：S10, S12（访谈中多次拒绝给建议）
**类别**：能力圈判断型
**优先级**：高（自我诚实测试）

---

### H12: Right Business先于Right Price

**规则**：先判断生意模式，再看价格；顺序不能反

**执行逻辑**：
```
Step 1: Right Business? → 生意模式护城河够不够深？
Step 2: Right People? → 企业文化和管理层OK吗？
Step 3: Right Price? → 现在价格便宜吗？

IF Step 1或Step 2不通过
THEN 无论价格多低都不买
```

**真实案例**：
- 比亚迪："即使回到当年巴菲特买的价格，我还是不会买，因为还是不懂"（S12）
- 说明价格再低，生意模式不懂就不买

**来源**：S04, S12
**类别**：决策顺序型
**优先级**：最高（框架性原则）

## 启发式使用流程

### 投资决策完整检查清单

```
阶段0: 初筛
├─ H4: 三不原则检查
│  ├─ 需要做空？→ 拒绝
│  ├─ 需要借钱？→ 拒绝
│  └─ 不懂？→ 拒绝
└─ H1: 诚信门槛
   └─ 不诚信？→ 一票否决

阶段1: 深度研究
├─ H12: Right Business, Right People, Right Price 顺序检查
│  ├─ 生意模式？
│  ├─ 企业文化？（H7）
│  └─ 价格？
└─ H3: 10年持有测试
   └─ 10年后还会更好吗？

阶段2: 估值判断
├─ H2: 5分钟法则
│  └─ 5分钟算不明白？→ 不够便宜或不够懂
└─ H8: 市场恐慌买入法则
   └─ 市场极度悲观 + 我早就懂？→ 重仓买入

阶段3: 执行
├─ H10: 集中持仓法则
│  └─ 真正理解 → 重仓
├─ H11: 需要问就不该买
│  └─ 还需要问别人？→ 说明不懂
└─ H3: 10年持有心态

阶段4: 持有期管理
├─ H5: 立即止损法则
│  └─ 发现错了 → 立即卖出
├─ H9: 不与成本挂钩
│  └─ 卖出只看当前价值
└─ H6: 卖出=不懂检验
   └─ 事后复盘：为什么卖？
```

## 启发式的边界条件

### H2（5分钟法则）的边界

**失效场景**：
- 早期科技公司：商业模式尚未成熟，无法"毛估估"
- 周期性行业：需要跨周期估值，5分钟不够

**适用场景**：
- 成熟期消费品公司
- 商业模式清晰的互联网平台

---

### H3（10年持有测试）的边界

**失效场景**：
- 快速变化的行业（如AI芯片）
- 创始人驱动型公司（人的变化难以预测10年）

**适用场景**：
- 护城河极深的公司（可口可乐、茅台）
- 平台型公司（苹果、拼多多）

---

### H8（市场恐慌买入法则）的边界

**风险**：
- 可能抄底抄在半山腰
- 可能误判"暂时问题"vs"永久问题"

**必要条件**：
- 必须是我之前就研究过的公司（强调"早就懂"）
- 必须能区分暂时问题vs根本问题

**反例**：
- 如果一家公司基本面真的恶化了，市场恐慌是正确的

---

### H10（集中持仓法则）的边界

**不适用人群**：
- 普通投资者（没有足够的研究深度）
- 风险承受能力低的投资者

**段永平的特殊条件**：
- 已实现财务自由（不需要这笔钱）
- 有极强的心理承受力（能忍受大幅回撤）
- 有深度研究能力（真正理解持仓公司）

**外界批评**：
"段永平的极简持仓策略不适合大部分投资者"（S31-外界观察）

## 与其他投资者启发式的对比

### 段永平 vs. 巴菲特

| 启发式 | 段永平 | 巴菲特 |
|--------|--------|--------|
| 诚信门槛 | 一票否决（特斯拉） | 容忍度稍高（投资过所罗门兄弟） |
| 5分钟法则 | 极端简化 | 也强调简单但允许更复杂的分析 |
| 10年持有 | 严格执行（Apple 14年） | 严格执行（可口可乐几十年） |
| 集中持仓 | 极度集中（Top 3占70%+） | 相对集中（Top 5占70%） |
| 做空 | 绝对不做（做空百度后反思） | 早期偶尔做，后期不做 |

**核心差异**：段永平的启发式更**极端、更简化、更少例外**

---

### 段永平 vs. 张磊

| 启发式 | 段永平 | 张磊（高瓴） |
|--------|--------|-------------|
| 参与深度 | 纯财务投资，不干预管理 | 深度参与，派驻董事 |
| 投资阶段 | 主要二级市场 | 一级+二级并重 |
| 退出策略 | "十年不卖" | 灵活退出（IPO/并购/减持） |
| 持仓集中度 | 极度集中（3-5个） | 相对分散（10-20个） |
| 对新技术态度 | 保守（"看不懂不碰"） | 积极（重仓AI、生物医药） |

**核心差异**：段永平的启发式更适合**个人投资者**，张磊的更适合**机构投资者**

## 总结

### 启发式体系的核心特征

1. **极简主义**：12条启发式覆盖投资全流程
2. **负面优先**：一半以上是"不做什么"（H1, H4, H5, H7, H9, H11）
3. **可操作**：每条都有明确的"if-then"逻辑
4. **严格执行**：几乎没有"视情况而定"的灰色地带
5. **相互支撑**：H1-H12形成完整的决策链

### 与心智模型的关系

```
心智模型（M1-M7）
    ↓ 
  抽象思维框架
    ↓
决策启发式（H1-H12）
    ↓
  可执行规则
    ↓
  具体投资行为
```

### 适用人群

**最适合**：
- 已实现财务自由的个人投资者
- 有能力深度研究3-5家公司的人
- 心理承受力极强（能忍受持仓大幅回撤）

**不适合**：
- 普通散户（研究深度不够）
- 追求短期收益的交易者
- 需要持续现金流的投资者
