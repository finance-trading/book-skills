## 不可核验 / 待补充 / 已证伪清单（重要）

| 条目 | 问题 |
|------|------|
| "$100M 1929 做空利润" | 无任何一手财务凭证；TIME 记载崩盘时他净**多头**（short 20k/long 80k），与传说直接冲突。应视为传说级数字 |
| "死时破产" vs 遗产>$5M | 矛盾并存：1934 破产属实；V20 称留有约$5M信托为孤证；遗产数额无定论 |
| J.P. Morgan 1907 请他停空 | 无法证实的传奇层，NYT 1907 无直接记录 |
| "Trend is your friend" | 后世提炼，非原话 |
| "Wall Street never changes, pockets change, suckers change…" | 两本原著全文均无，流传语未核实 |
| "A prudent speculator never argues with the tape" | 未核实原文 |
| "Cut your losses short and let your winners run" 口号形式 | 后世口号化，原著无此原句 |
| "Markets are never wrong – opinions often are" | **已核实出自 1940 原著**（常被误疑为伪造） |
| "It's a bull market"（Old Turkey） | 是 Reminiscences 中角色 Partridge 的台词，非 Livermore 本人 |
| 网传"Lefèvre 未发表访谈" | 实为小说对话体重排，存疑标记 |
| 1901 北太平洋爆仓 vs 赚$50万 | 两说并存已裁定并列（P04 vs 部分传记） |
