# 第2章：投资者与通货膨胀

## Core Idea
通货膨胀与股票利润之间没有直接联系。历史数据表明，通胀率的高低对公司每股利润没有任何直接影响，因此不能因为通胀预期而忽略估值买入股票。

## 核心发现
- **通胀不会自动提升股票价值**：1966-1970年生活费上涨22%，是1946年以来最大涨幅，但股票利润和价格均下降
- **公司资本利润率并未随通胀上升**：过去20年尽管存在通胀，公司利润率反而有明显下降
- **通胀与股票利润没有直接联系**：过去20年道琼斯成分股所有大幅增长的利润都来自利润再投资形成的资本增长，而非通胀

## 通胀对各类资产的影响

| 资产类型 | 通胀保护效果 | 说明 |
|---------|-------------|------|
| 债券 | 差 | 固定收益被通胀侵蚀，但当前高利率可部分抵消 |
| 股票 | 中等 | 长期看可部分对冲通胀，但短期关联度低 |
| 黄金 | 差 | 1935-1972年仅涨35%，无利息收入 |
| 房地产 | 中等 | 理论上可保值，但价格不稳定、流动性差 |
| 收藏品 | 差 | 报价人为、不可靠，不适合普通投资者 |

## 结论
- 投资者不能把全部资金都放入一个篮子：既不能完全放债券，也不能完全放股票
- 防御型投资者必须力图使自己的风险最小化
- 坚持股债平衡策略（50/50），比任何极端配置都更安全
