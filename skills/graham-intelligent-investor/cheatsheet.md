# 快速参考指南 — 《聪明的投资者》

## 决策框架速查

### 你属于哪种投资者？

| 特征 | 防御型（被动型） | 积极型（进取型） |
|------|----------------|----------------|
| 每周投入时间 | < 1小时 | ≥ 5小时 |
| 目标 | 市场平均回报 | 超越市场平均 |
| 投资工具 | 指数基金 + 蓝筹股 | 个股 + 特殊情形 |
| 策略复杂度 | 低 | 中到高 |
| 风险承受 | 低 | 中 |

## 防御型投资者选股七标准

| # | 标准 | 数值阈值 | 说明 |
|---|------|---------|------|
| 1 | 企业规模 | 大型、知名 | 排除小公司和投机型公司 |
| 2 | 财务状况 | 流动比率 ≥ 2:1 | 长期债务 ≤ 营运资本 |
| 3 | 股息记录 | 连续20年 | 不间断支付 |
| 4 | 无亏损记录 | 过去10年 | 每个财年都有利润 |
| 5 | 利润增长 | 10年增长 ≥ 1/3 | 基期和末期用3年平均 |
| 6 | 市净率 | 股价 ≤ 1.5 × 有形账面价值 | 重资产行业参考价值高 |
| 7 | 市盈率 | P/E ≤ 15倍 | 与标准6乘积 ≤ 22.5 |

## 格雷厄姆估值公式

```
V = EPS × (8.5 + 2g)

V  = 内在价值
EPS = 过去12个月每股收益
8.5 = 零增长股票合理市盈率
g  = 未来7-10年预期年增长率（%）
```

### 利率调整
当AAA债券利率 ≠ 4.4%时：
```
V_adjusted = V × (4.4 ÷ AAA当前利率)
```

### 示例计算

| 场景 | EPS | g | AAA利率 | 计算 | 价值 |
|------|-----|---|---------|------|------|
| 基准 | $5 | 5% | 4.4% | 5 × (8.5 + 10) | $92.50 |
| 高利率 | $5 | 5% | 7.0% | 92.5 × (4.4/7.0) | $58.14 |
| 低利率 | $5 | 5% | 3.0% | 92.5 × (4.4/3.0) | $135.67 |
| 零增长 | $5 | 0% | 4.4% | 5 × (8.5 + 0) | $42.50 |
| 高增长 | $5 | 10% | 4.4% | 5 × (8.5 + 20) | $142.50 |

## 安全边际水平评估

| 安全边际 | 水平 | 行动 | 风险 |
|---------|------|------|------|
| ≥ 50% | 极安全 | 可买入 | 低 |
| 20% - 50% | 安全 | 可买入（结合其他因素） | 中低 |
| < 20% | 不足 | 等待更低价格 | 中 |
| ≤ 0% | 无 | 不买入 | 高 |

## 资产配置速查

### 防御型配置（50/50基准）

| 市场环境 | 股票比例 | 债券比例 | 行动 |
|---------|---------|---------|------|
| 正常估值 | 50% | 50% | 维持 |
| 显著低估 | 75% | 25% | 逐步买入 |
| 显著高估 | 25% | 75% | 逐步卖出 |

### 再平衡触发条件
- **时间触发**：每年或每半年检查一次
- **阈值触发**：偏离目标比例 ≥ 5%
- **极端市场触发**：市场跌/涨超20%

## 净流动资产价值 (NCAV) 计算

```
NCAV = 流动资产 - 总负债
筛选条件：股价 ≤ 2/3 × NCAV
```

### 步骤
1. 从资产负债表中找到流动资产
2. 减去总负债（包括所有长期和短期债务）
3. 除以总股本 → 每股NCAV
4. 比较每股NCAV与当前股价
5. 股价 ≤ 2/3 × NCAV → 可考虑买入

## 关键比率速查表

| 比率 | 公式 | 防御型标准 | 说明 |
|------|------|-----------|------|
| 市盈率 (P/E) | 股价 ÷ EPS | ≤ 15倍 | 越低越好，但需确认利润质量 |
| 市净率 (P/B) | 股价 ÷ 账面价值 | ≤ 1.5倍 | 重资产公司参考价值高 |
| 股息率 | 股息 ÷ 股价 | 无硬性要求 | 持续支付比高股息率更重要 |
| 流动比率 | 流动资产 ÷ 流动负债 | ≥ 2:1 | 短期偿债能力 |
| 负债权益比 | 总负债 ÷ 股东权益 | 越低越好 | 长期财务稳健性 |
| 格雷厄姆数 | P/E × P/B | ≤ 22.5 | 综合估值指标 |

## Mr. Market 决策框架

```
市场报价 → 问自己：
1. 这个报价远低于我的估值吗？ → 买入
2. 这个报价远高于我的估值吗？ → 卖出
3. 这个报价与我的估值相近？ → 不动
4. 这个报价在狂跌？ → 冷静，评估是否已发现新信息
5. 这个报价在暴涨？ → 冷静，不要追涨
```

## 投资 vs 投机检查清单

### 投资的三条件（全部满足）：
- [ ] 经过深入分析
- [ ] 确保本金安全
- [ ] 获得适当回报

### 投机的三条禁令：
- [ ] 不要自以为在投资实则投机
- [ ] 不要在缺乏知识和技能时把投机当正经事
- [ ] 投机资金不要超出自己能承受亏损的能力

## 常见错误一览

| 错误 | 表现 | 后果 | 纠正方法 |
|------|------|------|---------|
| 忽略安全边际 | 追涨买入 | 本金损失 | 坚持等待安全边际 |
| 相信"这次不一样" | 在牛市中抛弃原则 | 牛市结束时大亏 | 记住市场周期规律 |
| 高估增长率 | 为成长股支付过高价格 | 估值回归时亏损 | 保守估计增长率 |
| 忽视债务 | 选择高杠杆公司 | 对公司判断失误 | 检查负债率和利息覆盖 |
| 缺乏分散化 | 押注少数股票 | 无法对冲风险 | 至少10-30只股票 |
| 以通胀为借口追涨 | 因担心通胀而买入被高估股票 | 同时承担通胀和高估值风险 | 通胀不是买入的理由 |
