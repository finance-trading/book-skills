# Agent Instructions

This repository stores generated knowledge skills from books and long-form sources.

## Directory Rules

- Keep converter/source skills in `.agents/skills/`. These are tools such as `book-to-skill`, `cangjie-skill`, `pdf`, and `pdf-ocr-extraction`.
- Put every skill generated by `book-to-skill` under `books/<skill-slug>/`.
- Put every skill generated by `cangjie-skill` under `cangjie-skills/<skill-slug>/`.
- Put every skill generated by `huashu-nuwa` (person/topic perspective skills) under `.agents/skills/nuwa-skills/<skill-slug>/`, then symlink it into `.claude/skills/<skill-slug>` pointing at the real directory (relative link like `../../.agents/skills/nuwa-skills/<skill-slug>`).
- Do not place generated book skills directly under `.agents/skills/` unless the user explicitly asks for an installable runtime skill there.

## Workflow

- For continuation requests, inspect the existing output directory first and resume from the real breakpoint.
- Preserve already-generated extraction, distillation, and verification files unless the user explicitly requests regeneration.
- After generating or moving a skill, verify that its `SKILL.md` links point to files inside the same skill directory.
