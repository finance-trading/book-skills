# 第十五章：公式、推荐与来源边界

## 核心思想

附录把前文压缩为可记忆的公式和法则，例如“收入 = 责任 + 杠杆 + 特殊知识”“健康 = 运动 + 饮食 + 睡眠”。这些公式是启发式，不是可直接计算人生结果的科学方程。推荐书目展示作者的思想来源和阅读路径；本书本身是由推文、访谈、会谈记录和二手摘录编辑而成的思想选编，不应被当成逐字、单一时间点的原始著作。

## 引入的框架

- **公式作为索引**：用短句压缩复杂原则，帮助回忆；遇到具体决策时回到定义、假设和证据。
  - 适用：复盘、记忆或在决策前快速提醒自己时。
  - 做法：先调用公式；再展开每个变量的含义；检查变量是否可观测；补充反例和边界。
- **阅读路径**：按兴趣从财富、科学、历史、哲学、精神和科幻等领域扩展模型；不要把推荐书单当成必读清单。
- **来源意识**：引用或复述时区分原始推文、访谈、编辑重排和译文；对具体措辞先查第一手来源。

## 关键概念

- **启发式公式**：帮助记忆和组织判断的简化关系，而非精确预测模型。
- **元技能**：阅读、写作、数学和说服等能迁移到多个领域的能力。
- **编辑编纂**：将多个采访、推文和来源重新排列成主题化作品。
- **第一手来源**：作者原始发布或直接访谈记录。
- **来源边界**：理解材料的语境、可靠性和编辑转换，避免过度归因。

## 心智模型

- 公式能压缩，不能替代推理；先问变量是否定义清楚、关系是否因情境而变。
- “耐时间筛选的书”提高先验可信度，但不保证每一条观点都正确。
- 编纂作品适合作为导航和思想索引；重要引文或事实应回到原始来源核实。

## 反模式

- 把“收入 = 责任 + 杠杆 + 特殊知识”当作保证财富的机械公式。
- 把书单当作社会身份或阅读 KPI。
- 将编辑者重新组织的观点全部当作作者在同一语境下说过的原话。

## 学习案例

使用“收入 = 责任 + 杠杆 + 特殊知识”评估职业时，先把它当检查表：我解决什么问题？对什么结果负责？有哪些放大器？哪些能力难以替代？然后再补充现金流、竞争、健康、伦理和风险等变量。若需要引用一句话，回查书中的来源说明，而不是仅凭网络卡片传播。

## 关键要点

1. 公式用于记忆和提问，不用于替代证据或财务规划。
2. 推荐读物的价值在于扩展模型，不在于制造书单压力。
3. 这本书是跨来源编辑的编纂物，引用时保留语境与不确定性。
4. 学习成果要靠应用、验证和修正，而非背诵金句。

## 关联

- **第四章**：模型必须可检验并接受反例。
- **第十四章**：原典和输出能提高理解质量。
- **全书**：附录把财富、健康、幸福、学习和价值观压缩成导航索引。
