# Chapter 32: Value Enhancement—Economic Value Added, Cash Flow Return on Investment, and Other Tools

## Core Idea
Economic value added (EVA) and cash-flow return on investment (CFROI) make excess returns visible, but they do not create a different source of value from DCF when accounting and capital charges are handled consistently.

## Frameworks Introduced
- **Economic value added**: `EVA = after-tax operating income − (WACC × invested capital)`; value the firm as invested capital plus present value of future EVA when definitions and terminal treatment are consistent.
  - When to use: Diagnose whether operating performance exceeds the required capital charge.
- **CFROI**: Compare cash return on gross operating investment with a required return, accounting for depreciation and asset lives.
- **Metric-to-value reconciliation**: Check whether changes in ROIC, invested capital, and growth preserve the same forecast free cash flows as a DCF.

## Key Concepts
- **Capital charge**: Required return on committed capital for a period.
- **Economic profit**: Profit after charging all invested capital, including equity.
- **Gross investment**: Capital base before depreciation adjustments used in some CFROI formulations.
- **Fade**: Decline of excess return as competition responds.
- **Residual income**: Earnings after a charge for capital, conceptually related to EVA.

## Mental Models
- A positive EVA year can coexist with declining value if future EVA falls; the forecast path matters.
- Accounting changes can move EVA and invested capital in opposite directions without changing economic cash flow.

## Anti-patterns
- **Treating EVA as additional to DCF value**: It is an alternative representation, not a separate asset.
- **Cherry-picking invested capital**: A smaller denominator can make return metrics look attractive while omitting real investment.
- **Rewarding EVA level without growth-quality analysis**: Managers can boost one-period EVA by underinvesting in good projects.

## Worked Example
The chapter's introductory example shows the reconciliation: discount future free cash flows to value the firm, or begin with invested capital and add discounted future EVA. Both use the same operating forecasts and capital cost and should converge. The Lululemon case illustrates how measured EVA depends on the invested-capital base and return spread. If capitalized investments or asset write-downs alter that base, an analyst must reconcile accounting changes before interpreting improved EVA as real value creation.

## Key Takeaways
1. Calculate economic profit after a charge for all capital.
2. Reconcile EVA and CFROI conclusions with free cash flow.
3. Judge performance by future excess-return paths, not a single reported metric.
