# Chapter 6: The Financing Decision

## Core Idea
Financial leverage — "OPM," other people's money — is the two-edged sword that raises owners' expected return only by raising their risk, so the financing decision is a trade-off between return and risk, not a hunt for the cheapest rate.

## Frameworks Introduced
- **Financial leverage (OPM)**: substituting fixed-cost debt for equity increases expected ROE *and* the dispersion of ROE.
  - When to use: to predict how a given debt level shifts both the mean and the spread of owners' returns.
  - How: add debt, watch fixed interest rise and both the expected return and the variance move in the same direction.
- **The leveraged ROE identity**:
  `ROE = ROIC × (D + E)/E − i′(D/E)`
  where ROIC is return on invested capital, D/E is debt-to-equity, and i′ is the after-tax interest rate. Leverage helps only while ROIC > i′.
  - When to use: to see *exactly* how much leverage adds or subtracts from ROE at a given spread.
  - How: compute the spread (ROIC − i′); if positive, more D/E boosts ROE, else it destroys it.
- **The pecking order**: firms prefer internal funds first, then debt, then new equity — an observed ordering driven by costs, signaling, and control.

## Key Concepts
- **Financial leverage** — the use of fixed-cost debt financing, measured by assets/equity or D/E.
- **Two-edged sword** — leverage amplifies both expected return and variability of return.
- **ROIC** — return on invested capital, the unlevered return on all capital before financing effects.
- **WACC (weighted-average cost of capital)** — the blended after-tax cost of debt and equity, the minimum return a project must clear.
- **Coverage ratios** — times-interest-earned style measures of the safety margin on fixed charges.
- **EBIT-EPS analysis** — comparing earnings per share under alternative capital structures across EBIT levels.

## Mental Models
- Read leverage as **buying expected return with risk** — never evaluate a debt level on its return side alone.
- Use the **ROIC vs. after-tax borrowing rate spread** as the single gating test: leverage helps *only* when ROIC exceeds the after-tax cost of debt.
- Think of capital structure as a **spectrum of risk transfer**: each step toward debt shifts risk from equity holders to the fixed claim.

## Anti-patterns
- **Picking debt because it's "cheaper" than equity**: the lower rate is compensation for the lender taking less risk; the owners' expected return rises *because* their risk rose.
- **Ignoring the downside leg**: the same leverage that raises expected ROE raises the probability of distress.
- **Overlooking signal/costs**: flotation, distress, and information costs make the financing menu more than a pure rate comparison.

## Key Takeaways
1. Leverage is a **return-for-risk trade**, not a bargain; model both moments before deciding.
2. Apply the test `ROIC > after-tax borrowing rate` — it separates value-adding from value-destroying leverage.
3. Order financing by the **pecking order** unless a reason overrides it.
4. Use **coverage ratios** as the safety check on any proposed debt level.
5. Run **EBIT-EPS** analysis to see the crossover point where each capital structure wins.
