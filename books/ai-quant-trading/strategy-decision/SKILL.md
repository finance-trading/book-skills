# 量化交易策略设计决策树

## R — 原文 (Reading)

> 量化交易的本质在于：在充满不确定性的金融市场中，利用概率和统计
> 优势，寻找非对称高胜率的投资机会。其基本假设包括：市场存在可被
> 挖掘的结构性规律；没有绝对最优的策略，只有阶段性的、局部的最优
> 解；理性与非理性行为共同影响着市场波动。
>
> — 罗勇 等, 第1章 1.1节

> 量化交易策略通常涵盖统计分析、机器学习、行为金融、自然语言处理
> 等多学科知识，并结合大数据、人工智能等现代信息技术，提升策略的
> 有效性和稳定性。
>
> — 罗勇 等, 第1章 1.1节

## I — 方法论骨架 (Interpretation)

本书建立了一个四层策略分类体系，帮助投资者系统化地选择策略：

**第一层：宏观量化** — 基于宏观经济指标（GDP、CPI、利率等）构建模型。适合超大资金（养老金、主权基金），追求长期稳健。代表：全天候策略（Ray Dalio）。

**第二层：资产配置量化** — 跨资产类别动态调整比例（股票/债券/现金/商品），通过定期再平衡实现风险与收益的动态平衡。适合追求长期稳健收益的投资者。

**第三层：阿尔法量化** — 挖掘"超额收益因子"，追求高于市场平均的回报。适合风险偏好高的专业投资者，需要持续优化因子。代表：James Simons 大奖章基金。

**第四层：贝塔量化** — 跟踪市场整体趋势，利用系统性波动获利。适合技术分析派，强调顺势而为。代表：Stanley Kroll 趋势跟踪。

**补充层：另类量化** — 基于非传统数据（舆情、事件、游资行为等）构建策略。

决策逻辑：资金规模→风险偏好→市场状态→策略类型。没有最优策略，只有阶段性局部最优解。

## A1 — 书中的应用 (Past Application)

### 案例 1: 中国全天候产品组合
- **问题**: 如何构建穿越牛熊的稳健投资组合
- **方法论的使用**: 采用资产配置量化思路，配置股票、债券、现金等资产，定期再平衡
- **结论**: 通过分散投资在不同经济周期中表现各异的资产，实现稳定回报
- **结果**: 中国全天候产品组合展现了较低的波动率和回撤率

### 案例 2: 指数群因子策略（阿尔法量化）
- **问题**: 如何获取超越市场平均的收益
- **方法论的使用**: 跟踪全市场/中证500/涨停个股等不同板块，结合市盈率、市净率、涨幅等因子，动态调整持仓
- **结论**: 通过不断优化因子组合，在不同市场环境下均表现出较强的适应性和超额收益能力
- **结果**: 实现了超越市场的收益

### 案例 3: 趋势跟踪策略（贝塔量化）
- **问题**: 如何在趋势明显的市场中获利
- **方法论的使用**: 对市场成交量、波动率等宏观指标进行量化分析，判断多头/空头状态，据此调整仓位
- **结论**: 顺势而为，利用市场的系统性波动获取收益
- **结果**: 有效规避大盘下跌风险，在牛市中捕捉上涨机会

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户刚开始接触量化交易，不知道从哪类策略入手
2. 用户有多个策略候选，需要根据自身条件（资金/风险偏好/市场状态）做选择
3. 用户要理解"为什么我的策略在这个市场环境下失效了"
4. 用户需要系统化地评估不同策略类型的优缺点
5. 用户在问"宏观量化和阿尔法量化有什么区别"

### 语言信号

- "该用什么量化策略" / "which quant strategy"
- "策略选择" / "strategy selection"
- "alpha 还是 beta"
- "资产配置" vs "选股"
- "我的策略失效了" / "strategy stopped working"
- "宏观量化" / "macro quant"
- "适合小资金的策略"

### 与相邻 skill 的区分 (定稿)

- 与 `factor-mining` 的分工: 本 skill 是**策略层决策**（选哪类策略），factor-mining 是**因子层执行**（怎么挖因子）。先选策略类型（本 skill），再挖对应因子（factor-mining）。当你问"我该做阿尔法量化还是贝塔量化"→本 skill；问"如何做阿尔法量化里的因子挖掘"→factor-mining
- 与 `a-share-patterns` 的分工: 本 skill 是**通用策略分类框架**（覆盖宏观/资产配置/alpha/beta/另类全品类），a-share-patterns 是其中**A 股特色模式的专精方法论**（涨停/竞价/连板/游资/龙头）。本 skill 的"贝塔量化"和"另类量化"分支落地到 A 股时，具体实现参考 a-share-patterns
- 与 `llm-capability` 的区分: 本 skill 评估**策略类型**的适配度，llm-capability 评估**AI 工具能力**的适配度。两者是"交易决策"vs"工具决策"的平行问题

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **评估用户条件**
   - 资金规模：小（<100万）/ 中（100万-1000万）/ 大（>1000万）
   - 风险偏好：保守 / 稳健 / 积极
   - 交易频率偏好：低频（月/季）/ 中频（周/日）/ 高频（日内）
   - 完成标准: 已明确用户的三个维度

2. **映射到策略类型**
   - 大资金 + 保守 → 宏观量化 / 资产配置量化
   - 中资金 + 稳健 → 资产配置量化 / 贝塔量化
   - 中资金 + 积极 → 阿尔法量化
   - 小资金 + 积极 → 阿尔法量化 / 贝塔量化 / 另类量化
   - A股市场 + 短期 → A股特色模式（参考 `a-share-patterns`）
   - 完成标准: 已推荐 1-2 个策略类型

3. **评估当前市场状态**
   - 趋势市 → 贝塔量化（趋势跟踪）
   - 震荡市 → 阿尔法量化（选股）
   - 危机/极端市 → 宏观量化（避险配置）
   - 完成标准: 已结合市场状态调整推荐

4. **输出策略方案**
   - 说明推荐策略的核心逻辑
   - 列出所需数据源和工具
   - 提示风险点和失效条件
   - 完成标准: 用户得到可操作的策略方向

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已经明确知道要哪类策略，只需要具体的实现方法 —— 用对应的专项 skill（factor-mining / a-share-patterns 等）
- 用户在做纯理论学术研究，不需要实操指导
- 用户的任务与策略选择无关（如纯数据处理、编程问题）

### 作者在书中警告的失败模式

- **没有绝对最优策略**: 任何策略都有阶段性，不能迷信单一策略
- **Alpha 因子时效性**: 阿尔法因子会衰减，需要持续挖掘新因子
- **过拟合风险**: 回测好看但实盘失效
- **情绪化执行**: 量化策略需要纪律性执行，人为干预会破坏策略逻辑

### 作者的盲点 / 时代局限

- 书中以 A 股市场为主要背景，对美股/港股/加密货币的策略选择讨论有限
- 未充分讨论策略容量问题（某些策略只适合小资金）
- 监管变化可能使某些策略不可行（如高频交易限制）
- 实盘交易成本（滑点、手续费）对策略收益的侵蚀未深入讨论

### 容易混淆的邻近方法论

- 主观交易的策略选择 —— 本 skill 专门面向量化策略
- 资产配置理论（Markowitz 等）—— 本 skill 侧重 AI 时代的量化资产配置
