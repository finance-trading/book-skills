## I — 方法论骨架 (Interpretation)

本书展示了用 NLP 和大模型量化市场情绪的完整方法论：

**数据来源**: 财经新闻、社交媒体（微博/雪球/股吧）、券商研报、公司公告、政策文件。这些非结构化文本蕴含丰富的市场情绪信息。

**情感分析流程**: 数据采集 → 文本预处理 → 情感分类（正面/负面/中性）→ 情感强度评分 → 聚合为市场情绪指标。大模型在此过程中可以同时做信息提取和情感判断。

**情绪指标构建**: 将个股/行业/全市场的情感评分聚合为可交易的情绪指标。例如：某板块正面新闻占比突然上升 → 情绪升温信号；社交媒体恐慌指数飙升 → 可能的抄底机会。

**事件驱动策略**: 识别重大事件（政策发布、财报超预期、突发事件），评估事件的情感方向和强度，构建事件驱动交易策略。大模型能理解事件的语义复杂度，比关键词匹配更准确。

**与量价因子的结合**: 情绪因子不是独立的，需要与量价因子、基本面因子结合使用，形成多维度信号。

## A1 — 书中的应用 (Past Application)

### 案例 1: 市场情绪量化评分系统
- **问题**: 如何量化市场整体的情绪状态
- **方法论的使用**: 用 NLP 对财经新闻和社交媒体做情感分析，构建情绪评分体系；将个股情绪聚合为板块/市场级别指标
- **结论**: 市场情绪指标能作为交易的辅助信号
- **结果**: 形成了情绪评分系统和监控面板

### 案例 2: 舆情监控与事件驱动分析
- **问题**: 如何从海量财经文本中实时识别重大事件并评估影响
- **方法论的使用**: 用大模型实时监控新闻/公告/社交媒体，识别重大事件，评估情感方向和强度，构建事件驱动策略
- **结论**: 大模型能比关键词匹配更准确地理解事件语义
- **结果**: 建立了事件驱动交易的信号生成系统

### 案例 3: 游资席位行为模式解析
- **问题**: 如何通过龙虎榜数据识别游资操作模式
- **方法论的使用**: 分析知名游资席位的买入偏好、持仓周期、题材选择，结合舆情数据理解其背后的逻辑
- **结论**: 游资行为有可量化的模式
- **结果**: 形成了游资跟踪因子

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要用大模型对财经新闻/社交媒体做情感分析
2. 用户要构建舆情监控或事件驱动交易策略
3. 用户要从非结构化文本（研报、公告、新闻）中提取交易信号
4. 用户要评估市场情绪（恐慌/贪婪）作为交易参考
5. 用户要理解游资行为模式

### 语言信号

- "情感分析" / "sentiment analysis"
- "舆情监控" / "public opinion monitoring"
- "事件驱动" / "event driven"
- "市场情绪" / "market sentiment"
- "NLP 量化"
- "新闻分析" / "news analysis"
- "恐慌指数" / "fear index"

### 与相邻 skill 的区分 (定稿)

- 与 `factor-mining` 的对比: 本 skill 是**情绪/舆情类因子的专精方法论**（NLP 情感分析 + 事件驱动 + 情绪指标构建），factor-mining 是**通用因子挖掘框架**（覆盖量价/基本面/高频/另类全类型）。当目标是纯情绪因子时，本 skill 更专精（包含情感分类、情绪强度评分、舆情聚合等专门技术）；当目标是多类型因子组合或需要跨类型比较时，用 factor-mining
- 与 `a-share-patterns` 的组合: 本 skill 侧重**文本/舆情分析**（新闻/社媒/研报情感），a-share-patterns 侧重**交易行为模式**（涨停/竞价/游资席位）。A 股短线场景中两者高度互补：舆情判断题材热度 → 交易模式判断龙头/连板机会
- 与 `data-pipeline` 的依赖: 本 skill 以 data-pipeline 为**数据上游**——data-pipeline 提供舆情数据的采集、清洗、结构化存储，本 skill 在此基础上做情感分析和指标构建

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确定情绪分析的数据源**
   - 财经新闻：东方财富、新浪财经、财联社
   - 社交媒体：微博、雪球、股吧
   - 研报：券商研报 PDF
   - 公告：交易所公告
   - 完成标准: 已确定数据源和采集方式

2. **构建情感分析流水线**
   - 文本预处理：去噪、分词、去停用词
   - 情感分类：用大模型或情感分析模型（正面/负面/中性）
   - 情感强度：0-100 分评分
   - 完成标准: 情感分析流水线可运行

3. **构建情绪指标**
   - 个股情绪：该股票相关新闻的情感加权平均
   - 板块情绪：板块内个股情绪的聚合
   - 市场情绪：全市场情绪的聚合
   - 完成标准: 情绪指标可计算

4. **设计交易信号**
   - 情绪极值策略：恐慌时买入，贪婪时卖出
   - 情绪动量策略：情绪快速上升时跟进
   - 事件驱动策略：重大正面事件时买入
   - 完成标准: 交易信号规则已定义

5. **与量价因子结合**
   - 情绪因子 + 量价因子 → 多维信号
   - 回测验证组合效果
   - 完成标准: 组合策略回测结果可接受

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只需要简单的新闻摘要 —— 不需要情绪量化
- 用户做高频交易 —— 情绪分析有延迟，不适合高频
- 用户的数据源只有量价数据，没有文本数据 —— 用 `factor-mining` 做量价因子

### 作者在书中警告的失败模式

- **NLP 误判**: 讽刺、反语、双重否定等导致情感分析错误
- **滞后性**: 新闻发布时市场可能已经反应完毕
- **噪声数据**: 社交媒体大量噪声（广告、水军）影响情绪指标质量
- **过度依赖单一信号**: 情绪因子不能独立使用，需要与其他因子结合

### 作者的盲点 / 时代局限

- 书中未讨论大模型情感分析的幻觉问题（可能编造不存在的情感倾向）
- 对数据合规性（爬虫抓取社交媒体数据的合法性）讨论不足
- 中文金融 NLP 的特殊挑战（金融术语、行业黑话）未深入讨论
- 情绪因子的衰减速度可能比其他因子更快

### 容易混淆的邻近方法论

- 通用 NLP 情感分析 —— 本 skill 专门面向金融/量化场景，强调可交易性
- 传统情绪指标（VIX、put/call ratio）—— 本 skill 用 NLP/大模型构建新型情绪指标
