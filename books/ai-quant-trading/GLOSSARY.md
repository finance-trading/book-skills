## 策略分类类

### 阿尔法量化 (Alpha Quant)
- **作者定义**：挖掘"超额收益因子"，追求高于市场平均回报的策略类型。适合风险偏好高的专业投资者。代表：James Simons 大奖章基金。
- **与常识差异**：常识中 alpha 泛指超额收益；作者将其定义为**一种独立的策略类型**，与贝塔对立。

### 贝塔量化 (Beta Quant)
- **作者定义**：跟踪市场整体趋势，利用系统性波动获利的策略类型。强调顺势而为。代表：Stanley Kroll 趋势跟踪。
- **与常识差异**：常识中 beta 指市场风险系数；作者定义为**趋势跟踪策略类型**。

### 宏观量化 (Macro Quant)
- **作者定义**：基于宏观经济指标（GDP、CPI、利率等）构建模型，适合超大资金（养老金、主权基金）。
- **与常识差异**：较少在业界使用此独立分类；作者将其作为策略金字塔顶层。

### 资产配置量化 (Asset Allocation Quant)
- **作者定义**：跨资产类别动态调整比例（股票/债券/现金/商品），通过定期再平衡实现风险收益的动态平衡。代表：Ray Dalio 全天候策略。
- **与常识差异**：不同于一般资产配置概念；作者强调**量化模型驱动**的动态再平衡。

### 另类量化 (Alternative Quant)
- **作者定义**：基于非传统数据（舆情、事件、游资行为等）构建的策略。是书中四大类策略的补充层。

## AI / 大模型类

### CRISPE 框架
- **作者定义**：面向量化策略设计的提示词框架。C=Capability（能力角色）、R=Recommendation（见解）、I=Insight（声明）、S=Statement（个性）、P=Personality（实验）、E=Experiment。
- **与常识差异**：作者原创/整理，专门面向量化交易场景。

### BROKE 框架
- **作者定义**：面向策略生成与迭代优化的提示词框架。B=Background、R=Role、O=Objective、K=Key Results、E=Evolve。

### ICIO 框架
- **作者定义**：面向数据处理和结构化提取的提示词框架。I=Instruction、C=Input、I=Context、O=Output Indicator。
- **与常识差异**：书中将其专用于研报因子提取、数据清洗等场景。

### MCP (Model Context Protocol)
- **作者定义**：大模型与外部工具/数据源的标准化连接协议。作者比喻为"给 AI Agent 配了一个工具箱"。
- **与常识差异**：2024–2025 年新兴协议；书中做了较深入的解读，并给出了 fastmcp SDK 的代码示例。

### A2A 协议 (Agent-to-Agent)
- **作者定义**：AI 智能体之间直接交流协作的协议。作者比喻为"给 AI Agent 找了队友"。
- **与常识差异**：与 MCP 配合使用——MCP 解决"工具调用"，A2A 解决"多智能体协作"。

### SAL (数据插件层)
- **作者定义**：大模型与量化交易的数据插件与辅助平台，是将外部数据/工具接入大模型的中间层。
- **与常识差异**：作者提出的概念，类似业界常说的"数据连接器"。

### BALA (中国量化平台生态)
- **作者定义**：对中国量化平台（如聚宽、米筐等）的统称。
- **与常识差异**：作者创造的缩写，业界无此通用说法。

### 智力平权
- **作者定义**：大模型赋予普通人接近专业量化团队的分析和建模能力。
- **与常识差异**：不是纯技术术语，是作者的**核心价值主张**。

### 推理模型 vs 非推理模型
- **作者定义**：推理模型（如 DeepSeek-R1、o1）能进行多步逻辑推理；非推理模型（如 GPT-4、Claude）擅长模式匹配和文本生成。
- **与常识差异**：业界常用"reasoning model" vs "base model"；作者用此二分法评估模型在量化任务中的适用性。

### 九大段位
- **作者定义**：大模型使用能力的分级体系，从"无畏玄铁"到"荣耀王者"共九档，按四个维度评估：提示词优化能力、数据利用能力、RAG 能力、工作流复杂度。
- **与常识差异**：作者原创分类，借用王者荣耀段位命名，业界无此标准。

## 量化技术类

### 因子 / Alpha 因子 (Factor)
- **作者定义**：能预测股票收益的可量化指标，用数学公式表达。
- **与常识差异**：与业界通用定义一致；但作者强调用大模型**自动生成**因子，而非手工设计。

### IC 值 (Information Coefficient)
- **作者定义**：因子预测值与实际收益的相关系数，衡量因子预测能力。
- **与常识差异**：业界通用；书中给出的有效门槛是 IC > 0.03。

### 单调性
- **作者定义**：将股票按因子值分组后，各组收益呈现单调递增或递减的趋势。
- **与常识差异**：业界通用；书中将其作为因子有效性的重要检验指标。

### 因子衰减
- **作者定义**：Alpha 因子随时间推移预测力下降的现象。因市场参与者增多、市场结构变化导致。
- **与常识差异**：业界通用；书中提及但承认监控和淘汰机制讨论不足。

### LV2 数据 (Level 2)
- **作者定义**：Level 2 逐笔委托数据，包含买卖盘口（前 5 档）的详细信息，是高频因子的重要数据源。
- **与常识差异**：业界通用；书中用于构建"订单簿不平衡因子"。

### 特征工程 (Feature Engineering)
- **作者定义**：从原始量价数据中构造有预测力的特征，是因子挖掘的核心步骤。
- **与常识差异**：业界通用；书中强调用随机森林、XGBoost 等 ML 方法做非线性特征筛选。

## 数据源类

### AKShare
- **作者定义**：开源的 Python 金融数据接口库，免费获取 A 股行情、财务等数据。
- **与常识差异**：业界通用；书中推荐作为免费数据源的首选。

### Tushare
- **作者定义**：提供 A 股行情、财务、研报等数据的 Python 数据平台，部分接口需付费。
- **与常识差异**：业界通用；书中推荐与 AKShare 搭配使用。

### Wind
- **作者定义**：专业的金融数据终端，覆盖全面但费用较高，主要面向机构用户。
- **与常识差异**：业界通用；书中指出个人投资者可能负担不起。

## A 股特色术语

### 涨停板
- **作者定义**：A 股市场单日涨幅上限（通常 10%，科创板/创业板 20%）。是短线策略的核心信号。
- **与常识差异**：A 股独有机制；书中将其作为量化策略的重要信号源。

### 集合竞价
- **作者定义**：A 股市场 9:15–9:25 的竞价交易阶段，决定开盘价。
- **与常识差异**：A 股独有机制；书中构建了"竞价强度因子"用于捕捉主力资金动向。

### 连板 / 连板梯队
- **作者定义**：股票连续多个交易日涨停。连板梯队指各连板高度（2 板/3 板/.../N 板）的股票分布结构。
- **与常识差异**：A 股独有现象；书中用晋级率（N 板→N+1 板成功率）作为市场情绪指标。

### 晋级率
- **作者定义**：N 板股票成功晋级到 N+1 板的概率。
- **与常识差异**：A 股短线圈常用；书中将其系统化作为**市场情绪的领先指标**。

### 龙头股
- **作者定义**：在某一题材或板块中领涨的股票，通常是连板高度最高的标的。
- **与常识差异**：业界通用；书中提取了龙头股的共性特征——小市值 + 新题材 + 低换手率。

### 游资 / 龙虎榜
- **作者定义**：活跃在 A 股市场的短线投机资金。龙虎榜是披露异常交易数据（买卖前五大席位）的官方机制。
- **与常识差异**：A 股独有；书中通过龙虎榜数据分析游资席位行为模式。
