# 方法与模式

## 数据—模型—优化—执行链
**何时用**：从研究假设进入可交易设计时。  
**怎么做**：定义信息时点和目标 → 清洗并验证数据 → 选择统计/微观结构模型 → 在风险和交易约束下优化 → 用订单算法执行 → 以成交、成本和风险回馈校准。  
**取舍**：流程完整但研究和系统成本高；省略任何环节都会把模型误差伪装成交易优势（第1章）。

## 参数不确定性组合
**何时用**：均值、协方差或模型参数估计误差可能支配权重时。  
**怎么做**：先验/收缩/Bootstrap 或 NPEB → 约束优化 → 观察权重与样本外稳定性 → 加入成本和风险压力。  
**取舍**：稳健性可能牺牲样本内目标；先验与重抽样假设会影响结果（第2章）。

## 高频波动与协变差估计
**何时用**：需要用 TAQ 估计波动、协变差或相关性时。  
**怎么做**：选择成交/报价变量 → 检查微观结构噪声与非同步 → 比较采样频率和估计器 → 对跳跃、日内周期和噪声做敏感性分析。  
**取舍**：更高频提供更多记录，却可能累积噪声；同步处理可能损失信息（第4章）。

## 订单簿事件模型
**何时用**：分析限价单、市价单、撤单的到达与队列变化时。  
**怎么做**：保留逐事件顺序和档位 → 用多元点过程/机器学习/排队模型表达目标 → 用时间变换、QQ 图或样本外预测检查 → 验证规则和隐藏流动性影响。  
**取舍**：点过程解释事件强度，机器学习侧重预测，排队模型侧重等待与耗尽；任何模型都受数据可见性限制（第5章）。

## 执行速度—冲击权衡
**何时用**：大单必须在期限内成交时。  
**怎么做**：估计波动、价差、冲击和深度 → 比较立即成交、分批和状态响应 → 加入数量/期限/参与率约束 → 以成本、剩余和风险对照基准。  
**取舍**：快交易降低等待风险但提高冲击，慢交易相反；最优路径依赖模型假设（第6章）。

## 库存约束做市
**何时用**：持续报双边价且成交会改变库存时。  
**怎么做**：设定参考价格、库存、风险偏好和剩余时间 → 估计报价对应的到达强度 → 用 Avellaneda–Stoikov、Ho–Stoll 或 HJB 类模型选择报价 → 以离散控制管理异常库存。  
**取舍**：价差收入与成交概率、库存风险、信息风险冲突；连续模型需适配离散价格和延迟（第7章）。

## SOR 探索—开发
**何时用**：多个场所或暗池的流动性未知且需分派订单时。  
**怎么做**：按价格、费用、延迟和成交历史生成候选 → 保留探索份额 → 根据部分成交与删失观察更新 → 调整剩余订单并记录路由表现。  
**取舍**：探索改善未来估计但可能增加当期成本；暗池成交结果不能直接揭示完整流动性（第7章）。

## 生产风控闭环
**何时用**：把研究策略接入真实交易系统时。  
**怎么做**：交易前限额 → 交易中订单/仓位/延迟监测 → 故障时停止新增并对账 → 交易后归因和审计。  
**取舍**：控制会增加延迟和运维工作，但没有可审计的状态和停止条件就无法可靠隔离故障（第8章）。
