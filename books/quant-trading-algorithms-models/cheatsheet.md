# 决策速查

## 先选问题，再选模型

| 如果问题是 | 先看 | 关键检查 |
|---|---|---|
| 组合权重不稳定 | 第2–3章 | 参数误差、收缩/先验、约束、样本外 |
| 高频波动或相关性 | 第4章 | 噪声、采样频率、非同步、跳跃 |
| 成交等待与盘口变化 | 第5章 | 事件顺序、档位、队列、撤单 |
| 在期限内完成大单 | 第6章 | 冲击、波动、深度、剩余数量 |
| 双边报价 | 第7章 | 库存、到达强度、风险偏好、终端条件 |
| 多场所分单 | 第7章 | 费用、延迟、成交、删失与探索 |
| 上线或异常 | 第8章 | 数据新鲜度、订单状态、限额、审计 |

## 判断规则

- **若信号收益小于价差、手续费和冲击的保守估计，则不交易或降低规模**；先修正成本模型，不先调信号。
- **若模型输入是高频成交价，先检查微观结构噪声**；不要因为采样更密就接受更高的波动估计。
- **若订单超过最优档可见量，使用多档深度和冲击估计**；最佳报价乘数量会低估成本。
- **若样本最优组合对均值或协方差微小变化很敏感，优先做收缩、先验、约束和样本外检验**；不要把尖锐权重当作信息强度。
- **若“α”换了基准就消失，先重做风险归因**；它可能只是未建模的β或风险补偿。
- **若暗池订单完全成交，只推断可用量至少达到订单量**；不要把一次观察当作总流动性。
- **若行情陈旧、订单回报缺失或仓位无法对账，停止新增依赖该状态的订单**；恢复前完成状态核对。

## 速度—成本—风险

| 方案 | 优点 | 主要代价 |
|---|---|---|
| 立即/市价执行 | 成交确定性较高 | 跨档、冲击和价差 |
| 均匀拆单 | 降低瞬时冲击 | 暴露于价格波动、可能剩余 |
| 状态响应拆单 | 匹配流动性状态 | 模型、延迟和控制风险 |

## 公式与定义边界

- `R_t=(P_t-P_{t-1})/P_{t-1}`；`r_t=log(P_t/P_{t-1})`。跨期对数收益可加。
- 书中IWFV：最优买/卖价分别为 `b/a`，对应量为 `v_b/v_a`，则 `(b·v_a+a·v_b)/(v_b+v_a)`；分母必须为正。
- 积分方差、HJB、TLFV 和价格冲击的完整公式依赖模型假设；本提炼不补写从PDF排版中无法可靠核对的长公式。
- 任何公式应用前都要核对变量定义、信息时点、单位、边界条件和交易成本是否一致。
