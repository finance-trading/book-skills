# 量化交易：算法、分析、数据、模型和优化

**作者**：Xin Guo（郭新）、Tze Leung Lai、Howard Shek、Samuel Po-Shing Wong；**译者**：冯玉林、刘庆富。中文版高等教育出版社，2020，ISBN 978-7-04-051508-4。源 PDF 共 355 页，正文八章。

## 使用方法

先按主题选择章节并读取对应文件；需要行动顺序时查 [patterns.md](patterns.md)，术语查 [glossary.md](glossary.md)，决策和边界条件查 [cheatsheet.md](cheatsheet.md)。回答时区分书中模型、示意例子与对现实市场的推论。先明确资产、数据时间尺度、交易场所、成本、约束和评价基准，再选择模型；不足的信息应说明而非猜测。

## 核心思路

1. **数据 → 分析 → 模型 → 优化 → 算法**：数据和模型连接观察与决策；算法求解决策并执行，交易执行结果又受到市场机制影响。预测、组合选择和执行不能混为一谈。（第1章）
2. **把估计误差纳入组合决策**：历史均值和协方差不是确定真值。考虑贝叶斯、收缩、Bootstrap 和非参数经验贝叶斯（NPEB）；将时间序列特征、交易成本和约束纳入，再检验样本外表现。（第2–3章）
3. **按采样尺度建模**：低频收益可能弱自相关、平方收益却有持续性；高频报价受离散价格、噪声、不规则时间与非同步交易影响。采得更密不必然使波动率估计更准。（第2、4章）
4. **把盘口当事件流而非静态价格表**：限价单、市价单与撤单改变多档队列；点过程、机器学习和排队模型各自回答事件强度、预测和队列动态问题。检查队列优先权、数据完整性和状态变化。（第5章）
5. **执行是风险与冲击的权衡**：大单拆分要平衡交易速度、价格波动风险、流动性和自身冲击；投资组合执行还要考虑资产间依赖与约束。模型最优依赖冲击函数、价格动态及信息假设。（第6章）
6. **报价与路由受库存和成交不确定性制约**：做市同时管理买卖报价与库存；智能订单路由在多个场所权衡价格、成交机会及信息泄露。暗池未成交不能直接解释为零流动性，因为可见结果受订单量删失。（第7章）
7. **模型必须嵌入生产控制**：策略、行情、订单、风控、监控与监管共同决定能否安全运行。历史制度和基础设施描述不自动适用于当前司法辖区。（第8章）
