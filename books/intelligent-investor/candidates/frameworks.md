# Frameworks — The Intelligent Investor

## Framework: Investment vs Speculation Decision Framework

- id: f01
  title: Investment vs Speculation Decision Framework
  type: framework
  source_chapter: 第1章
  source_quote: |
    "投资操作是经过深入分析、能确保本金安全且获得适当回报的操作。不能满足这些要求的操作就是投机。"
  summary: |
    判断任何证券操作属于投资还是投机的三要素检验框架：是否经过深入分析？本金是否安全？预期回报是否适当？三者缺一不可，否则即为投机。

## Framework: Defensive Investor 50/50 Allocation Framework

- id: f02
  title: Defensive Investor 50/50 Asset Allocation Framework
  type: framework
  source_chapter: 第4章
  source_quote: |
    "防御型投资者应在股票和债券之间平均分配资金，或根据市场估值高低在25%-75%之间调整。"
  summary: |
    防御型投资者的资产配置框架：初始50%股票、50%债券；当市场高估时可将股票降至25%，市场低估时可升至75%。定期再平衡使比例回到目标。
  tags: [asset-allocation, defensive-investor, rebalancing]

## Framework: Graham Valuation Formula (V = EPS × (8.5 + 2g))

- id: f03
  title: Graham Valuation Formula
  type: framework
  source_chapter: 第11章
  source_quote: |
    "内在价值 = 每股收益 × (8.5 + 2 × 预期年增长率)"
  summary: |
    基于当前盈利和未来增长预期的保守估值公式。8.5为零增长公司的合理市盈率，2g为增长溢价。计算时增长率应采用保守估计（如过去5-7年平均），并考虑利率环境调整。
  tags: [valuation, formula, quantitative]

## Framework: Defensive Stock Selection Checklist (7 Criteria)

- id: f04
  title: Defensive Stock Selection Checklist
  type: framework
  source_chapter: 第14章
  source_quote: |
    "防御型投资者的选股标准：1) 规模足够大；2) 财务状况稳健；3) 连续支付股息至少20年；4) 过去10年每股收益增长至少1/3；5) 市盈率不超过过去平均的15倍；6) 市净率不超过1.5倍；7) 盈利与股价比例达到长期AAA债券利率的2倍。"
  summary: |
    七项定量筛选标准，用于防御型投资者识别合格的普通股。全部通过才能进入投资组合。核心是"便宜"和"稳健"双重过滤。
  tags: [stock-screening, defensive-investor, checklist, quantitative]

## Framework: Margin of Safety Framework

- id: f05
  title: Margin of Safety Framework
  type: framework
  source_chapter: 第20章
  source_quote: |
    "安全边际 = 内在价值 - 市场价格。投资的秘密在于以显著低于内在价值的价格买入。"
  summary: |
    评估任何投资决策安全边际是否充分的框架：估算内在价值（保守），比较当前价格，计算差价比例。差价越大，安全边际越充足，投资风险越低。安全边际是贯穿全书的核心概念。
  tags: [margin-of-safety, risk-management, core-principle]

## Framework: "Mr. Market" Mental Model

- id: f06
  title: "Mr. Market" Mental Model
  type: framework
  source_chapter: 第8章
  source_quote: |
    "市场先生每天都会给你一个报价：有时他情绪高涨报高价，有时他抑郁报低价。你要利用他的情绪，而不是被他的情绪影响。"
  summary: |
    将市场视为一个情绪不稳定的生意伙伴。你每天收到报价，但你有权决定是否交易。当报价远低于内在价值时买入，远高于时卖出，其他时候忽略。这个框架帮你将市场波动转化为机会而非威胁。
  tags: [market-psychology, behavior, opportunity-framework]

## Framework: Net Current Asset Value (NCAV) Screening Framework

- id: f07
  title: Net Current Asset Value (NCAV) Screening Framework
  type: framework
  source_chapter: 第15章
  source_quote: |
    "净流动资产价值 = 流动资产 - 总负债。股价低于此值的股票是极度廉价的信号。"
  summary: |
    筛选股价低于净流动资产价值的股票（"烟蒂股"）。净流动资产价值是极端保守的清算价值估算，不计固定资产。股价低于此值意味着投资者免费获得固定资产，是格雷厄姆式价值投资的经典策略。
  tags: [deep-value, quantitative-screening, nifty-fifty]

## Framework: Dollar-Cost Averaging Framework

- id: f08
  title: Dollar-Cost Averaging Framework
  type: framework
  source_chapter: 第4章
  source_quote: |
    "定期定额投资法——无论市场高低，固定时间投入固定金额——可以消除时机选择的焦虑。"
  summary: |
    通过固定时间间隔投入固定金额来构建投资仓位。市场下跌时买入更多份额，上涨时买入较少。消除"何时入场"的决策压力，是一种自动化的纪律化投资方式。
  tags: [investment-discipline, automation, behavioral-finance]

## Framework: Speculation Account Separation Rule

- id: f10
  title: Speculation Account Separation Rule
  type: framework
  source_chapter: 第1章
  source_quote: |
    "如果你要投机，请使用独立的账户，资金不得超过总资产的10%，并且从心理上明确这是投机而非投资。"
  summary: |
    将投机活动（短线交易、杠杆操作、跟风炒作）与投资账户严格物理隔离。投机账户资金上限为总资产的10%，且必须清楚标记为"赌博账户"，与投资账户的心理账户分开。
  tags: [risk-control, behavioral, account-segregation]
