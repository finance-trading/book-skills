# 第二天：财富决策速查

## 核心决策规则

| 情况 | 决策规则 | 原因 / 核查 |
|---|---|---|
| 突然获得大额财富 | 先建立账本、预算与应急现金，至少一年内不升级生活标准 | 管钱能力跟不上，财富会变成麻烦（ch02、ch13） |
| 身边人都在赚钱、消费炫耀到极端 | 启动散场检查，分批降低风险敞口 | 狂热是共识极端的信号，不是安全证明（ch01、ch07） |
| 想加杠杆扩张 | 先判断企业是抵补型、投机型还是庞氏型 | 现金流不足以覆盖本息的扩张会把优势变成脆弱（ch08） |
| 拍卖、并购、抢项目、争排名 | 先独立估值并写下上限，保留"不参与"选项 | 赢家往往支付超过价值的价格（ch05） |
| 有人主动推荐"专属、保密、高回报"机会 | 先追踪对方佣金与获利方式，再做独立尽调 | 猎手常以朋友或顾问姿态出现（ch10） |
| 决策已被证明错误 | 公开承认、止损、复盘假设 | 承认错误的成本通常小于错误的代价（ch11） |
| 日程被会议、饭局、项目填满 | 做行动减法，删掉低价值事务 | 忙碌不等于价值，认知带宽有限（ch12） |
| 想通过消费证明成功 | 问"它增加的是物品、资产，还是自由" | 消费是财富的出口，资产与自由才是留存（ch13） |
| 考虑与权力或舆论对抗 | 退回边界内，保持低调 | 财富在权力与舆论面前通常处于弱势（ch15） |
| 家族准备传承 | 同时建设能力、价值观、制度与治理 | 只交钱不交能力，财富会变成诅咒（ch17） |
| 投资期限很长 | 稳健收益、避免大亏、持续再投入 | 复利依赖时间与不中断（ch18） |
| 青年/中年阶段选择 | 青年创造资产，中年配置资产 | 不同阶段核心优势不同（ch20） |

## 决策树

1. **这笔财富/这个机会会不会造成不可逆损失？** 会 → 先移除风险或放弃；不确定 → 继续调查。
2. **我有没有能力照顾它？** 没有 → 先补财商、预算与治理；有 → 进入下一步。
3. **收益依赖什么共识或假设？** 共识极端或假设脆弱 → 降低敞口；共识合理 → 继续。
4. **最坏情况下现金流能否覆盖本息与生活？** 不能 → 降杠杆、留冗余；能 → 继续。
5. **这件事增加的是物品、资产，还是自由？** 只有物品 → 重新考虑；资产或自由 → 执行。
6. **我是否因为沉没成本、面子或圈层压力而坚持？** 是 → 回到事实与赔率；否 → 执行并设置复盘条件。

## 关键阈值与默认值

- **生活升级**：大额财富到手后，至少延迟 12 个月再升级固定支出。
- **单点依赖**：任一产品/客户/供应链节点贡献超过 30% 利润或供给，视为需要备份。
- **杠杆**：若收入下降 30% 就无法覆盖本息，杠杆已过高。
- **决策带宽**：同时评估超过 3 个重大项目时，主动减少或延后。
- **社交配置**：核心圈约 10 人、资源圈约 50 人、礼貌圈约 300 人；核心圈投入最多时间。
- **复利检查**：每年检查一次是否出现负复利（大额亏损、频繁中断、收益率不可持续）。
- **学习投入**：每年至少投入 5% 时间进入完全陌生的领域。

## 危险信号

- 把"能花"当"有钱"，把负债包装成资产。
- 认为"这次不一样"，并用杠杆表达信念。
- 把时代红利、运气或政策窗口归因于个人能力。
- 用新债还旧债、用展期掩盖资不抵债。
- 把拍卖纪录、榜单排名、社交媒体热度当成真实价值。
- 身边只剩赞美者，没有唱反调的人。
- 为维持圈层地位而持续支付无法取消的固定开销。
- 把子女教育等同于学费，把家族传承等同于遗嘱。
- 在情绪高涨时做不可逆的承诺或大额支付。
