# 术语表

- **安全边界** — 企业为抵御需求、供应、融资与政策意外而保留的缓冲；扩张过快会侵蚀它（ch08）。
- **比较暴政** — 在圈层中不断与他人比较物质规格，导致欲求永远无法满足（ch16）。
- **财富照顾能力** — 让财富不被欲望、关系、杠杆与错误决策侵蚀的能力；与赚钱能力不同（ch02）。
- **财富致幻效应** — 作者引用神经经济学说法，指巨额财富改变风险感知与自信，使人高估掌控力（ch11）。
- **藏富** — 中国传统智慧，通过低调减少被觊觎、被攻击与被舆论聚焦的风险（ch15）。
- **超级个体** — 借助 AI、网络与远程协作获得过去组织级能力的个人（ch19）。
- **第二天** — 财富已经获得、但尚未转化为稳定幸福的人生阶段，全书核心议题（ch00）。
- **反脆弱** — 不仅承受冲击，还能从波动中学习、调整并变强的系统特性（ch08）。
- **负复利** — 亏损后需要更高收益才能回本，一次大亏会破坏长期复利曲线（ch18）。
- **共识** — 群体共同相信的叙事，能让货币、品牌、艺术品等具有价值（ch07）。
- **归因偏差** — 成功归因于自己，失败归因于环境；易把时代红利误当个人能力（ch03）。
- **饥饿感** — 成功者刻意保留的资源约束与一线接触，用以对抗安乐与迟钝（ch03）。
- **家族办公室** — 为家族提供投资、治理、慈善与继承管理的专业机构（ch17）。
- **贾而好儒** — 明清晋商、徽商把儒家伦理嵌入商业，以诚信降低长期交易成本（ch06）。
- **价值** — 作者认为价值不是物质固有属性，而是客观属性、共识强度与流动性的共同结果（ch07）。
- **焦虑清单** — 富人为维持社交认同、地位、人情与隐秘欲望而承担的持续支出与压力（ch02）。
- **结构化理论** — 吉登斯理论：社会结构规范人的行为，人的行为又强化社会结构（ch09）。
- **经济脆弱性** — 企业依赖单一利润源、单一供应链或高杠杆，受冲击后损失被放大的状态（ch08）。
- **抗熵系统** — 通过能量、信息、时间与意义四个维度持续对抗衰退的生命系统（ch20）。
- **口碑黑市** — 圈层中传播未经证实的评价，用来影响他人声誉与合作机会（ch09）。
- **老钱 / 新钱** — 老钱有传承有序的财富管理智慧；新钱常在学习管钱前就获得财富（ch05、ch13）。
- **猎手** — 以朋友、顾问或猎物姿态接近富人，通过佣金、交易或关系获取利益的人（ch10）。
- **路径依赖** — 过去成功的做法被不断强化，形成难以跳出的认知与行为惯性（ch03、ch08）。
- **卖者困境** — 需要变现时才发现市场已变冷；赢家诅咒在流动性层面的表现（ch05）。
- **能力圈** — 自己真正理解并能评估关键因果与风险的范围（ch12）。
- **逆向思维** — 从失败或不想要的结果反推原因，再有意识地避开（ch04）。
- **穷人的认知** — 把财富等同于消费能力、把花钱当自由的思维方式，与账户余额无关（ch13）。
- **认知带宽** — 有限的注意力与判断资源，不能无限并行处理项目与决策（ch12）。
- **社会绑架** — 被荣誉、口碑与日程控制，失去拒绝与退出的能力（ch09）。
- **身份消费** — 支出主要用于向他人展示位置与圈层，而非满足实际使用需求（ch02）。
- **损失厌恶式加码** — 已投入后不愿承认错误，继续投入以证明最初判断（ch11）。
- **投机型融资** — 经营现金流不足以覆盖本息，需要持续再融资才能维持（ch08）。
- **稀缺心态** — 长期资源不足使人优先满足眼前需求，难以进行长期投资（ch13）。
- **幸福公式** — 作者概括为"幸福 = 拥有 ÷ 欲求"，减少欲求也能提高幸福（ch16）。
- **赢家诅咒** — 在信息不对称的竞拍中，赢家往往支付超过标的真实价值的价格（ch05）。
- **元学习** — 对自身学习过程进行认知、监控、调节与优化的能力（ch14）。
- **知识半衰期** — 知识从学到过时所需时间；作者引用数据称已缩短至数年（ch14）。
- **终身学习** — 把学习作为贯穿生命的生活方式，而非青年阶段的突击任务（ch14）。
- **自我服务偏差** — 成功时过度归功于自己，失败时归咎外部环境（ch03）。
- **自我技术** — 福柯概念：个体主动塑造自身行为；在财富阶层表现为选择性隐遁（ch15）。
