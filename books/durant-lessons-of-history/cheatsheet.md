# 历史判断速查

## 基本决策规则

| 情况 | 规则 | 依据 |
|---|---|---|
| 有人用历史规律预测未来 | 先假设历史会嘲笑这条规律，找反例 | 历史是对概括化的反动 (Ch 1) |
| 判断国家/城市的长期机会 | 先看水、路、气候，再看技术与制度 | 地理是子宫，人才是创造者 (Ch 2) |
| 新交通/通信技术出现 | 追踪谁失去旧路线优势、谁获得新路线 | 贸易线转移权力 (Ch 2) |
| 讨论竞争与合作 | 问合作是对谁竞争的工具 | 生命即竞争 (Ch 3) |
| 设计平等政策 | 优先法律与教育机会平等，不承诺结果平等 | 自由与平等存在结构张力 (Ch 3) |
| 听到“某族天生优越/落后” | 找同环境反例，查文化传播 | 文明塑造民族，而非种族塑造文明 (Ch 4) |
| 面对激进改革 | 让新观念接受异议与替代成本检验 | 百种新思路至少九十九种不如旧传统 (Ch 5) |
| 判断道德松弛 | 查旧规范的经济基础是否已变 | 道德随经济阶段调整 (Ch 6) |
| 用丑闻推断时代道德 | 补上未被记录的日常善行 | 史书是“悔罪的记录” (Ch 6) |
| 宗教衰退 | 追踪谁接替安慰、秩序与道德功能 | 天堂与乌托邦是水桶 (Ch 7) |
| 分析战争/革命 | 经济、政治、军事、宗教、情绪五因并列 | 经济解释有边界 (Ch 8) |
| 贫富差距扩大 | 越早用和平再分配，越可能避免暴力 | 财富集中—再分配周期 (Ch 8) |
| 评估经济体制 | 先看激励与官僚成本，再看口号 | 利润动机不可缺 (Ch 8–9) |
| 出现紧急状态管制 | 警惕管制永久化 | 内部自由与外部危险成反比 (Ch 9) |
| 判断政体 | 看实际权力、继承与制衡，不看名义形式 | 寡头现实 (Ch 10) |
| 考虑革命 | 先比较渐进改革能否达到同等结果 | 革命破坏大于再分配 (Ch 10) |
| 和平时期 | 找它依赖的均势或霸权基础 | 和平是不稳定平衡 (Ch 11) |
| 文明/组织衰退 | 列挑战，查领导层是否回应 | 衰退源于回应失败 (Ch 12) |
| 评价技术进步 | 分开控制能力、收益普及与破坏用途 | 科学中立 (Ch 13) |

## 三个总公式

1. **历史认识**：过去的知识 = 不完整证据 + 史家偏见；结论只能是概率性的背景，不是判决。
2. **历史动力**：竞争与选择（生物）→ 财富集中与再分配（经济）→ 秩序与自由（政治）→ 挑战与回应（文明）。
3. **历史进步**：手段变强 ≠ 目的变好；真正的进步是文明遗产的丰富、保存、传播与利用。

## 快速诊断

- **过度概括**：论证只给一条铁律，没有反例 → 回到 Ch 1。
- **地理宿命**：把贫富全归因气候地形 → 回到 Ch 2。
- **乌托邦平等**：假设人人生而相同 → 回到 Ch 3。
- **血统论**：用族群标签解释文明 → 回到 Ch 4。
- **传统/创新二选一**：只骂旧或只捧新 → 回到 Ch 5。
- **道德恐慌**：把规范变化直接当衰亡 → 回到 Ch 6。
- **世俗化直线论**：以为宗教必然消失 → 回到 Ch 7。
- **单因经济论**：把所有冲突都归为金钱 → 回到 Ch 8。
- **计划万能论**：忽视激励与官僚成本 → 回到 Ch 9。
- **民主自动优良论**：忽视教育、分配与战争 → 回到 Ch 10。
- **和平自然论**：忽视均势与制度 → 回到 Ch 11。
- **文明宿命论**：用“有机体衰老”替代具体失败分析 → 回到 Ch 12。
- **技术乐观/悲观**：只谈工具，不谈目的与分配 → 回到 Ch 13。
