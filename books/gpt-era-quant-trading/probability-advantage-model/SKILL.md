## R 原文

> "量化交易是通过在不确定的金融市场中寻找确定性，从而在特定范围内利用概率（然率、机会率或可能性）优势取得超额收益的方法。其核心假设是：①上帝视角（基于概率的系统思维）；②没有全局最优解，只有局部最优解；③市场普遍存在超额收益（非理性）。"（第1.1节）

## I 方法论骨架

概率优势思维模型是量化交易的底层哲学，它将投资者的目标从"预测下一次结果"转向"在足够多次交易中保持概率优势"。

核心逻辑有三层：

**第一层：上帝视角（概率替代预测）**
不问"明天涨还是跌"，而问"在满足条件X的情况下，历史上上涨的概率是多少"。决策依据是概率分布，而非单次预言。一旦确立规则，系统严格执行，以克服恐惧和贪婪。

**第二层：局部最优（承认边界）**
没有任何策略在所有市场环境下都有效。概率优势只在特定范围（特定品种、特定周期、特定市场状态）内成立。策略的任务是找到"在哪里、什么时候、对谁"有优势，而非追求万能圣杯。

**第三层：非理性创造机会**
市场参与者的认知偏差、情绪反应和信息不对称持续产生非理性定价。这是超额收益的来源——量化的目的是系统性地捕捉这种非理性，而非预测理性价格。

三个假设共同构成"量化可行性"的哲学基础：市场不可精确预测，但概率优势可以被发现和利用。

## A1 书中应用

书中以量化交易系统的实际运作验证此模型：

1. **系统化执行**：量化系统"一旦确定了规则，系统就将严格按照既定的规则执行各种操作，以克服人们在面对市场大幅度波动时所产生的恐惧和贪婪等弱点"（1.1节）——这正是概率优势思维的实践：单次亏损被纳入预期，不破坏整体正期望值。

2. **局部最优的体现**：书中所有策略均指定适用范围——如打板策略只适用于开盘3-10分钟窗口、RSRS策略对贝塔量化有效但无法覆盖基本面场景——正是局部最优假设的表达。

3. **非理性捕捉**：阿尔法002因子通过捕捉价量背离（市场参与者的非理性定价模式）产生信号，IC分析验证其在创业板（非理性更强）的表现优于沪深300（3.1节）。

## A2 触发场景

1. 策略连续亏损几次后想放弃 — 用概率优势框架重建预期管理
   触发词：`连续亏损 / losing streak / 策略是不是失效了`
2. 设计新策略时需要确立基础假设 — 用三核心假设检验策略的可行性前提
   触发词：`策略逻辑 / strategy foundation / 为什么这个有效`
3. 评估过拟合风险 — 检查策略是否声称"全局最优"（局部最优假设的反例）
   触发词：`过拟合 / overfitting / 样本内外差距大`
4. 向非量化背景的人解释量化交易 — 用概率优势模型作为入口
   触发词：`量化是什么 / explain quant trading / 量化和主观的区别`
5. 回测结果很好但实盘差 — 检查概率优势的"特定范围"是否在实盘中消失
   触发词：`回测好实盘差 / backtest vs live / 策略漂移`

## E 可执行步骤

1. **明确概率优势的范围边界**：确定策略在什么市场状态、什么品种池、什么周期内有效。写下三个条件：市场状态条件、标的筛选条件、持仓周期条件。
   完成标准：三个条件均可量化，不含"通常""一般"等模糊词。

2. **计算历史胜率和赔率**：用足够长的历史数据（覆盖至少一个牛熊周期）统计：满足条件时的胜率、平均盈利/平均亏损比（赔率）。计算期望值 = 胜率×平均盈 - 负率×平均亏。
   完成标准：期望值为正，样本量 ≥ 30次交易。

3. **设置单次头寸上限**：基于凯利公式或固定比例，确保单次最大亏损不超过总资金的2%。这是"承认局部最优"的操作化——任何单次押注不能威胁全局。
   完成标准：最大回撤场景下，剩余资金仍够执行后续10次交易。

4. **建立执行规则，排除情绪**：将步骤1-3的结论写成自动化规则或检查清单，决策时只看规则输出，不看当日情绪。
   完成标准：规则文档存在，且近10次交易均按规则执行（有记录可查）。

5. **定期审查概率优势是否仍然有效**：每季度用滚动窗口重新计算胜率和期望值，检测市场非理性是否已被套利消除。
   完成标准：IC值或分组收益差仍然显著，换手成本可控。

## B 边界

**不适用场景**：
- 单次高确定性的事件驱动（如明确的政策公告），此时不需要概率优势，需要事件解读能力
- 极低频率策略（年交易次数 < 10），样本太小，概率优势无法稳定显现
- 市场结构突变期（如停牌、熔断、极端政策冲击），历史概率分布失效

**作者警示的失败模式**：
- 将"局部最优"误解为"随时可用"——在概率优势范围之外强行执行策略
- 单次亏损后修改规则——破坏了大数定律发挥作用的前提
- 追求"全局最优"圣杯策略——耗尽研发资源，最终一无所得

**盲点**：
- 框架未说明如何识别"概率优势是否已消失"的具体信号阈值
- 三个核心假设本身无法被证伪——它们是信念而非可测试命题
- "上帝视角"要求充足历史数据，新兴市场或新品种数据稀疏时适用性受限
