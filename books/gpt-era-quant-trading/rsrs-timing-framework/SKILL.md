## R 原文

> "市场在牛市中：如果支撑位的作用力明显强于阻力位，则牛市持续，价格加速上涨；相反则牛市可能即将结束，价格见顶。市场在震荡状态中：如果支撑位的作用力明显强于阻力位，则牛市可能即将启动；相反则熊市可能即将启动。市场在熊市中：如果支撑位的作用力明显强于阻力位，则熊市可能即将结束，价格见底；相反则熊市持续，价格加速下跌。"（第2.3.3节）

## I 方法论骨架

RSRS（Resistance Support Relative Strength，阻力支撑相对强度）择时框架的核心是：**用最高价与最低价之间的线性回归斜率，动态量化"买方（支撑）力量"相对于"卖方（阻力）力量"的强弱**，而非设定固定的价格阈值。

**指标构建逻辑**：
对滚动N日窗口内的最高价（high）和最低价（low）做线性回归，回归斜率 β 即为 RSRS 斜率。斜率越大，表示最高价和最低价同步抬升越快——支撑力越强，多头共识越明显。

**三种市场状态下斜率信号的含义不同**：
- 牛市中斜率持续高 → 牛市加速；斜率开始下降 → 注意顶部
- 震荡市中斜率超过阈值 → 牛市启动信号；跌破阈值 → 熊市启动信号
- 熊市中斜率低位回升 → 底部信号；继续下跌 → 熊市加速

**与传统均线择时的根本差异**：
均线用价格绝对水平，RSRS 用价格结构变化速率。均线在震荡市产生大量假信号；RSRS 通过支撑/阻力的相对强度动态适应市场状态。

框架背后的市场微观结构逻辑：支撑位的作用力反映买方共识，阻力位的作用力反映卖方共识；斜率即二者力量对比的动态快照。

## A2 触发场景

1. 判断当前是否应该持仓还是空仓 — 用 RSRS 斜率确认多空方向
   触发词：`现在该买还是空仓 / 市场方向 / timing signal / 何时入场`
2. 趋势跟踪策略需要入场/离场信号 — RSRS 作为趋势确认过滤器
   触发词：`趋势确认 / trend confirmation / 入场信号 / exit timing`
3. 均线策略假信号太多，需要更稳健的择时方法 — 用 RSRS 替换或补充均线
   触发词：`均线失效 / moving average / 震荡市假突破 / whipsaw`
4. 判断市场从震荡转为趋势的时点 — RSRS 在震荡-趋势转换时最敏感
   触发词：`盘整突破 / breakout confirmation / 震荡转趋势`
5. 评估贝塔量化策略的择时模块 — RSRS 是标准的贝塔择时组件
   触发词：`贝塔策略 / beta strategy / 趋势追踪 / trend following`

## E 可执行步骤

1. **计算 RSRS 原始斜率**：对滚动 N 日（推荐 N=18 或 N=25）的 high 和 low 做线性回归，得到回归斜率 β。公式：对每日 (low_t, high_t) 对做 OLS 回归 high = α + β × low + ε，β 即斜率。
   完成标准：输出每日一个斜率值的时间序列，无缺失值（前 N 天除外）。

2. **标准化斜率（Z-score）**：对过去 M 日（推荐 M=300-600）的斜率序列计算滚动均值和标准差，标准分 = (β_t - mean) / std。标准分 > 0.7 为看多信号，< -0.7 为看空信号。
   完成标准：生成每日标准分时间序列，信号分布合理（过多信号说明阈值太低，过少说明太高）。

3. **识别当前市场状态**：计算市场是否处于牛市（价格在200日均线以上）、熊市（价格在200日均线以下），或震荡（价格在均线±5%区间内）。
   完成标准：每日输出明确的市场状态标签（bull/bear/ranging）。

4. **结合市场状态解读 RSRS 信号**：
   - 牛市 + 标准分持续下降 → 注意顶部，考虑减仓
   - 震荡 + 标准分上穿0.7 → 牛市启动候选，可建仓
   - 熊市 + 标准分从低位回升 → 底部候选，轻仓观察
   完成标准：输出带有市场状态修正的综合信号。

5. **回测验证并设定进出场规则**：用历史数据回测，确认胜率、最大回撤、空仓比例合理。制定书面规则：标准分超过阈值 X 时满仓，低于阈值 Y 时清仓，中间区间减半仓位。
   完成标准：回测期覆盖至少一个完整牛熊周期，空仓信号确实规避了主要下跌段。

## B 边界

**不适用场景**：
- 选股（RSRS 是市场级别的择时工具，不区分个股）
- 日内超短线（斜率基于日线数据，无法捕捉日内微观结构）
- 基本面驱动的配置决策（RSRS 是纯技术指标，不包含基本面信息）
- 成交量极低或流动性差的市场（最高最低价容易被异常成交扭曲）

**作者警示的失败模式**：
- 用绝对斜率值设定固定阈值——市场不同时期的斜率均值不同，固定阈值会产生大量失效信号
- 不区分市场状态直接使用斜率——同样的斜率值在牛市和熊市含义相反
- 忽略回归拟合质量（R²低时斜率不可信）——这是 f21 框架专门解决的问题

**盲点**：
- 框架未说明 N（回归窗口）和 M（标准化窗口）的最优参数选择方法，存在过拟合风险
- RSRS 对市场状态的判断（牛/熊/震荡）本身也依赖某种择时方法，构成循环依赖
- 在趋势极强的单边市中，RSRS 可能过早产生顶部/底部信号，导致提前离场或进场
