## R 原文

> "全天候量化交易策略的核心逻辑是桥水公司认为，任何资产的价格都和这2个因素有关——经济活动水平（增长、衰退）和价格水平（通胀、通缩）。针对上述4种情况配置平衡资产可以有效减小不利波动，并且不需要进行预测。"（第2.2.3节）

## I 方法论骨架

全天候四象限框架的核心洞见：**所有资产价格最终都由两个宏观变量驱动——增长和通胀**。将两个变量各取两个方向，得到四个象限，每个象限都有一类资产表现最佳。

**四象限与对应资产**：
- 高增长 + 通胀正常：股票、大宗商品、公司债、新兴市场信用产品
- 高增长 + 高通胀：通胀联结债券（TIPS）、大宗商品、新兴市场债
- 低增长（衰退）+ 通胀正常：普通债券、通胀联结债券
- 低增长 + 低通胀（通缩）：股票、普通债券

**核心操作原则**：
不预测哪个象限会出现，而是为每个象限都配备"表现好"的资产。让四个象限的风险贡献相等（四等分风险分配）——无论宏观进入哪个象限，组合都有对应资产正常运作。

**与传统配置的根本差异**：
传统配置假设投资者能预测宏观走势；全天候假设投资者无法可靠预测，所以为所有可能做准备。"全天候"不是指全天候盈利，而是指全天候不崩溃。

## A1 书中应用

书中以桥水公司实际运作的全天候投资组合为案例（第2.2.3节）：

**组合构成**（5只ETF版本）：
- GLD（黄金）7.5%、GSG（大宗商品）7.5%、IEI（中期国债）15%、TLT（长期国债）40%、VTI（股票）30%
- 固定收益占大头（55%资金），以风险加权而非资金加权为准

**实测表现**：2007年1月至2023年3月，复合年化增长率5.45%，夏普比率0.73。2008年金融危机、2010年欧债危机期间均保持相对稳健。

**中国本土化版本**：书中以股票+债券+现金三维全天候组合演示中国适配版，15年覆盖多个牛熊周期，复合年增6.18%，最大回撤-17%，并与美国401K计划做了风险指标对比（表1.3、1.4）。

## A2 触发场景

1. 无法判断当前是通胀还是通缩、增长还是衰退 — 用四象限框架确保每个象限都有覆盖
   触发词：`宏观不确定 / macro uncertainty / 不知道经济走向`
2. 构建养老金、家族信托等超长期资金配置 — 四象限为全周期提供风险保护
   触发词：`长期资金 / long-term allocation / 养老金 / 家族财富传承`
3. 现有组合在某个宏观环境下持续亏损 — 检查是否缺少该象限对应资产
   触发词：`一到通胀就亏 / bond crash / 某类环境表现差`
4. 从单市场转向多资产配置 — 四象限提供跨资产类别配置的结构框架
   触发词：`多资产 / multi-asset / 大类资产配置 / asset allocation`
5. 评估现有基金是否真正"全天候" — 检查四个象限是否均有资产覆盖
   触发词：`这个基金是全天候吗 / all-weather fund / 评估组合`

## E 可执行步骤

1. **画出四象限资产覆盖矩阵**：列出当前持仓的所有资产，将每类资产标注在四个象限中（哪个象限它表现最好）。检查是否有象限空缺。
   完成标准：四个象限均有至少一类资产覆盖。

2. **按象限补全资产类别**：
   - 缺高增长覆盖 → 加股票类ETF
   - 缺通胀覆盖 → 加TIPS/黄金/大宗商品
   - 缺衰退覆盖 → 加长期国债
   - 缺通缩覆盖 → 加短期国债/现金
   完成标准：每个象限有明确对应的可投资工具（具体ETF或基金代码）。

3. **四等分风险分配**：用风险平价方法（见 risk-parity-framework）计算使四个象限风险贡献相等的权重。或使用简化版：按历史波动率倒数分配权重。
   完成标准：最大象限风险贡献 / 最小象限风险贡献 < 1.5。

4. **设定再平衡规则**：确定再平衡频率（月度/季度）和触发阈值（任意资产偏离目标权重超过5%时再平衡）。
   完成标准：书面规则存在，包含具体数字阈值，不含主观判断空间。

5. **压力测试四个象限**：用历史场景（2008金融危机、2022年滞胀、2020年新冠崩盘）分别模拟组合在每个象限下的表现，验证无象限导致组合崩溃性亏损。
   完成标准：任何单一宏观场景下的最大回撤 < 预设容忍上限（通常-25%以内）。

## B 边界

**不适用场景**：
- 需要主动博取高额收益（全天候的目标是稳健，不是跑赢市场）
- 资金规模太小（< 50万），无法有效分散到4类以上资产
- 需要精确预测宏观走势然后下注（这与框架哲学相悖）
- 所有资产同向暴跌的极端危机期（全天候不能对冲系统性崩溃，只能降低损失）

**作者警示的失败模式**：
- 把"全天候"理解为"全天候盈利"——该策略在某些象限仍会亏损，只是不崩溃
- 忽略再平衡：随时间漂移后，高增长象限资产权重会显著扩大，重新集中风险
- 仅用股票+债券两类，未覆盖通胀象限（黄金/大宗）——在高通胀环境下组合崩溃

**盲点**：
- 四象限框架假设经济状态可以清晰分类，但实际上转换过程是渐进且模糊的
- 中国市场债券、大宗商品品种选择有限，本土化适配难度高于美国市场
- 框架来自1996年，对数字经济、加密资产等新资产类别如何归象限没有明确指引
- 低利率/零利率环境下，债券的通缩对冲功能显著下降，该场景未被原始框架充分考虑
