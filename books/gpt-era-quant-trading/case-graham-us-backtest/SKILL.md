## R 原文

> "斯坦福大学Charles Lee教授用美国1999年1月2日至2013年11月9日数据对格雷厄姆选股法回测。前2个十分位数股票年化收益率约14%，最后2个十分位数约5%，标普中型股400指数同期为8.5%。"
> —— Section11 (2.1.2)

## I 方法论骨架

格雷厄姆选股法是价值投资量化化的最早系统性尝试，将主观判断转化为可机械执行的多维度筛选标准。

原版10条标准被斯坦福Charles Lee教授更新为8条（去掉时间过长的第9、10条，将股息率替换为自由现金流收益率，将10年收益增长缩短为5年），并在美股1999-2013年进行回测。

8条标准分为两组：
- 廉价度组（前5条）：盈利收益率>AAA债券收益率×2、市盈率<5年历史均值40%、自由现金流收益率>AAA债券收益率×2/3、股价<有形账面价值×2/3、股价<净流动资产价值×2/3。
- 质量度组（后3条）：负债权益比<1、流动比率>2、负债<净流动资产×2。

按综合评分将股票分成10个十分位，最高分位（更便宜+更高质量）年化14%，最低分位5%，标普中型股400指数同期8.5%。核心结论：在近14年美股中，"更便宜+更高质量"长期有效，验证80年前格雷厄姆逻辑的持久性。

## A1 书中应用

书中以此回测作为格雷厄姆价值投资原则"经得起量化检验"的实证支撑，在介绍格雷厄姆选股法（Section11，2.1.2）后直接呈现：

- 测试机构：斯坦福大学商学院Charles Lee教授及学生。
- 数据区间：1999年1月2日至2013年11月9日，横跨互联网泡沫破裂、2008年金融危机、后危机复苏，约14年。
- 结果：前2分位年化约14%，末2分位约5%，价值加权标普中型股400指数为8.5%。高质量低价股超额收益约5.5个百分点/年，低质量股跑输基准约3.5个百分点/年。
- 书中解读：格雷厄姆的选股框架"廉价度"与"质量度"两个维度均对收益有独立预测力，两者叠加效果最强，证明安全边际+企业质量的组合是长期有效的投资原则。

## A2 触发场景

**触发此案例作为论据的场景：**

1. 讨论"价值投资是否可以量化"——本案例是格雷厄姆主观框架量化落地后回测有效的直接证据。触发词：value investing quant / 价值投资量化 / systematic value / 量化价值
2. 讨论"低市盈率+低杠杆组合是否长期有效"——14年跨越两次危机的实证是有力支撑。触发词：low PE / 低市盈率 / low leverage / quality+value / 质量+估值
3. 讨论"经典投资框架的时效性"——80年前的格雷厄姆原则在2000年代仍有效，说明底层逻辑的稳健性。触发词：timeless investing principles / 经典原则有效性 / long-term validity / 跨时代有效
4. 讨论"如何设计多维筛选因子"——本案例的8条标准是"廉价度"+"质量度"双维度设计的范本。触发词：multi-criteria screening / 多维筛选 / composite score / 综合评分
5. 讨论"回测设计的最佳实践"——本案例展示了学术级回测的关键要素：长区间、跨周期、与基准对比、十分位分析。触发词：backtest design / 回测设计 / academic backtest / 学术回测

## E 可执行步骤

使用本案例时的操作步骤：

1. **定位引用目的**：判断是用于"价值投资有效性论证"还是"量化因子设计方法论"。
2. **引用关键数字**：前2分位14%，末2分位5%，基准8.5%，1999-2013年约14年，超额约5.5%/年。
3. **解释两组标准**：说明前5条衡量廉价度（估值低），后3条衡量质量度（财务健康），两者叠加预测力最强。
4. **点出跨周期价值**：数据区间覆盖互联网泡沫、2008金融危机、复苏期，结论的跨周期稳健性是核心论点。
5. **连接格雷厄姆历史背景**：1934年提出的原则，2013年仍有效，强调底层逻辑的普适性（价格回归价值）。
6. **完成标准**：引用后能清楚说明"哪组标准贡献更大"和"为何14年跨多轮周期仍有效"。

## B 边界

**不适用场景：**
- 讨论A股市场有效性（本回测仅覆盖美股，A股市场结构差异显著）
- 讨论成长股投资（格雷厄姆框架强调安全边际，排斥高估值高成长股）
- 短期（1年内）策略有效性论证（本案例为长期均值回归逻辑）

**作者警示的失败模式：**
- 单独使用低市盈率（廉价度）而忽视质量度，可能落入"低估值陷阱"（书中引用费雪的低PE买股反而持续下跌案例）
- 将8条标准全部满足作为硬性条件，在不同市场环境下可能筛出股票极少
- 忽视市场环境对因子有效性的影响，在利率上行周期价值股表现可能不同

**盲点：**
- 回测结束于2013年，2014年后美股价值因子的表现相对偏弱，长期有效性存在时代背景争议
- 斯坦福回测使用价值加权标普中型股400作为基准，而非市值加权的标普500，比较基准选择会影响结论
- 书中未提供具体代码实现，从8条标准到实际选股的工程细节（数据源、更新频率等）需读者自行补充
