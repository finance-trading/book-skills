## R — 原文

> "索普有一个著名的'2%法则'：当你过度下注时，你将会失去一切。在21点的赌博中，如果你从不一次下注超过你总筹码的2%，就永远也不可能输光所有的钱。投资也一样。如果你从不将超过2%的头寸暴露在任何一种风险中，那么就不可能亏光本金。"
>
> — §3.3.2《凯利公式所引发的思考·启示三》

## I — 方法论骨架

爱德华·索普（Edward Thorp）从21点赌博中提炼出"2%法则"，其数学本质是：
只要单次损失不超过总资金的固定小比例，连续亏损（哪怕无限次）也无法使资金归零。
这来自对数增长的基本性质：每次损失2%后剩余98%，无限次连乘趋向极小但永不为零。
反之，过度下注会使单次重大损失不可恢复，进而破坏复利增长的基础。

关键洞察有三：
1. 破产风险是路径问题，不是均值问题——平均期望值为正不能防止极端路径归零；
2. 仓位上限是不对称保护：下限（太小）只损失增速，上限（太大）可能损失一切；
3. 量化基金通常将单只股票最大持仓设定为总资产的2%，由此自然持有约50只股票。

适用边界：此法则适用于独立风险头寸；若多个头寸高度正相关，实际等效单仓位风险
远超名义上各自2%的加总，需用相关性调整后的风险敞口计算。

## A1 — 书中应用

书中§3.3.2以索普的21点赌博研究为实证起点：
索普通过数学证明，若每次下注不超过筹码的2%，即使持续亏损也永远不会输光。
他将此原理迁移至投资市场，形成量化基金的持仓纪律：每只股票最大持仓2%，
组合自然保持约50只持仓，分散化通过纪律而非主观判断实现。
书中明确指出"很多量化基金经理也参照2%法则进行资产配置"，以此作为防止破产的底线。
与ce01（LTCM过度杠杆）形成直接对比：LTCM违反了此法则，而索普遵循了它。

## A2 — 触发场景

1. 策略文档中单只股票或单一合约持仓没有明确上限时触发。
   信号词：no position cap / 无仓位上限、conviction-based sizing / 主观信念定仓。

2. 组合持仓集中在少于10只标的时触发。
   信号词：concentrated portfolio / 集中组合、high conviction few stocks / 精选少数。

3. 单次交易资金超过账户总额5%时触发。
   信号词：5% position / 5%仓位、10% bet / 下注10%。

4. 回测中出现单笔最大亏损超过总资金10%的记录时触发。
   信号词：large single loss / 单笔大额亏损、max loss event / 最大损失事件。

5. 策略被设计为"集中押注少数高信念标的"时触发。
   信号词：best ideas portfolio / 精选最优观点、concentrated alpha / 集中alpha。

## E — 可执行步骤

1. 审查仓位上限规则：检查策略文档，确认是否有明确的单标的最大持仓比例。
   若无，立即制定并写入策略规则。完成标准：规则以百分比形式明文记录。

2. 计算当前组合的实际最大单仓位：统计当前或回测中出现过的最大单标的持仓占比。
   完成标准：最大单仓位 ≤ 2%（量化策略）或 ≤ 5%（主动策略）。

3. 检查相关性调整后的集中度：对相关系数 > 0.7 的标的组合，合并计算等效单仓位。
   完成标准：任何相关标的群组的合并持仓不超过单标的上限的3倍。

4. 设定破产测试（bankruptcy test）：模拟最坏情景——持仓中最大的一只标的归零，
   计算账户总损失。完成标准：账户损失 < 总资金的5%。

5. 回测验证单笔最大损失：在历史回测中找出单日或单事件最大亏损金额。
   完成标准：单次最大亏损 < 总资金的10%。

6. 建立自动告警：在实盘系统中，当任何单标的持仓占比超过设定上限时触发告警。
   完成标准：告警逻辑已测试，有操作记录。

## B — 边界

**不适用场景：**
- 期权策略中，名义持仓与风险敞口差异大，需用delta或VaR衡量实际风险，
  不能直接用市值比例判断是否"过度下注"。
- 宏观对冲策略中，货币或利率头寸的2%规则需调整为基点价值（BPV）限制。

**作者警告的失败模式：**
- 以"高确定性"为由突破仓位上限（conviction bias），实际上是主观过度自信。
- 将凯利公式激进值（公式二）直接作为仓位依据，忽略黑天鹅（参见ce01和ce09）。
- 在连续盈利后逐步提升单仓位比例，认为"已经证明了策略有效"。

**盲点：**
- 2%法则是独立事件假设下的结论，在系统性风险（如2008年）中多头寸同时亏损，
  2% × 50只 = 100%，仍可能全额亏损，需要配合资产类别分散化。
- 法则本身不指导最优仓位，只提供破产防护的下界；最优仓位仍需凯利公式或其他方法。
