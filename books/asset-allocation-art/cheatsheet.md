# 资产配置决策速查

| 情况 | 判断与行动 |
|---|---|
| 近期有刚性支出 | 先核对到期日、现金流与可变现资金；避免把必要资金完全暴露于可能无法及时回收的风险资产。 |
| 问卷显示激进，但无法承受亏损 | 以财务能力与真实心理承受力中较弱者约束风险，复核目标和储蓄。 |
| 历史赢家近年涨幅最大 | 检查当前权重、估值和不同周期表现；不要把历史排名当预测。 |
| 资产标签不同但共同暴跌 | 穿透至信用、股票、利率、货币和杠杆暴露，重新评估分散效果。 |
| 权重超出政策范围 | 先比较现金流、税费、流动性及约束，再调整；再平衡不是收益保证。 |
| 新市场判断要求偏离战略 | 写明依据、最大偏离、期限、失败条件与基准；没有可验证理由则维持战略。 |
| 模型给出极端权重 | 测试收益和相关性输入变化，增加现实约束并检验压力情景。 |
| 目标或家庭情况改变 | 更新资产负债与现金流，再复核战略；不要只机械恢复旧权重。 |
| 涉及非流动或集中资产 | 纳入家庭总风险，注明锁定及税务约束，制定可执行的分阶段方案。 |

## 最小政策记录
目标和期限 → 资产负债、现金流及风险能力 → 候选资产与币种 → 目标和区间 → 基准 → 实施和再平衡 → 风险情景 → 复核日期。缺少关键输入时先补充，不凭年龄直接给固定比例。
