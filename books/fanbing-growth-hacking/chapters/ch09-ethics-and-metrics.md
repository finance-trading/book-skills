# 第9章：职业道德与常用指标

## Core Idea
增长手段越强，越需要伦理边界；没有隐私保护与用户知情同意的增长，短期有效但长期反噬。指标体系则是判断一切手段是否有效的标尺。

## Frameworks Introduced
- **增长黑客职业道德三原则**：
  1. **换位思考**：己所不欲勿施于人；站在用户立场反推对策是否妥当。
  2. **隐私保护**：能力越大责任越大；在用户已知前提下只征求最小授权，提供最大知情。
  3. **国际视野**：以法规最严、价值观最正的国际化标准规划增长；避免依赖法规盲点。
- **常用指标体系**：网站类（PV、UV、Visit、跳出率、转化率、停留时间、访问来源等）与移动应用类（新增、活跃、升级、留存、总用户、使用时长、使用间隔、K 因子、ARPU、ARPPU、MPR、LTV 等）。
  - When to use: 建立增长看板、设定目标、做 A/B 测试前后对比时。

## Key Concepts
- **PV / UV / Visit**：页面浏览量、独立访问者、一次完整访问过程；UV 受统一出口 IP 影响，需结合 Cookie。
- **跳出率（Bounce Rate）**：仅浏览一页即离开的比例；整站跳出率反映导航效率，单页跳出率反映页面价值。
- **转化率（Conversion Rate）**：达成预设目标（下载、注册、订阅、完成引导）的比例。
- **新增用户（New Users）**：首次打开应用；设备标识符识别，卸载重装不算新增。
- **活跃用户（Active Users）**：统计周期内有特定行为的用户；定义因产品而异（WhatsApp 看消息数，陌陌看登录并定位一次）；常看 DAU / MAU。
- **留存率（Retention Rate）**：新增用户中第 N 天仍在使用的比例；次日、3 日、7 日、15 日、30 日；主动搜索下载的用户留存高于博眼球活动引入的用户。
- **总用户数（Total Users）**：历史上所有新增之和；含水分，不反映流失。
- **单次使用时长 / 平均单次使用时长 / 使用间隔**：衡量黏性与使用习惯。
- **K 因子（K-Factor）**：每用户平均发出邀请数 × 收到邀请转成新用户的比率；K > 1 表示具备自我传播能力。
- **ARPU（Average Revenue Per User）**：收入 / 活跃用户；衡量单用户盈利能力，可用于检验渠道用户质量。
- **ARPPU（Average Revenue Per Paid User）**：收入 / 付费用户；把握付费用户支付能力，针对性运营。
- **MPR（Monthly Payment Ratio）**：付费用户占活跃用户比例。
- **LTV（Life Time Value）**：用户从首次到末次使用累计贡献的付费总量。
- **“疯狂来往”事件**：游戏未经授权将玩家隐私视频上传官方账号，引发“艳照门”；负面消息让搜索量上涨 200%、PC 流量涨 7 倍——短期曝光不等于可接受的代价。

## Mental Models
- **数据指标是共识工具**：团队争执时回到核心指标，判断什么是必须坚守、可以妥协、可以放弃。
- **指标定义比指标数字重要**：先对齐“活跃”“转化”“留存”的定义与上报机制，再谈提升。
- **LTV 与 CAC 决定增长可持续性**：单用户获取成本（CAC）必须显著低于 LTV，增长才不是烧钱游戏。
- **隐私保护是品牌资产，不是成本**：最小授权 + 最大知情是长期信任的最低标准。
- **曝光不等于健康增长**：负面话题可以带来流量，但透支用户信任与品牌。

## Anti-patterns
- **未经授权上传用户隐私内容**：如“疯狂来往”事件。
- **静默后台下载、滥用通讯录/邮箱授权**：技术中立，但用法越界。
- **黑暗设计（Dark Patterns）**：强制分享、误导性界面、默认勾选等“耍小聪明”的交互。
- **用指标欺骗自己**：刷 PV、拆分长文多页、虚增总用户数，掩盖真实流失。
- **只索取数据不定义用途**：没有明确分析目的的数据索取浪费团队时间。

## Key Takeaways
1. 每次设计增长手段前问三句：用户知情吗？授权最小化了吗？站在用户立场会反感吗？
2. 建立指标体系时，先对齐定义与上报机制，再谈优化。
3. 用 LTV、K 因子、ARPU 判断渠道与传播健康度，而不是只看新增。
4. 负面曝光的短期流量不是增长的正当理由；品牌信任不可透支。
5. 以国际最严标准作为内部合规基线，避免依赖法规盲点。
6. 指标看板要服务于决策：每个指标都要对应一个可行动项。
