# 决策速查

| 情况 | 决策 | 原因 |
|---|---|---|
| 信号在收盘才可知 | 使用之后可执行的成交假设 | 防止前视 |
| 回测只含现存股票 | 补充历史成分和退市数据 | 避免存活偏差 |
| 参数稍变利润消失 | 暂停筛选，查试验次数与机制 | 可能过拟合 |
| 成本后优势消失 | 拒绝部署或重做研究 | 毛收益不可交易 |
| 高夏普但最大回撤大 | 同看杠杆、尾部和持续期 | 单一指标不够 |
| 模拟收益好、成交不符 | 对账并调查滑点、部分成交与延迟 | 模拟不是实盘 |
| 凯利给出高杠杆 | 核验参数及压力约束，保守缩减 | 均值估计误差被放大 |
| 相关性高 | 不直接认定协整 | 相关与平稳残差不同 |
| 系统断线 | 暂停新单、查询实际仓位与未成交订单 | 避免重复下单 |

书中历史规则、软件与供应商需重新核实；这些规则不是投资建议。
