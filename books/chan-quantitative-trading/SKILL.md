# 量化交易：如何建立自己的算法交易事业

作者：Ernest P. Chan（欧内斯特·陈）。来源为扫描版 PDF 共 169 页，8 章及 MATLAB 附录；英文原版版权 2009。本文为学习工具，不是个性化投资建议。

## 使用方法
先确定研究对象、频率、资金与可承受风险；再按下列流程识别缺失证据。按主题读取对应章节，使用 [清单](cheatsheet.md) 作决策、[方法](patterns.md) 作实施、[术语](glossary.md) 查定义。输出时区分书中观点、独立补充和未验证假设，旧经纪商、数据商、规则和业绩数字不作为现行事实。

## 核心流程
1. **选可实施的策略**：先约束时间、编程、资金、交易频率、流动性和可借券性；对历史收益同时索取基准、波动、回撤、成本和样本选择方法。参见 [第2章](chapters/ch02-strategy.md)。
2. **回测是反证而非证明**：对齐信息发布时间与成交时间；保留退市证券，处理公司行为；用独立样本、参数稳定性和交易成本检验；记录尝试次数。参见 [第3章](chapters/ch03-backtesting.md)。
3. **先搭可恢复的业务**：比较零售与自营的资本、分成、限制与技术；验证数据、经纪商接口、对账和断线应急。参见 [第4章](chapters/ch04-business.md) 和 [第5章](chapters/ch05-execution.md)。
4. **仓位先于收益目标**：凯利优化依赖收益分布和参数估计；模型不稳、尾部风险或杠杆约束下应保守，设置独立风险限制，不能把公式结果当保证。参见 [第6章](chapters/ch06-risk.md)。
5. **选择机制而非图形**：区分均值回归与动量的期限、状态与失效条件；协整、因子、季节性和高频均需独立验证与成本分析。参见 [第7章](chapters/ch07-topics.md)。
6. **实盘是新的实验**：仿真不能复现所有成交和市场冲击；小规模检验信号、订单、实际持仓及成本，偏离时暂停并调查。参见 [第8章](chapters/ch08-conclusion.md)。
