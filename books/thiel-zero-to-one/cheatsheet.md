# 从0到1决策速查

| 情况 | 决策规则 | 原因 / 核查 |
|---|---|---|
| 大多数人都相信一个重要判断 | 问“其反面是否为真？这揭示未来吗？” | 反主流观点要重要且可验证，不为反对而反对 |
| 计划是在复制他人 | 寻找从0到1的垂直进步 | 从1到n扩大已知成果，不等同创新 |
| 行业教条来自上一次泡沫 | 检验教条及其反面，独立判断 | 对过去过错的错误反应也会成为教条 |
| 市场被定义得很小或很大 | 还原真实客户市场与市场份额 | 非垄断者缩小市场求独特，垄断者扩大市场掩盖主导 |
| 计划靠“做得比对手稍好” | 追问是否有创造性垄断路径 | 同质竞争会让利润消失 |
| 技术优势只稍有改进 | 除非接近10倍或创造新事物，否则重做 | 用户切换与市场噪声吞噬微小优势 |
| 想直接瞄准大市场 | 先占领极小且真实的利基，再逐步扩张 | 大市场通常意味着竞争，不能用“1%份额”自我安慰 |
| 公司以破坏旧产业为身份 | 改为描述要创造的新价值 | 对抗叙事导致负和竞争与注意力分散 |
| 只看到当前利润或增长数字 | 估计未来现金流与10–20年持久性 | 企业价值取决于未来利润现值 |
| 需要分配时间、资本或职业选择 | 用幂次法则找少数可支配结果的机会 | 公司、投资与职业的回报高度不平均 |
| 认为所有秘密已被发现 | 去未被标准化领域，检查常识与禁忌 | 秘密是困难但可为，不是不可解之谜 |
| 创业团队还没形成 | 先检查合伙默契、治理与股权 | 蒂尔定律：早期基础坏了无法挽救 |
| 创业计划很宏大 | 逐项回答工程、时机、垄断、人员、销售、持久、秘密 | 共识、大市场和补贴不是答案 |
| 产品“自己会卖” | 设计销售渠道并计算 CLV 与 CAC | 顾客不会自动上门 |
| 多个获客渠道同时尝试 | 找出一条最有效渠道，集中资源 | 销售策略遵循幂次法则，大杂烩失效 |
| 正考虑机器替代人 | 优先设计人机互补，让人负责判断 | 计算机擅长数据，人擅长复杂情境与解释 |
| 公司文化只谈福利 | 用独特使命、团队与职责清晰度定义文化 | 公司即文化，福利装饰不建立凝聚力 |
| 创始人行为看起来反常 | 判断特质是否推动长期创造，同时保持治理约束 | 创始人既可能带来大跳跃，也可能被自己的神话吞噬 |
| 期待技术进步自动发生 | 把创新变成当下可执行的行动 | 未来不是自行发生，奇点不是宿命 |

## 创业七问
1. 技术有突破性，而不只是稍有改进吗？
2. 现在开创事业，时机合适吗？
3. 是否从小市场起步并能主导它？
4. 是否有合适的团队？
5. 除创造产品外，能否销售产品？
6. 未来10–20年能否守住市场地位？
7. 是否找到别人未发现的独特机会？

## 垄断构建路径
**秘密 → 极小市场主导 → 相邻市场扩张 → 持久垄断利润**
- **秘密**：重要、未被广知、困难但可为。
- **起步**：特定小群体、有明确需求、少有竞争者。
- **扩张**：仅进入相邻市场，别一开始就横跨到无关领域。
- **壁垒**：专利技术、网络效应、规模经济、品牌相互强化。

## 销售渠道选择
| 典型交易规模 / 产品 | 优先考虑 | 核查 |
|---|---|---|
| 七位数以上，决策复杂 | CEO/创始人复杂销售 | 客户是否需要高层关系和长期售后 |
| 1万–10万美元，可复制交易 | 人员销售团队 | 从强痛点、小账户扩展 |
| 大量低客单价消费品 | 市场营销与广告 | CLV 能否覆盖 CAC |
| 产品核心功能引发邀请 | 病毒式营销 | 每位新用户能否带来一位以上新用户 |

## 快速危险信号
- 只谈市场规模、使命、用户量或增长率，不谈现金流、利润与壁垒。
- “市场太大足够所有人”与“我们只占一点点市场”同时出现。
- 公司产品只比替代品好一点，或技术仍无法抵消真实成本。
- 创始人刚认识就合伙、董事会人数膨胀、CEO现金薪酬过高。
- 销售渠道未验证，却把产品质量当作获客计划。
- 数据很多但无人负责解释；自动化系统被对手轻易适应。
- 竞争对手定义了公司身份，团队开始互相模仿。
- 公司依赖补贴、短期热潮或一次融资才能持续。
