# 第5章：如何买卖指数基金：懒人定投法

## Core Idea
定投是定期、分批买入，不等于无论价格贵贱都机械投入。本书推荐“低估值定投”：固定时间投入可承受的金额，只在价格低于价值时增加或继续买入，估值正常时持有，高估时分批卖出。

## Frameworks Introduced
- **定投三优势**：低门槛、降低择时要求、分摊成本并训练纪律。
  - When to use: 有稳定收入但没有大笔本金，或无法持续盯盘时。
  - How: 选发薪日后固定交易日；按月或按周均可；预先写下金额和执行条件。
- **盈利收益率定投规则**：书中经验规则为 >10% 买入，6.4%～10% 持有并暂停该品种新增，<6.4% 分批卖出。
  - When to use: 指数盈利稳定且该指标适用时。
  - How: 每次投资前更新估值；若该品种变贵，资金转向仍低估的其他指数，而不是停止全部投资。
- **博格公式定投规则**：PE/PB处于历史底部区域时定投，正常估值时持有，高估区域分批卖出。
  - When to use: 盈利收益率不适用或需用估值与股息、增长共同解释时。
  - How: 看区间，不追求精确最低点；把卖出拆成多批，减少一次性判断错误。
- **渠道选择**：场内交易价格实时、费用可能较低但需手动；场外操作简单可自动，但估值策略更适合下单前手动复核。
  - When to use: 选择交易路径和执行工具时。
  - How: 比较流动性、费率、申赎规则、到账时间和是否能稳定执行。

## Key Concepts
- **定投**：定期买入，不要求使用平台的自动定投功能。
- **平均成本**：不同价格买入后形成的持仓平均成本。
- **IRR**：考虑每笔资金投入时间差异的定投年化收益率。
- **场内基金**：在证券交易所交易的基金，通常按实时价格成交。
- **场外基金**：按基金净值申购赎回的基金，可设置自动定投。
- **暂停定投**：不再增加某品种，但保留已有份额等待估值变化。
- **分批止盈**：在估值进入较高区域时逐步卖出，而非一次清仓。

## Mental Models
- 定投不是预测工具，而是现金流和行为纪律工具；低估值规则才是收益增强和风险约束。
- “便宜的西瓜多买、贵的西瓜少买”：固定金额在价格低时自动获得更多份额。
- 手动复核优于盲目自动化：自动扣款解决忘记，但不能判断当前是否仍值得买。

## Anti-patterns
- **无脑长期买同一只指数**：指数变贵后预期收益下降、风险上升。
- **下跌就停止**：低估阶段往往伴随恐慌，停止会错过成本下降。
- **用总收益率代替IRR**：分批投入的资金占用时间不同，必须按现金流时间计算年化。
- **忽略交易成本和分红处理**：小额高频交易、分红不再投入会拖累复利。

## Worked Example
某投资者每月发薪后投入固定金额。第一阶段盈利收益率为12%，照计划买入；估值回落至8%后暂停该指数的新增，但继续持有；当盈利收益率回到6%附近，分十批逐步卖出，并把资金转入货币基金或另一只低估指数。若市场重新低估，再按同一规则投入。这样既避免一次性押注，也避免贵价持续加仓。

## Key Takeaways
1. 固定时间和金额让计划可执行，估值区间决定买、持有或卖。
2. 周投和月投长期差异通常小，选择最容易坚持的频率。
3. 卖出规则必须在买入前写下，否则上涨和下跌都会改变判断。
4. 低估值定投可能长期等待，机会成本是它的真实代价。
