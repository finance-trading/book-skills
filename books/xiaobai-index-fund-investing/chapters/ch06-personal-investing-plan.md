# 第6章：构建属于自己的定投计划

## Core Idea
一份合格的定投计划必须能落在纸面上，并让不同的人按同一规则执行。它从现金流开始，明确投资目标、品种、渠道、频率、金额、估值区间、卖出方式和复盘周期，最终形成可检查的操作记录。

## Frameworks Introduced
- **现金流先行**：未来一年内要用的钱不进入股票资产；指数定投按至少三年以上准备。
  - When to use: 确定每月定投额度或面对短期大额支出时。
  - How: 记收入、必要支出、可削减支出和应急金；用可持续结余而不是偶然收入制定额度。
- **四步计划**：梳理现金流 → 挑选低估指数 → 设定固定买卖规则 → 定期检查优化。
  - When to use: 从“想定投”转为真正开户执行时。
  - How: 把每一步写成清单，记录日期、品种、价格、估值、买卖方向和金额。
- **目标分层计划**：养老、加薪、教育等目标共享方法，但期限和取用规则不同。
  - When to use: 为家庭不同成员或不同时间目标配置资产时。
  - How: 养老可长期积累并用分红/分批卖出；加薪计划强调持续积累；教育金临近使用时优先转为现金或低波动资产。

## Key Concepts
- **可投资结余**：收入扣除必要生活支出、应急储备和近期确定性支出后的资金。
- **定投记录**：每次操作的日期、品种、金额、价格、份额和估值依据。
- **计划纪律**：在情绪强烈时仍按预先定义的规则执行。
- **目标期限**：资金从投入到必须使用的时间长度。
- **动态优化**：根据记录和目标变化调整规则，而不是凭当天涨跌改计划。

## Mental Models
- 把计划写成“别人拿到也能执行”的操作手册，才能减少临场解释。
- 投资计划像飞行检查单：先确认燃料和目的地，再起飞，不因天气变化临时忘记安全步骤。
- 目标越近，风险预算越低；教育金不应为了多一点收益而承担无法恢复的回撤。

## Anti-patterns
- **用最大可投入额做定投**：生活压力会迫使投资者在低点退出。
- **只写买入不写卖出**：上涨时贪婪，下跌时恐惧，计划失去约束。
- **频繁重写计划**：把噪声当信息，导致长期策略无法验证。

## Worked Example
一个家庭先连续记账数月，确定每月结余。养老账户采用长期低估指数定投，前期只进不出；加薪账户把固定比例的结余投入，并在估值高时分批兑现；教育账户在确定的入学年份前逐步从股票指数转向货币或债券基金。每月记录操作，每季度检查现金流和目标期限，每年才评估规则是否需要改动。

## Key Takeaways
1. 计划的最小完备字段是：目标、期限、金额、品种、估值规则、渠道、买卖条件和记录方式。
2. 资金用途决定风险预算，不能把所有目标混成一笔高波动资产。
3. 优化应基于记录和目标变化，不应响应每一次市场波动。
