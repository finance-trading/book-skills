# 第16章：影响金融市场的世界大事

## Core Idea
世界大事对股市的影响集中在短期，且难以预测：真正驱动单日大幅波动的，是事件的意外程度而非新闻标题的严重程度。1885年以来单日变动超过5%的交易日有145个，其中能与明确世界性事件对上的不到1/4。西格尔的结论是，重大政治或经济事件可能造成剧烈波动，但长期数据无法证明它们会改变股票的长期收益率。

## Frameworks Introduced
- **事件—意外—现金流三问**：判断一条新闻是否构成交易信号。
  - 何时使用：突发战争、袭击、评级或选举结果发布时。
  - 如何使用：先问"价格是否已隐含该结果"，再问"事件会否持久改变现金流或风险溢价"，最后才看"是否伴随利率或政策预期变化"。9·11当天买盘反复涌入，正是因为多数交易者先判断"是否大事发生"。
- **单日波动归因法**：用历史大波动日统计，检验"新闻驱动"假设。
  - 何时使用：有人把某次崩盘归咎于某条新闻时。
  - 如何使用：查1885年以来>5%的145天中事件关联比例（<1/4）；在金融危机期15次大波动里也仅4次有明确事件；再核对当日各大媒体归因是否彼此矛盾。

## Key Concepts
- **9·11的期货先动**：2001年9月11日8点48分首机撞北塔，标普500期货（Globex全天候交易）先跌数点后买盘回补；9点03分二机撞南塔，9点05分期货暴跌30点（约3%），对应若开盘将损失近3000亿美元市值；9点15分收市仅跌15点，捞回一半。
- **最长休市**：所有美股、债券、商品交易所取消当日交易，且该周余下时间未再开盘；自罗斯福1933年3月"银行假日"以来美国股市从未闭市如此之久。德国DAX当日先挫9%。
- **重开日跌幅**：2001年9月17日重开日道指跌7.13%，是珍珠港当日跌幅（3.5%）的两倍多，为有战争记录以来最大。
- **归因混乱案例**：1991年11月15日道指跌120点（近4%），《投资者商业日报》归因于生物技术、计算机程序、到期合约与国会，而《金融时报》归因于俄罗斯终止石油许可证、接管黄金供应——"重要原因"在另一家媒体中根本没有出现。
- **不确定性敏感**：航空与近6000亿美元的旅游业损失难以估算，让市场下跌；总统突发变故也常触发抛售——1955年9月26日艾森豪威尔心脏病发作，道指跌6.54%（战后第五大），1963年11月22日肯尼迪遇刺当日跌2.9%，周一因葬礼休市，周二约翰逊入主白宫后反弹4.5%（战后最佳单日）。
- **货币政策主导大波动**：20世纪5次有具体原因的最大单日变动中，4次与货币政策相关；1931年10月6日胡佛50亿美元银行救助计划推动道指单日涨14.87%（新闻相关最大单日变化），2008年10月13日美联储注入无限美元流动性推动单日涨11.08%。
- **战争波动悖论**：按道指月度标准差，和平年代波动反而大于战时；一战波动远高于二战（一战初涨近100%、美国参战后跌40%；二战参战后六年偏离战前水平从未超过32%）。

## Mental Models
- **新闻≠方向**：同一事件可被不同媒体归因到完全不同的原因，价格反应由预期差与不确定性主导，而非事件的"道德"属性。
- **不确定是价格，不是消息**：市场最讨厌的是无法量化的不确定性；当航空、旅游损失无法估计时，恐慌先于信息。
- **长期与短期解耦**：重大事件造成的是数日到数月的波动，长期收益率由盈利与股息决定，历史证据不支持"大战改变长期回报"。

## Anti-patterns
- **按标题交易**：把"重大袭击/战争/评级下调"直接等价为卖出信号，忽略了价格是否已计价、事件是否改变现金流。
- **迷信单一归因**：1991年11月15日案例显示，权威媒体也会给出相互矛盾的归因；单日波动归因高度依赖信息集。
- **把战争当熊市起点**：一战初恐慌抛售者恰好错过了1915年史上最强年度（道指+82%）；二战爆发后立刻重仓者则因政府限制战争利润而失望。
- **用近期危机否定长期**：2003年3月至2007年6年年化17.5%的涨幅，最终在金融危机中几乎全部回吐，短期事件不决定长期路径。

## Worked Example
以9·11当天为样本，套用"事件—意外—现金流"框架：8点48分首机撞击时，市场先跌数点即被买盘拉回，因为交易者仍判断"是事故而非袭击"；9点03分二机撞击南塔，事件性质跳变为"美国本土二战后首次直接遇袭"，不确定性陡增，期货9点05分跌30点（约3%）、对应3000亿美元市值。随后数小时内，尽管冲击未定，仍有交易者认为"反应过度"而抢反弹，9点15分只跌15点。到9月17日重开日道指跌7.13%，但2001年11月13日即收复9月10日水平，9月21日低点8062点至12月28日高点10184点，三个月反弹26.3%——短期事件冲击在政策与流动性支持下可被完全消化，而长期回报并未因袭击而永久性下移。

## Key Takeaways
1. 世界大事对股市的冲击集中在短期；1885年以来>5%的145个交易日中，能对应明确事件的不到1/4。
2. 单日大波动更常由货币政策与不确定性驱动：1931年银行救助与2008年无限流动性是两次最大单日新闻驱动上涨。
3. 战争不必然压低长期回报——一战与二战的股价轨迹相反，恐慌抛售者往往错过战后最强牛市。
4. 归因本身不可靠：同一天道指跌120点，权威媒体可给出完全相反的"原因"，交易者应关注预期差而非标题。
