# 第17章：股票、债券与经济数据

## Core Idea
市场不是对新闻本身，而是对实际数据相对于预期的意外程度作出反应；同一份强劲数据可能抬高企业盈利预期，也可能推高利率与通胀担忧，因此股票方向取决于两股力量的相对强弱。1996年7月就业报告带来的全球市场急跌，正说明公众眼中的好消息可以成为投资者的坏消息。经济数据可帮助理解短期波动，但作者不建议多数长期投资者据此频繁调整仓位。

## Frameworks Introduced
- **预期差分析**：将公告值与市场共识比较，而非孤立判断数字高低。
  - 何时使用：解读就业、增长或通胀数据发布时。
  - 如何使用：先查市场预期，再判断实际值偏离方向；再追踪它对利率、央行政策和企业盈利的传导。
- **增长—利率双通道**：把经济数据对股票的影响拆为未来利润（分子）与折现率（分母）。
  - 何时使用：强劲增长数据公布后股价反而下跌，或疲弱数据后股市上升时。
  - 如何使用：判断周期所处阶段及利率压力；衰退期利润变化通常更关键，扩张后期利率与通胀的影响更可能占上风。
- **连续数据确认法**：避免把一个月的噪声误当趋势。
  - 何时使用：单项通胀、就业报告出现意外时。
  - 如何使用：观察后续报告是否同向；连续意外会强化市场反应，因为它们更可能揭示趋势，而非偶然误差。

## Key Concepts
- **1996年7月5日就业意外**：新增就业23.9万人、失业率5.3%（六年低点）、时薪上涨9美分（30年来最大涨幅）；市场担心美联储收紧，长期债券急跌、利率升近0.25%，标普期货不到一小时跌近2%，全球股票市值损失约2000亿美元。
- **经济数据与利率**：增长高于预期通常推升长短期利率，因消费与企业借贷需求增加，也可能意味着通胀与央行收紧；增长低于预期则往往压低利率、利好债券。
- **就业报告的两种调查**：BLS薪资调查覆盖近40万家企业场所、约5000万员工（劳动力约40%），关注非农就业人数变化；家庭调查访问6万户，依据过去四周是否积极找工作计算失业率。
- **两种就业口径会背离**：薪资调查统计岗位，家庭调查统计个人；一人两份工作会在薪资调查计两次、自雇者不在薪资调查中但计入家庭调查。复苏初期求职者回流也可能令失业率上升。
- **ADP全国就业报告**：2005年起发布，通常早于BLS就业报告两天，衡量非农私营部门；基于约50万家客户中的一半及约2300万名员工。
- **制造业PMI尺度**：ISM调查250名采购代理；50表示报告上升与下降者各半，52~53通常对应正常扩张，60代表强劲增长，低于50为萎缩，低于40接近衰退边缘。
- **核心通胀与PCE**：核心CPI/PPI剔除食品、能源，以看基础趋势；美联储更重视PCE平减指数，其权重更新更及时并含雇主、雇员医疗保险支出，通常比CPI低0.25~0.5个百分点，是2%通胀目标的参照。
- **劳动力成本**：劳动力约占企业生产成本2/3；小时工资若增速超过生产率提升，会形成成本通胀压力。综合劳动力成本指数按季度发布，并包括工资与福利。
- **央行的市场冲击**：美联储每年召开8次FOMC例会；2001年1月3日意外把联邦基金利率从6.5%降至6%，标普500单日涨5%、纳斯达克涨14.2%。

## Mental Models
- **好坏由预期决定**：新增就业23.9万若低于更高的共识，可能被视为坏消息；市场价格早已包含普遍预期。
- **强增长不等于股票必涨**：盈利上升抬高现金流，利率上升却压低现值；周期阶段决定哪一端主导。
- **利率连接数据与资产价格**：经济数据先改变市场对央行政策和利率的判断，再传导到债券价格及股票折现率。
- **趋势需要重复验证**：一份通胀报告可能被修订，连续同向的报告才更能建立趋势可信度。

## Anti-patterns
- **把头条直接当交易信号**：1996年报告的工资、就业表现看似利好，却触发对紧缩与通胀的担忧，资产价格全面下跌。
- **把失业率当成就业全貌**：它来自家庭调查，与薪资调查的单位、样本和统计对象不同，二者可能同时上升或下降。
- **忽略核心指标与噪声**：食品能源受天气、供应中断和短期交易影响，单月总体通胀偏差不如核心通胀偏差重要。
- **用短期数据频繁改长期策略**：作者指出，观察短线反应虽有趣，但据此安排投资并不容易，更适合能承受波动的投机者。

## Worked Example
1996年7月5日的反应链条：月度就业报告显示新增23.9万人、失业率降至5.3%、时薪上涨9美分。表面上就业与工资改善，但市场把工资快速上升解读为劳动短缺和通胀风险，进而预期美联储紧缩。结果长期债券价格暴跌、利率上升近0.25%；标普期货跌近2%，欧洲DAX、CAC与FT-SE也下跌约2%。关键不是“就业好所以股市应涨”，而是就业意外改变了政策与利率预期，压过盈利乐观情绪。

## Key Takeaways
1. 阅读经济公告先看预期差，再判断对政策、利率与盈利的影响路径。
2. 就业报告中的非农人数与失业率来源不同，不能当作互相验证的同口径指标。
3. 经济数据对股票的净影响取决于盈利增长和折现率变化的较量，并随周期而异。
4. 央行政策和通胀预期能迅速改变股债定价；长期投资者不应把每次数据发布都变成交易指令。
