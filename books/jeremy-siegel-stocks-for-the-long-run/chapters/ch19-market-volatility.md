# 第19章：市场波动性

## Core Idea
股市的剧烈波动集中在熊市与衰退期，但"崩盘"是否演变成大萧条，取决于政策 regime 而非图表形态。1929年与1987年的走势图几乎重合，结局却相反：1987年美联储果断注入流动性、承诺支持存款，银行挤兑与货币收缩没有发生，经济甚至继续扩张；1929年则没有这样的最后贷款人。西格尔由此主张，面对抛售狂潮不应恐慌，剧烈波动往往同时提供买入机会，尽管这绝不意味着波动会消失。

## Frameworks Introduced
- **历史类比检验框架**：把"这次图形和1929年一样"拆成形态、估值、政策反应三层。
  - 何时使用：市场用历史崩盘图警告未来时。
  - 如何使用：先承认形态相似，再问政策当局是否有能力且有意愿提供流动性；1929与1987的分野正在于美联储是否充当最后贷款人。
- **崩盘解剖链**：估值与利率失衡→触发事件→放大机制（止损、投资组合保险、高频交易）→流动性枯竭→政策应对。
  - 何时使用：分析任何单日暴跌时。
  - 如何使用：逐层定位；1987年的放大机制是做空股指期货的动态对冲，2010年则是40亿美元期货卖单与高频交易撤退。
- **波动率状态判断**：用已实现波动与隐含波动（VIX）区分"恐慌水平"与"买卖信号"。
  - 何时使用：看到"VIX爆表该抄底"之类说法时。
  - 如何使用：VIX高只说明保护需求大、市场焦虑，不说明下跌已结束；1987年10月16日VIX已达40点，随后周一仍崩盘22.6%。

## Key Concepts
- **1987年10月19日**：道琼斯工业指数从2247点跌至1739点，单日下跌508点、跌幅22.6%，为史上最大单日跌幅；周一与周二成交量超过6亿股，超过1966年全年总和。
- **全球传染**：东京股市单日跌15.6%（其史上最大），新西兰跌近40%，香港股市被迫关闭。
- **崩盘前的估值与利率**：1987年初道指1933点，8月升至2725点，较1982年8月低点上涨250%；五年间英国涨164%、瑞士涨209%、德国涨217%、日本涨288%、意大利涨421%。长期国债利率从年初7%升至9月9%，10月19日上午达10.4%，股票收益率与债券实际收益率的差距创战后新高。
- **投资组合保险的失灵**：该策略通过做空标普500期货动态对冲，假定期货市场始终有流动性；10月12日当周市场已跌10%，19日期货价格远低于现货，买家全面停止买入，保险在最需要时失效。
- **1929年的对照**：1929年10月后道指最终跌去近89%（至1932年7月8日）；1987年美联储注入流动性并支持银行存款，货币供应未萎缩，经济继续扩张。
- **波动率统计**：1885~2012年中有145个交易日道指单日变动超过5%，其中68天上涨、77天下跌；77天集中在1929~1933年，1932年一年就有35天。全部交易日中约24%的单日变动超过1%，比例从1964年的1.2%到1932年的67.6%。
- **衰退期波动更高**：经济衰退期间日收益率标准差比扩张期高25%；公司盈利下滑时固定成本负担加重，利润波动被放大，股票价值类似价外看涨期权。
- **VIX指数**：CBOE于1993年推出，依据标普500指数期权价格计算，可回溯至1986年；1987年股灾次日峰值达172点，1993年12月低至8.89点，2008年雷曼破产后触及90点。
- **2010年闪电崩盘**：5月6日下午道指几分钟内跌约600点（6%），2点47分盘中低点跌近10%，5分钟内蒸发8000多亿美元市值；宝洁从86美元开盘价跌至39.37美元，埃森哲从38美元跌至1美分，300种证券的2万笔交易涨跌幅超过60%。

## Mental Models
- **形态相同，制度不同**：图表只描述价格路径，不包含央行反应函数；跨时代类比必须先比较政策工具箱。
- **波动是状态的函数**：高波动多出现在熊市与衰退，低波动多出现在扩张；用平静期的经验为危机期定策略会失真。
- **流动性只在不需要时可靠**：止损单、动态对冲都假设能在下跌中卖出，而崩盘恰恰是买卖双方同时消失的时刻。
- **恐慌是价格的组成部分**：1932年5月股价已从1929年高点跌85%，德·添惠的备忘录指出"股票便宜得令人发指"，两个月后市场触底。

## Anti-patterns
- **因"重演1929年"而清仓**：1987年末市场开始复苏，1989年8月创新高；按类比卖出者错过了后续全部修复。
- **把止损单或投资组合保险当保险**：止损在跳空时按下一个最优价成交，众人同价止损会引发恐慌性抛售；真正的保险是买入时即锁定价格的看跌期权。
- **见VIX高就抄底**：VIX只衡量焦虑，不衡量底部；1987年10月16日VIX为40点，随后仍有单日22.6%的暴跌。
- **把每次5%波动都归因于新闻**：1885年以来145次5%以上变动中只有30次能对应明确的重大政治经济事件。
- **迷信熔断能稳定市场**：暂停交易可能加速价格向限制位下跌，1997年10月27日即为例证。

## Worked Example
复原1987年10月19日的传导链：此前道指已从8月2725点回落，10月12日当周跌10%；10月19日开盘前长期国债收益率报10.4%，而通胀仍在可控范围，股债收益率差达到战后极值。持有股票组合的机构用"投资组合保险"做空标普500期货，价格越跌、空头越多。开盘后期货迅速跌破现货，套利者无法买回股票，纽交所买家因期货贴水而停止报价，流动性冻结。道指当日收于1739点，较2247点下跌508点（-22.6%）。随后美联储注入流动性并承诺支持银行体系，挤兑没有发生，货币供应未收缩——同样的价格形态，因政策反应不同，没有走向1929~1932年道指跌89%的结局。

## Key Takeaways
1. 崩盘的破坏力取决于政策是否提供流动性，而不是跌幅本身；1929与1987的对照是本章的核心证据。
2. 高波动集中在衰退与熊市，衰退期日收益率标准差比扩张期高25%，用平静期经验管理危机期会低估风险。
3. 止损与动态对冲不是真正的保险，它们在流动性枯竭时失效；期权才是买入时即确定成本的保护。
4. 恐慌抛售常把价格压到远低于长期价值的位置，但VIX高低本身不能作为择时信号。
