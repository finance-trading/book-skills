# 第18章：交易所交易基金、股指期货与期权

## Core Idea
20世纪80年代以来的指数化衍生工具彻底改变了股票市场的微观结构：股指期货把指数变成可杠杆、可做空的合约，ETF把一篮子股票变成可全天交易的份额，指数期权则把下行风险切割成可购买的保险。西格尔认为，这些工具本身并未被证明加剧了长期波动或损害投资者，反而提高了流动性、降低了分散成本；真正的危险在于杠杆与频繁交易，而非工具。

## Frameworks Introduced
- **三种指数化工具选择框架**：按交易频率、税收账户与杠杆需求在ETF、指数基金、股指期货之间取舍。
  - 何时使用：需要获得某个指数敞口时。
  - 如何使用：频繁交易、需要做空或对冲选ETF；每月定投、自动再投资选低成本指数基金；只有充分理解杠杆与展期成本的专业投机者才用期货。
- **期货—现货平价框架**：用短期利率与股息收益率之差判断期货升贴水。
  - 何时使用：观察股指期货价格高于或低于现货指数时。
  - 如何使用：持有现货并卖出期货可锁定"股息+基差"的无风险收益，因此期货价格由利率减股息率决定；危机前利率高于股息率，期货升水，近零利率时期转为贴水。
- **套利锚定机制**：理解ETF与期货为何不会长期偏离指数。
  - 何时使用：看到ETF折溢价或"程序化交易打压市场"的评论时。
  - 如何使用：ETF靠授权参与者以一篮子成份股申赎创设单位（通常5万份）；期货靠到期收敛与指数套利；偏离越大，套利资金越会进场买卖成份股。

## Key Concepts
- **ETF的规模与起源**：1993年发行的"蜘蛛"（SPDRs，标普500存托凭证）是第一只ETF；此后有纳指100的"立方体"（QQQ）与道指的"钻石"（DIA）。2012年底ETF资产超过1.3万亿美元，约为标准共同基金市值的10%，自2002年以来增长13倍。
- **ETF的税收机制**：授权参与者用成份股与ETF份额互换属于实物兑换（exchanges in kind），不产生应税资本利得，因此ETF几乎不分配资本利得；指数基金在赎回或成分调整时仍须卖出股票。
- **成本对比**：指数基金年费率不到0.15%，多数ETF更低，但ETF与期货需通过经纪账户支付佣金和买卖价差；期货虽无年费，却需每年至少展期一次。
- **股指期货的诞生**：1982年2月堪萨斯市期货交易所推出价值线指数期货（约1700只股票）；两个月后芝商所推出标普500期货。到1984年，标普500期货成交额已超过纽交所全部股票成交额，如今日均成交额逾1000亿美元。
- **合约乘数**：标准标普500期货乘数250倍，指数1700点时合约价值42.5万美元；1998年推出的E-mini乘数50倍，在电子市场交易，成交量已远超标准合约。
- **保证金与杠杆**：标普500期货初始保证金约为合约价值的5%，可用国库券缴纳且利息归投资者；杠杆至少20倍。ETF可做保证金交易，美联储规定保证金比率50%。
- **期权合约**：CBOE于1974年成立，1978年开始交易标普500等指数期权，乘数100倍。买方的最大损失限于期权费，卖方则承担无限风险；据市场专业人士估算，约85%的期权投资者最终亏损。
- **到期日共振**：股指期货在3、6、9、12月第三个星期五结算，股指期权与个股期权每月第三个星期五结算，故每年有四天"三巫聚首"，其余月份为"双巫聚首"。

## Mental Models
- **工具放大的是行为，不是收益**：同样的ETF，定投者得到低成本分散，短线者得到过度反应的通道；杠杆把1%的判断误差放大成20%以上的损益。
- **衍生品是现有资产的影子**：期货与ETF的价格最终被现货套利锚住，理解影子要先理解标的、利率与股息。
- **流动性有价格，也有诱惑**：全天交易与做空能力提升了市场效率，也提高了投资者犯错的频率。
- **保险与赌博是同一张合约的两面**：买期权是付保费买有限损失，卖期权是收保费承担尾部风险。

## Anti-patterns
- **用期货加杠杆做方向投机**：5%保证金意味着指数反向波动5%即可吞掉全部保证金；作者明确建议除非充分使用杠杆、否则避免股指期货。
- **把"程序化交易"当替罪羊**：程序化买卖多是指数套利者为纠正期货与现货价差而进行的成份股交易，套利者在股票上的盈亏会被期货头寸对冲。
- **在ETF与指数基金之间忽略账户类型**：免税账户（IRA、Keogh）中两者税收差异无关紧要，应税账户中ETF的税后收益才可能更优。
- **把期权当低成本彩票**：买方需同时判断方向、时点与执行价，约85%的期权投资者亏钱，多数期权到期一文不值。

## Worked Example
以本章的标普500期货算术为例：指数1700点、乘数250，一份合约价值425000美元。若以1700点买入9月合约，结算日指数为1710点，盈利为250美元/点×10点=2500美元；若跌至1690点，亏损同样是2500美元。把这笔交易放回保证金账户：初始保证金约为合约价值的5%，即21250美元；指数上涨0.59%带来2500美元，相当于保证金上约11.8%的回报；反向同样放大亏损。这一算例说明期货的核心不是预测更准，而是杠杆把微小的指数变动转化为巨大的权益波动。

## Key Takeaways
1. ETF解决的是交易便利与税收效率，指数基金解决的是低成本定投，期货解决的是杠杆与对冲，用途错配才是亏损来源。
2. 期货价格由短期利率与股息收益率之差决定，到期必然收敛于现货，套利使大幅偏离难以持续。
3. 保证金交易把指数的小幅波动放大20倍以上；作者对多数投资者的建议是限制交易、降低杠杆。
4. 指数期权可用有限期权费购买下行保护，但买方胜率低，卖方则在极端行情中承担巨大尾部风险。
