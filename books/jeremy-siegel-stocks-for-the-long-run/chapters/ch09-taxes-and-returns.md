# 第9章：税收对股票与债券收益率的影响：股票更胜一筹

## Core Idea
税后实际总收益最大化才是长期投资者的目标（坦普尔顿）。债券利息按普通收入逐年征税，股票则享有资本利得与股息的较低税率，且资本利得可递延到出售时才缴——这使股票在税后层面的优势大于税前。1913年联邦所得税开征以来，免税投资者的股票实际年收益为6.7%，最高税级且每年实现资本利得的投资者仍有2.7%；应税长期债券从2.2%降到-0.3%，短期国债从0.4%降到-2.3%。税收不是中性的，它系统性地惩罚固定收益。

## Frameworks Introduced
- **税后实际总收益框架**
  - 何时使用：比较股票、债券、市政债或任何收益工具时。
  - 如何使用：先把票息、股息、资本利得按适用税率与实现时点分别计税，再扣通胀；不要用税前收益排序。表9-1的四档税级给出同一资产从免税到最高税级的完整区间。
- **延期利益框架**
  - 何时使用：在"高股息"与"资本增值"两种股票之间选择，或决定是否频繁交易时。
  - 如何使用：设年收益均为10%、税率20%。付息股票每年税后8%；资本利得若30年后才实现，年税后9.24%，仅比免税的10%低0.76个百分点。持有期越长、实现越晚，递延优势越大；每年实现资本利得会把这一优势清零。
- **资产放置决策**
  - 何时使用：决定股票、债券、REITs放应税账户还是IRA/401(k)等延期纳税账户（TDA）时。
  - 如何使用：长期被动持有的股票放应税账户，享受资本利得低税率与递延；房地产信托及其他信托收入、频繁交易的基金/活跃交易放TDA。TDA提取时全部按普通收入征税，但政府也分担了投资损失风险。

## Key Concepts
- 1913年美国开征联邦所得税；2003年以前股息按普通收入征税，二战刚结束时股息边际税率一度高达90%。
- 2003年《就业与进一步减税协调法案》把合格股息与资本利得的最高税率降至15%；2012年《美国纳税人救助法案》将其提高到20%，加上联邦医疗保险税后为23.8%。
- 资本利得最高税率路径：1978年35%（此后60% exclusion降至28%）→1982年20%→1986年取消优惠→1988年与普通收入同为33%→1990年28%→1997年20%→2003年15%→2013年23.8%。
- 1913年以来税后实际年收益：股票6.7%（免税）至2.7%（最高税级、每年实现利得）；应税长期债券2.2%至-0.3%；短期国债0.4%至-2.3%；市政债券1.3%。
- 1946年初把1000美元投入短期国债，经通胀调整后的税后收益到2012年只剩138美元，购买力损失86%；同期股票变为5719美元，购买力增值470%。
- 自1871年以来，最高税级投资者的短期国债税后实际收益已为负；同一时期股票把购买力增值288倍。
- 通货膨胀税：资本利得按名义价格征税。实际收益不变时，3%通胀使5年持有者的年化税后收益比零通胀低0.6个百分点；6%通胀则低超过1.12个百分点。持有期越短，伤害越大。
- 股息平均收益率从1980年以前的5%降至近年约2%；回购替代股息增加了资本利得形式的收入。
- 过去30年，税率下降、低通胀、股息转资本利得等因素合计使股票税后实际收益增加约2个百分点。

## Mental Models
- 税是对现金流征收的，不是对未实现增值征收的：能合法推迟实现，就等于获得一笔无息贷款。
- 债券的税负无法推迟：票息每年按普通收入征税，税后复利起点天然低于股票。
- 通胀让名义资本利得税变成"对亏损征税"：资产只跟上物价，出售时仍要缴税。
- 资产放置是收益的一部分：同样的股票与债券，放在不同账户，30年后的税后结果不同。
- 税制变化会改变估值：股票税收优势应体现为更高的合理市盈率（第10章展开），但不要为税惠牺牲分散与风险控制。

## Anti-patterns
- 用税前收益率比较股票与债券，忽略债券利息按普通收入逐年征税、股票资本利得可递延。
- 每年实现资本利得或频繁交易，把递延利益主动变成当年税负。
- 机械遵循"股票放退休账户、债券放应税账户"的常见做法，忽略长期股票放在应税账户的税率优势。
- 忽略通胀税，用名义资本利得计算真实税后收益。
- 为了规避股息税而只买零股息股票；第12章显示付息股票的税前与税后收益反而更高。

## Worked Example
书中用1946年初的1000美元做税后购买力对照：投入短期国债，按历年税率缴税并扣通胀后，到2012年只剩138美元，购买力缩水86%；投入股票，同样扣税、扣通胀后为5719美元，购买力增长470%。再把视角拉长：自1871年以来，最高税级投资者的短期国债税后实际收益为负，而股票把购买力放大了288倍。这个对照说明，税收与通胀叠加后，名义上"安全"的短债并不保护购买力；税后实际收益才是可消费的结果。

## Key Takeaways
1. 1913年以来，股票税后实际年收益2.7%–6.7%，应税长债-0.3%–2.2%，短债-2.3%–0.4%；税收扩大而非缩小股票优势。
2. 资本利得可递延：10%收益、20%税率下，每年付息税后8%，30年后实现资本利得则年税后9.24%。
3. 通胀按名义利得征税：3%通胀让5年持有者少0.6个百分点，6%通胀少超过1.12个百分点。
4. 资产放置要按投资者类型：长期被动股票放应税账户，REITs、信托收入与高频交易放TDA；不要机械照搬。
