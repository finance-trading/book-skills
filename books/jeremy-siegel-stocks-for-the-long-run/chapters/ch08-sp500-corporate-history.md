# 第8章：标准普尔500指数：半个多世纪的美国公司史

## Core Idea
如果1957年买入标普500的全部500只原始成份股、此后不再买入指数新增的1000多只股票，这一"冻结组合"的年收益率比不断换股的指数高出1个百分点（指数为10.07%）。原因不是老公司天生优秀，而是新公司往往在高市值、高乐观预期时被纳入指数：20世纪70年代末至80年代初新增的13只能源股有12只跑输，1999–2000年加入的科技公司占该板块新增总数的30%，世通、环球电讯、Quest随后破产。指数的换股记录了一部美国公司兴衰史，也暴露了"按市值纳入"的系统性买贵倾向。

## Frameworks Introduced
- **原始成份股冻结检验**
  - 何时使用：判断指数换股究竟创造还是损耗收益、或评估"长期持有"时。
  - 如何使用：固定1957年的500只成份股，按总收益口径追踪并购、分拆、私有化与破产到2012年，再与动态指数比较。结果：原始组合比指数10.07%高约1个百分点，换股整体略有拖累。
- **行业权重—收益率分离框架**
  - 何时使用：看到某行业权重上升，想据此超配时。
  - 如何使用：把权重变化拆成"新公司加入"与"存量公司升值"；再看行业收益。1957–2012年金融与科技权重上升主要来自新增公司；行业扩张只能解释约10%的行业收益，其余90%取决于行业内公司表现。
- **换股节奏诊断**
  - 何时使用：判断指数换股是常态还是情绪信号时。
  - 如何使用：看年均新增数量与峰值年份。1957–2012年平均每年新增20家，新公司约占指数市值5%；1976年新增60家（15家银行、10家保险），2000年科技泡沫顶部新增49家，2003年低谷仅8家。高峰常对应热门行业的高估值。

## Key Concepts
- 标普500诞生于1957年2月28日，脱胎于1926年90只大盘股的标准普尔综合指数；最初425只工业股、25只铁路股、50只公共事业股，占纽交所市值近90%。1988年放弃行业配额，改为"经济中各个领先行业中的500家龙头公司"。
- 1957–2012年共新增1159家公司，平均每年20家、约占指数市值5%；1976年最多60家，2003年最少8家。
- 1957年最大公司美国电报电话公司市值112亿美元，保持全球最大到1975年；2012年这一市值只能排在标普500下半区。1984年分拆为"小贝尔"，若持有全部分拆股，55年年均收益9.76%，与指数几乎持平。
- 通用汽车1957–2012年年均收益仅3.71%；伊士曼柯达2012年1月破产，但因1994年剥离伊士曼化学，年均仍有6%；伯利恒钢铁2001年破产，原始股东一无所获；美国钢铁2003年市值缩水至10亿美元，回到一个世纪前的规模。
- 1957年最初的20大公司中，9家石油公司全部进入前十，年收益比标普500高96–275个基点；皇家荷兰石油表现最好，美孚1999年与埃克森合并，海湾石油、加州标准石油、得克萨斯石油最终并入雪佛龙–德士古。
- 行业权重：材料与能源1957年几乎占指数一半，2013年合计仅14%；金融、医疗保健、信息技术1957年合计仅6%，2013年接近一半。材料从最大行业变成最小行业之一。
- 1957年IBM占科技板块权重三分之二；2013年科技板块有70家公司，IBM只排第三。
- 菲利普莫里斯是原始成份股中业绩第一，1957–2012年复合年收益19.47%，几乎是指数10.07%的两倍；业绩前20名中15家来自日用消费品与医疗保健（制药）。

## Mental Models
- 指数的历史是"公司生命周期"而非"赢家名单"：今天的巨头会像1957年的AT&T、美国钢铁一样被重估。
- 按市值纳入意味着"在受欢迎时买入"：市值高企常来自乐观预期，而非可持续的现金流；新成份股整体跑输老成份股正是这一机制的代价。
- 行业增长不等于行业收益：为快速扩张的行业支付高价格，往往抵消增长；停滞行业因被忽视、价格低于基本面，反而可能收益最高。
- 看权重要问来源：是新公司上市进入指数，还是老公司股价上涨？前者稀释老股东，后者才是财富效应。
- 单一公司命运极难预测：AT&T分拆后仍与指数打平，CVS靠收购药店从制鞋业转身，撒切尔玻璃被并购后变成菲利普莫里斯的一部分。

## Anti-patterns
- 把标普500的长期收益归功于"不断剔除失败公司、纳入赢家"；原始500只冻结组合反而比指数高1个百分点。
- 用2012年的赢家名单倒推1957年"显而易见"的好公司，忽略AT&T、GM、柯达、伯利恒的结局。
- 把行业权重上升当成行业将跑赢的信号，忽略权重上升主要来自新公司加入。
- 把"行业增长快"等同于"投资回报高"；金融业增长第二快，收益却倒数第二。
- 在热门行业市值膨胀时被动买入其新纳入指数的股票（1970年代能源、1999–2000年科技），复制指数换股的高位买入。

## Worked Example
用本章的能源股换股检验"纳入即优质"：20世纪70年代末至80年代初能源危机期间，标普500把环球海洋石油、西部公司等13只能源股纳入指数，随后其中12只的收益率低于能源行业或标普500平均水平，部分公司破产。类似地，1957年以来科技板块新增125家公司，其中30%在1999–2000年加入，世通、环球电讯、Quest Communications上市风光后破产清盘。把这些新增公司与1957年原始500只的冻结组合相比，后者年收益反而高约1个百分点——说明"市值大、故事好"并不等于"未来收益高"。

## Key Takeaways
1. 1957年原始500只冻结持有到2012年，年收益比动态标普500的10.07%高约1个百分点；换股整体不是收益来源。
2. 原始成份股中最好的20家年均19.47%（菲利普莫里斯第一），但大多数原始公司衰落、被并购或破产。
3. 行业权重轮动剧烈（材料+能源从约50%降到14%，金融+医疗+科技从6%升到近半），行业扩张只能解释约10%的行业收益。
4. 指数换股平均每年20家、约占市值5%；新增公司常在行业高估值时进入，1970年代能源与2000年科技的结局都是跑输。
