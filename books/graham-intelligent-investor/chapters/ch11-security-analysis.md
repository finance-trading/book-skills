# 第11章：普通投资者证券分析的一般方法

## Core Idea
普通投资者可以通过几种定量方法对证券进行估值分析，其中最重要的是格雷厄姆估值公式，它将每股收益、增长率和债券利率结合起来评估内在价值。

## 格雷厄姆估值公式
**V = EPS × (8.5 + 2g)**
- V = 内在价值，EPS = 每股收益，g = 预期年增长率
- 8.5 是零增长公司的合理市盈率
- 利率修正：当AAA债券利率 ≠ 4.4%时，结果需乘以 4.4/AAA当前利率

## 三种主要估值方法
1. **资产价值法**：以公司净资产（账面价值）为估值基础，适用于控股收购或清算场景
2. **盈利能力法**：以过去7-10年的平均利润为基准，适用于稳定盈利的公司
3. **市场乘数法**：以市盈率（P/E）为基准，比较同行业公司

## 关键概念
- **市盈率（P/E）**：股价 ÷ 每股利润，是市场评估公司价值的最常用指标
- **利润乘数**：市盈率的另一种说法，反映了市场愿意为每单位利润支付的价格
- **账面价值**：公司资产减去负债后的净值，通常作为估值的下限参考

## 分析原则
- 采用保守假设——宁可低估，不可高估
- 使用过去7-10年的平均利润，而非仅看最近一年的利润
- 排除非经常性项目对利润的影响
- 关注股息记录——持续支付股息是公司财务健康的重要标志
