# 投资模式与技术 — 《聪明的投资者》

## 防御型投资者 (Defensive Investor)

### 1. 50/50 资产配置与再平衡
**章节**: ch04
**定义**: 将资金平均分配于股票和债券，定期（如每年或每半年）再平衡恢复初始比例。
**何时使用**: 作为防御型投资者的基础策略，适用于任何市场环境。
**实施要点**:
- 初始比例：股票50% + 债券50%
- 可接受范围：25%～75%，避免频繁调整
- 再平衡触发：时间（每年/每半年）或阈值（偏离超过5%）
- 市场极低估值时可将股票提高至75%，极高估值时降至25%

### 2. 美元成本平均法 (Dollar-Cost Averaging)
**章节**: ch05
**定义**: 定期定额持续买入同一只股票或指数基金，无视价格波动。
**何时使用**: 长期定投，尤其是防御型投资者积累财富时。
**实施要点**:
- 固定金额 + 固定时间间隔（如每月$1000）
- 价格低时自动多买，高时少买，降低平均成本
- 关键：严格遵守纪律，不受市场情绪干扰
- 适用于指数基金，不建议用于个股

### 3. 防御型选股七标准
**章节**: ch14
**定义**: 七条量化标准筛选适合防御型投资者的普通股。
**标准**:
1. 适当规模：大型、知名、财务稳健的公司
2. 财务状况强劲：流动比率 ≥ 2:1，长期债务 ≤ 营运资本
3. 连续20年支付股息
4. 过去10年无亏损
5. 过去10年每股利润增长至少1/3
6. 股价 ≤ 有形资产账面价值 × 1.5
7. 市盈率 ≤ 15倍（与标准6乘积 ≤ 22.5）

### 4. 程式投资 (Formula Investing)
**章节**: ch04
**定义**: 按预定规则调整资产比例，机械执行，不依赖市场预测。
**何时使用**: 希望系统化投资决策的投资者。
**实施要点**:
- 定义明确的规则：何时买入、卖出、调整
- 消除情绪干扰
- 定期审视规则有效性

## 积极型投资者 (Enterprising Investor)

### 5. 净流动资产价值 (NCAV) 策略
**章节**: ch15
**定义**: 买入股价低于净流动资产价值的股票，相当于免费获得固定资产。
**何时使用**: 寻找深度价值机会时。
**计算方法**:
```
NCAV = 流动资产 - 总负债
筛选条件：股价 < 2/3 × NCAV
```
**实施要点**:
- 极端保守，提供最大安全边际
- 需分散投资（至少10-30只）
- 格雷厄姆-纽曼公司历史回报：年均14.7%
- 现代应用中需考虑资产质量

### 6. 廉价证券筛选 (Bargain Issues)
**章节**: ch07
**定义**: 寻找售价低于内在价值的证券，尤其是低于净流动资产价值的股票。
**筛选标准**:
- 市盈率很低（如 < 10倍）
- 股价相对过去高点的跌幅很大
- 财务稳健，无重大债务
- 有持续支付的股息记录

### 7. 特殊情形 (Special Situations)
**章节**: ch07
**定义**: 利用公司特定事件（并购、重组、清算）产生的定价差异获利。
**类型**:
- **并购套利**: 收购价格与目标公司当前股价之间的价差
- **资产清算**: 清算价值高于当前股价
- **公司重组**: 分拆、资产出售等
**实施要点**:
- 收益确定性高，但专业性强
- 需要迅速评估和操作
- 收益率逐渐递减，竞争加剧

### 8. 交叉套利 (Cross Arbitrage)
**章节**: ch07
**定义**: 利用同一公司不同证券之间的价差进行套利，如可转换证券与普通股之间的转换套利。
**何时使用**: 市场出现定价错误时。
**实施要点**:
- 需要高度专业的知识
- 风险相对较低但操作复杂

## 估值模式

### 9. 格雷厄姆估值公式
**章节**: ch11
**定义**: V = EPS × (8.5 + 2g)
**用途**: 快速估算普通股的内在价值。
**参数说明**:
- V = 内在价值
- EPS = 过去12个月的每股收益
- 8.5 = 零增长公司的合理市盈率
- g = 未来7-10年的预期年增长率
**利率修正**: 当AAA债券利率 ≠ 4.4%时，结果需乘以 4.4 ÷ AAA当前利率

### 10. 安全边际框架
**章节**: ch20
**定义**: 安全边际 = 内在价值 - 市场价格，以差价作为保护层。
**实施步骤**:
1. 估算公司的内在价值
2. 比较市场价格与内在价值
3. 只在安全边际充足时买入
4. 分散化投资以降低风险
**安全边际水平**:
| 安全边际 | 水平 | 行动 |
|---------|------|------|
| ≥ 50% | 极安全 | 可买入 |
| 20-50% | 安全 | 可买入（结合其他因素）|
| < 20% | 不足 | 等待更低价格 |
| ≤ 0% | 无 | 不买入 |

### 11. 市盈率分析 (P/E Ratio)
**章节**: ch11, ch12
**定义**: 股价 ÷ 每股利润，衡量市场对公司价值的评估。
**应用**:
- 低市盈率：可能被低估，但需确认低P/E不是出于盈利质量问题
- 高市盈率：市场预期高增长，但风险相应加大
- 格雷厄姆建议：防御型投资者选P/E ≤ 15倍
- 注意：周期股的利润波动会导致P/E失真

### 12. 市净率分析 (P/B Ratio)
**章节**: ch14
**定义**: 股价 ÷ 每股账面价值，衡量价格与净资产的关系。
**应用**:
- 格雷厄姆标准：股价 ≤ 有形资产账面价值 × 1.5
- 与P/E结合使用：P/E × P/B ≤ 22.5
- 适用于金融、制造业等重资产行业
- 轻资产公司（科技、服务）的P/B参考价值有限

## 市场行为模式

### 13. 市场先生 (Mr. Market)
**章节**: ch08
**定义**: 市场是情绪不稳定的合伙人，每天报价。他的报价是服务你的，不是指导你的。
**实施要点**:
- 不因市场情绪改变自己的判断
- 向乐观主义者卖出，从悲观主义者手中买进
- 利用市场波动，而非跟随
- 市场下跌是买入机会，不是恐慌理由

### 14. 通货膨胀应对策略
**章节**: ch02
**定义**: 通胀对股票利润没有直接提升作用，这是历史数据证实的。
**应对**:
- 不要因为通胀预期而忽略估值买入股票
- 债券在通胀期间表现不佳，但仍是防御型配置的必要部分
- 股票的长期收益来自企业利润增长，而非通胀对冲
- 调整股息率预期：高通胀时期实际股息率可能为负

### 15. 长期市场周期分析
**章节**: ch03
**定义**: 市场在极端乐观和极端悲观之间摆动，聪明的投资者利用这种波动。
**历史模式**:
- 1871-1971年：19次熊市和牛市周期
- 1949-1968年大牛市：道指涨4倍，利润仅涨1倍
- 1969-1970年市场下跌36-37%
**启示**:
- 投资者应关注长期周期而非短期波动
- 极端估值水平是市场顶/底的信号
- 不要追逐热门题材

## 风险管理模式

### 16. 分散化投资 (Diversification)
**章节**: ch04, ch20
**定义**: 将资金分散到多个不同的投资标的，降低单一风险。
**实施要点**:
- 防御型：指数基金提供天然分散
- 积极型：至少10-30只股票
- 跨行业分散，避免过度集中在热门行业
- 分散化是安全边际的补充——双重保护体系

### 17. 双重保护 (Double Protection)
**章节**: ch20
**定义**: 安全边际 + 分散化 = 投资组合的完整保护体系。
**逻辑**:
- 安全边际：保护你免受判断错误的影响
- 分散化：保护你免受单一公司灾难的影响
- 两者结合提供最强保护

### 18. 投资与投机分离
**章节**: ch01
**定义**: 严格区分投资账户和投机账户，独立操作。
**规则**:
- 投资账户：经过深入分析，确保本金安全，获得适当回报
- 投机账户：单独设立，资金不超过可承受亏损的额度
- 不要自以为在投资实则投机
- 不要在缺乏知识和技能时把投机当正经事
