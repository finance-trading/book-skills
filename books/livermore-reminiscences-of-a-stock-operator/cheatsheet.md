# 交易判断速查

## 决策顺序

1. **大势是否明确？** 不明确 → 等待；明确 → 确定与其一致的方向。
2. **事实是否由自己理解？** 只有贴士或权威观点 → 独立验证；事实和价格一致 → 继续。
3. **时机是否到来？** 价格未确认 → 等待；市场行为证实判断 → 以可承受风险试仓。
4. **市场是否继续证明？** 有利且趋势持续 → 可以分批加仓；不利或判断失效 → 退出，不摊平。
5. **趋势是否结束？** 仍在 → 耐心持有；结束 → 了结，不要求精确卖在顶点。

## 如果……那么……

| 信号 | 行动及原因 |
|---|---|
| 总体市场与个股判断冲突 | 缩小风险或等待；个股并非脱离大势。 |
| 价格不按预期行为变化 | 重新检验，必要时退出；市场比原观点重要。 |
| 交易开始即亏损 | 重新审查并控制损失；不要仅为回本加码。 |
| 趋势继续而仅有正常回撤 | 按事先的失效条件判断；避免因微小波动打断大行情。 |
| 仓位令你失眠 | 降低仓位至能理性判断；心理压力是暴露信号。 |
| 听到可靠贴士 | 查利益和证据，等待价格确认；声望不等于时机。 |
| 市场沉闷而你想天天挣钱 | 等待；迫切需要收入不是优势。 |
| 浮盈巨大或制度风险上升 | 检查仓位、流动性和兑现需求；账面利润仍有风险。 |
| 做空个股且筹码集中 | 考虑逼空、借券和被迫回补；方向正确也可能先遭强平。 |
| 推介密集而价格疲弱 | 查谁在卖、谁需要买家；故事不能消除卖压。 |

**边界**：关键点、持有和止损没有适用于所有市场的固定阈值；滑点、跳空和杠杆均可能使实际损失大于预期。历史案例不是投资建议。
