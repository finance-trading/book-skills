# Decision cheatsheet

Based on the current English PDF, with the retained Chinese *Illuminated* chapter 20 identified in the main skill. These are reasoning prompts, not trade signals.

## 决策规则

| 情况 | 行动 |
|---|---|
| 市场已经把好消息全买进 | 不追价，等更好价格 |
| 资产无人喜欢但价值没坏 | 重点看，必要时逆向买入 |
| 估值看起来“好到不像真的” | 先怀疑，再验证 |
| 需要靠预测才能成立 | 降低仓位或放弃 |
| 需要加杠杆才能勉强达标 | 重新设目标 |
| 没有安全边际 | 不买 |
| 没有时间研究 | 选择更防守的结构 |
| 组合在下跌时会被迫卖出 | 先修结构，不先求收益 |

## 记住这几条

- 价格低于价值才是买点。
- 风险里最重要的是永久亏损和被迫卖出。
- 预测可以参考，不能依赖。
- 周期和钟摆不会直线走完。
- 便宜往往来自厌恶、恐慌、错配和被迫卖出。
- 真正的技巧是少亏、活久、等机会。

## 常见误判

| 误判 | 更好的问法 |
|---|---|
| “这家公司不错” | “我是不是买贵了？” |
| “这次不一样” | “历史和激励为什么会失效？” |
| “大家都在买” | “价格里还剩多少上行？” |
| “模型说没问题” | “极端情境下会怎样？” |
| “我能预测” | “我能承受预测错多少？” |
| “高回报很合理” | “为什么这笔机会轮到我？” |

## 组合原则

1. 先定义不能承受的损失。
2. 再定义可接受的报酬。
3. 用价格、分散、流动性和杠杆去约束结果。
4. 多头时别把防守扔掉。
5. 空头时别把勇气扔掉。

## 先判断环境，再判断资产

| 观察 | 推论 | 下一步 |
|---|---|---|
| 信贷宽松、契约变弱、风险溢价收窄 | 低风险感觉可能掩盖高价格 | 提高折价要求，检查杠杆与再融资 |
| 恐慌、赎回或保证金引发强制卖盘 | 价格可能短暂低于价值 | 独立算信用损失，保留持有流动性 |
| 热门资产质量好、价格也极高 | 成长可能早已写进价格 | 比较市场隐含预期与自己的证据 |
| 便宜资产基本面也恶化 | 低价可能合理 | 先修正内在价值，勿机械逆向 |

## 判断超额收益是否来自能力

1. 写下基准、风格和 beta；上涨年份放大的收益本身不算 alpha。
2. 看下跌和逆风阶段是否少亏，并检查是否只是低 beta。
3. 列出当时本可发生的其他结果；若一个结果会令组合毁灭，实际好运不能证明过程稳健。
4. 用多个周期而非单年评价。
