# Cheatsheet

## Decision Rules

| If you see… | Do this | Because… |
|---|---|---|
| 收入增加但月末仍缺钱 | 先画现金流并冻结生活升级 | 高收入不等于净资产或流动性改善。 |
| 想买房、车或其他大件 | 分开列使用价值、持有成本和投资回报 | 能使用的东西不必然是能产生现金的资产。 |
| 只依赖一个技能或雇主 | 在不破坏基本收入的前提下补一项互补技能 | 技能组合扩大可创造价值的场景。 |
| 被高回报故事吸引 | 先核实信息、压力测试和退出路径 | 机会不是保证，杠杆会放大损失。 |
| 想注册公司来“省税”或“避险” | 先确认当地税法、责任边界和合规成本 | 公司不自动消除担保、违法或经营风险。 |
| 因害怕损失而完全不学习 | 把最坏损失和可承受金额写出来，再做小实验 | 风险应被理解和限制，而非用回避掩盖无知。 |
| 只因怀疑一切而不行动 | 选择一个可撤回、低成本、可复盘的步骤 | 用证据替代无穷争论。 |
| 想用借款购买非必需品 | 先验证自由现金流能覆盖债务和应急需要 | 消费债务会把未来收入锁给银行。 |

## Cash-Flow Gate

1. 现金从哪里来：工资、业务、资产还是借款？
2. 现金到哪里去：必要支出、税费、维护、利息和本金分别是多少？
3. 资产真的带来净现金，还是只带来账面升值或使用价值？
4. 最坏情形下，多久需要现金？能否不卖出或不再借债？
5. 复盘期限、退出条件和负责核实的人是否明确？

## Skill-Stack Check

- 会计：能否读懂收入、支出、资产、负债和现金流？
- 投资：能否解释回报来源、估值、风险与退出？
- 市场：谁愿意付费，为什么现在付，需求能否持续？
- 法律：所有权、合同、税务、责任和申报由谁承担？
- 沟通/销售：能否清楚表达真实价值和限制？

## Obstacle Tells

- **恐惧**：不愿看数字，或只接受“绝不亏损”的说法。
- **怀疑**：永远等待完美确定性，从不做可控验证。
- **惰性**：知道现金流问题却继续自动化消费。
- **坏习惯**：加薪后支出同步升级，资产没有增长。
- **自负**：不懂税法、合同或投资对象却拒绝专业意见。

## Guardrails

- 书中资产/负债定义是教育性简化，不替代正式会计与估值。
- 书中税务、公司和房地产案例以特定时期、主要是美国环境为背景；执行前查当地现行规则。
- 任何“无钱投入”“快速致富”叙事都要先核实费用、担保、流动性和失败情景。
