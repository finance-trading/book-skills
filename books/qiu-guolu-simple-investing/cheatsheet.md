# 决策速查

| 观察 | 下一步 | 原因 |
|---|---|---|
| 股价大跌 | 检查价格、问题可修复性、反身性 | 下跌不等于错杀 |
| 市盈率很低 | 正常化盈利，核查债务和衰退风险 | 周期顶峰或价值流失可制造低倍数 |
| 需求快速增长 | 查进入门槛、供给、渠道及利润归属 | 市场扩大不保证企业赚钱 |
| 企业看起来优质 | 倒推当前价格隐含的增长 | 好公司也可能买贵 |
| 利润突然大增 | 分离周期恢复和持续竞争优势 | 高运营杠杆会放大上行与下行 |
| 持仓亏损 | 从当前价格比较未来情景及替代方案 | 原始成本是沉没成本；税费另计 |
| 投资逻辑暂时不受市场认可 | 检查反证、流动性及资金期限 | 正确判断也可能在可承受时间外兑现 |
| 价格波动 | 分开核查经营、政策、情绪 | 不同驱动对价值的影响不同 |
| 历史表现优异 | 检查起始估值、区间和幸存者 | 后视镜不能预测未来回报 |

## 先停手的信号

- 说不清企业靠什么赚钱、现金流如何产生，或价格已隐含什么预期：先补证据。
- 只能用别人会接盘解释价格：重新估值，不把成交价当价值。
- 跌价会触发追加保证金、信心危机或融资断裂：先评估反身性和生存。
- 论点依赖某个历史底部顺序或精确转折日期：改用多个情景。
- 任何数字和行业判断若出自书中旧案例：更新财报、价格和制度后再用。
