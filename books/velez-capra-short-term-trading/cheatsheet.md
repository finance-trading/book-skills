# 速查表

先确认：账户限额、最大亏损金额、品种、时间框架、当前市场背景、事件、流动性与可交易时段。缺失条件时只列出缺口，不下单指令。

## 交易决策树

```
有信号？
├─ 无 → 记录并等待
└─ 有
   ├─ 市场背景明显相反？
   │   ├─ 是 → 只作小仓研究或不交易
   │   └─ 否 → 检查形态、触发、失效位
   ├─ 触发未完成？
   │   ├─ 是 → 不入场
   │   └─ 否 → 计算止损距离
   ├─ 单笔风险超过限额？
   │   ├─ 是 → 缩小股数或放弃
   │   └─ 否 → 按订单计划执行
   └─ 离场
       ├─ 触发止损 → 立即执行
       ├─ 达到目标 → 按分批计划执行
       └─ 时间限制届满 → 重新评估或退出
```

## 原书历史默认值

| 项目 | 原书数值 | 使用限制 |
|---|---:|---|
| 关键点新高窗口 | 不超过 8 根线 | 周期需自选并验证 |
| 连续更低高点 | 至少 3 根 | 不是趋势反转保证 |
| 关键点触发 | 前一线高点上方 1/16–1/8 美元 | 旧分数报价 |
| 30分钟高开 | 至少 5/8 美元 | 旧分数报价 |
| 30分钟买入止损 | 当日低点下方 1/16 美元 | 可能过宽 |
| 尾市整理 | 至少 1.5 小时，5分钟图 | 尾盘流动性需另查 |
| 保本阈值 | 波段约 1 美元；低于 12 美元股票 0.75 美元；日内 1/4–3/8 美元 | 历史固定金额 |
| 时间止损 | 波段第 5 个交易日；日内约 1–2 小时 | 策略相关 |
| TRIN | 1 为背景线；作者称 0.35 以下极端 | 数据口径须核对 |
| TICK | 约 ±300 中性，约 ±1000 极端 | 数据口径须核对 |
| 成交量突增 | 10日均量的 2 倍 | 仅作筛选条件 |
| 回抽概率 | 40%、50%、60% | 无样本说明，不可当统计事实 |

## 每笔开仓前检查

- [ ] 环境：指数方向与广度是否一致？
- [ ] 形态：至少一个客观设置和一个触发？
- [ ] 失效：止损价、订单类型、超时？
- [ ] 风险：股数 ×（入场价－止损价）≤ 单笔限额？
- [ ] 成本：价差、手续费、滑点、隔夜？
- [ ] 事件：财报、宏观、休市或数据延迟？
- [ ] 退出：目标、分批和跟踪止损是否已写明？

## 行为警报

止损被改远、亏损后改成长线、因盯金额而频繁离场、用“再等等”替代规则、连续亏损后放大仓位——任何一项都暂停交易并复盘。
