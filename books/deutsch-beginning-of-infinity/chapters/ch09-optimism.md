# Chapter 9: 乐观主义

## Core Idea
乐观主义不是情绪或盲目自信，而是一套关于知识创造的理论：所有恶与失败最终都源于知识不足；由于知识创造没有根本限制，问题原则上可以解决。悲观主义的预防性原则反而增加灾难风险。

## Frameworks Introduced
- **乐观主义原则**：所有的恶都是知识不足造成的。
  - When to use：面对灾难预测、资源枯竭、技术风险和制度失败。
  - How：把问题转化为“缺少什么知识”；区分自然规律禁令与知识不足；支持能加速创造与传播知识的制度。
- **盲目乐观 vs 盲目悲观 vs 乐观主义**：盲目乐观假定坏结果不会发生；盲目悲观（预防性原则）要求避免一切未经确认安全的东西；乐观主义承认风险，但主张用知识解决问题。
  - When to use：评估风险管理、创新政策和危机应对。
  - How：明确最坏情况；问是否有知识路径降低风险或恢复；避免把“未知”当成“不可知”的证据。
- **财富作为转换能力**：财富不是固定物品存量，而是人有能力进行的物理转换的集合；知识和制度可扩大财富。
  - When to use：讨论资源稀缺、经济增长和灾难恢复能力。
  - How：区分物质存量与可用转换能力；投资知识、技术和制度以扩大转换集合。

## Key Concepts
- **乐观主义**：所有失败源于知识不足的理论。
- **预防性原则**：避免未经确认安全之物的原则；本书认为其导致停滞。
- **盲目乐观**：无视风险的自信。
- **财富**：人可进行的物理转换的集合。
- **问题是不可避免的 / 问题是可以解决的**：知识永远不完备，但没有特定问题注定无解。

## Mental Models
- 把灾难预测看作待解决的问题，而不是宿命。
- 对创新风险，问“需要什么知识来降低风险”，而不是“如何完全避免新事物”。
- 把财富理解为能力，而非仓库中的东西。

## Anti-patterns
- **预防性原则**：以“可能有害”为由禁止创新，会扼杀解决问题的知识。
- **盲目乐观**：无视真实风险，不做准备。
- **马尔萨斯式预测**：把当前资源和技术当成固定边界，忽略未来知识。
- **把文明存亡当俄罗斯轮盘赌**：忽略人类选择与知识能改变概率。

## Worked Example
里斯以俄罗斯轮盘赌比喻文明风险：每项进步都可能增加一次致命抽奖。但轮盘赌的概率不受玩家想法影响；文明的未来却取决于人们创造什么知识、做什么选择。若只按现有知识预测灾难，就会误把“当前未知的解决方案”当成“不存在解决方案”。历史上许多文明不是因创新过快而亡，而是因知识不足无法应对灾难。

## Key Takeaways
1. 乐观主义是知识理论，不是情绪。
2. 预防性原则会阻止知识增长，从而增加长期风险。
3. 财富是转换能力，不是固定资源。
4. 灾难预测应激发知识创造，而非宿命论。
5. 问题可以解决，但不会一劳永逸。
