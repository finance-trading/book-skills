# 第14章 货币供给过程

## Core Idea
货币供给由央行、银行和存款人共同决定；基础货币增加并不机械地保证存款和贷款按固定倍数扩张。

## Frameworks Introduced
- **三位参与者**：央行影响基础货币，银行决定超额准备金和放贷，存款人决定现金与存款的配置。分析政策效果时逐个列出反应。
- **基础货币与 T 账户**：公开市场购买增加央行资产及银行准备金或公众现金；若把存款转换为现金，准备金减少、流通现金增加，基础货币总量可不变。
- **简化多倍存款创造**：在公众不持现且银行不保留超额准备金等强假设下，新增准备金可支持存款扩张；现实中须用现金／存款比和超额准备金比调整货币乘数。

### 从 T 账户推导 M1 乘数
1. 定义 `M=C+D`（流通现金加支票存款），`MB=C+R`（现金加准备金）。
2. 将准备金分为法定与超额部分：`R=rr×D+ER`。
3. 定义公众选择的 `c=C/D` 和银行选择的 `e=ER/D`，则 `M=(1+c)D`，`MB=(c+rr+e)D`。
4. 因此在这些比率暂时固定的条件下，`m=M/MB=(1+c)/(c+rr+e)`。提高 `e` 或 `c` 会压低乘数；固定比率是情景假设，不是行为定律。

## Key Concepts
- **基础货币**：流通中现金与银行准备金之和。
- **法定准备金率**：规定银行对特定存款保留准备金的比例。
- **超额准备金**：银行持有超过法定要求的准备金。
- **货币乘数**：货币总量与基础货币之比，取决于行为与制度。
- **公开市场操作**：央行买卖证券以改变准备金或基础货币。

## Mental Models
- 使用 T 账户避免把存款转移、贷款创造和央行购债混为同一动作。
- 乘数是条件关系，不是央行可直接操纵的常数。

## Anti-patterns
- **把准备金注入直接乘固定乘数**：危机时银行可持有超额准备金，公众也可转为持现。
- **把央行资产扩大等同贷款增长**：先检验银行资本、贷款需求与风险偏好。

## Worked Example
书中数字例题给出法定准备金率 `rr=0.10`、流通现金 `C=1.2` 万亿美元、支票存款 `D=1.6` 万亿美元、超额准备金 `ER=2.5` 万亿美元。由此 `c=0.75`、`e≈1.56`，`M=2.8` 万亿美元，`MB=1.2+0.16+2.5=3.86` 万亿美元，`m≈0.73`。这与在 `c=e=0` 时的简单存款乘数 `1/rr=10` 相差很大。危机后银行大量保留准备金，基础货币扩张未按十倍带来存款扩张；不能把 0.73 当作未来各年的固定预测值。

## Key Takeaways
1. 将央行、银行、存款人的决定分别建模。
2. 所有货币供给计算先写资产负债表。
3. 对乘数假设进行危机情景压力测试。
