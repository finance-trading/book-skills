# 第2章 金融体系概览

## Core Idea
金融体系的任务是把储蓄转化为有生产性的投资；市场与中介各自处理交易成本、风险分担和信息不对称。

## Frameworks Introduced
- **直接融资／间接融资**：发行证券让资金使用者直接向储蓄者融资；经银行等中介融资则由中介承担筛选、监控和期限转换。选择路径时比较规模、透明度、信用记录与信息成本。
- **市场结构矩阵**：区分债务与股权、一级与二级市场、交易所与场外市场、货币与资本市场。先确定合同与交易阶段，才能解读收益率和流动性。
- **金融中介的三项经济功能**：规模经济降低交易成本，资产转换分担风险，私人信息生产缓解逆向选择与道德风险。

## Key Concepts
- **一级市场**：新证券发行并将资金交给发行人的市场。
- **二级市场**：已有证券的买卖，直接提高证券的流动性。
- **货币市场**：短期债务工具市场；并非第3章作为交易媒介的“货币”本身。
- **资本市场**：长期债务和股权融资市场。
- **逆向选择**：交易前，风险较高的一方更可能主动寻求交易。
- **道德风险**：交易后，一方可能采取另一方难以观察的不利行动。

## Mental Models
- 二级市场不直接把交易额交给企业，却能通过流动性降低新发行的融资成本。
- 中介的价值由其实际降低的筛选、监控和交易成本衡量，而非由其存在本身证明。

## Anti-patterns
- **把证券交易额当作新增融资**：二级交易通常只是投资者之间的所有权转移。
- **认为去中介化消除了中介功能**：证券化常将筛选、服务和风险留在不同机构之间。

## Worked Example
书中比较个人直接向陌生借款人放贷与通过银行存款融资。个人难以分散单笔损失，也缺少核实借款人信息的规模；银行汇集存款、筛选贷款并持续监控。若银行筛选失效，间接融资的优势也会消退，因此仍需监管与披露。

## Key Takeaways
1. 先确认融资合同、期限和交易阶段。
2. 判断中介是否真正降低信息与交易成本。
3. 将流动性、风险分担和监管放在同一资金流向图上。
