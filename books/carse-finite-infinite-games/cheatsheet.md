# 有限与无限游戏：判断速查

## 先做类型判断

| 如果你看到…… | 可能是…… | 立即追问 |
|---|---|---|
| 明确终点、赢家、固定成员和规则 | 有限游戏 | 谁设定边界？谁认可赢家？所有参与者自愿吗？ |
| 规则会随参与者共同改变，目标是继续参与 | 无限游戏 | 什么威胁着延续？规则改变能否让更多人继续？ |
| 以“必须做”为理由、角色不可质疑 | 社会剧本 | 为什么我们觉得必须做？谁从这个必然性中获益？ |
| 有邀请、新参与者、传统被改造 | 文化视界 | 这项创造如何在新参与者身上继续生长？ |

## 决策规则

| 情况 | 卡斯式判断 | 为什么 |
|---|---|---|
| 想赢一场比赛 | 进入有限游戏，但记住自愿性与边界 | 赢者必须由参与者共同认可；强迫参与无意义 |
| 事业、关系或组织只剩赢家与输家 | 把规则改回能够延续游戏的规则 | 无限游戏遇到有限结局威胁时必须改变规则 |
| 不确定该认真还是玩 | 全力进入角色，同时承认角色是面具 | 自我遮蔽不可避免；忘记面具才会被角色吞没 |
| 想证明别人错了 | 检查自己是否在迎合想象中的敌意观众 | 越想扭转观众评价，越在证明观众是对的 |
| 面对意外 | 有限游戏用训练预测；无限游戏用教育准备被改变 | 惊奇在有限游戏终止比赛，在无限游戏延续比赛 |
| 追求奖项、名声或权力 | 问自己是否把头衔当作自我 | 头衔是已结束的过去，需要观众和重复比赛维护 |
| 面对技术方案 | 问机器服务花园，还是花园服务机器 | 工具会把操作者标准化；自发生长才有生命力 |
| 讨论自然的控制 | 追问要实现的社会结果和被控制的人 | 对自然的控制常是掩饰人对人的权力欲望 |
| 讲述传统或经典 | 选择共鸣，不要放大成单一命令 | 共鸣让声音相互展开；放大使其他人沉默 |
| 面对看似终结的历史 | 保留叙事的开放性，不宣布最后一幕 | 解释解决问题；叙事把必然性重新放回可能性 |

## 两种游戏对照

| 维度 | 有限游戏 | 无限游戏 |
|---|---|---|
| 目的 | 取胜、结束 | 延续游戏 |
| 参与者 | 被选中；必须自愿 | 任何愿意者可加入；必须自愿 |
| 边界 | 时间、空间、数值明确 | 无外部边界；与边界游戏 |
| 规则 | 先公布，游戏期间不变 | 游戏中可以改变，以保持延续 |
| 结果 | 赢家、排名、头衔 | 没有终局，没有赢家 |
| 时间 | 逐渐减少；自由是时间的变量 | 不被消费而被产生；时间是自由的变量 |
| 惊奇 | 过去对未来的胜利，威胁获胜 | 未来对过去的胜利，带来新开端 |
| 关系 | 对抗、比较、头衔与权力 | 互惠、触动、名字与力量 |
| 言说 | 权威、命令、使人沉默 | 致辞、聆听、使他人能够言说 |

## 两种游戏的快速判断树

1. **是否有可以明确指出的赢家和终点？** 有 → 这是有限游戏。没有 → 继续。
2. **规则是否固定，成员是否由资格筛选？** 是 → 这是有限游戏或社会游戏；找出其边界。否 → 继续。
3. **规则是否为了让参与者继续而能改变？** 是 → 这是无限游戏。否 → 可能是无边界名义下的有限竞争。
4. **新参与者加入会改变传统，还是被要求重复既定剧本？** 改变 → 文化视界；重复 → 社会边界。
5. **这套安排是否使某些人无声、无资格、被丢弃？** 是 → 检查权力或邪恶如何取消竞争、强迫认可。

## 关键规则与阈值

- 有限游戏规则：**游戏开始前公布并获得参与者认同**；特定规则在游戏进行期间改变，就成了另一场游戏。
- 无限游戏规则：**为了延续而改变**；不能把“无限”理解成随意更改任何规则。
- 规则的源头不是立法者、英雄或神的宣布，而是参与者自愿遵守。
- 有限游戏的空间、时间、数值边界须共同认可；越界会使胜利的合法性受质疑。
- 观众人数无关紧要，关键是观众是否共同急于见证胜负。
- 自然、死亡、资源等限制应被纳入游戏；无限并非没有限制，而是限制无法终结游戏。

## 危险信号

- “没有别的选择”“历史必然如此”“我们必须赢”——有限游戏把自由隐藏在必然性面具后。
- “唯一的正确历史 / 唯一的真理 / 只有我们能代表所有人”——意识形态正在把神话放大为单一声音。
- 头衔、财产、成功必须不断被展示和捍卫——已结束的过去在索要新的比赛。
- 工具越高效，操作者越像工具；技术让人看见但不被看见、移动却不被触动。
- 社会产生越来越多废弃物，却越来越大声地否认它——废弃物正在解蔽社会。
- 试图消除所有邪恶、制造唯一秩序——“消除邪恶的欲望”本身可能就是邪恶。

## 经典对照句

- 有限游戏以取胜为目的；无限游戏以延续游戏为目的。
- 有限游戏参与者在界限内游戏；无限游戏参与者与界限游戏。
- 惊奇导致有限游戏终止；惊奇是无限游戏继续的原因。
- 训练将过去视为已结束；教育将未完成的过去延续到未来。
- 社会由边界定义；文化由视界定义。
- 权力关乎已经发生的事情；力量关乎还未发生的事情。
- 自然是不能言说者的王国；神话激发解释，但不接受任何解释。
- 世上有且只有一种无限游戏。
