# Transaction Cost Impact — 交易成本影响评估

## R — 原文 (Reading)

> "E-迷你标普500的简单均值回归策略...不计交易成本时夏普比率大约为3——当然非常出色！不幸的是，如果扣除1个基点的交易成本，夏普比率则变成了-3，变成了完全无利可图的策略。"
>
> — Ernest P. Chan, 第2章 2.2.3

## I — 方法论骨架 (Interpretation)

交易成本是回测与实盘之间的 **死亡之谷**。作者把它拆成四类：

1. **佣金（Commission）**：券商收取的固定或按笔费用，最易估算。
2. **流动性成本（Liquidity Cost）**：买卖价差（bid-ask spread），低流动性标的尤为严重。
3. **市场冲击（Market Impact）**：你的订单本身推动价格反向运动，规模越大越严重。
4. **滑价（Slippage）**：下指令时的报价与实际成交价之差，含延迟和信号传播成本。

核心洞察：**高频、小持仓、高频换手的策略对成本最敏感**。学术策略通常忽略成本，回测夏普 4.47 扣 5bp 后变成 -3.19。
操作法则：
- 如果策略作者没说明是否包含成本，**假设他没考虑**。
- 估算时把每类成本单独列出来加总，不要用一个"模糊的 10bp"糊弄过去。
- 优先交易高流动性标的、限制单指令 ≤ 日均成交量 1%、用暗池执行、按市值四次方根分配资本。

## A1 — 书中的应用 (Past Application)

### 案例 1: Khandani-Lo 均值回归模型（ca013）
- **问题**: MIT 学者 Khandani 和 Lo 提出均值回归策略（买前日最差的股票、卖空最好的），1995 年以来回测表现卓越，2006 年夏普比率 4.47。
- **方法论的使用**: Chan 在回现时加入 5 个基点的每笔交易成本。
- **结论**: 夏普比率从 +4.47 骤降至 **-3.19**，完全无利可图。
- **结果**: 原因——策略主要收益来自小盘股/微盘股，流动性成本远高于假设；若只应用于 S&P 500 成分股（大盘），夏普仅 0.25。

### 案例 2: 清仓时点的微小调整（ca014）
- **问题**: 上一个案例因成本变得不可用，能否通过策略变形挽救？
- **方法论的使用**: 仅把"收盘时更新头寸"改为"开盘时更新头寸"。
- **结论**: 不考虑成本时夏普从 0.25 升至 1.43；考虑成本后从 -3.19 升至 **+0.78**，重新变得有利可图。
- **结果**: 证明交易成本是策略生死的分水岭，而通过"变形"有时能把策略从死亡线拉回来。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 回测夏普 3+，但实盘 3 个月持续小亏，怀疑是成本吃掉利润。
2. 准备复现学术论文策略，但论文未提交易成本。
3. 评估一个高频 / 日内 / 小盘股策略，判断成本是否致命。

## E — 可执行步骤 (Execution)

1. **列出策略的交易特征**：平均持仓期、日换手率、标的平均成交量、标的平均价格。
   - 完成标准：能计算"每笔交易规模 / 日均成交量"比例。

2. **逐项估算四类成本**：
   - 佣金：按券商报价单计算。
   - 流动性成本：取标的历史 bid-ask spread 均值。
   - 市场冲击：用"订单规模 / 日均成交量"经验公式（< 1% 可忽略，> 1% 必须建模）。
   - 滑价：取"信号生成时刻 vs 实际成交时刻"的价差回测数据。
   - 完成标准：四类成本分别给出"每笔 bp 数"和"年化占收益比例"。

3. **在回测中加入总成本重新计算 S**：对比"无成本 S"和"有成本 S"。
   - 完成标准：输出两张 S 值，并标注下降比例。
   - 判停条件：若"有成本 S" < 0，则该策略宣告不可行，停止进一步分析。
   - 判停条件：若"有成本 S"在 0-1 之间，标注"风险区"，建议优先做策略变形（参考 ca014）。

4. **成本最小化优化**（若仍可行）：限制单指令 ≤ 日均成交量 1%、用暗池、按市值四次方根分配资本。
   - 完成标准：输出优化后"有成本 S"，必须比步骤 3 更高。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 策略尚未回测——先回测，再来算成本。
- 策略是低频季度调仓、标的为大盘股 ETF——成本影响极小，不必逐项拆解。
- 比较两个策略的相对优劣时——去 `sharpe-ratio-supremacy`（成本应在两侧都已扣除后才可比）。

### 作者在书中警告的失败模式

- **ce07**: 忽略交易成本——学术策略回测亮眼但实盘亏损的常见原因。
- **ce13 / Khandani-Lo 案例**: 5bp 的成本让 S 从 +4.47 跌到 -3.19。

### 作者的盲点 / 时代局限

- 书中讨论的成本估算基于 2009 年美股市场（固定佣金、手工暗池）。2026 年加密市场有 maker/taker 反转、gas 费、MEV 等全新成本类别，书中未涉及。
- 市场冲击模型使用简单经验公式，未涉及 Almgren-Chriss 等更严谨框架。
- "按市值四次方根分配资本"是经验法则，未讨论在小市值股票极端流动性不足时的失效。

### 容易混淆的邻近方法论

- "扣完成本 S 仍然 > 1" ≠ 策略可行，还要考虑滑价非线性、极端行情下流动性枯竭。
- 佣金不是大头——很多人只算佣金，忽略流动性和冲击成本。
