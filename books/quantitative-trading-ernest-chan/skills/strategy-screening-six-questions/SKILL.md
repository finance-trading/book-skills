# Strategy Screening — 策略快速筛选六问法

## R — 原文 (Reading)

> "在投入大量时间回测前，先用六个问题快速筛选：跑赢基准了吗？夏普比率 >1？最大回撤可承受？无存活偏差？近年还有效？有特色避开竞争？任何一条答 No，就该淘汰。"
>
> — Ernest P. Chan, 第2章 2.2

## I — 方法论骨架 (Interpretation)

回测成本很高（几小时到几天），而 90% 的策略经不起严格检验。与其把时间浪费在注定失败的策略上，先用六个 Yes/No 问题做 **快速淘汰**：

1. **基准对照**：策略是否明确跑赢某个基准（SPY、同期无风险利率）？没有，则只是 Beta 伪装。
2. **夏普比率 > 1**：S < 1 意味着单位风险收益不够，不能单独使用，更无法安全加杠杆。
3. **回撤可承受**：最大回撤是否超过用户心理和资金的阈值？超过则实盘必因恐惧清仓。
4. **无存活偏差**：数据是否包含退市/破产股？否则业绩被系统性高估。
5. **近年有效**：近 3-5 年是否仍成立？金融序列非平稳，10 年前的光鲜数据已无参考价值。
6. **有特色**：策略是否交易"被机构忽略的小容量标的/时段"？否则已被竞争套利殆尽。

任何一条 No → 立刻停止。全部 Yes → 进入 `sharpe-ratio-supremacy` 和 `transaction-cost-impact` 做深度分析。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者筛选财富实验室论坛策略
- **问题**: 读者推荐了一个据称高夏普的策略，Chan 拿到后没有立刻投入大量时间回测，而是先用几个问题做快速检查。
- **方法论的使用**: 虽然六问在书中以清单形式呈现，但实际操作时 Chan 是先验证"近年有效"和"有特色"，再进入详细回测。
- **结论**: 初筛通过，但详细回测发现"完全没有声称的那样出色"——六问是必要非充分。
- **结果**: 虽然基础版本不合格，但 Chan 通过变形（缩短持有期、改开盘建仓）将其变成主要盈利来源。

### 案例 2: 读者否定作者推荐的季节性策略（ca007）
- **问题**: Chan 在博客推荐了一个金融学教授的季节性股票策略。
- **方法论的使用**: 读者迅速回测，发现近年已失效（问题 5 答 No），立刻淘汰。
- **结论**: 作者随后的回测证实读者正确——教授的策略早年有效，近年因竞争已失效。
- **结果**: 避免了作者可能的实盘损失，验证了"先用六问快速淘汰"比"详细回测后再判断"更高效。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 读到一篇论文/论坛帖/推特分享的策略，想知道"值不值得花 3 天写代码回测"。
2. 自己脑中出现一个新策略灵感，想快速自检可行性。
3. 面对一个 10+ 策略的清单，要挑出最值得深做的 2-3 个。

### 语言信号

- "这个策略值得回测吗 / is this worth backtesting"
- "怎么快速判断策略好坏 / how to quickly screen a strategy"
- "别急着写代码 / before I code this up"
- "六个问题 / six questions / 快速淘汰"
- "这个策略靠谱吗 / does this strategy sound legit"

### 与相邻 skill 的区分

- 与 `sharpe-ratio-supremacy` 的区别：本 skill 是 **二元筛选**（过/不过），后者是 **连续比较**（A 比 B 好多少）。
- 与 `backtest-dual-purpose` 的区别：本 skill 在回测之前；后者回答"回测之后怎么优化"。
- 与 `data-quality-traps` 的区别：本 skill 把数据问题作为六问之一（问题 4/5）；后者是深度排查数据陷阱的专门工具。

## E — 可执行步骤 (Execution)

1. **列出候选策略**：从论文、论坛、灵感中收集，每个策略一行描述（标的、频率、持仓期）。
   - 完成标准：每个策略能用一句话说明白"做什么、在哪做、多久做一次"。

2. **对每个策略逐一回答六个问题**：Yes/No，不允许模棱两可。
   - 完成标准：输出一个 N×6 的表格（策略 × 六问）。

3. **淘汰含 No 的策略**：任一问题答 No 即从候选池移除，记录淘汰原因。
   - 判停条件：若所有策略都被淘汰，则返回第 1 步重新搜集候选；不得放宽标准。

4. **对通过全部六问的策略**：转交给 `sharpe-ratio-supremacy` 做夏普比较，和 `transaction-cost-impact` 做成本核算。
   - 完成标准：交付一份 ≤ 3 行 × 策略的"通过清单"。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 策略已经回测完成且夏普、回撤数据齐备——直接去 `sharpe-ratio-supremacy`。
- 用户在做"策略变形/参数微调"——这属于 `backtest-dual-purpose` 或 `parameter-complexity-overfitting`。
- 纯信息收集（"有哪些经典策略"）——不属于本 skill。

### 作者在书中警告的失败模式

- **ce24**: 学术策略的局限性——过于复杂、已因竞争失效、所需数据昂贵、只对小盘股有效，常卡在问题 5/6。
- **ce09**: 只看收益率不看夏普比率——问题 2 直接过滤这类策略。

### 作者的盲点 / 时代局限

- 六问中的"近年有效"需要定义"近年"——书中未给出精确年数；2026 年实践建议至少 3 年、包含一个完整熊市。
- "有特色避开竞争"在 2009 年指小容量股票策略，2026 年加密/DeFi 领域的小容量策略同样适用，但书中未涉及。
- 六问是必要条件非充分条件——通过全部六问的策略仍可能在深度回测中失败（作者自己的财富实验室案例即如此）。

### 容易混淆的邻近方法论

- "六问全部 Yes" ≠ "策略可用"，只是"值得继续研究"。
- 与"快速拍脑袋判断"不同：六问每条都有可验证的数据支撑。
