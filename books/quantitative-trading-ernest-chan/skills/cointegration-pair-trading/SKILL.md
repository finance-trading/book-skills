# Cointegration Pair Trading — 协整性检验与配对交易构建

## R — 原文 (Reading)

> "许多配对交易员并不熟悉平稳性和协整性的概念。但他们中的大多数人却熟悉'相关性'，并且觉得与协整性似乎是同一个意思。实际上，这两个概念截然不同。...如果两个股票在目前与未来都是协整的，它们的价格（经过合适的权重）就不大可能会偏离，即使它们的日收益率可能不相关。...如果你认为同行业中的任意两只股票都是协整的，我可以给出一个反例：KO与PEP。ADF检验显示协整的可能性小于90%。"
>
> — Ernest Chan, 第7章 7.3节 line 4750-4823

---

## I — 方法论骨架 (Interpretation)

这个框架回答一个核心问题：**如何科学地构建配对交易策略，而不是凭直觉选"同行业股票"？**

方法论骨架：
1. **相关性 vs 协整性**：
   - **相关性**衡量的是两只股票**日收益率**在短期内的同向变动程度
   - **协整性**衡量的是两只股票**价格**在长期内偏离不会越来越大的关系
   - 关键洞察：正相关无法保证两只股票长期价格偏离不会越来越大。两只股票可以协整但不相关（图7-6虚构股票A和B），也可以相关但不协整。

2. **KO/PEP反例**：可口可乐与百事可乐——最"应该"协整的同行业配对——ADF检验显示协整概率小于90%，日收益率相关系数只有0.4849（统计学上不显著）。彻底证伪了"同行业=协整"的想当然。

3. **协整配对交易构建流程**：
   - **步骤1**: 用ADF检验（Augmented Dickey-Fuller test）确认差价序列平稳（协整）
   - **步骤2**: 用线性回归得到对冲比率（如GLD:GDX = 1:1.6766）
   - **步骤3**: 设定进出场阈值（通常为1倍或0.5倍标准差）
   - **步骤4**: 用Ornstein-Uhlenbeck公式估计半衰期，确定最优持有期
   - **步骤5**: 样本外测试验证稳健性

4. **GLD-GDX成功案例**：
   - GLD（黄金现货ETF）与GDX（金矿股ETF）高度相关且协整
   - 构建组合：1份GLD多头 + 1.6766份GDX空头 → 差价序列平稳
   - 训练集夏普2.3 → 优化阈值后升至2.9
   - 测试集夏普1.5 → 优化后升至2.1
   - 验证了协整配对交易的有效性

5. **数据陷阱警告**：
   - **异常报价**：历史数据库中的虚假低价会被均值回归策略"买入"，按正常价格"卖出"产生虚假盈利
   - **存活偏差**：极端低价股票破产后从数据库消失，策略"买入"后实际会亏100%，但回测看不到

关键洞察：**配对交易不是"找两只看起来相似的股票"，而是严格的统计检验流程**。必须用ADF检验确认协整性，而不是凭行业直觉或相关性。

## A1 — 书中的应用 (Past Application)

### 案例 1: GLD-GDX配对交易 (ca015)
- **问题**: 需要判断GLD（黄金现货ETF）与GDX（金矿股ETF）是否适合做配对交易。
- **方法论的使用**:
  1. 用协整分析确认差价序列平稳
  2. 用线性回归得到对冲比率（1份GLD多头 + 1.6766份GDX空头）
  3. 设定进出场阈值（1倍标准差建仓，0.5倍标准差清仓）
  4. 样本外测试验证
- **结论**: GLD和GDX确实协整，差价序列均值回归。
- **结果**: 训练集夏普2.3 → 优化后2.9；测试集夏普1.5 → 优化后2.1。验证了协整配对交易的有效性。

### 案例 2: KO与PEP不协整的反面教材 (c21)
- **问题**: 可口可乐(KO)与百事可乐(PEP)同行业，看起来"应该"协整，但真的协整吗？
- **方法论的使用**:
  1. ADF检验：统计量-2.14，大于10%临界值-3.038 → 协整概率小于90%
  2. 相关性检验：日收益率相关系数0.4849 → 统计学上不显著
- **结论**: KO/PEP不满足协整条件，不适合做配对交易。
- **结果**: 教育性地澄清了"同行业=协整"的常见误区。相关性≠协整性。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **协整性检验**
   - 完成标准: 用户能用ADF检验确认两只股票的价格差价序列平稳（协整）。
   - 方法:
     1. 获取两只股票的历史价格数据（无存活偏差数据）
     2. 用线性回归计算差价序列：z(t) = price_A(t) - h * price_B(t)
     3. 对z(t)进行ADF检验
     4. 若ADF统计量小于临界值（如-3.038为10%水平），则协整
   - 判停条件: 若协整检验通过，进入步骤2；若不通过，换其他股票对或放弃。

2. **计算对冲比率**
   - 完成标准: 用户能确定配对中两只股票的权重比例。
   - 方法: 用线性回归 price_A 对 price_B 回归，回归系数即为对冲比率 h。
   - 判停条件: 对冲比率确定，进入步骤3。

3. **设定进出场阈值**
   - 完成标准: 用户能确定建仓和清仓的阈值。
   - 方法:
     - 计算差价序列z(t)的均值μ和标准差σ
     - 建仓阈值：z(t)偏离μ超过1倍σ时建仓
     - 清仓阈值：z(t)回归到μ±0.5倍σ时清仓
   - 判停条件: 阈值确定，进入步骤4。

4. **估计最优持有期（半衰期）**
   - 完成标准: 用户能用Ornstein-Uhlenbeck公式估计半衰期。
   - 方法:
     1. 将dz(t)对(z(t)-μ)进行线性回归，得到参数θ
     2. 半衰期 = -log(2)/θ
     3. 半衰期即为最优持有天数
   - 判停条件: 半衰期估计成功，进入步骤5。

5. **样本外测试与数据质量检查**
   - 完成标准: 用户能确认策略在样本外数据上仍有效，且数据质量合格。
   - 方法:
     - 将数据分为训练集和测试集，分别回测
     - 彻底清除异常报价（虚假高价/低价）
     - 使用无存活偏差数据库
     - 加入交易成本（佣金、滑点、市场冲击）
   - 判停条件: 若样本外夏普比率仍>1且扣除成本后盈利，策略可用；否则返回步骤1重新优化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **单向多头策略**：本skill专做空多配对的均值回归策略，不适用于只做多头的策略。
- **非配对类均值回归**：如单一股票的均值回归（不配对），不需要协整检验。
- **基本面选股**：如果用户基于基本面分析（如价值投资）选股，不需要协整检验。

### 作者在书中警告的失败模式

- **pr-p2-019 - 异常报价和存活偏差人为拔高均值回测**: 均值回归策略买入虚假低价、按正常价格卖出产生虚假盈利。存活偏差隐藏了破产股票的亏损。**必须**在回测前彻底清除异常报价，使用无存活偏差数据。
- **ce04 - 存活偏差**: 极端价格股票被收购或破产后从数据库消失，导致均值回测业绩虚假抬高。
- **ce07 - 忽略交易成本**: 配对交易频繁进出，交易成本影响巨大。Khandani-Lo策略夏普从4.47降至-3.19。

### 作者的盲点 / 时代局限

1. **忽视了现代协整检验方法**: 书中仅用ADF检验，但2010年代后发展出Johansen检验、Engle-Granger两步法等更稳健的方法。
2. **未讨论高维协整**: 书中仅讨论两只股票的配对，但实际中可能涉及多只股票的协整关系（如ETF与一篮子成分股）。
3. **忽视了机器学习方法**: 可以用深度学习自动学习对冲比率和进出场阈值，而非固定线性回归。

### 容易混淆的邻近方法论

- **相关性 ≠ 协整性**: 相关性衡量短期收益率同向变动，协整性衡量长期价格偏离不会越来越大。
- **同行业 ≠ 协整**: KO/PEP反例证明同行业股票不一定协整。
- **协整 ≠ 永远盈利**: 即使协整，策略仍可能因交易成本、异常报价、状态转换而亏损。
