# Glossary

Terms are defined for study use. Chapter references are the skill's chapter files, not the PDF's page numbers.

**传染** - 观点、情绪或行为经社会互动扩散，不必然经过独立推理。(Ch 3, Ch 6)
**权威效应** - 地位、名望或机构身份额外影响判断可信度。(Ch 10, Ch 12)
**信念滞后** - 观念或正当性变化后，相关制度与习惯仍延续的现象。(Ch 7)
**匿名化** - 个体身份在集体中降低可见性，可能改变自我约束。(Ch 2, Ch 9)
**基本信仰** - 勒庞所称长期稳定、能塑造社会框架的共享观念。(Ch 7)
**刺激—暗示—传染链** - 刺激引发解释，解释被重复并在互动中扩散的机制。(Ch 3)
**短期意见** - 受情境与即时议题影响、较易变化的判断。(Ch 7)
**断言** - 直接提出主张，证据不足或被省略。(Ch 6, Ch 11)
**情绪夸张** - 情境中情绪趋于强烈、简单和极端的倾向。(Ch 3)
**反馈循环** - 结果反过来增强原有判断，使分歧被放大的过程。(Ch 3, Ch 6)
**群体幻觉** - 多人因共同预期和相互影响形成一致错误观察。(Ch 2, Ch 3)
**群体精神统一律** - 勒庞对群体成员思想、情绪趋同的命名。(Ch 2)
**归因** - 把结果分配给个人、情境或制度的分析过程。(Ch 1, Ch 9)
**制度化群体** - 有名称、角色、规则和责任的集体，如陪审团或议会。(Ch 8, Ch 10, Ch 12)
**经验学习** - 重复接触使观念变熟悉；熟悉不等于证据正确。(Ch 5)
**形象思维** - 以鲜明、具体、带情绪的场景组织判断和传播。(Ch 3, Ch 5)
**基本观念** - 长期塑造群体行为和社会结构的深层共享观念。(Ch 7)
**间接因素** - 为群体接受某类信念提供长期背景的制度、传统和教育等条件。(Ch 4)
**直接因素** - 在既有背景下推动观点具体化并促发行动的临近刺激或资源。(Ch 4, Ch 5)
**名望** - 人物、制度或观念因地位或声誉而对受众产生的影响力。(Ch 6, Ch 11)
**模仿** - 受他人行为影响而复制的过程。(Ch 3, Ch 7)
**民族偏见** - 书中过时且不可靠的固定民族心理假设；现代分析应使用可检验条件。(Ch 4, Ch 8)
**群体** - 在共同刺激与互动下，成员反应趋于一致的集体状态；人数本身不足为据。(Ch 2)
**群体极化** - 讨论使共同意见比成员初始立场更极端的现代研究现象；非勒庞原术语。(Ch 3, Ch 10)
**去个体化** - 个人身份与独立判断在群体情境中减弱。(Ch 2)
**路径依赖** - 既有制度与习惯限制后续选择的现象。(Ch 4, Ch 7)
**套话** - 高频使用、能唤起共同形象但含义可能简化的表达。(Ch 5, Ch 11)
**审议** - 成员交换信息、形成集体决定的过程。(Ch 10, Ch 12)
**舆论** - 在公共传播中形成或表达的集体判断；可见表达不等于全体成员意见。(Ch 7)
**暗示** - 未经验证便形成的接受倾向。(Ch 2, Ch 3)
**意见简化** - 复杂议题被压缩成易于表态的对立选项。(Ch 12)
**议程设置** - 决定哪些问题、事实和方案进入正式讨论。(Ch 12)
**短期主义** - 对近期反应的关注压过长期后果评估。(Ch 12)
**群体时代** - 群众组织、舆论与行动成为社会政治力量的历史阶段。(Ch 1)
**社会认同** - 个体因群体归属而调整判断、情绪或行为。(Ch 2, Ch 9)
**心理群体** - 个体思想与情绪在互动中趋同并形成集体反应的状态。(Ch 2)
**相互传染** - 情绪、行为或看法经社会互动扩散。(Ch 3)
**异质性群体** - 成员背景、职业或教育差异较大的群体。(Ch 2, Ch 8)
**同质性群体** - 成员因信仰、职业或社会地位而较接近的群体。(Ch 2, Ch 8)
**责任分散** - 多人参与时个人感到责任减轻。(Ch 3, Ch 9)
**重复** - 反复呈现同一主张以增强熟悉度和记忆。(Ch 6)
**重复效应** - 信息因多次出现而显得更熟悉、更可信的现象。(Ch 6, Ch 11)
**基本观念** - 长期且稳定的社会性观念，与短期意见相对。(Ch 4, Ch 7)
**稳定信念** - 能长期塑造社会结构、较不易被单一事件改变的共享观念。(Ch 7)
**易变意见** - 表面流动、受情境驱动的短期判断。(Ch 7)
**领袖** - 为分散个体提供方向、号召或协调的人。(Ch 6)
**个人名望** - 与个人能力、声誉或社会地位相关的声望。(Ch 6, Ch 11)
**制度化名望** - 来自职位、称号或身份的权威。(Ch 6)
**无名称群体** - 临时聚集、组织与责任程度较低的人群。(Ch 8)
**有名称群体** - 具有制度身份、规则和责任的集体。(Ch 8)
**派别** - 以共同信仰或政治主张为主要纽带的同质性群体。(Ch 8)
**身份团体** - 以职业或社会角色为核心的同质性群体。(Ch 8)
**阶级** - 由相近社会处境、利益和生活条件形成的同质性群体。(Ch 8)
**犯罪群体** - 勒庞对实施集体暴力或违法行为的心理群体的称呼。(Ch 9)
**陪审团** - 由若干公民组成、对案件事实作出判断的制度化集体。(Ch 10)
**选民群体** - 承担选举选择的群体。(Ch 11)
**议会** - 通过议事、辩论和表决处理公共事务的代议机构。(Ch 12)
**理性论证** - 基于证据、逻辑和利益权衡的说服方式；其效果受信任、证据与语境限制。(Ch 5, Ch 10)
