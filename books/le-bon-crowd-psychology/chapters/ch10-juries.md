# Chapter 10: 陪审团

## Core Idea
勒庞把刑事陪审团视为有名称、有责任的异质性群体，认为其判断会受情感、名望和群体互动影响。现代应用应把这些观察转化为程序保障：证据展示、审议规则、偏见控制和可复核性，而不是得出“群体不能推理”的结论。

## Frameworks Introduced
- **陪审判断的情境影响**：审议结果可能受叙事、情绪、权威和群体互动影响。
  - When to use: 设计或评估陪审程序、证据呈现和审议质量。
  - How: 分开事实、法律标准与情感叙事；要求证据来源可追溯；记录异议；避免由个别成员垄断解释。
- **关键影响者**：少数积极成员可能不成比例地引导讨论。
  - How: 确保每人有独立发言和提问机会，使用结构化审议而非先形成公开立场。
- **陪审与职业法官的比较**：作者认为两者都可能犯错，陪审可在严格法律之外考虑情境。
  - How: 比较时要依据管辖区的证据规则、上诉机制和实证结果，不能只依赖19世纪逸事。

## Key Concepts
- **有名称的异质性群体**：成员背景不同但有正式身份与职责的集体。
- **审议**：成员交换信息并形成集体决定的过程。
- **情感证据**：能激发同情、愤怒或恐惧、但不一定增加事实证明力的材料。
- **权威效应**：专家、地位或声誉对判断产生的额外影响。
- **群体极化**：讨论后意见可能比讨论前更极端的现象；此为现代补充概念，不是勒庞原术语。

## Mental Models
把陪审团决定看成信息、程序和互动的产物。评估质量时问：成员是否独立接触证据、是否理解证明标准、异议是否被听见、结论是否可由记录复核。

## Anti-patterns
- **用故事或身份替代证据**：鲜明叙事和被告名望都可能偏转判断。
- **让最先发言者定义事实**：早期公开立场会锚定后续讨论。
- **把作者对智力无用的判断绝对化**：专业知识和程序设计可以改善集体判断。

## Worked Example
在审议开始前，先让成员独立列出已证明事实、未证明主张和适用标准；讨论时逐项核对来源，再处理争议。这样可以降低一个人的情绪化叙述或权威语气主导全体结论的风险。

## Key Takeaways
1. 陪审质量取决于程序，而非“群体”这个标签。
2. 情感、名望和强势发言者是需要管理的偏差来源。
3. 独立记录事实与法律标准，再进行集体讨论。
4. 对法官和陪审团都应使用可检验的错误与纠错机制。
