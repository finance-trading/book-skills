# Chapter 8: 群体的分类

## Core Idea
勒庞按成员构成和共同纽带把群体分为异质性群体与同质性群体，并进一步区分派别、身份团体和阶级。分类可帮助提出研究问题，但书中把民族差异归为固定种族禀性的做法没有现代科学依据。

## Frameworks Introduced
- **群体分类**：按成员差异和共同纽带区分临时人群、有组织群体与较稳定的社会团体。
  - When to use: 选择观察对象或比较不同集体的行为。
  - How: 记录成员构成、共同目标、组织程度、规则、责任和成员进出机制；避免只根据人数或名称分类。
- **派别、身份团体、阶级**：勒庞分别以共同信仰、共同职业或共同社会利益解释三类同质性群体。
  - How: 现代研究应把这些标签当作起点，进一步验证成员身份、利益、规范和权力结构。

## Key Concepts
- **异质性群体**：成员职业、教育、背景差异较大的群体。
- **同质性群体**：勒庞所称成员因信仰、职业或社会地位而较接近的群体。
- **派别**：以共同信仰或政治主张为主要纽带的团体。
- **身份团体**：以职业或社会角色为核心的团体。
- **阶级**：以相近社会处境、利益和生活条件形成的群体。
- **有名称的群体**：如议会或陪审团等有制度身份、规则和责任的集体。
- **无名称的群体**：临时聚集、组织程度较低的人群。

## Mental Models
分类不是解释本身。先描述共同纽带和制度约束，再比较行为；民族、阶级或职业差异必须由可观察条件解释，而非先天本质。

## Anti-patterns
- **把种族或民族当作固定心理原因**：书中的民族比较属于过时理论，不能作为当代结论。
- **把职业或阶级成员视为心理上完全同质**：群体内部仍有利益和意见差异。
- **名称即机制**：有正式名称不自动说明责任、决策质量或凝聚力。

## Worked Example
比较街头集会、行业工会和议会委员会：分别记录成员如何进入、是否有规则与问责、目标是否明确、异议如何处理。若只说三者都是“群体”，会掩盖组织、责任和权力差异。

## Key Takeaways
1. 用共同纽带、组织和责任区分群体，而不是只看规模。
2. 派别、职业团体和阶级的内部差异仍然重要。
3. 制度身份可能带来责任，但不保证判断质量。
4. 拒绝以种族本质解释群体差异。
