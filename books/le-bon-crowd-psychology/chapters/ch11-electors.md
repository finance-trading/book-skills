# Chapter 11: 选民群体

## Core Idea
勒庞认为选民在候选人之间作选择时，容易受名望、重复口号、断言和群体传染影响，而复杂纲领不一定被持续检验。现代阅读应把它作为选举传播风险清单：提高信息可核查性和问责，而不是学习如何操纵选民。

## Frameworks Introduced
- **选举说服的风险因素**：知名度、简单承诺、重复攻击和群体认同都可能影响选择。
  - When to use: 评估竞选信息、选民教育和政治传播。
  - How: 把候选人主张拆成可验证承诺、成本、权限和期限；追踪攻击性断言的证据；比较多个独立信息源。
- **纲领的可检验性**：口头承诺如果无法观察执行情况，就难以约束当选后的行为。
  - How: 记录承诺的具体内容、负责机构、衡量指标和复核时间，而不是只保留口号。
- **委员会与组织影响**：作者指出政治组织能塑造选项和舆论；现代分析应同时看候选人、媒体、资金、选举规则和选民结构。

## Key Concepts
- **选民群体**：勒庞对承担选举选择的集体的称呼。
- **名望**：候选人既有声誉或社会地位带来的注意力与信任。
- **断言**：缺乏充分证据却被反复提出的判断。
- **套话**：能激活认同但含义宽泛的政治用语。
- **承诺可验证性**：主张能否通过后续事实检验。
- **选举问责**：选民依据实际表现而非初始口号评价当选者。

## Mental Models
把竞选信息分成事实主张、价值号召和情绪攻击。事实主张要有来源和复核日期；价值号召不能代替权限与成本；情绪攻击要检查是否提供可核对证据。

## Anti-patterns
- **用重复指控代替证据**：熟悉的负面标签不是事实。
- **把无法检验的宏大承诺当作选择依据**：缺少指标、成本和责任人的承诺难以问责。
- **把本书的说服描述用作操纵选民的方法**：合法的政治传播应便于核查和反驳。

## Worked Example
评估一名候选人的三项承诺：每项写下目标、预算或代价、法定权限、完成期限和公开数据来源。无法填写这些内容的承诺先标记为不可验证；再单独记录其口号吸引了哪些群体认同。投票研究因此同时看政策内容与传播效果。

## Key Takeaways
1. 名望和重复影响注意力，但不证明能力或主张为真。
2. 把竞选承诺转成可验证、可追责的内容。
3. 检查攻击性断言的原始证据和独立来源。
4. 使用本章识别选举传播风险，不用于设计欺骗。
