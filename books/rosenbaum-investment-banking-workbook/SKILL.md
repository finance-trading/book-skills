## Core Frameworks and Mental Models

### Build a comparable-company analysis from claims upward
Choose an economically relevant peer set, align financial periods, calculate fully diluted shares, derive equity value and enterprise value, normalize operating metrics, and calculate matching multiples. Use TSM for in-the-money options: net new shares equal in-the-money option shares less shares repurchased with proceeds. EV multiples pair with operating measures; equity multiples pair with equity earnings. Explain why the target merits a discount or premium rather than treating a peer median as an answer. See [Chapter 1](chapters/ch01-comparable-companies-analysis.md).

### Treat transaction precedents as negotiated outcomes
Build transaction value consistently, normalize the target metric, and compare deal date, buyer type, competitive process, strategic fit, and financing conditions. Control premium is not synonymous with synergy. A small, highly comparable set is usually more informative than a large list of superficially similar deals. See [Chapter 2](chapters/ch02-precedent-transactions-analysis.md).

### Make a DCF internally consistent
Forecast operating drivers through EBIT, operating taxes, D&A, capex, and working capital to derive FCFF. Discount FCFF at WACC; add a terminal value consistent with sustainable growth and reinvestment; then bridge EV to equity by accounting for debt-like claims and cash once. Sensitize assumptions—especially terminal growth, WACC, margins, and reinvestment—rather than presenting a false point estimate. See [Chapter 3](chapters/ch03-discounted-cash-flow-analysis.md).

### Separate LBO business quality, financing, and return math
Screen cash-flow durability and downside debt service before considering leverage. Reconcile sources and uses; forecast cash available after operating needs and financing costs; roll forward debt by tranche; calculate exit equity proceeds; measure both MOIC and time-sensitive IRR. Return attribution should distinguish operating performance, debt paydown, entry price, and exit multiple. See [Chapters 4](chapters/ch04-leveraged-buyouts.md) and [5](chapters/ch05-lbo-analysis.md).

### Optimize M&A outcomes, not headline numbers
For a seller, stage information, preserve confidentiality, and compare complete bids by value, conditions, financing, timing, and closing certainty. For a buyer, establish standalone value and a walk-away price; add only risk-adjusted synergies net of implementation cost; translate diligence findings into model changes and protections. EPS accretion is not proof of value creation. See [Chapters 6](chapters/ch06-sell-side-ma.md) and [7](chapters/ch07-buy-side-ma.md).
