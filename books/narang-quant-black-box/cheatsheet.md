# Cheatsheet

| 情况 | 决策 | 原因 / 代价 |
|---|---|---|
| 回测收益高 | 核实信息时点、独立检验、搜索次数和成本 | 历史拟合可能来自未来信息或多重试验 |
| 多个证券看似分散 | 检查共同因子与压力下相关性 | 不同名称可能承受同一种风险 |
| 信号弱或衰减快 | 比较可实现收益与规模相关的成本 | 毛收益可能不足以覆盖换手与冲击 |
| 大额订单 | 按紧迫性与盘口深度权衡立即成交和分批 | 成交速度、冲击和未成交风险相互制约 |
| 极端预测驱动大头寸 | 检查单位、异常值、约束与输入敏感性 | 优化器会放大错误输入 |
| 管理人只展示夏普 | 追问机制、风险、成本、容量与组织控制 | 历史单指标不能解释未来失效机制 |
| 听到“高频” | 先区分做市、套利、快速阿尔法与执行 | 不同机制有不同收益、风险和法规问题 |
| 想降低延迟 | 先测量全链路瓶颈并保留风控 | 速度只有在改变执行经济性时才有价值 |
| 市场结构或监管问题 | 查当前规则与独立证据 | 书中论证具有出版时代背景 |

**阈值**：书中 3% 单一头寸上限是说明硬约束的例子，不是通用推荐。
