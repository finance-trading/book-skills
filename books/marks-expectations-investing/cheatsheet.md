# Decision Cheatsheet

## 三步驟
| 順序 | 核心問題 | 輸出 |
|---|---|---|
| 1. 解讀價格 | 現價要求哪些現金流、利潤率、投資與持續年限？ | 市場隱含基準 |
| 2. 找修正 | 哪個觸發因素可能改變？因果證據和領先指標是什麼？ | Turbo trigger與情境 |
| 3. 決策 | 機率加權價值相對價格是否足夠有利？下行能否承受？ | 買進、賣出、持有或等待 |

## if / then 規則
- 若預期成長的增量報酬低於資金成本，則不要把成長當利多；它可能毀損價值。
- 若自己與市場的差異無可驗證觸發因素，則視為觀點而非投資優勢。
- 若預期價值略高於價格但分布窄、下行大，則安全邊際不足，等待或放棄。
- 若情境分布寬，上行尾部可使期望值有吸引力，但要檢查尾部機率和資金承受力。
- 若研究變數很多，先測銷售情境；只深入分析足以改變股東價值的成本/投資觸發因素。
- 若新資訊、價格大幅變動或管理層改組出現，則重新反解價格隱含預期，而非沿用舊結論。
- 若宏觀預測是個股論點唯一支柱，則降低信心；若宏觀看法確有優勢，優先思考資產配置。

## 事件快檢
| 事件 | 問題 |
|---|---|
| 併購 | 綜效現值是否超過溢價？誰承擔失敗風險？EPS變化是否只是估值差異？ |
| 回購 | 價格低於價值嗎？是否犧牲更好投資或流動性？稀釋有無抵銷？ |
| 高層更替 | 新團隊能否改變經營、策略或資本配置？市場預期已多低？ |
| 極端股價波動 | 新資訊改變了哪個觸發因素？參考類別和路標怎麼說？ |
| 新法規/訴訟/外部衝擊 | 對銷售、成本、投資、負債和競爭優勢的金額影響為何？ |

## 反偏誤提示
- 用數字機率取代「可能」；寫下預測並追蹤校準。
- 建立基準率，再加入公司特有證據；不要只用內部觀點。
- 事前驗屍：假定論點失敗，列出最可能的原因與早期路標。
- 會計盈餘、EPS增厚、股票拆分、管理層宣稱均非價值本身。
- 歷史案例及統計以書中年代為準；現在的市場與公司事實須另行核實。
