# Chapter 12: 把握投資機會

## Core Idea
將預期投資法用於具體事件，並把模糊判斷轉為可追蹤的機率、路標和重新評估觸發條件。

## Frameworks Introduced
**概率紀律**：寫數字機率並追蹤校準；用事前驗屍找失敗路徑；追蹤領先路標。重大事件（宏觀、管理層、股利/回購/發股、訴訟、法規、剝離、極端波動）都映射回銷售、成本、投資和資本成本。

## Key Concepts
- **核心主題**：事前驗屍、機率校準、路標、分拆、極端波動。
- **應用邊界**：結論取決於市場已定價的預期與可驗證證據，而非單一指標。

## Mental Models
逐一量化事件對三類觸發因素及六項價值因子的影響；用參考類別衡量極端波動。管理層更替和資產剝離可重設預期；發股/回購及股利帶有訊號但不必然產生價值。原書的歷史數據和案例截止約2020，僅作方法示例。

## Anti-patterns
- **用「可能」「很有機會」逃避機率；把專家宏觀預測當確定；情緒化處理暴漲暴跌；把股票拆分等不改變現金流的行動當價值變化；忽略資產出售可能以縮小換取增值。**

## Worked Example
投資前召集逆向審查：假設一年後投資失敗，每人獨立列出原因；再為關鍵事件設定機率與可觀察路標。若銷售成長超過10%的機率估為70%，事後記錄是否發生，以長期校準判斷品質。

## Application Protocol
把新信息转换成现金流驱动因素：宏观冲击影响行业地图和需求/成本；管理层变化可能重新设定策略和资本配置；股利、回购、发股及拆股各自含有不同讯号；诉讼会增加负债并损害声誉与未来现金流；监管或贸易壁垒改变竞争成本；卖出资产可能以缩小规模提高价值。极端股价波动时暂停情绪反应，重做隐含预期、触发因素、情境机率和投资论点检查表。

## Key Takeaways
1. 先以價格還原市場基準，再提出差異判斷。
2. 把差異判斷落在經營因果和價值驅動因子上。
3. 用情境、機率及價格比較形成可重估的決策。
