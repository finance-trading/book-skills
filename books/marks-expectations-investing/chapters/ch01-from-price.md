# Chapter 1: 一切從股價開始

## Core Idea
從股價反推出市場必須相信的長期現金流量，再判斷預期修正，而不是直接預測未來並把自己的估值當答案。主動投資的機會是市場預期錯置，不是公司品質本身。

## Frameworks Introduced
**預期投資法**：比較價格隱含預期與可能修正。
  - When to use: 評估個股、基金經理人或公司重大資本決策。
  - How: 解讀目前價格 → 找預期修正來源 → 評估價值並決定買進、賣出或持有。
- **盈餘成長不等於價值創造**：只有投資回報高於資金成本的成長才增加價值。

## Key Concepts
- **核心主題**：價值、股價、盈餘成長、預期錯配。
- **應用邊界**：結論取決於市場已定價的預期與可驗證證據，而非單一指標。

## Mental Models
價格是市場集體預期的可觀測表達。超額收益來自預期錯配，而非只發現「好公司」。盈利報表只是價值線索，不能取代現金流與再投資分析。

## Anti-patterns
- **傳統盈餘指標忽略長期現金流、再投資與市場已定價的基準；依故事選股卻不核對價格；把好公司直接當成好股票。**

## Worked Example
例：某公司投入 1,500 萬美元，使銷售增加 10%，但增量現金流按 8% 資金成本折現後恰等於投資額，則盈餘增長、股東價值不變。若增量報酬低於資金成本，盈餘仍可上升但價值下降。

## Application Protocol
先把市场基准、自己的判断与证据分开记录：价格代表当前交易者集体愿意交换的条件，不意味着市场拥有完美信息，也不意味着它必然错误。主动投资需要判断市场预期将怎样变化，而非只判断公司未来会不会增长。书中指出，短期盈余对长期价值代表性有限；对无形投入、再投资需求大的企业尤其如此。**校验**：如果论点只说公司「优秀」或「成长快」，尚未解释价格为何低估未来。

## Key Takeaways
1. 先以價格還原市場基準，再提出差異判斷。
2. 把差異判斷落在經營因果和價值驅動因子上。
3. 用情境、機率及價格比較形成可重估的決策。
