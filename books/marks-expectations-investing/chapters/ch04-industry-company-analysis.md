# Chapter 4: 如何分析產業與企業？

## Core Idea
競爭策略分析有雙重用途：管理者用來改善競爭地位，投資者用來預測市場預期將如何改變。歷史資料提供基線與現實檢查，不是機械外推。

## Frameworks Introduced
**策略—預期連結**：讀取歷史驅動因子 → 找到變化來源 → 評估產業結構、競爭者與策略執行 → 推斷銷售、成本、投資如何變 → 映射到價格隱含預期。分析價值鏈各環節及價值捕捉者。

## Key Concepts
- **核心主題**：競爭優勢、價值鏈、產業地圖、預期修正。
- **應用邊界**：結論取決於市場已定價的預期與可驗證證據，而非單一指標。

## Mental Models
先問企業如何創造並捕捉價值，再問優勢是否可持續、價格是否已反映。辨認策略改變的可驗證證據，區別產業順風與公司特有能力。歷史對照用來發現可疑假設，不能代替因果解釋。

## Anti-patterns
- **只因企業護城河強就預期股票超額報酬；忽略競爭者反應、替代品、買方議價力或產能限制；不檢查歷史到未來的斷點。**

## Worked Example
若公司降價以分享成本節省，單位毛利可能下降，但銷量上升；須評估量增、組合、利潤率及競爭反應的合計價值，而不是單看降價或成本節省。

## Application Protocol
**三层策略分析**：先画产业地图，列供应商、客户、竞争者和替代方案；再评估市场增长、供需、创新、监管、进入壁垒、竞争和获利结构；最后检查公司自身产品质量、技术、成本、定价、品牌和渠道选择及执行。稳定产业的历史数据更能提供基线；快速变化或新兴产业需要降低历史外推权重。公司创造价值并不代表其股票有吸引力，仍需对照市场预期。

## Key Takeaways
1. 先以價格還原市場基準，再提出差異判斷。
2. 把差異判斷落在經營因果和價值驅動因子上。
3. 用情境、機率及價格比較形成可重估的決策。
