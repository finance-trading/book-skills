# Chapter 3: 預期的基礎架構

## Core Idea
不要只改變模型的利潤率假設；追問造成改變的經營原因。從具體觸發事件，經由因果機制，推到財務驅動因子與股東價值。

## Frameworks Introduced
**三層預期架構**：價值觸發因素（銷售、成本、投資）→價值因子→經營價值驅動因子（銷售成長、營業利益率、投資增加率）。六項價值因子：數量、價格與產品組合、營運槓桿、規模經濟、成本效率、投資效率。

## Key Concepts
- **核心主題**：營運槓桿、規模經濟、門檻毛利率、價值因子。
- **應用邊界**：結論取決於市場已定價的預期與可驗證證據，而非單一指標。

## Mental Models
逐層說明觸發事件如何改變數量、定價組合、固定成本分攤、規模採購、成本流程或資本效率；再更新銷售成長、利潤率及投資率。以歷史數據和競爭情況檢驗鏈條。銷售成長只有在增量報酬超過資金成本時才創造價值。

## Anti-patterns
- **把相關性當因果；將營運槓桿與規模經濟混為一談；只跑敏感度表而不解釋變數為何會變；假設銷售成長必然創造價值。**

## Worked Example
銷量增加可能帶動營收，但若產品組合轉向低毛利，利潤率未必改善；固定產前成本暫時不變時，銷量提升會產生營運槓桿。反之，到產能上限需再投資時，增長可能需要新成本。先描述觸發因素，再估計利潤率變化。

## Application Protocol
**六因子因果检查**：数量变化是否来自份额或行业需求？价格/组合改变会怎样影响单位毛利？产前成本是否已投入、产能是否逼近上限？采购、生产或配送规模经济会否被组织复杂度抵销？成本效率来自流程重组还是一次性削减？投资效率是否减少资本而未损害增长？按这条链把证据映射到经营驱动因子，避免把同一收益重复算入多个因素。

## Key Takeaways
1. 先以價格還原市場基準，再提出差異判斷。
2. 把差異判斷落在經營因果和價值驅動因子上。
3. 用情境、機率及價格比較形成可重估的決策。
