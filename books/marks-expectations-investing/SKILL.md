## Core Frameworks & Mental Models

### Expectations Investing: three steps
1. **Read the price**: reverse the valuation model to estimate the long-run sales growth, margins, investment and duration required to justify the current share price. This is a description of consensus, not a claim that consensus is right.
2. **Find expectation revisions**: identify the value trigger—sales, operating costs or investment—then map it through the six value factors (volume; price/mix; operating leverage; economies of scale; cost efficiency; investment efficiency) into sales growth, operating margin and incremental investment. Prioritize the “turbo trigger” that can move shareholder value most. Use competitive analysis to test whether the change is plausible and persistent.
3. **Decide**: build plausible scenarios, use reference-class base rates to assign explicit probabilities, calculate expected value and compare it with price. Require a sufficiently large, evidence-backed expectation mismatch; account for downside and uncertainty. Revisit when new information, extreme price moves, or management changes alter the implied baseline.

### Price is the starting point, not the answer
Use reverse DCF to ask what must be true for the market price to make sense. Avoid replacing this with short-term EPS or a P/E multiple. Keep market-implied assumptions separate from your own forecast to avoid circular reasoning.

### Trace causes, not just model sensitivities
A sensitivity table tells how value changes when an assumption changes; the expectation architecture asks why it should change. Trace observable trigger → economic value factor → financial driver → shareholder value. Historical performance is a base and reality check, not a mechanical forecast.

### Growth creates value only above the cost of capital
Revenue and earnings growth alone do not establish value creation. Incremental returns must exceed the cost of capital. Growth below that threshold can increase reported earnings while destroying shareholder value.

### Use outside view and probability discipline
Use reference classes to counter optimistic inside-view forecasts. State probabilities numerically, log the outcomes, and calibrate over time. Run a premortem to surface failure paths. The expected value is a summary of a distribution, not a promise or a substitute for downside analysis.

### Value flexibility selectively
Use ordinary DCF for the existing business and normal growth. Add real-option value only for distinct opportunities that grant a genuine right—not obligation—to expand, enter adjacent markets, stage investment or abandon a project. Consider reflexivity when share price can change financing, talent, customer or investment outcomes.

### Analyze capital allocation by economics
For acquisitions, value creation is present value of synergies less premium; EPS accretion is not proof. Assess integration evidence and who bears synergy risk under cash versus stock consideration. For buybacks, ask whether shares are below intrinsic value and whether repurchase is better than reinvestment or balance-sheet resilience.
