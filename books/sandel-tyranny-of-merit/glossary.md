# 术语表

- **差异原则** — 罗尔斯的主张：自然才能的分配应视为共同资产，不平等只有在改善最不利者处境时才正当（ch09）。
- **成功伦理** — 把市场成功视为个人努力与美德的证明，并据此评判赢家与输家的道德体系（ch07、ch09）。
- **成功神学** — 认为上帝以财富与健康奖励信仰的基督教流派；把恩赐与应得的界限模糊化（ch06）。
- **程序公平** — 竞争规则对所有人一致；桑德尔指出程序公平不能自动推出结果在道德上应得（ch04）。
- **抽签录取** — 达到基本学术门槛后以抽签决定录取；把成绩当门槛而非最大化目标，以削弱精英傲慢（ch02、ch10）。
- **大学溢价** — 大学毕业生相对高中毕业生的收入优势；近几十年显著扩大（ch11）。
- **道德应得** — 因美德、努力或贡献而“理应”获得回报的强主张；罗尔斯认为市场结果不证明道德应得（ch09）。
- **道德任意性** — 天赋、家庭、出生地、时代等影响成功却不能归功于个人的因素（ch09）。
- **文凭主义** — 以大学文凭判断人的能力、价值与可信度的偏见；被称为“最后可接受的偏见”（ch08）。
- **分配正义** — 关注收入、财富与机会如何在社会成员间分配（ch11）。
- **分类机器** — 把高等教育变成按学业能力筛选、排序并分配社会尊重与机会的制度（ch10）。
- **贡献正义** — 关注谁因对公共利益的贡献而赢得承认与尊重，而非仅关注收入分配（ch02、ch11）。
- **公民概念（公共利益）** — 公共利益不是消费者偏好之和，而是公民共同商议、批判性反思并培养美德的产物（ch11、ch12）。
- **工作尊严** — 工作不仅是谋生，也是为他人所需之物作出贡献并赢得社会承认的舞台（ch11）。
- **公共利益（共同善）** — 一个政治共同体共同追求的目标与善；不能简化为 GDP 或消费者福利（ch12）。
- **技术官僚** — 把有争议的道德与政治问题交给专家、以效率与“优质信息”取代民主辩论的治理方式（ch05、ch08）。
- **阶层跃升话语** — “只要你努力，就能成功”的政治修辞；把机会平等、个人责任与应得绑定（ch07）。
- **绝望而死** — 凯斯与迪顿提出的概念：因自杀、吸毒过量与酒精性肝病导致的死亡，集中于无学士学位者（ch11）。
- **合法期望 / 正当期待的权益** — 在公平规则下有权得到的收益；不等于因美德而道德应得（ch09）。
- **精英的傲慢** — 成功者把成功归功于自己、低估运气与他人帮助，并轻视不如自己者的态度（ch05）。
- **民粹主义** — 对精英与既有秩序的反弹；桑德尔强调它同时是经济抗议与尊严抗议（ch05）。
- **生产者 vs 消费者** — 消费者视角把公共利益视为偏好满足；生产者视角把工作视为贡献与承认的舞台（ch11）。
- **市场价值** — 市场愿意为产品或服务支付的价格；受供需与偶然性影响，不等于道德价值（ch09、ch11）。
- **天命论** — 把世俗成功、灾难或国家伟大解释为神意或道德优越的证明（ch06）。
- **羞辱政治** — 失败者不仅怨恨赢家，还怀疑自己活该失败的政治情感结构（ch05）。
- **天赋 / 才能** — 个人拥有的能力；其分配是道德上任意的，不能单独证明应得（ch09）。
- **优绩（merit）** — 才能、努力与成就的组合；优绩制据以分配机会与回报（ch09）。
- **优绩主义 / 优绩制（meritocracy）** — 社会与经济奖赏应依据才能、努力与成就分配的制度理想（ch01、ch05）。
- **优绩至上** — 把优绩制从制度原则扩展为整套成功观、责任观与尊重分配方式（ch05、ch07）。
- **运气平等主义** — 主张补偿由坏运气而非坏选择造成的不幸；桑德尔批评它把帮助变成对受害者的审查（ch09）。
- **责任（个人责任）** — 优绩制话语把命运归因于个人选择；桑德尔区分道德责任与对全部命运的无限责任（ch07）。
- **前门 / 后门 / 侧门** — 前门凭成绩录取；后门靠校友与捐赠；侧门靠舞弊与贿赂（ch04）。
- **成功** — 本书追问的核心：成功是个人功劳、运气、社会奖励，还是三者混合（ch01、ch12）。
- **失败者** — 优绩制话语中被判定为咎由自取的人；其屈辱是民粹反弹的燃料（ch05）。
- **赢家** — 在优绩竞争中胜出的人；其傲慢与焦虑是优绩制暴政的另一面（ch05、ch10）。
