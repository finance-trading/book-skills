# 桑德尔决策速查

## 核心决策规则

| 遇到什么 | 桑德尔式判断 | 核查要点 |
|---|---|---|
| “成功全靠自己” | 先拆分家庭、教育、时代与市场偏好中的运气成分 | 哪些因素个人真正可控？“我应得”能否改写为“我受益于”？ |
| 以学历判断人 | 区分“完成某任务的证据”与“人的价值” | 是否把大学文凭当作道德资格？非大学路径是否获得同等承认？ |
| 用工资衡量贡献 | 分开市场价值与道德价值 | 供需与运气解释了价格，不能自动解释道德重要性 |
| 政策争论只剩“聪明/愚蠢” | 恢复道德与公民论证 | 是否把价值观分歧伪装成技术问题？利益相关者是否被排除在协商外？ |
| 民粹主义反弹 | 同时诊断经济不平等与社会承认缺失 | 排外言论背后是否有合理的尊严诉求？政策是否既补偿收入又恢复承认？ |
| 精英分类（大学、招聘、竞赛） | 检查对获胜者与落选者的双向伤害 | 是否产生完美主义、羞耻与社会排斥？能否用抽签或多路径认证减压？ |
| “机会平等就够了” | 问没有向上流动的人是否能在原地过上有尊严的生活 | 机会平等是补救，不是理想；需要生活境况平等作为公共目标 |
| 经济增长目标 | 问公共利益是消费者偏好之和，还是公民共同商议的善 | 生产者的工作尊严、技能培养与公共空间是否受损？ |
| 税制 | 既看财政与效率，也看它表达的社会判断 | 是否用罪恶税劝阻某行为？能否把工资税部分转向消费、财富与投机？ |
| 成功者的自负 | 做谦卑测试：如果重来一次，是否仍会成功？ | 承认运气不是否认努力；谦卑是公共生活的起点，不是自我贬低 |

## 决策树：面对“优绩制”争论

1. **争论焦点是程序公平吗？** 是 → 先消除歧视与特权；否 → 进入 2。
2. **是否把成功直接当作美德、把失败直接当作过错？** 是 → 拆分成功归因；识别天命论/成功神学；用谦卑测试替代应得叙事；否 → 进入 3。
3. **政策是否只把公共利益当作消费者福利？** 是 → 引入公民概念与贡献正义；讨论哪些工作值得尊重；否 → 进入 4。
4. **分类制度是否对赢家与输家都造成伤害？** 是 → 设计抽签、多路径认证或降低单一精英标准；否 → 检查是否只是分配不足。
5. **是否存在可执行的政治方案？** 没有 → 先做公共协商，明确“贡献”与“尊严”的可操作标准；有 → 同时配套收入补偿与承认政策。

## 常见危险信号

- 把“只要你努力就能成功”当作事实，而不只是理想。
- 用名校、高薪或高收入证明一个人比他人更有价值。
- 把失败归因于个人选择，同时否认结构因素。
- 用“优质信息”或“聪明/愚蠢”替代价值观辩论。
- 民粹主义反弹被简单斥为种族主义或无知。
- 只补偿输家的收入，不恢复其社会承认。
- 只扩大精英通道，不提升职业教育与社区学院的尊严。
- 把市场回报当作对公共利益的道德计量。
- 成功者声称“我白手起家”，而否认家庭、老师与时代的作用。

## 替代性提问

- 如果我把运气交给别人，我是否仍觉得自己优越？
- 这个分类制度让落选者如何定义自己？
- 我们是在分配资源，还是在分配人的价值？
- 这项政策把公民当作消费者还是生产者？
- 如果“我们都在一起”是真的，制度是否让赢家与输家真正共享风险与命运？
