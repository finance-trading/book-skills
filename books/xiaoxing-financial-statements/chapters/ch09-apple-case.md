# Chapter 9: 综合案例：苹果公司

## Core Idea
综合分析要把同业比较、趋势、利润率、周转率、资产结构和战略叙事串起来，而不是凭单一指标评价公司。

## Frameworks Introduced
- **同业—趋势双重比较**：先把苹果与华为放在同一财年比较，再看苹果 2016–2018 年自身变化。
  - When to use: 识别差异化战略和变化趋势。
  - How: 对齐口径，比较毛利率、净利率、总资产周转、研发/销售费用、应收和存货。
- **产业链整合分析**：销售体系、供应商账期和库存管理会同时影响费用率、周转和现金。

## Key Concepts
- **差异化**：苹果以品牌、产品和生态获得较高净利率与较低周转。
- **供应商占款**：较长应付账款周期释放现金。
- **服务业务**：相对硬件更可能成为后续增长点。

## Mental Models
低销售费用、高收款效率和较长供应商账期，可能比单纯加大研发更直接地提升现金回报；成熟硬件业务与新服务业务应分开估值。

## Anti-patterns
- **拿不同业务模式的公司硬比总量**：需先对齐业务范围和会计口径。
- **把研发占比低直接判为不创新**：产品设计、生态与历史研发积累也会影响当期比例。

## Worked Example
书中指出，2017 年苹果净利润率显著高于华为，但总资产周转率约 0.6 次、低于华为约 1.2 次，体现差异化定位；苹果应收和存货占比低、销售费用率低，应付账款周转约 4.7 次（约 78 天），显示供应链管理优势。服务收入占比上升，被视为新的增长点。

## Key Takeaways
1. 先做可比口径，再解释指标。
2. 用利润率×周转率理解商业模式。
3. 从报表变化反推未来业务与资本配置重点。
