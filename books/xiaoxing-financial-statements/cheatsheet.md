# Cheatsheet

| 看到什么 | 先问什么 | 判断规则 |
|---|---|---|
| 净利润增长 | 现金是否同步？ | 应收/存货上升而经营现金流弱，利润质量存疑 |
| 毛利率下降 | 行业竞争还是执行问题？ | 先用五力和价格/成本变化解释，再评估管理 |
| 经营现金流为正 | 投资现金流为何正/负？ | 正且投资为负可能扩张；正且投资为正、融资为负常见成熟分红还债 |
| 融资现金流为正 | 是否有真实投资计划？ | 经营良好但无投资计划仍大量融资，检查关联方占款或挪用 |
| 流动比率很高 | 流动资产是什么？ | 存货/应收占比高不等于现金安全 |
| ROIC 高 | 是否超过资本成本？ | ROIC − 资本成本 > 0 才创造经济价值 |
| 两家公司指标不同 | 业务模式是否可比？ | 先统一口径，再做同业与趋势双重比较 |

## 快速顺序
1. 经营现金流真实性 → 2. 收入、毛利、费用结构 → 3. 应收/存货/应付周转 → 4. 债务期限与偿债 → 5. ROIC 对资本成本 → 6. 行业、战略、执行解释。

## 红旗
- 资产处置或一次性收益撑起利润。
- 应收账款、存货增速长期超过收入。
- 经营现金流持续为负、靠融资续命。
- 各项现金流都为正却缺乏明确投资用途。
- 高增长伴随 ROIC 下降。
