# Chapter 1: Start

## Core Idea
创业不是按计划执行已知路线，而是在极端不确定条件下建立组织、发现可持续业务。初创企业的进步单位是 validated learning，而不是忙碌、按时交付或产出功能。

## Frameworks Introduced
- **创业管理（entrepreneurial management）**：把创业当作一种管理职能。传统管理假设目标已知、主要考验执行；创业管理假设目标本身未知，必须用适配不确定性的流程快速检验业务假设。
  - When to use：新业务、新市场、新技术，或既有企业内部的创新项目。
  - How：明确愿景与战略假设 → 设计能产生客户行为证据的实验 → 用创新会计判断是否值得继续 → 依据证据调整战略。
- **Build-Measure-Learn 反馈循环**：把想法转为产品（Build），测量客户如何反应（Measure），从结果中学习（Learn），再决定 pivot 或 persevere。关键不是单个环节的速度，而是整圈循环的总时间。
- **愿景—战略—产品三层结构**：愿景是目的地；战略包括商业模式、产品路线、伙伴/竞争判断与目标客户；产品是战略的具体产物。产品可持续优化（tuning the engine），战略偶尔需要 pivot，愿景通常保持稳定。
- **驾驭隐喻**：创业像开车而非发射火箭。开车需要持续微调方向；火箭需要发射前精确校准，微小的初始误差会在后期放大。多数商业计划写得更像火箭发射。

## Key Concepts
- **Startup**：在极端不确定条件下创造新产品或服务的人类组织，不由规模、行业、营利性或融资阶段定义。
- **Validated learning**：以客户行为和可验证证据证明团队对可持续业务的认知有所进展。
- **Engine of growth**：驱动新客户与收入持续增长的反馈机制；早期每次产品/营销改动都是对引擎的调校。
- **Achieved failure**：高效、忠实地执行错误计划，结果仍然失败。
- **Portfolio of activities**：任何时刻，公司都同时在服务现有客户、调优产品、判断是否转向。

## Mental Models
- 先问“做的是正确的事吗”，再问“做得够不够快”。
- 把创业看成一连串实验：每个功能、营销活动与发布都是检验假设的机会。
- “按时、按预算”只有在做对事情时才有价值；做错事时，它只是更高效的浪费。

## Anti-patterns
- 把创业等同于无管理的“just do it”：常导致混乱、返工与资源耗尽。
- 以功能数量、预算执行或媒体关注替代客户学习。
- 详细计划建立在未经检验的假设上，却把“按计划执行”视为成功。
- 将愿景、战略与产品混为一谈：产品失败就放弃愿景，或死守已被证伪的战略。

## Worked Example
一家公司预测某新产品会被数百万客户采用，于是按计划大举投入基础设施、招聘与客服。产品上线后客户没有出现，但组织已按“成功”规模配置，无法及时调整，最后“成功地执行了一个彻底错误的计划”。Lean Startup 的替代做法是：先以最小实验验证采用假设，再按真实需求扩张。

## Key Takeaways
1. 将 validated learning 而非产出设为早期进展的单位。
2. 尽快跑完整个 Build-Measure-Learn 循环，而不是局部加速。
3. 让愿景稳定、战略可调整、产品持续迭代。
4. 用真实客户行为检验“我们是否在做正确的事”。
