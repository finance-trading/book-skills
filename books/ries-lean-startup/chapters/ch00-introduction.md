# Chapter 0: Introduction

## Core Idea
Lean Startup 把创业看作可在极端不确定性下管理的过程：以科学实验、validated learning 与 Build-Measure-Learn 循环，替代“详细计划 + 执行”的传统管理范式。

## The Lean Startup Method — 5 Principles
1. **Entrepreneurs are everywhere**：创业不限于车库。定义是“在极端不确定条件下创造新产品或服务的人类组织”，因此政府、非营利、大企业内部的创新团队都适用。
   - 含义：不要用公司规模、行业或是否有风投来判断是否属于创业管理问题。
2. **Entrepreneurship is management**：startup 是机构而非仅产品；需要一套适配不确定性的管理方法。作者主张“entrepreneur”应成为现代公司里负责创新的正式岗位与职业路径。
3. **Validated learning**：startup 的目标是学习如何构建可持续业务；通过频繁实验、以真实客户行为验证假设来证明进展。
   - 关键区别：不是“我们学到了很多”的事后叙事，而是可被证据检验、能改变决策的学习。
4. **Build-Measure-Learn**：把想法变成产品 → 测量客户反应 → 决定 pivot 或 persevere。成功创业流程的目标是加速整个反馈循环，而非单点效率。
5. **Innovation accounting**：为创业结果设定度量、里程碑与问责；区别于传统会计，专为不确定环境设计。要回答“如何衡量进展、如何设里程碑、如何排优先级”。

## Origins and Influences
- **Lean manufacturing（Toyota Production System）**：小批量、just-in-time、pull、andon cord、Five Whys、消除浪费。Lean Startup 借用其“价值 vs 浪费”与持续改进思想，但把价值重新定义为 validated learning。
- **Customer development（Steve Blank）**：强调“get out of the building”，在真实客户中检验问题与解决方案，而非只在办公室做产品。
- **Scientific method / OODA loop**：把假设、预测、实验、观察、修正组织成循环；John Boyd 的 Observe-Orient-Decide-Act 是 Build-Measure-Learn 的思想来源之一。

## How This Book Is Organized
- **Part One — Vision**：论证创业管理，定义 startup，提出 validated learning 与科学实验。
- **Part Two — Steer**：完整走一轮 Build-Measure-Learn：leap-of-faith 假设 → MVP → innovation accounting → pivot 或 persevere。
- **Part Three — Accelerate**：小批量、增长引擎、自适应组织与组合管理，让 Lean Startup 在规模化时不失敏捷。

## Key Concepts
- **Extreme uncertainty**：startup 区别于复制型小企业的关键背景；后者主要考验执行，可用常规预测与贷款评估。
- **Institution building**：创业是造组织，不是做产品；需要招聘、协调、文化与问责。
- **Management’s second century**：20 世纪管理解决了生产效率；21 世纪的挑战是“应该造什么”，需要把科学方法用于创新。

## Mental Models
- 把创业视为可学习的学科，而非不可言传的个人天赋。
- 用“能否被证伪、能否快速试验”筛选管理方法。
- 先建立能持续学习的最小组织，再追求规模。

## Anti-patterns
- 把 Lean Startup 当成固定步骤蓝图，而非可调整框架。
- 用愿景与英雄式天才替代可检验的流程。
- 把“精益”误解为单纯削减成本，而非加速学习。

## Key Takeaways
1. 把“学习如何构建可持续业务”设为 startup 的进步标准。
2. 加速 Build-Measure-Learn 循环，而非局部速度。
3. 用 innovation accounting 替代传统预测做问责。
4. 把精益制造、客户开发与科学方法整合成一套创业管理。
