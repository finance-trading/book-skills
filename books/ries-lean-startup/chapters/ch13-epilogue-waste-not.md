# Chapter 13: Epilogue — Waste Not

## Core Idea
20 世纪的科学管理解决了“如何高效生产”的问题；21 世纪的瓶颈变成“应该生产什么”。最大的浪费不再是动作低效，而是高效地做错误的事；Lean Startup 要把实验方法用于回答“是否应该做”。

## Frameworks Introduced
- **Should it be built?**：当生产能力充足时，核心问题从“能否造”转为“是否值得造”；用 validated learning 与实验回答。
  - How：① 识别正在进行的“高效做错事”（失败发布、烂尾项目、大批次死亡螺旋）；② 把每个项目视为假设组合；③ 用实验在投入前证伪致命假设；④ 把节省的时间重新投入下一轮学习。
- **防止伪科学**：不能把 pivot、MVP、学习当作事后合理化的口号；必须用可预测、可测量、可重复的实验证明因果。
  - 红旗：用总量指标的事后高光证明成功；用“我们学到了”为失败开脱；在数据真空里做无限“实验”（stealth 模式）。
- **Long-Term Stock Exchange（LTSE，提案）**：用 innovation accounting 报告创新成果（例如三年前不存在的产品的收入占比）、把高管薪酬与长期表现绑定、提高交易成本以抑制短线交易，换取治理上支持长期投资。

## Key Concepts
- **Taylorism 的教训**：系统化本身有价值，但把系统置于人之上、把科学等同于 rigid procedure，会压制创造力与适应性；lean 把效率从个人任务转向整个组织，正是对 Taylor 的修正。
- **Pseudoscience**：用总量指标的事后高光、或以“我们学到了”为失败开脱，都是缺乏因果证据的伪科学。
- **Preventable waste**：多数创新浪费并非不可避免；理解其成因后可以系统性减少。
- **Organizational superpowers**：掌握 Lean Startup 原理的人能向高管快速指出项目基于哪些可检验假设；风险是管理层把成功归因于“聪明个人”而非可复制的系统。

## Mental Models
- 先问“这是不是正确的事”，再问“是否高效”。
- 速度与质量不是敌人：发现缺陷越早，长期越快。
- 任何新方法都应接受“能否预测结果、能否小范围试验、能否测量”的检验（Deming：分清特殊原因与系统性原因）。
- 从 validated learning 切换团队体验通常“先变差后变好”：旧系统的问题无形，新系统的问题有形；要有理论预期并提前沟通。

## Anti-patterns
- 用忙碌、工时或功能交付衡量知识工作。
- 把 MVP/pivot 变成新的教条或流行词。
- 用事后挑选的数据证明成功。
- 因短期财报压力牺牲长期创新能力。
- 把“系统优先”读成“人可以被替换”。

## Worked Example
Taylor 的钢铁切削实验持续 25 年、做了两万多次实验，全部由产业界用即时生产率收益资助。作者以此对照现代知识工作：多数创新管理仍依赖直觉、口号与事后叙事，而缺少同等级别的实验投入与因果检验；他呼吁建立“startup testing labs”，像 Taylor 测钢一样系统比较不同开发方法（周期时间、不确定度、问责方式）对真实产出的影响。

## Key Takeaways
1. 把创新视为可研究的实验过程，而非英雄直觉。
2. 用因果证据而非总量高光判断成败。
3. 警惕 Lean Startup 自身变成伪科学。
4. 制度层面需要支持长期创新的会计与资本市场设计。
5. 停止浪费人的时间，是组织层面最容易被忽视的最大浪费。
