# 芒格决策速查

| 情况 | 决策规则 | 原因 / 核查 |
|---|---|---|
| 业务、风险或现金流无法解释 | 放进“太难”而非强行估值 | 能力圈边界比圈大小重要 |
| 价格明显低但企业可能永久受损 | 先调查生存、负债和竞争，不因便宜就买 | 账面折价可能无法补偿永久损失 |
| 好企业价格很高 | 分开判断质量与价格；估值不合适就等待 | 好公司不自动是好投资 |
| 市场热闹、同行都行动 | 先独立写下事实和赔率 | 社会认同与压力可能放大错误 |
| 自己已投入大量资金或声誉 | 只比较从今天起的选择及未来后果 | 沉没成本和一致性倾向易促使错误加码 |
| 管理者口头承诺与奖金冲突 | 先研究真实激励与可核验行为 | 奖励结构可能改变判断及行动 |
| 机会看似清楚 | 再检查护城河、诚信、负债、价格和替代方案 | 复合风险会改变赔率 |
| 模型给出非常精确的价值 | 列假设、做敏感性及下行分析 | 计算精度不等于预测精度 |
| 权威要求立即执行 | 复述指令、核验事实、允许异议与暂停 | 地位不保证正确 |
| 多种心理力量同向 | 检查激励、从众、压力和承诺如何相互强化 | 组合效应可能远大于单项影响 |

## 决策树
1. **会造成无法承受或永久性损失吗？** 是 → 拒绝或先移除风险；未知 → 继续调查。
2. **能理解业务与关键风险吗？** 否 → 太难；是 → 分析经济与心理双轨。
3. **长期竞争优势、管理层、现金与负债能否经得起反证？** 否 → 不投；未知 → 等待证据。
4. **价格相对保守价值及替代机会是否足够有利？** 否 → 等待；是 → 确定可承受仓位与事前复盘条件。
5. **新证据推翻核心前提？** 是 → 重新评估，不让沉没成本决定行动。

## 常见危险信号
- 把会计盈利直接当成可分配现金。
- 只用一种模型解释复杂系统，或把群体赞同当成证据。
- 奖金奖励短期交易量、规模或报表数字，却无人承担长期后果。
- 论证只包含最乐观的终值和增长假设。
- 认为集中下注总是优于分散；集中会放大错误，须考虑自身生存与流动性。
