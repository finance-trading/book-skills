# 附二：巴菲特教你读财报

**来源**：PDF第235–305页，目录列出的第37、57章未见正文，末页术语汇编在条目中途截断，故附二并不完整。这是附在本书后的独立材料，作者是玛丽·巴菲特与戴维·克拉克（序言落款“玛丽·巴菲特，2008年8月”，p241），**不是芒格著作**。历史公司数字、税率和估值案例均须按当前情况重核。

## 核心思想
巴菲特的两大发现（p241）：如何辨别具有持久竞争优势的优质企业；如何估算这类企业的价值。重点不是“便宜”，而是**利润的来源**：企业是否需要大量研发、资本开支或财务杠杆才能维持竞争力（p248）。

## 损益表八项（p247）
1. **毛利率** ≥40%，并查看过去10年是否持续；低于40%通常意味着高度竞争，低于20%更明显。
2. **销售费用及一般管理费用**占毛利润的比例 ≤30%最好；不少优质公司仍在30%–50%。
3. **研发开支**：巴菲特回避必须持续投入巨额研发的公司，尤其是高科技公司；研发失败会威胁长期前景。
4. **折旧费**占毛利润比例较低，通常优于过度竞争企业。
5. **利息费用**：优质消费品公司常小于营业利润的15%，甚至没有利息支出。
6. **税前利润**：便于跨公司、跨投资比较，也是计算回报率的常用口径。
7. **净利润**：长期增长；净利率持续高于总收入20%通常提示竞争优势；持续低于10%通常提示高度竞争；10%–20%是灰色地带。
8. **每股收益**：连续10年或以上持续上涨，才足以帮助判断长期竞争优势。

## 资产负债表与现金
- **流动比率**：传统标准说应大于1，但很多持久竞争优势公司（如穆迪0.64、可口可乐、宝洁0.82、安海斯-布什0.88）低于1；作者结论是它“毫无用处”作为竞争优势判断指标（p262、p269）。
- **长期贷款**：优质公司通常很少或没有；作者的经验规则是年盈余应在3–4年内偿还全部长期债务（p279）。这是筛选线索，不是所有行业的硬标准。
- **留存收益**：持续增长是竞争优势的好指标；可口可乐5年年均约7.9%、箭牌10.9%、伯灵顿北方15.6%、伯克希尔23%（p284）。留存收益增长也可能来自收购，须看来源。
- **库存股票**：资产负债表出现库存股票，通常说明公司回购过股票；回购能提高每股收益，但价值取决于价格、资金来源和机会成本（p281–284）。
- **股东权益回报率（ROE）**：净利润÷股东权益；优质公司往往较高（可口可乐约30%、箭牌24%、好时更高），但高ROE可能来自杠杆、回购或会计处理，须还原（p286–288）。
- **资本开支**：作者把“减少资本开支”视为致富秘诀之一；高资本开支会吞噬利润，需区分维持性与扩张性支出（p289–291）。
- **商誉与无形资产**：可能抬高或扭曲资产回报；需看是否来自高价并购及减值风险（p264–274）。

## 用原文示例做一次计算（p248）
示例损益表（百万美元）：总收入10,000；销售成本3,000；毛利润7,000；SGA 2,100；研发1,000；折旧700；营业利润3,200；利息200；出售资产收益1,275；其他225；税前利润1,500；税525；净利润975。
**先记一个原文疑点**：按表内项目相加，营业利润3,200 − 利息200 + 出售资产收益1,275 + 其他225 = 4,500，并非表上写的税前利润1,500；税525与净利润975也只对应1,500的税前利润。原表示例存在内部不一致，不能当作可靠算术模板。以下比率仅按印刷数字计算以说明方法：
- 毛利率 = 7,000/10,000 = 70%（通过≥40%）
- SGA/毛利润 = 2,100/7,000 = 30%（处于“最好≤30%”边界）
- 研发/毛利润 = 1,000/7,000 ≈ 14.3%（研发负担不低）
- 折旧/毛利润 = 700/7,000 = 10%
- 利息/营业利润 = 200/3,200 = 6.25%（通过<15%）
- 净利率 = 975/10,000 = 9.75%（低于20%，落在高度竞争/灰色地带）
- 结论：单看毛利率会误判；必须把利润来源、研发、净利率和一次性收益（出售资产收益1,275）一起看。该例还提醒：净利润可能被非经常项目抬高，且原表本身可能有错，引用前要重算。

## 使用顺序
1. 先读损益表，判断利润来源与可持续性。
2. 再读资产负债表，检查负债、流动性、留存收益、回购、商誉和ROE质量。
3. 最后读现金流量表，核对利润是否转化为现金、资本开支和融资需求。
4. 把结果与行业、竞争者、历史10年数据对照；单一 threshold 不构成买入理由。
5. 好公司仍需合理价格；用 ch15 的估值方法检验价格与价值。

## 反模式
- **用单一指标选股**：高毛利、高ROE或低流动比率都可能被行业、杠杆或会计扭曲。
- **把 threshold 当定律**：40%、30%、15%、20%、10年都是作者总结的经验阈值，不是会计恒等式。
- **忽略一次性项目**：出售资产收益、重组费用、税项变化会扭曲净利润。
- **把历史案例当现况**：书中的公司数字、利率、税率和估值是2008年前后的材料。
- **把附录当芒格原话**：本附录作者是玛丽·巴菲特与戴维·克拉克，引用时须区分。
