# 决策速查

| 情况 | 优先动作 | 原因 |
|---|---|---|
| 输入含财报、研报或公告 | 先核披露及实际可得时间 | 报告期不等于市场知情时间 |
| 组合多个因子 | 对照等权与单因子，限制换手 | 动态权重可能只是追逐噪声 |
| 训练机器学习模型 | 时间切分，训练窗口内拟合预处理 | 随机切分和全样本缩放可能泄露 |
| 目标区间重叠 | 按标签跨度隔离训练与测试 | 相邻样本可能共享未来信息 |
| 盘口或竞价策略 | 模拟延迟、买卖价与成交限制 | 显示的挂单不是保证成交 |
| 连板、龙头或题材 | 固定事前识别规则和分母 | 事后选股会夸大可预测性 |
| 新闻或席位研究 | 区分事件、披露和可交易时刻 | 公开后交易不能使用公开前价格 |
| 策略只在单一窗口成功 | 做分期与参数敏感性检查 | 可能过拟合或依赖特定行情 |
| AI给出公式、代码或引用 | 回查来源、字段、时间和运行结果 | 流畅回答不证明正确 |
| 数据或成交模拟不足 | 标为研究假设而非实盘结论 | 无法可靠估计真实净收益 |

**交易前闸门**：数据可得性 → 假设与基准 → 时间隔离 → 净成本与容量 → 风险限额 → 模拟与监控。任何关键环节无法验证时，先补证据。
