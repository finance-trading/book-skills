# 决策速查

## 先选问题
- **制度为何改变？** → 依次查技术/环境、保护与掠夺成本、行为激励、组织规模；保留竞争解释。
- **职业是否有选择权？** → 查技能可迁移性、客户集中度、关键资产控制、退出成本与法律约束。
- **数字业务是否跨境？** → 分别核实人员、客户、数据、资金和司法管辖，而不是只看服务器位置。
- **长期承诺是否脆弱？** → 设基准和50年情景，检验税基、人口、支出、债务与政策调整；期限不是预测的崩溃日。

## 四类依赖关系
| 类型 | 主要依赖 | 优先检查 |
|---|---|---|
| Peasants（农民） | 固定地域及传统生产关系 | 资产可移动性、风险缓冲 |
| Courtiers（朝臣） | 权力中心的庇护与分配 | 关系集中、权力变更 |
| Professionals（专业人士） | 专业技能、资格或组织职位 | 技能可迁移性、替代风险 |
| Sovereigns（主权者） | 可迁移技能与资本、选择能力 | 真实退出成本、法律及平台依赖 |

以上为任务要求保留的分析标签；所给中文文本未核实为原书明确成组分类。它们可重叠，不是人的等级。

## 判断规则
- **保护成本下降** → 重新评估集中保护的必要性，同时检查新的攻击面。
- **退出成本高** → 先建立合法替代方案和缓冲，别把抽象的自由当作可执行选择。
- **收入高度依赖单一客户或平台** → 建立多元关系，衡量冗余的真实成本。
- **看到原书预测应验的案例** → 同时找相同时间尺度的失败和未定案例，分别检验方向、时间和机制。
- **权力下放** → 检查谁接手安全、问责及争端解决；分权不等于权力消失。
- **涉及跨境税务或身份** → 以现行法律及专业意见核验；书中旧建议不是当前法律或财务建议。
