# 第 4 章：Adult Education

## Core Idea
Salomon 的培训项目不是课堂，而是一个内部劳动力市场：培训生被当作可交易的“牲口”，岗位在 blackboard 上被争夺，真正的胜负手不是产品知识，而是找到有权力的 jungle guide（丛林向导）和 rabbi（拉比/保护人）。同时，交易员与销售员的分工把权力写进了组织结构：交易员决定销售员的奖金，销售员只是交易员对外的嘴。

## Frameworks Introduced

- **Front row / back row 博弈**
  - 观察：培训生分成两派——前排讨好演讲者、争取好感；后排扔纸团、装酷、用羞辱对抗权威。
  - 机制：两派都在争夺稀缺岗位，只是策略不同；前排用“顺从”换信息，后排用“反叛”换同侪地位。
  - 用法：在高度竞争的培训/试用环境中，观察谁在表演“忠诚”、谁在表演“不在乎”；两者都可能是策略，不是性格。

- **“Desirability Ponzi”（受欢迎度庞氏）**
  - 观察：一个培训生若被其他部门争抢，就会变得更有价值；管理层愿意要“别人也想要的人”，而不一定是最有能力的人。
  - 机制：制造“我被追求”的信号，让其他老板产生错失恐惧；信号本身会创造需求。
  - 用法：在内部人才市场中，可见的“外部选择”会改变你的内部定价；但信号必须有人背书，否则会被识破。

- **Jungle guide 选择框架**
  - 观察：演讲者说“选哪个产品可能不如选哪个 jungle guide 重要”；jungle guide 是带你进入交易桌的资深者。
  - 机制：在信息不对称的组织里，保护人提供机会、掩护和解释规则的能力；产品知识可以后学，保护关系难以替代。
  - 用法：选择第一份交易/销售工作时，先看谁愿意教你、保护你、把你带上牌桌；再看产品本身。

- **Trader / salesman 权力不对称**
  - 观察：交易员在市场上用公司的钱下注，销售员把交易员的产品卖给客户；销售员的奖金由交易员决定，交易员的奖金由自己的交易账本决定。
  - 结果：交易员是“老板”，销售员是“嘴”；最好的交易员也是最好的销售员，反之亦然，但制度权力偏向交易员。
  - 用法：分析金融机构时，先看奖金决定权；它比组织图更能说明谁真正拥有权力。

## Key Concepts

- **front row / back row**：培训班的两个阵营；前排讨好权威，后排用嘲弄和纸团维持地位。
- **Equities in Dallas**：岗位 blackboard 上最差的去处；成为“最低等人类”的代名词。
- **job placement blackboard**：部门 × 城市的岗位矩阵；培训生的命运被钉在上面。
- **jungle guide**：带你进入交易桌的资深导师；比产品选择更重要。
- **rabbi**：交易桌上的保护人/赞助人；提供机会与政治掩护。
- **bid / offer**：交易员说“买/卖”的方式；培训后期，全班开始用交易语言替代日常语言。
- **Big Swinging Dick**：能赚钱的交易员；培训生渴望的身份。
- **“men trade, women sell”**：Salomon 的性别分工；女性被系统性地挡在交易桌外，因而远离权力。

## Mental Models

- **把培训看成“内部 IPO”**：每个培训生都在向各部门“路演”，部门在竞标；价格不是薪酬，而是“谁愿意为你承担风险”。
- **可见性先于能力**：在无法客观衡量新人的组织里，“被谁追求”比“会什么”更能决定岗位；制造可见性是一种合法的政治策略。
- **保护人是一种期权**：jungle guide 给你的是“在坏结果时有人替你解释”的期权；产品知识只是执行价值。
- **权力跟着奖金走**：交易员决定销售员奖金，所以交易员是真正的老板；title 和办公室不说明问题。

## Anti-patterns

- **一开始就全力讨好**：前排的 grovel 可能换来好感，但也可能被标记为“没有骨气”；一旦押错人，就没有退路。
- **把命运交给管理层**：培训生若相信“公司会公平分配”，就会在 blackboard 前被动等待；Salomon 的制度并不奖励被动。
- **只选产品，不选人**：按揭债券再热门，若没有 jungle guide，你也可能在桌上被孤立；产品会变，保护关系不会。
- **忽视结构性歧视**：女性被排除在交易桌外，不是能力问题，而是制度安排；把“她没上桌”归因于个人，会误读组织。

## Worked Example

**刘易斯如何“制造被追求”的假象**

1. 培训初期，刘易斯没有把握能进入想去的部门；直接乞求梦想老板风险太高，可能被当成“remaindered goods”。
2. 他先在一个并非最想去的部门交了一个朋友，并让这位朋友公开表示“想要 Lewis 来我们部门”。
3. 他再让其他培训生知道“我被追求了”；消息在同侪中传播，最终传到他想去的部门老板耳中。
4. 老板开始好奇：“为什么别人都在抢他？”于是主动约刘易斯吃早餐。
5. 刘易斯没有撒谎，也没有直接乞求；他只是让“外部选择”变得可见，从而改变了自己的内部定价。

**读法**：这是一次典型的信号操作。在缺乏客观能力指标的组织里，“谁想要你”会成为能力的代理指标；但信号必须由真实的人背书，否则就是空话。刘易斯用最小的行动制造了最大的可见性差。

## Key Takeaways

1. 培训/试用期的核心任务不是学产品，而是找到愿意为你承担风险的保护人。
2. 在内部人才市场，“被追求”本身就是一种定价信号；可见性可以合法地制造。
3. 交易员的权力来自奖金决定权，不是来自 title；分析组织先看分配机制。
4. 结构性的排除（如女性不能交易）往往不是能力问题，而是制度设计。
5. 选择第一张牌桌时，先看人，再看产品。
