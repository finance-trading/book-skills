# 第 1 章：Liar's Poker

## Core Idea
Liar's Poker 是 Salomon 交易桌的缩影：概率只是入场券，真正决定输赢的是读人、隐藏自己的 fear 与 greed，以及知道什么时候拒绝一个“没有 upside 的赌局”。Gutfreund 与 Meriwether 的一百万美元对局，把“交易员的认识论”浓缩成一局牌。

## Frameworks Introduced

- **Liar's Poker 读局框架**
  - 规则：每人拿一张美元钞票贴近胸口，只看自己钞票上的序列号；轮流向圆圈中央“叫牌”，例如“三个六”表示所有人钞票中至少有三个数字 6；下家可以叫更高（同数量更高数字，或更多数量任意数字），也可以“challenge”（我怀疑）；只有当其他所有人都同意 challenge 某一个人的叫牌时，才亮出序列号结算。
  - 两层能力：第一层是概率——“四十个随机序列号里出现三个六的可能性有多大”；第二层是读脸——“他叫高是在 bluff，还是真有一手？他是在诱我犯错，还是自己有四张？”
  - 适用场景：任何信息不对称、对手会 bluff、结果由“概率 × 心理”共同决定的博弈。
  - 做法：先算基础概率，再观察对手的松弛/紧张、下注节奏和模式；同时刻意消除自己的可预测性。

- **“赢家总有概念”（winners always have a concept）**
  - 含意：交易桌上的人做任何事都有理由，哪怕理由很糟；不要假设大佬的行为是纯随机。
  - 用法：看到异常出价或挑战，先问“他想让我相信什么？他的真实收益结构是什么？”再决定跟不跟。

- **枪客代码（the code of the gunslinger）**
  - 含意：Liar's Poker 的玩家必须接受一切挑战；拒绝会被视为软弱。
  - 反作用：代码会逼人接受负期望的赌局。Meriwether 的解法不是拒绝游戏，而是把赌注提高到对方不敢接，从而在不失面子的情况下退出。

- **“没有 upside 的赌局”判据**
  - 问题清单：赢了会得罪谁？输了会损失多少？单局中运气占比多大？我是否在用全天避免蠢赌的原则换一次情绪满足？
  - 结论：当赢的收益主要是“保住面子”、输的损失是真实财富时，最优动作是抬高门槛或直接不玩。

## Key Concepts

- **Liar's Poker**：以美元钞票序列号为载体的 bluff 游戏；Salomon 债券交易员把它当作交易能力的试金石。
- **bid（叫牌）**：声明“所有人合计至少有多少个某数字”，是概率判断与心理战的结合。
- **challenge（挑战）**：表示“我不信”，迫使叫牌者亮牌；只有所有其他玩家一致同意才结算。
- **King of the Game**：交易桌内部对 Liar's Poker 冠军的称呼；Meriwether 被视为“游戏之王”，而 Gutfreund 只是“华尔街之王”。
- **fear and greed**：Meriwether 能同时压制的两种情绪；大多数交易员会通过语言或动作泄露自己是在赚钱还是亏钱。
- **no tears**：输了不许哭、不许抱怨；一种把痛苦内部化的交易桌伦理。
- **Big Swinging Dick**：本书后文会展开的交易桌雄性符号；本章先以“merchant of risk”的气场出现。

## Mental Models

- **把市场想成一场牌局，而不是一台估值机器**：价格不是“算出来的答案”，而是“对手愿意在什么信息下成交”。你不需要比市场更聪明，只需要比交易对手更清楚他为什么坐在桌边。
- **用加注测试信念**：当你不想接受一个赌局、又不想显得害怕时，提出一个对方大概率不接受的更高赌注。这不是虚张声势的炫技，而是把“拒绝”转化为“重新定价”。
- **管理者的权力是二手的**：Gutfreund 是董事长，但交易员崇拜的是 Meriwether，因为后者直接掌控风险和利润。头衔不等于对游戏的理解；在交易组织里，靠近钱的人拥有真实权威。
- **单局运气会淹没长期优势**：即使 Meriwether 是更好的玩家，一局定胜负也可能输。优势只在重复博弈中兑现；单局大赌是把技术优势交给方差。

## Anti-patterns

- **为了证明勇气而接受负期望赌局**：Gutfreund 的一百万挑战更像“从高台跳下”的表演，而不是交易判断；在交易桌上，这种表演会直接转化为亏损。
- **把“职位高”误当成“游戏强”**：Gutfreund 是华尔街之王，但在 Liar's Poker 里是 outsiders；用头衔推断能力，会让你低估真正的高手。
- **在单局中押上无法承受的金额**：Meriwether 知道“一局什么都能发生”，所以他不接受 1M 的赌局；若把长期优势押在一次结果上，就是把技术变成彩票。
- **让情绪写在脸上**：大多数交易员赚钱时过度松弛、亏钱时过度紧张；这等于把底牌递给对手。

## Worked Example

**Gutfreund 的一百万挑战（1986 年，Salomon 交易厅）**

1. Gutfreund 走到 Meriwether 桌前，说：“One hand, one million dollars, no tears.”
2. Meriwether 的处境：他是更好的玩家，但只打一局；赢了会让老板难堪，输了要自掏 100 万美元。期望值为负，且没有战略 upside。
3. 直接拒绝会违反枪客代码；于是他反提案：“No, John, if we're going to play for those kind of numbers, I'd rather play for real money. Ten million dollars. No tears.”
4. 这是一次“开局前的 bluff”：他把赌注提高到 Gutfreund 大概率不愿承担的水平，同时保住“我敢玩”的姿态。
5. Gutfreund 考虑后拒绝：“You're crazy.” Meriwether 心想：“No, just very, very good.”

**读法**：Meriwether 没有赢下牌局，但赢下了博弈。他识别出“单局 + 负期望 + 老板情绪”的组合，用一个对方无法接受的加注把局面重新定价。这就是本书反复出现的交易智慧：不是每一局都值得玩，真正的高手先选择牌桌。

## Key Takeaways

1. 先判断这是不是“重复博弈”；单局大赌会把你的技术优势交给运气。
2. 读人之前先算概率；读人之后仍要算期望值。两者缺一，都是半套功夫。
3. 当你不想玩又不能不玩时，改变赌注结构，而不是改变立场。
4. 在交易组织里，靠近风险与利润的人比头衔更高的人更有权威。
5. 控制 fear 与 greed 的外在表现，是交易员最稀缺的能力之一。
