# 推理与应用模式

## 以预测误差修正世界模型
**何时使用**：解释学习、感知异常或纠正错误判断。
**如何**：形成模型 → 预测下一输入 → 与实际输入比较 → 错误时把注意力转向冲突 → 更新模型。
**权衡**：多数准确预测不会进入意识；但错误模型可能把反证解释为伪造，阻断更新。（Ch 3–4, 12）

## 通过感觉-运动探索学习
**何时使用**：学习新物体、环境、工具或任务。
**如何**：移动身体/传感器 → 观察输入变化 → 建立位置与特征的关联 → 预测新动作后的输入 → 以误差检验模型。
**权衡**：静态/虚拟环境也可移动（如浏览网页、数学推理）；探索需要时间与环境交互。（Ch 3, 5, 8, 10）

## 选择合适参考系
**何时使用**：学习复杂主题、解决问题、定位知识缺口。
**如何**：界定对象和目标 → 找到/建立坐标结构 → 将事实放到位置 → 沿关系移动到目标 → 检查预测。
**权衡**：参考系决定能学什么；狭窄地图适合专用任务，不适用于通用智能。（Ch 5–6, 8）

## 位点法（method of loci）
**何时使用**：快速记忆清单或有序项目。
**如何**：选熟悉空间 → 将每项放到独特位置 → 用熟悉路线逐点检索。
**权衡**：依赖已有地图与路线；更复杂知识通常需要为任务建立新参考系。（Ch 6）

## 跨模型投票
**何时使用**：解释多感官输入融合、遮挡、稳定感知，或设计多传感器智能系统。
**如何**：各独立模型提出候选 → 共享与对象相关的假设 → 找到候选交集/最一致结果 → 保留不确定性直至输入消歧。
**权衡**：投票模型互补而非完全相同；系统仍可能达成错误共识。（Ch 7–8）

## 评估通用智能系统
**何时使用**：判断 AI 是否具备灵活学习能力。
**如何**：逐项检查持续学习、运动学习、多重模型、参考系；再检查具身/传感器、行为原语、目标与安全机制。
**权衡**：单任务成绩不能证明通用智能；这是霍金斯的评估框架，不是全领域共识标准。（Ch 8, 10）

## 审计信念与证据
**何时使用**：处理高影响、难以直接观察或社会传播的主张。
**如何**：区分观察与推断 → 明确什么证据会反驳 → 主动搜索反证 → 比较独立来源 → 更新模型。
**危险信号**：主张不可直接验证、要求忽略矛盾证据、鼓励传播或惩罚异议。（Ch 12–13）

## 分解机器风险
**何时使用**：讨论机器智能是否构成生存威胁。
**如何**：分别问机器有何智能、谁/什么设定目标、是否可自我复制、是否能控制关键资源、是否可安全停止。
**权衡**：区分智能自身风险与人为滥用风险；作者反对前者必然化，但不否认后者。（Ch 10–11）

## 设计长期知识遗产
**何时使用**：规划跨代或跨文明知识保存。
**如何**：选择内容 → 离地/多副本存储 → 设计持久且可发现信号 → 考虑未来解码 → 定期更新 → 明确接收者与目的。
**权衡**：静态档案易腐坏或不可读；可复制的智能载体更灵活，但自我复制也需治理。（Ch 15–16）
