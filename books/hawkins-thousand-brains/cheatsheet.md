# 千脑智能决策速查

## 学习与推理
| 情况 | 判断/行动 | 理由 |
|---|---|---|
| 新皮质为何注意异常？ | 找预测与输入的差异 | 正确预测通常无意识；误差吸引注意并触发更新。 |
| 如何学新物体/环境？ | 主动移动，观察感觉如何变 | 感觉-运动经验构成模型。 |
| 复杂问题卡住？ | 先找参考系/地图，再放置事实 | 思考是参考系中的移动；事实孤立时难以检索。 |
| 模型遇到反例？ | 主动找更多反证，并允许更新 | 只搜支持材料会保护错误模型。 |

## 判断智能
检查以下四项，而非单项榜单成绩：
1. 是否能**持续学习**新知识而不抹除旧知？
2. 是否能通过**运动/交互**学习世界？
3. 是否有**多重互补模型**，适配不同感觉与任务？
4. 是否用**参考系**表示位置、关系、结构与行动？

## 判断机器风险
- 将风险拆成 **智能 / 动机 / 复制 / 资源控制**，不以“更聪明”直接推导“更危险”。
- 检查停止能力、权限隔离、复制门槛、关键基础设施控制与人为滥用路径。
- 书中作者认为智能爆炸并非必然；不要把此结论误读成“AI 没有现实风险”。

## 检查信念
- 是亲自观察、仪器/研究证据，还是转述？
- 什么证据会证明这个模型错？是否主动寻找？
- 是否要求忽略反证、只信同温层、传播并惩罚异议？若是，视为高风险信念模式。
- 结论强度应匹配证据；作者假说与价值判断须标明。

## 设计机器智能
| 组件 | 设计问题 |
|---|---|
| 具身 | 有哪些可移动传感器？环境如何被探索？ |
| 行为原语 | 哪些动作需由底层稳定、安全地执行？ |
| 学习系统 | 如何形成世界模型、预测、纠错与持续学习？ |
| 目标/安全 | 谁设目标？如何响应停止指令？如何限制滥用与复制？ |

## 长期遗产
- **只表明曾存在** → 持久、远距可探测的信号。
- **保存历史与知识** → 离地档案、多重冗余、更新与未来解码计划。
- **获取新知识并延续传播** → 可学习、可维护的智能载体；自我复制既是能力也是治理风险。
