# 术语表

**方向细胞（orientation cell）** — 皮质柱中假定的功能细胞，表征相对物体/环境的方向；旧脑的对应机制为头朝向细胞（Ch 5）。

**感觉-运动学习（sensorimotor learning）** — 通过观察感觉输入如何随运动变化来学习世界模型（Ch 3, 7–8）。

**感受质（qualia）** — 感觉输入被体验的方式与主观感受；霍金斯认为某些感受质是世界模型的属性（Ch 9）。

**感官融合 / 绑定问题（binding problem）** — 分散、变化且可能扭曲的感觉输入如何形成单一统一知觉；千脑理论用皮质柱投票解释（Ch 1, 7）。

**海马 / 内嗅皮质** — 旧脑导航系统的重要部分，包含位置细胞、网格细胞等地图机制（Ch 4–5）。

**旧脑** — 较早进化的脑区，控制身体机能、先天行为、情绪与动机；与新皮质互相作用（Ch 1, 10–13, 16）。

**记忆-预测模型** — 霍金斯早期用语；后改称“新皮质学习世界模型并基于模型预测”（Ch 3）。

**具身（embodiment）** — 能移动传感器、与环境互动的身体或虚拟行动界面，是学习世界模型的条件（Ch 8, 10）。

**网格细胞（grid cell）** — 在环境多个位置按网格模式活动的旧脑神经元，为空间参考系提供坐标（Ch 5–6）。

**位置细胞（place cell）** — 在动物处于特定地点时活动的神经元，类似地图中的“你在这里”（Ch 5–6）。

**预测模型（predictive model）** — 新皮质学习的世界模型，持续预测运动或世界变化带来的感觉输入（Ch 3–4）。

**树突脉冲（dendritic spike）** — 霍金斯用来解释预测如何在神经元内部发生的机制假说（Ch 4）。

**突触（synapse）** — 神经元之间的连接；书中将学习描述为形成新连接、遗忘描述为连接减弱或移除（Ch 3）。

**通用皮质算法** — 芒卡斯尔提出新皮质各区域共享基本算法、功能差异主要来自连接对象的观点（Ch 2）。

**通用人工智能（AGI）** — 能跨任务灵活学习、迁移知识与解决新问题的机器智能（Ch 8）。

**投票（voting）** — 皮质柱分享物体候选，跨柱形成共识；作者以此解释统一感知与感官整合（Ch 7）。

**皮质柱（cortical column）** — 新皮质中相对重复的基本组织单元；作者模型中每柱是感觉-运动系统，可在参考系中学习多个物体（Ch 2, 5–7）。

**迷你皮质柱（minicolumn）** — 皮质柱内更细的纵向神经元组织（Ch 2）。

**参考系（frame of reference）** — 类似地图坐标的结构，用位置组织物体、知识和预测；霍金斯主张它是思考与知识存储的基础（Ch 4–8）。

**模因（meme）** — 可在文化中复制、变异和传播的观念；书中用于讨论观念与基因的协同传播（Ch 12–13）。

**新皮质（neocortex）** — 哺乳动物大脑的“新外层”，书中视为学习世界模型与实现智能的主要器官（Ch 1–4）。

**世界模型（world model）** — 大脑对物体、环境、关系与互动变化的内部模型，是预测、感知和计划的基础（Ch 3, 8–12）。

**长程连接** — 跨较远皮质区域的轴突连接；在千脑理论中，部分承载皮质柱间投票（Ch 7）。

**知识表征（knowledge representation）** — 如何以机器可使用的结构表达知识；霍金斯主张用可操作的世界模型，而非事实/规则清单（Ch 8）。

**智能爆炸** — 假设机器递归设计更聪明机器、智能迅速超越人类的情景；作者认为学习受世界互动时间限制（Ch 11）。

**目标失调（goal misalignment）** — 机器追求与人类福祉相悖的目标，且无法被人类制止的风险场景（Ch 11）。

**达尔文轨道** — 以自然选择与基因复制为中心的生物演化路径；第 16 章用来对照以知识为中心的未来（Ch 13, 16）。

**维基地球（WikiEarth）** — 作者设想的绕日卫星知识档案，用于跨人类文明保存知识（Ch 15–16）。

**SETI / METI** — 搜寻地外智能 / 向外发送地外智能信息（Ch 15）。
