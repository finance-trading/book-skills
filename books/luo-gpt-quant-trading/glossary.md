# 术语表

按术语字母排序；定义为便于应用的概括，中文市场术语可能因平台或语境略有不同。

- **Alpha（阿尔法）** — 相对于市场或指定基准的超额收益；需明确基准并调整风险。（第1、2章）
- **Beta（贝塔）** — 对整体市场收益的暴露或收益来源；本书亦讨论趋势与宽泛的因子溢价语境。（第1、2章）
- **CTA（商品交易顾问/管理期货）** — 使用期货、期权等交易多资产市场的系统或主观策略，常见量化形式为趋势跟踪。（第2、4章）
- **IC（信息系数）** — 因子值与后续横截面收益的相关性，用于评估预测排序能力。（第3章）
- **Smart Beta（聪明贝塔）** — 以透明规则和因子暴露构建非传统市值加权组合的策略类别。（第2章）
- **阿尔法因子** — 用于刻画证券收益/风险差异并形成选股或交易信号的数据特征。（第3章）
- **安全边际** — 估值与买入价格之间留出的缓冲，降低估值误差带来的损失。（第2章）
- **贝塔策略** — 本书狭义指偏向市场方向/波动机会的策略；讨论前应说明口径。（第2章）
- **分组收益分析** — 按因子值将标的分组并比较未来收益，检验信号区分能力。（第3章）
- **过度拟合** — 模型贴合样本噪声，样本外表现恶化。（第3–5章）
- **基本面量化** — 将企业基本面指标系统化，用于筛选和构建组合。（第2章）
- **凯利公式** — 在理想化胜率/赔率假设下推导长期财富增长最优下注比例的框架；估计误差会使直接使用风险过高。（第3章）
- **可持续性** — 因子在不同样本或市场状态中仍具有稳定证据的性质。（第3章）
- **可投资性** — 因子数据在决策时可得且信号能纳入费用、容量和制度约束执行。（第3章）
- **可解释性** — 因子与所假设的收益或风险机制之间有可说明的联系。（第3章）
- **可区分性** — 因子能在标的间区分未来收益或风险的能力。（第3章）
- **量化交易** — 用可检验规则在不确定市场中寻找概率优势，并以系统执行辅助投资决策。（第1章）
- **未来函数** — 使用决策时点之后才可得的信息，导致回测虚高。（第3、4章）
- **另类量化** — 基于事件、微观结构等非传统信号的策略集合。（第2章）
- **资产配置量化** — 依据量化规则在资产类别间分配风险与资金。（第2章）
- **夏普比率** — 超额收益相对于收益波动的尺度；不代表尾部风险、容量或因果有效性。（第3章）
- **趋势跟踪** — 根据价格趋势信号参与上涨或下跌行情，通常容忍多次小损失以等待趋势收益。（第2、4、5章）
- **样本外检验** — 使用未参与模型拟合或调参的数据评估泛化能力。（第3–5章）
- **因子溢价** — 承担某种系统风险或利用市场结构而获得的回报差异，不必然等于无风险超额收益。（第2章）
- **换手率** — 一段时期内组合持仓变更程度的度量，与交易费用和容量相关。（第3章）
